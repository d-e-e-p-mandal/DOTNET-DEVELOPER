# API Testing in ASP.NET Core

---

# What is API Testing?

API Testing is the process of testing Web APIs.

Used to:
- Send requests
- Check responses
- Verify APIs work correctly

---

# Why API Testing Important?

Used to:
- Test APIs before frontend
- Find errors
- Verify response data
- Test authentication
- Debug APIs

---

# API Testing Tools

- Swagger
- Postman
