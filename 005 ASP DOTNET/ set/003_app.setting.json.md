
# The way of using appsettings.json

File: appsettings.json File
```cs
{
  "MySettings": {
    "AppName": "Student Management System",
    "Version": "1.0"
  },
  "ConnectionStrings": {
    "DefaultConnection": "Server=.;Database=StudentDB;Trusted_Connection=True;"
  }
}
```

##### Read appsettings.json in Program.cs

File: ogram.cs
```cs
var builder = WebApplication.CreateBuilder(args);
// Read values from appsettings.json
string appName = builder.Configuration["MySettings:AppName"];
string version = builder.Configuration["MySettings:Version"];
Console.WriteLine(appName);
Console.WriteLine(version);
var app = builder.Build();
app.Run();
```

##### Read Connection String
```cs
string conStr = builder.Configuration
                       .GetConnectionString("DefaultConnection");
Console.WriteLine(conStr);
```

##### Use in Another Class/File

For Cs File: AppSettings.cs : Using Interface `Iconfiguration`
```cs
public class AppSettings
{
    private readonly IConfiguration _configuration;
    public AppSettings(IConfiguration configuration)
    {
        _configuration = configuration;
    }
    public void ShowData()
    {
        string appName = _configuration["MySettings:AppName"];
        Console.WriteLine(appName);
    }
}
```


##### Register Class in Program.cs
```cs
var builder = WebApplication.CreateBuilder(args);
builder.Services.AddTransient<AppSettings>();
var app = builder.Build();
using (var scope = app.Services.CreateScope())
{
    var settings = scope.ServiceProvider.GetRequiredService<AppSettings>();
    settings.ShowData();
}
app.Run();
```


Important Points

- `:` is used for nested JSON values

**Example:**
```cs
builder.Configuration["MySettings:AppName"]
```
**means:**
```json
"MySettings": {
   "AppName": "Student Management System"
}
```

**Common Methods:**

| Method | Purpose |
|---|---|
| `builder.Configuration["Key"]` | Read single value from `appsettings.json` |
| `GetConnectionString()` | Read connection string |
| `GetSection()` | Read complete section |

Example Using GetSection
```cs
var section = builder.Configuration.GetSection("MySettings");
string appName = section["AppName"];
```
