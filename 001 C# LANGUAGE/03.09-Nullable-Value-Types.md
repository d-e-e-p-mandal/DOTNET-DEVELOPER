# 03.09 Nullable Value Types

## Nullable<T> and T?

`Nullable<T>` represents either a value of a non-nullable value type or no value. `int?` is shorthand for `Nullable<int>`.

```csharp
int? score = null;
Console.WriteLine(score.HasValue); // False
score = 10;
Console.WriteLine(score.HasValue); // True
Console.WriteLine(score.Value); // 10
```

The nullable type can represent all values of `T` plus null. It is not a nullable reference annotation.

## HasValue, Value, and GetValueOrDefault

```csharp
int? count = null;
Console.WriteLine(count.GetValueOrDefault()); // 0
Console.WriteLine(count.GetValueOrDefault(5)); // 5
Console.WriteLine(count ?? 7); // 7
// Console.WriteLine(count.Value); // InvalidOperationException.
```

Read `.Value` only after establishing that a value exists. `??` evaluates its fallback only when necessary.

## Lifted operators and comparisons

```csharp
int? first = null;
int? second = 3;
Console.WriteLine((first + second) is null); // True
Console.WriteLine(first < second); // False
Console.WriteLine(first >= second); // False
Console.WriteLine(first == null); // True
Console.WriteLine(first == second); // False
```

Nullable arithmetic commonly propagates null. Relational comparisons with a missing operand return false, so `!(a < b)` is not equivalent to `a >= b` for nullable values.

Nullable Boolean `&` and `|` use three-state rules: `false & null` is false, and `true | null` is true. `bool?` does not support ordinary `&&` and `||` operators.

## Conversions and boxing

```csharp
int? present = 4;
object? boxedPresent = present;
Console.WriteLine(boxedPresent!.GetType() == typeof(int)); // True

int? missing = null;
object? boxedMissing = missing;
Console.WriteLine(boxedMissing is null); // True

int restored = (int)present; // Explicit extraction; throws if missing.
Console.WriteLine(restored); // 4
```

Boxing a non-null nullable value boxes its underlying value, not a separate `Nullable<T>` object. Boxing a missing nullable value produces null.

## Nullable values versus reference annotations

`int?` changes the runtime value type to `Nullable<int>`. `string?` still refers to `System.String` and adds compiler nullability information. An unconstrained generic `T?` requires careful interpretation; it does not always create a nullable value type.

Use null for a meaningful absence, not to hide invalid domain data. Validate a present value separately, such as ensuring a supplied quantity is positive.
