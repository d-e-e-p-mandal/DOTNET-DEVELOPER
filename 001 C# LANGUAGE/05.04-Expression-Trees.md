# 05.04 Expression Trees

## Delegates versus Expression<TDelegate>

A delegate is callable behavior. An expression tree represents supported code as inspectable nodes.

```csharp
using System.Linq.Expressions;

Func<int, int> function = value => value * 2;
Expression<Func<int, int>> tree = value => value * 2;
Console.WriteLine(function(3)); // 6
Console.WriteLine(tree.Body.NodeType); // Multiply
```

The compiler can convert supported expression lambdas into expression trees. It cannot convert an arbitrary statement lambda with a block into a tree automatically.

## Nodes and structure

```csharp
using System.Linq.Expressions;

Expression<Func<int, bool>> tree = value => value > 10;
var comparison = (BinaryExpression)tree.Body;
Console.WriteLine(comparison.NodeType); // GreaterThan
Console.WriteLine(comparison.Left.NodeType); // Parameter
Console.WriteLine(comparison.Right.NodeType); // Constant
```

Trees are immutable. To change behavior, build another tree or use a visitor that returns replacement nodes.

## Building a tree

```csharp
using System.Linq.Expressions;

var value = Expression.Parameter(typeof(int), "value");
var body = Expression.Add(value, Expression.Constant(1));
var tree = Expression.Lambda<Func<int, int>>(body, value);
Console.WriteLine(tree.Compile()(4)); // 5
```

Reuse the same parameter node for references to the same parameter. Matching parameter names alone does not make two different node objects the same parameter.

## Visiting and rewriting

```csharp
using System.Linq.Expressions;

Expression<Func<int, int>> original = value => value + 1;
var changed = (Expression<Func<int, int>>)new ReplaceOne().Visit(original)!;
Console.WriteLine(changed.Compile()(4)); // 6

class ReplaceOne : ExpressionVisitor
{
    protected override Expression VisitConstant(ConstantExpression node)
        => node.Type == typeof(int) && Equals(node.Value, 1)
            ? Expression.Constant(2) : base.VisitConstant(node);
}
```

## Compilation and query translation

`Compile()` creates a callable delegate. Compiling repeatedly adds cost; cache only when the tree and captured-state lifetime make that safe. Interpretation may be available when dynamic compilation is unsuitable.

An `IQueryable` provider may translate a tree into SQL or another query language. A valid expression tree is not necessarily translatable by that provider. Calling `Compile()` changes it into local behavior; it does not improve server translation. Captured variables and provider limitations must be considered separately.
