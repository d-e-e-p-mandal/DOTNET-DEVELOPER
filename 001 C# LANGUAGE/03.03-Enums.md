# 03.03 Enums

## Named constants and underlying types

An enum gives names to integral values. The default underlying type is `int`; another supported integral type can be specified.

```csharp
Status status = Status.Paid;
Console.WriteLine(status); // Paid
Console.WriteLine((byte)status); // 2

enum Status : byte { New = 1, Paid = 2, Shipped = 3 }
```

Enums do not use strings as their underlying storage.

## Explicit values and defaults

```csharp
Console.WriteLine((int)default(Status)); // 0
Console.WriteLine(Enum.IsDefined(default(Status))); // False

enum Status { New = 1, Paid = 2 }
```

An enum's default is zero even when no member names zero. An explicit `Unknown = 0` member often makes the default meaningful. Unspecified subsequent members increment from the preceding value.

## Parsing and formatting

```csharp
if (Enum.TryParse<Status>("paid", ignoreCase: true, out var status)
    && Enum.IsDefined(status))
    Console.WriteLine(status.ToString("G")); // Paid

Console.WriteLine(Status.Paid.ToString("D")); // 2

enum Status { Unknown = 0, New = 1, Paid = 2 }
```

`TryParse` also accepts numeric text that can produce unnamed values. Successful parsing alone does not validate that a named member exists.

## FlagsAttribute and combinations

Use independent bit values for options that can be combined.

```csharp
Access access = Access.Read | Access.Write;
Console.WriteLine(access.HasFlag(Access.Read)); // True
Console.WriteLine((access & Access.Execute) != 0); // False
access &= ~Access.Write; // Clear Write.
Console.WriteLine(access); // Read

[Flags]
enum Access { None = 0, Read = 1, Write = 2, Execute = 4 }
```

`[Flags]` documents the intended model and affects formatting; it does not prevent invalid bit combinations. `HasFlag(None)` is true because every value contains the zero bit mask.

## Undefined values and validation

For an ordinary enum, use `Enum.IsDefined` when only named values are valid. For flags, validate the allowed mask instead, because valid combinations need not be individually named.

```csharp
Access supplied = (Access)9;
Access allowed = Access.Read | Access.Write | Access.Execute;
Console.WriteLine((supplied & ~allowed) == 0); // False: bit 8 is unsupported.

[Flags]
enum Access { None = 0, Read = 1, Write = 2, Execute = 4 }
```

Preserve numeric meanings when an enum is stored in a database or protocol. Renumbering existing members can reinterpret previously saved data.
