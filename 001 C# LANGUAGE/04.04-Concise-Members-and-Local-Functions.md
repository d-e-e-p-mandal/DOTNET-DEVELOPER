# 04.04 Concise Members and Local Functions

## Expression-bodied methods and properties

Use `=>` when a single expression clearly represents the member.

```csharp
var size = new Rectangle(4, 3);
Console.WriteLine(size.Area); // 12
Console.WriteLine(size.Describe()); // 4 x 3

class Rectangle
{
    public int Width { get; }
    public int Height { get; }
    public Rectangle(int width, int height) { Width = width; Height = height; }
    public int Area => Width * Height;
    public string Describe() => $"{Width} x {Height}";
}
```

`int Area => ...;` is a computed getter. `int Area { get; } = ...;` stores an initialized value instead.

## Constructors and accessors

```csharp
var item = new Item("Book");
item.Name = "Pen";
Console.WriteLine(item.Name); // Pen

class Item
{
    private string _name;
    public Item(string name) => _name = name;
    public string Name
    {
        get => _name;
        set => _name = value ?? throw new ArgumentNullException(nameof(value));
    }
}
```

Expression-bodied syntax does not change accessibility, validation requirements, or whether an operation returns a value.

## Local functions and static local functions

```csharp
Console.WriteLine(Total(3, 4)); // 7

int Total(int left, int right)
{
    return Add(left, right);
    static int Add(int a, int b) => a + b;
}
```

A local function is scoped to its enclosing code. It can be called before its textual declaration. `static` prevents captures and requires state to be supplied explicitly.

## Local functions versus lambdas

A local function has a name and supports features such as generic parameters and recursion directly. A lambda is convenient when passing behavior to another API.

Calling a local function directly need not create a delegate. Converting it to a delegate can change allocation and lifetime behavior. Both forms can capture enclosing variables unless static.

## Readability and debugging

Use a block body for multi-step validation, logging, or branches. A shorter expression is not automatically clearer. Keep exceptions and side effects visible, and avoid nesting several conditional expressions into one line merely to use `=>`.
