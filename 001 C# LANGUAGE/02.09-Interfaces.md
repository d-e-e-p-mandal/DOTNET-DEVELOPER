# 02.09 Interfaces

## Declarations and implementation

An interface describes a capability. A class or struct implements the required members.

```csharp
IPrinter printer = new ConsolePrinter();
printer.Print("Invoice"); // Invoice

interface IPrinter
{
    void Print(string text);
}
class ConsolePrinter : IPrinter
{
    public void Print(string text) => Console.WriteLine(text);
}
```

Ordinary implicit implementations must provide compatible public instance members. Interfaces cannot be instantiated directly and do not supply per-object instance fields.

## Multiple interfaces

```csharp
var device = new Device();
device.Start(); // Started
device.Stop();  // Stopped

interface IStartable { void Start(); }
interface IStoppable { void Stop(); }
class Device : IStartable, IStoppable
{
    public void Start() => Console.WriteLine("Started");
    public void Stop() => Console.WriteLine("Stopped");
}
```

One class can implement several interfaces even though it can directly inherit only one class.

## Explicit implementation

Use explicit implementation when interface members have colliding names or should be accessible only through the interface contract.

```csharp
var item = new Document();
((IScreen)item).Show(); // Screen
((IPrint)item).Show();  // Paper
// item.Show(); // Error: neither implementation is a public class member.

interface IScreen { void Show(); }
interface IPrint { void Show(); }
class Document : IScreen, IPrint
{
    void IScreen.Show() => Console.WriteLine("Screen");
    void IPrint.Show() => Console.WriteLine("Paper");
}
```

Do not put an ordinary access modifier on these explicit implementation declarations.

## Interface inheritance

```csharp
IEditable item = new Editor();
item.Read();  // Read
item.Write(); // Write

interface IReadable { void Read(); }
interface IEditable : IReadable { void Write(); }
class Editor : IEditable
{
    public void Read() => Console.WriteLine("Read");
    public void Write() => Console.WriteLine("Write");
}
```

Implementing `IEditable` also requires satisfying its inherited contract. Interface inheritance can combine several parent interfaces.

## Default interface members

An interface can provide a default implementation for supported members.

```csharp
IReporter reporter = new Reporter();
reporter.Report(); // Default report

interface IReporter
{
    void Report() => Console.WriteLine("Default report");
}
class Reporter : IReporter { }
```

The default body is available through the interface; it does not become an ordinary member directly callable on `new Reporter()`. Ambiguous inherited defaults may require an explicit resolution.

## Interface versus abstract class

| Interface | Abstract class |
| --- | --- |
| Describes a capability across unrelated types | Models a shared base relationship |
| Supports multiple interface contracts | Occupies the single class inheritance path |
| No per-instance fields or instance constructors | Can own instance state and constructor logic |
| Can provide supported default members | Can combine implemented and abstract members |

Use small, meaningful interfaces. Adding a required member without a compatible default can break existing implementers. Interface calls on value types may involve boxing, depending on how the value is passed and constrained.
