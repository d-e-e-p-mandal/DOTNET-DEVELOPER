# 01.01 Introduction to C# and .NET

[Syllabus](000-syllabus.md)

## 1. What Is Programming? What Is C#?

**Programming:** writing instructions that a computer executes to perform a task.

**C#** (C sharp): a programming language used to build applications, usually with .NET.

```csharp
int price = 100;                 // Store a price.
int quantity = 2;                // Store a quantity.
Console.WriteLine(price * quantity); // Calculate and print the total.
```

**Output:** `200`

## 2. C# Language versus .NET Platform

| C# | .NET |
|---|---|
| Language used to write instructions | Platform used to build and run applications |
| Provides syntax such as `int`, `if`, and `class` | Provides the runtime, libraries, and development tools |

```csharp
Console.WriteLine("Hello");
```

`"Hello"` is a C# string literal. `Console.WriteLine` is a method from a .NET library.

## 3. SDK, Runtime, Compiler, Libraries, and IDE

| Term | Simple meaning | Example |
|---|---|---|
| SDK | Tools for developing applications | `dotnet build` |
| Runtime | Execution support for an application | Loading code and managing memory |
| Compiler | Translates C# and checks language rules | Roslyn C# compiler |
| Libraries | Reusable types and methods | `Console`, `List<T>`, `File` |
| IDE | Application for editing, building, and debugging | Visual Studio or Rider |

Install the **SDK** to develop applications. A runtime alone does not include the development toolchain.

```bash
dotnet --list-sdks
dotnet --list-runtimes
```

## 4. Source Code → CIL / IL → Native Machine Code

A typical JIT-based application follows this path:

```text
Program.cs
    ↓ C# compiler
Assembly: CIL instructions + metadata
    ↓ .NET runtime and JIT compiler
Native machine instructions for the target CPU
    ↓
CPU executes the instructions
```

**CIL** means Common Intermediate Language; **IL** is its common short name. Metadata describes types and members. IL is not the CPU's native instruction set.

## 5. Binary Digits, Bytes, and Machine Instructions

- **Bit:** one binary digit, `0` or `1`.
- **Byte:** eight bits.
- **Binary value:** `00000101` represents decimal `5` because `4 + 1 = 5`.
- **Machine instruction:** an encoded CPU operation, such as adding values.

```csharp
int number = 0b0101;         // Binary literal: decimal 5.
Console.WriteLine(number);  // Output: 5
```

The bits represent a value here, not an instruction to print it. A C# `int` is 32 bits; writing a short binary literal does not change its type size.

## 6. Compilation, JIT, and AOT Overview

| Term | When it happens | Purpose |
|---|---|---|
| C# compilation | During build | Checks source and normally produces IL + metadata |
| JIT: Just-In-Time | During application execution | Compiles IL methods into native code |
| AOT: Ahead-Of-Time | Before application execution | Compiles code into native instructions in advance |

**Native AOT** publishes a native application for a particular OS and CPU target. Some dynamic features and libraries need compatibility checks.

## 7. Cross-Platform Execution and Platform Limitations

Modern .NET supports Windows, Linux, and macOS on supported architectures. A compatible runtime executes portable managed code on each platform.

```csharp
Console.WriteLine("Hello from .NET!");
```

This example uses a portable API. Other applications may depend on platform-specific features:

- Windows Forms and WPF require Windows.
- Native libraries must match the target OS and CPU.
- Paths, permissions, and available APIs can differ.
- One Native AOT executable does not run on every platform.
