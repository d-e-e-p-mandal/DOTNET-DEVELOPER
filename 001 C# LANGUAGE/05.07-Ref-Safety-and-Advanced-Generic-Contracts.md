# 05.07 Ref Safety and Advanced Generic Contracts

## ref struct and readonly ref struct

A `ref struct` is restricted so references it contains cannot escape into ordinary heap storage. It cannot be boxed or stored as a field of an ordinary class.

```csharp
ReadOnlySpan<int> data = new[] { 1, 2, 3 };
var view = new IntView(data);
Console.WriteLine(view.Length); // 3

readonly ref struct IntView
{
    private readonly ReadOnlySpan<int> _values;
    public IntView(ReadOnlySpan<int> values) => _values = values;
    public int Length => _values.Length;
}
```

`readonly` restricts mutation of the view value; it does not freeze an externally owned backing array.

## scoped parameters and escape analysis

```csharp
Span<int> data = stackalloc int[] { 1, 2 };
PrintFirst(data); // 1

void PrintFirst(scoped ReadOnlySpan<int> values)
    => Console.WriteLine(values[0]);
```

`scoped` limits how a reference or ref-like parameter may escape. The compiler rejects operations that could expose shorter-lived storage beyond a safe context. It is a compile-time lifetime contract, not a request to allocate memory on the stack.

## Ref fields

```csharp
int number = 3;
var alias = new IntAlias(ref number);
alias.Set(8);
Console.WriteLine(number); // 8

ref struct IntAlias
{
    private ref int _value;
    public IntAlias(ref int value) => _value = ref value;
    public void Set(int value) => _value = value;
}
```

A ref field stores an alias to other storage and belongs in a ref struct. Its safe lifetime cannot exceed that of the referenced storage. A default-initialized ref field must not be dereferenced as though it identified valid storage.

## Interfaces and allows ref struct

C# 13 permits ref structs to implement interfaces, but converting a ref struct to an interface value would require forbidden boxing. Use a suitably constrained generic operation instead.

```csharp
Console.WriteLine(Read(new Number(7))); // 7

static int Read<T>(T item) where T : IValue, allows ref struct => item.GetValue();
interface IValue { int GetValue(); }
ref struct Number
    : IValue
{
    private int _value;
    public Number(int value) => _value = value;
    public int GetValue() => _value;
}
```

`allows ref struct` is an anti-constraint: the implementation must remain safe even when `T` is ref-like. It does not require every type argument to be a ref struct.

## Static abstract members and generic math

```csharp
using System.Numerics;

Console.WriteLine(Sum(new[] { 1, 2, 3 })); // 6
Console.WriteLine(Sum(new[] { 1.5M, 2.5M })); // 4.0

T Sum<T>(T[] values) where T : INumber<T>
{
    T sum = T.Zero;
    foreach (T value in values) sum += value;
    return sum;
}
```

Interfaces such as `INumber<T>` expose static abstract numeric operations to constrained generic code. The constraint supplies the operations, while the concrete numeric type still determines overflow, precision, and supported values.
