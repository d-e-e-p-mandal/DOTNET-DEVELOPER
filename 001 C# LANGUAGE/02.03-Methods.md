# 02.03 Methods

## Declaration, signature, invocation, and return type

A method groups a named operation. Its declaration specifies accessibility, return type, name, parameters, and body.

```csharp
Console.WriteLine(Calculator.Add(3, 4)); // 7

static class Calculator
{
    public static int Add(int left, int right)
    {
        return left + right;
    }
}
```

`void` means no result value. A method's return type alone cannot distinguish overloads; parameter names and default values also cannot distinguish them.

## Instance versus static methods

An instance method operates through an object and can use `this`. A static method has no current instance.

```csharp
var counter = new Counter();
counter.Increment();
Console.WriteLine(counter.Value); // 1
Console.WriteLine(Counter.Description()); // Counts changes

class Counter
{
    public int Value { get; private set; }
    public void Increment() => Value++;
    public static string Description() => "Counts changes";
}
```

## Positional, named, and optional arguments

```csharp
Print("Deep");                 // Deep: 1
Print("Mira", 2);              // Mira: 2
Print(copies: 3, name: "Sam");  // Sam: 3

void Print(string name, int copies = 1)
    => Console.WriteLine($"{name}: {copies}");
```

Optional parameters follow required parameters. Their defaults are normally embedded in compiled callers, so changing a library's default does not automatically update already compiled callers.

Named arguments identify parameters, not a different overload. Renaming a public parameter can break callers using its name.

## params parameters

`params` accepts a variable number of arguments. The traditional form uses a final array parameter.

```csharp
Console.WriteLine(Total(1, 2, 3)); // 6
Console.WriteLine(Total()); // 0
Console.WriteLine(Total(new[] { 4, 5 })); // 9

int Total(params int[] values)
{
    int total = 0;
    foreach (int value in values) total += value;
    return total;
}
```

Only one `params` parameter is allowed, and it must be last. C# 13 adds supported collection forms, such as `params ReadOnlySpan<int>`, with their own overload-resolution and allocation considerations.

## Overloading and overload resolution

```csharp
Console.WriteLine(Formatter.Format(3)); // Integer
Console.WriteLine(Formatter.Format(3.5)); // Double

static class Formatter
{
    public static string Format(int value) => "Integer";
    public static string Format(double value) => "Double";
}
```

The compiler chooses an applicable overload using argument types and conversions. Exact matches usually beat less direct conversions. Overloads with unrelated reference types can make a `null` argument ambiguous; use an explicit cast when necessary.

## Recursion and base cases

```csharp
Console.WriteLine(Factorial(5)); // 120

long Factorial(int n)
{
    if (n < 0) throw new ArgumentOutOfRangeException(nameof(n));
    if (n <= 1) return 1; // Base case.
    return checked(n * Factorial(n - 1));
}
```

Each recursive call must move toward termination. Deep recursion can exhaust the stack; tail-call optimization is not a general C# guarantee.

## Extension methods

A traditional extension method is static, inside a non-generic static class, with `this` on its first parameter.

```csharp
Console.WriteLine("C#".InBrackets()); // [C#]
Console.WriteLine(TextExtensions.InBrackets("C#")); // Same static call.

static class TextExtensions
{
    public static string InBrackets(this string value) => $"[{value}]";
}
```

Extension syntax does not modify the original type or grant access to its private members. Applicable instance members take precedence over extension methods.
