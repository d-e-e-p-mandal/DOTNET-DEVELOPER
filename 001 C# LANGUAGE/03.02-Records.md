# 03.02 Records

## Record classes and record structs

Records generate value-oriented equality and useful member implementations. `record` means a reference-type record class; `record struct` is a value type.

```csharp
var first = new Person("Deep", 20);
var second = new Person("Deep", 20);
Console.WriteLine(first == second); // True
Console.WriteLine(ReferenceEquals(first, second)); // False
Console.WriteLine(first); // Person { Name = Deep, Age = 20 }

record Person(string Name, int Age);
```

## Positional and nonpositional records

Positional parameters generate properties and a deconstruction method. A nonpositional record declares its properties explicitly.

```csharp
var item = new Product { Name = "Book", Price = 20M };
Console.WriteLine(item.Name); // Book

record Product
{
    public required string Name { get; init; }
    public decimal Price { get; init; }
}
```

A positional record class normally has init-only generated properties. A plain positional `record struct` normally has writable generated properties; use `readonly record struct` for a readonly value design.

## Generated members and equality

Generated equality considers the record's stored state using the relevant equality comparers. A list-valued member is normally compared by the list's reference identity, not by recursively comparing list elements.

Equality and hash codes must remain consistent. Mutable state participating in equality is a poor key for hash collections.

## with expressions and shallow copying

```csharp
var original = new Order("New", new List<string> { "Book" });
var changed = original with { Status = "Paid" };
changed.Items.Add("Pen");
Console.WriteLine(original.Status); // New
Console.WriteLine(changed.Status); // Paid
Console.WriteLine(original.Items.Count); // 2: shared list.

record Order(string Status, List<string> Items);
```

`with` produces a copy with selected assignments; it is not a deep clone. Choose immutable member types or explicitly copy nested state when independent ownership is required.

## Deconstruction

```csharp
var point = new Point(4, 5);
var (x, y) = point;
Console.WriteLine($"{x}, {y}"); // 4, 5

readonly record struct Point(int X, int Y);
```

Deconstruction assigns individual components to variables; it does not turn every record into a tuple.

## Inheritance and immutability limits

Record classes can derive from other record classes; ordinary class inheritance and record inheritance cannot be mixed arbitrarily. Record structs do not support user-defined inheritance.

`init` and `with` make non-destructive updates convenient, but they do not automatically make a complete object graph immutable. Validate domain rules through suitable constructors, factories, or property logic.
