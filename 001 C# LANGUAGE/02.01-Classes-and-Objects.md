# 02.01 Classes and Objects

## Class declarations and object creation

A class defines a reference type. An object is an instance of that type, created with `new`.

```csharp
var first = new Product();
first.Name = "Book";
first.Price = 20M;
Console.WriteLine(first.Name); // Book

class Product
{
    public string Name { get; set; } = "";
    public decimal Price { get; set; }
}
```

Declaring `Product? item = null;` creates a reference variable, not a `Product` object. A class declaration itself does not run its methods.

## State, behavior, and identity

State is stored data; behavior is provided by methods. Identity distinguishes one object from another even when their data matches.

```csharp
var first = new Counter();
var second = new Counter();
first.Increment();
Console.WriteLine(first.Value); // 1
Console.WriteLine(second.Value); // 0
Console.WriteLine(ReferenceEquals(first, second)); // False

class Counter
{
    public int Value { get; private set; }
    public void Increment() => Value++;
}
```

Each object owns its instance state. `private set` lets callers read a property while restricting writes to the class.

## Instance and static members

Instance members need an object. Static members belong to the type rather than to an individual instance.

```csharp
var a = new Ticket();
var b = new Ticket();
Console.WriteLine(a.Number); // 1
Console.WriteLine(b.Number); // 2
Console.WriteLine(Ticket.Created); // 2

class Ticket
{
    public static int Created { get; private set; }
    public int Number { get; }
    public Ticket() => Number = ++Created;
}
```

This simple counter is not safe for concurrent creation. Static state is shared, so thread safety and test isolation must be considered separately.

## References and object initializers

```csharp
var original = new Product { Name = "Book", Price = 20M };
Product alias = original;
alias.Price = 25M;
Console.WriteLine(original.Price); // 25
Console.WriteLine(ReferenceEquals(original, alias)); // True

class Product
{
    public string Name { get; set; } = "";
    public decimal Price { get; set; }
}
```

An object initializer runs after the selected constructor. Assignment copies the reference; it does not clone the object. Reassigning `alias` to another object would not change which object `original` references.
