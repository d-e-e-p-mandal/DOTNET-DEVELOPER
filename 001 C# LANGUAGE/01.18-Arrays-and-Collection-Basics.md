# 01.18 Arrays and Collection Basics

## One-dimensional arrays

An array stores a fixed number of elements of one element type. Indices start at zero.

```csharp
int[] scores = { 10, 20, 30 };
scores[1] = 25;
Console.WriteLine(scores.Length); // 3
Console.WriteLine(scores[1]); // 25

int[] emptyValues = new int[2];
Console.WriteLine(emptyValues[0]); // 0: elements receive default values.
```

The array length cannot change. `Array.Resize(ref array, length)` may allocate a replacement array and update that variable; it does not make the original array grow in place.

## Multidimensional arrays

A rectangular array has a fixed size for each dimension.

```csharp
int[,] grid = { { 1, 2, 3 }, { 4, 5, 6 } };
Console.WriteLine(grid.Rank); // 2 dimensions.
Console.WriteLine(grid.Length); // 6 total elements.
Console.WriteLine(grid.GetLength(0)); // 2 rows.
Console.WriteLine(grid.GetLength(1)); // 3 columns.
Console.WriteLine(grid[1, 2]); // 6
```

## Jagged arrays

A jagged array contains arrays. Its inner arrays may have different lengths.

```csharp
int[][] rows = { new[] { 1, 2 }, new[] { 3 } };
Console.WriteLine(rows.Length); // 2 inner-array slots.
Console.WriteLine(rows[0].Length); // 2
Console.WriteLine(rows[1][0]); // 3
```

`new int[2][]` creates two initially null inner-array slots; each inner array must be supplied before accessing its elements.

## Bounds and iteration

```csharp
int[] values = { 4, 8 };
for (int i = 0; i < values.Length; i++)
    Console.WriteLine($"{i}: {values[i]}"); // 0: 4; 1: 8

foreach (int value in values)
    Console.WriteLine(value); // 4; 8
```

Valid indices satisfy `index >= 0 && index < values.Length`. Invalid access throws `IndexOutOfRangeException` for arrays.

## List<T>

A list is an ordered, growable sequence. `Count` is the number of elements; `Capacity` is the currently reserved backing capacity.

```csharp
var names = new List<string> { "Deep", "Mira" };
names.Add("Sam");
names.Insert(1, "Asha");
names[0] = "Dev";
Console.WriteLine(names.Contains("Mira")); // True
Console.WriteLine(names.IndexOf("Sam")); // 3
names.Remove("Mira"); // Remove first equal match; returns success/failure.
names.RemoveAt(0); // Remove by position.
Console.WriteLine(string.Join(", ", names)); // Asha, Sam
```

Indexed access is fast. Searching with `Contains` usually scans elements; inserting or removing in the middle shifts later elements.

## Dictionary<TKey, TValue>

A dictionary maps unique keys to values. Use key lookup rather than searching by position.

```csharp
var stock = new Dictionary<string, int>(StringComparer.OrdinalIgnoreCase);
stock.Add("Book", 5);
stock["Pen"] = 10; // Add or replace.
stock["book"] = 7; // Replaces Book with this comparer.
if (stock.TryGetValue("BOOK", out int quantity))
    Console.WriteLine(quantity); // 7
Console.WriteLine(stock.TryAdd("Book", 99)); // False: key already exists.
stock.Remove("Pen");
Console.WriteLine(stock.Count); // 1
```

`Add` rejects a duplicate key; the indexer replaces an existing value. Reading an absent key through the indexer throws. Do not depend on dictionary enumeration as a sorting contract.

## HashSet<T>

A set stores unique values according to its equality comparer.

```csharp
var tags = new HashSet<string>(StringComparer.OrdinalIgnoreCase);
Console.WriteLine(tags.Add("C#")); // True
Console.WriteLine(tags.Add("c#")); // False
Console.WriteLine(tags.Contains("C#")); // True
Console.WriteLine(tags.Count); // 1
```

A set has no indexer and does not promise sorted order. Avoid changing fields used by equality or hashing while an object is stored as a set element or dictionary key.

## Queue<T> and Stack<T>

A queue removes the oldest added item; a stack removes the most recently added item.

```csharp
var queue = new Queue<string>();
queue.Enqueue("First");
queue.Enqueue("Second");
Console.WriteLine(queue.Peek()); // First: inspect without removal.
Console.WriteLine(queue.Dequeue()); // First

var stack = new Stack<string>();
stack.Push("First");
stack.Push("Second");
Console.WriteLine(stack.Pop()); // Second
Console.WriteLine(stack.TryPop(out string? last)); // True
Console.WriteLine(last); // First
```

Use `TryDequeue`, `TryPop`, or a count check when an empty collection is possible. Ordinary generic collections do not automatically make concurrent writes safe.

## Choosing a collection

| Requirement | Collection |
| --- | --- |
| Fixed-length indexed data | `T[]` |
| Growable ordered data | `List<T>` |
| Values identified by unique keys | `Dictionary<TKey, TValue>` |
| Uniqueness and membership checks | `HashSet<T>` |
| First-in, first-out processing | `Queue<T>` |
| Last-in, first-out processing | `Stack<T>` |

Collection copies are normally shallow: copying a list of objects copies their references, not independent clones of each object.
