# 03.05 Delegates

## Declarations and signatures

A delegate is a typed reference to a compatible method. Its signature specifies the parameter and return types callers can use.

```csharp
Calculation operation = Add;
Console.WriteLine(operation(2, 3)); // 5

int Add(int a, int b) => a + b;
delegate int Calculation(int left, int right);
```

Parameter names do not need to match. The method's signature must be compatible with the delegate type.

## Method groups and conversion

Writing a method name without invoking it creates a method group that can be converted to a compatible delegate.

```csharp
Action<string> print = Console.WriteLine; // Select a compatible overload.
print("Hello"); // Hello
```

`Console.WriteLine("Hello")` invokes immediately; assigning `Console.WriteLine` stores behavior to invoke later. An instance-method delegate also retains its target object.

## Single-cast and multicast delegates

```csharp
Action notify = () => Console.WriteLine("First");
Action second = () => Console.WriteLine("Second");
notify += second;
notify(); // First, then Second.
notify -= second;
notify(); // First.
```

Combining delegates produces an invocation list. Removing a delegate removes a matching occurrence; retain the original delegate when you need to unsubscribe a lambda reliably.

## Func, Action, and Predicate

```csharp
Func<int, int> square = n => n * n; // Last type argument is the result.
Action<string> print = text => Console.WriteLine(text); // No return value.
Predicate<int> positive = n => n > 0; // bool result.
Console.WriteLine(square(4)); // 16
print("Ready"); // Ready
Console.WriteLine(positive(-1)); // False
```

`Func<int, bool>` and `Predicate<int>` describe similar signatures but are distinct delegate types; they are not freely interchangeable variables.

## Anonymous methods

The older `delegate` syntax can provide an unnamed body. A lambda is usually more concise.

```csharp
Func<int, int> oldStyle = delegate(int value) { return value * 2; };
Func<int, int> modern = value => value * 2;
Console.WriteLine(oldStyle(3)); // 6
Console.WriteLine(modern(3)); // 6
```

## Invocation order, return values, and exceptions

```csharp
Func<int> values = () => 1;
values += () => 2;
Console.WriteLine(values()); // 2: result from the last invoked method.
```

Multicast invocation runs handlers in invocation-list order. An uncaught exception stops that invocation before later handlers run. A nullable delegate can be called with `handler?.Invoke(...)` when no subscription is valid. Do not use a multicast return value when results from every handler must be collected; enumerate and invoke deliberately instead.
