# 05.01 Iterators and Custom Enumeration

## IEnumerable<T> and IEnumerator<T>

An enumerable supplies an enumerator. The enumerator advances with `MoveNext()` and exposes its current value through `Current`.

```csharp
IEnumerable<int> values = new[] { 2, 4 };
using IEnumerator<int> iterator = values.GetEnumerator();
while (iterator.MoveNext())
    Console.WriteLine(iterator.Current); // 2, 4
```

Do not read `Current` before the first successful move or after enumeration ends. Generic enumerators are disposable; `foreach` arranges appropriate cleanup automatically.

## foreach pattern

`foreach` can use a supported `GetEnumerator`/`MoveNext`/`Current` pattern without the source implementing `IEnumerable<T>` explicitly.

```csharp
foreach (int value in new CountToThree())
    Console.WriteLine(value); // 1, 2, 3

readonly struct CountToThree
{
    public Enumerator GetEnumerator() => new();
    public struct Enumerator
    {
        private int _value;
        public int Current => _value;
        public bool MoveNext() => ++_value <= 3;
    }
}
```

Implement the standard interfaces when interoperability with LINQ and general collection APIs is required.

## yield return and yield break

```csharp
foreach (int value in UpTo(3))
    Console.WriteLine(value); // 1, 2, 3

IEnumerable<int> UpTo(int maximum)
{
    if (maximum <= 0) yield break;
    for (int value = 1; value <= maximum; value++)
        yield return value;
}
```

`yield return` suspends the iterator until the next move. `yield break` ends enumeration. Do not use an ordinary value-returning `return` to produce elements.

## Deferred execution and state

Calling an iterator method usually creates its enumerable state; the body executes as enumeration advances. Exceptions and side effects inside that body are therefore delayed.

```csharp
IEnumerable<int> values = GetValues();
Console.WriteLine("Created");
foreach (int value in values) Console.WriteLine(value);

IEnumerable<int> GetValues()
{
    Console.WriteLine("Started");
    yield return 10;
}
```

Output: `Created`, `Started`, `10`. Validate before returning a separate iterator helper when invalid arguments must fail immediately at method call time.

## Cleanup and repeated enumeration

A `using` or `finally` active inside an iterator is cleaned up when its enumerator completes or is disposed. An early `foreach` break disposes the enumerator when required. Abandoning an undisposed manually obtained enumerator can delay resource release.

Re-enumerating a reusable iterator executes its work again. An iterator is not automatically a cached list or a guarantee that its underlying data source can be repeated safely.
