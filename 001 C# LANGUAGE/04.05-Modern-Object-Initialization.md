# 04.05 Modern Object Initialization

## init-only properties

An `init` accessor allows assignment during initialization but prevents ordinary later assignment.

```csharp
var item = new Item { Name = "Book" };
Console.WriteLine(item.Name); // Book
// item.Name = "Pen"; // Error: initialization has ended.

class Item
{
    public string Name { get; init; } = "";
}
```

`init` does not make a nested list or referenced object immutable. It is available from C# 9.

## required members

`required` makes callers initialize a field or property unless the selected constructor declares that it satisfies the requirement.

```csharp
var user = new User { Name = "Deep" };
Console.WriteLine(user.Name); // Deep
// var missing = new User(); // Error: required member was not initialized.

class User
{
    public required string Name { get; init; }
}
```

`required` is available from C# 11. It requires assignment, not a nonempty or valid value. Assigning null to a required non-nullable reference property can satisfy the assignment requirement while still producing a nullable warning.

## SetsRequiredMembers

This attribute tells the compiler that a constructor handles all required members. The compiler trusts the declaration rather than proving those assignments.

```csharp
using System.Diagnostics.CodeAnalysis;

Console.WriteLine(new User("Deep").Name); // Deep

class User
{
    public required string Name { get; init; }
    [SetsRequiredMembers]
    public User(string name)
    {
        ArgumentException.ThrowIfNullOrWhiteSpace(name);
        Name = name;
    }
}
```

Only apply the attribute when the constructor actually honors the contract, including inherited required members.

## Primary constructors

C# 12 allows constructor parameters on ordinary class and struct declarations.

```csharp
var price = new Price(20M);
Console.WriteLine(price.Amount); // 20

class Price(decimal amount)
{
    public decimal Amount { get; } = amount >= 0
        ? amount : throw new ArgumentOutOfRangeException(nameof(amount));
}
```

For an ordinary class, `amount` does not automatically become a public property. Positional records differ because their parameters generate properties. Additional constructors must delegate appropriately to the primary constructor.

## Target-typed new

```csharp
List<string> names = new() { "Deep", "Mira" };
Console.WriteLine(names.Count); // 2
```

The target supplies the type, so it can be omitted after `new`. `var names = new();` has no target type and is invalid.

## Initialization versus runtime validation

`init`, `required`, and nullable annotations describe compiler-enforced usage contracts. They do not replace validation for external input, deserialization, reflection, or invalid domain values. Validate invariants in the construction path and decide whether callers may override constructor-initialized values through an initializer.
