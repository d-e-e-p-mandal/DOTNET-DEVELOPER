# 01.06 Built-In Data Types

A **data type** determines which values a variable can hold and which operations it supports.

## 1. Signed Integers: sbyte, short, int, long

Signed integers store whole numbers, including negatives. **8 bits = 1 byte.**

| Type | Bits | Range | .NET type |
|---|---:|---|---|
| `sbyte` | 8 | −128 to 127 | `System.SByte` |
| `short` | 16 | −32,768 to 32,767 | `System.Int16` |
| `int` | 32 | −2,147,483,648 to 2,147,483,647 | `System.Int32` |
| `long` | 64 | −9,223,372,036,854,775,808 to 9,223,372,036,854,775,807 | `System.Int64` |

```csharp
sbyte temperature = -10;
short altitude = 3200;
int quantity = 150_000;
long population = 8_000_000_000L;

Console.WriteLine(temperature); // -10
Console.WriteLine(5 / 2);       // 2: integer division truncates toward zero.
```

Use `int` for ordinary whole-number calculations; use `long` when a larger range is needed. `L` selects a long integer literal here; `_` improves readability.

## 2. Unsigned Integers: byte, ushort, uint, ulong

Unsigned integers store zero and positive whole numbers.

| Type | Bits | Range | .NET type |
|---|---:|---|---|
| `byte` | 8 | 0 to 255 | `System.Byte` |
| `ushort` | 16 | 0 to 65,535 | `System.UInt16` |
| `uint` | 32 | 0 to 4,294,967,295 | `System.UInt32` |
| `ulong` | 64 | 0 to 18,446,744,073,709,551,615 | `System.UInt64` |

```csharp
byte red = 255;
ushort port = 65000;
uint counter = 4_000_000_000U;
ulong largeCount = 18_000_000_000_000_000_000UL;

Console.WriteLine(red); // 255
// byte invalid = -1;  // Compile error: outside byte's range.
```

`U` requests an unsigned integer literal; `UL` specifies `ulong`. `byte` is common for binary data. Use other unsigned types when the API or data format needs them.

Arithmetic on `byte`, `sbyte`, `short`, and `ushort` usually promotes operands to `int`:

```csharp
byte first = 200;
byte second = 100;
int total = first + second;
Console.WriteLine(total); // 300
```

## 3. Native-Sized Integers: nint and nuint

Their size follows the **process architecture**, not simply the installed operating system.

- 32-bit process: `nint` has `int`'s range; `nuint` has `uint`'s range.
- 64-bit process: `nint` has `long`'s range; `nuint` has `ulong`'s range.
- In modern C#, their .NET aliases are `System.IntPtr` and `System.UIntPtr`.

```csharp
nint offset = -10;
nuint length = 100;

Console.WriteLine(offset);      // -10
Console.WriteLine(IntPtr.Size); // 8 in a 64-bit process; 4 in a 32-bit process.
Console.WriteLine(nint.MaxValue); // Maximum for this process architecture.
```

Use them for native interoperability and pointer-sized calculations. Use fixed-size integers when a stored value or network format requires a fixed width.

## 4. Floating-Point Types: float and double

These types represent fractional numbers using **binary floating-point**. Many decimal fractions are approximate.

| Type | Bits | Approximate significant digits | Largest finite magnitude |
|---|---:|---:|---:|
| `float` | 32 | 6–9 | 3.4 × 10³⁸ |
| `double` | 64 | 15–17 | 1.7 × 10³⁰⁸ |

Both also represent zero, negative values, very small fractions, infinity, and NaN. Smallest positive subnormal values are approximately 1.4 × 10⁻⁴⁵ and 4.9 × 10⁻³²⁴ respectively.

```csharp
float speed = 12.5f;      // f selects float.
double distance = 12.5;  // Fractional literals default to double.
double million = 1e6;    // Scientific notation: 1 × 10^6.

Console.WriteLine(speed == distance); // True for this exactly represented value.
Console.WriteLine(million);           // 1000000
```

`double` is the usual choice for general approximate calculations. `float` uses less storage per value and is common in graphics.

## 5. Decimal Arithmetic: decimal

`decimal` is a **128-bit value type** with about **28–29 significant decimal digits**. Its maximum magnitude is approximately **7.9228 × 10²⁸**; its smallest positive value is **10⁻²⁸**.

```csharp
decimal price = 19.99m;
decimal total = price * 3;

Console.WriteLine(total == 59.97m); // True
Console.WriteLine(0.1m + 0.2m == 0.3m); // True
```

Use `m` for decimal literals. Prefer decimal arithmetic for money and quantities requiring decimal rounding rules. It represents values such as `0.1m` exactly, but repeating fractions such as one-third still require rounding.

```csharp
decimal amount = 2.345m;
decimal rounded = Math.Round(amount, 2, MidpointRounding.AwayFromZero);
Console.WriteLine(rounded == 2.35m); // True
```

Choose the rounding rule explicitly when required. Mixing `decimal` with `float` or `double` in arithmetic requires an explicit conversion; converting an already approximate result does not recover lost precision.

## 6. Boolean and Character Types: bool and char

### bool — true or false

```csharp
bool isActive = true;
bool isAdult = 20 >= 18;
Console.WriteLine(isActive && isAdult); // True

// bool enabled = 1; // Invalid: C# does not convert integers to bool implicitly.
```

`sizeof(bool)` is 1 byte; actual field layout or native marshaling may differ. Use Boolean expressions for conditions.

### char — one UTF-16 code unit

`char` is 16 bits, ranging from `\u0000` to `\uFFFF`. Use single quotes.

```csharp
char grade = 'A';
char unicodeA = '\u0041';
char newline = '\n';

Console.WriteLine(grade == unicodeA); // True
Console.WriteLine("😀".Length);       // 2 UTF-16 code units.
```

One `char` does not always represent one complete visible character. `'A'` is a `char`; `"A"` is a `string`.

## 7. Reference Types: string and object

### string — immutable text

```csharp
string name = "Deep";
Console.WriteLine(name.Length); // 4

name += " Mandal";
Console.WriteLine(name); // Deep Mandal
```

Concatenation creates a new string; it does not modify the original string object. `Length` counts UTF-16 code units. A string's storage depends on its length, not a fixed size for all strings.

### object — an object reference

```csharp
object value = 42;        // Boxes the int as an object.
int number = (int)value;  // Unboxes it back to int.
Console.WriteLine(number); // 42

value = "Deep";           // Now references a string.
Console.WriteLine(value); // Deep
```

The variable's declared type remains `object`. Boxing wraps a value type for use as an object; casting back must match the boxed type.

## 8. Type Aliases: int versus System.Int32

A built-in keyword and its .NET type name identify the **same type**.

```csharp
int first = 10;
System.Int32 second = 20;

Console.WriteLine(first + second);            // 30
Console.WriteLine(typeof(int) == typeof(System.Int32)); // True
```

Integer aliases appear in the tables above. Other mappings:

| C# keyword | .NET type |
|---|---|
| `float` | `System.Single` |
| `double` | `System.Double` |
| `decimal` | `System.Decimal` |
| `bool` | `System.Boolean` |
| `char` | `System.Char` |
| `string` | `System.String` |
| `object` | `System.Object` |

Use C# keywords consistently in ordinary C# code. Choosing `int` instead of `System.Int32` does not change storage or performance.

## 9. Range, Precision, Overflow, Infinity, and NaN

### Range versus precision

**Range** describes the smallest and largest representable values. **Precision** describes how finely values can be represented; significant digits are not the same as decimal places.

```csharp
Console.WriteLine(int.MinValue); // -2147483648
Console.WriteLine(int.MaxValue); // 2147483647

double sum = 0.1 + 0.2;
Console.WriteLine(sum == 0.3);                 // False
Console.WriteLine(Math.Abs(sum - 0.3) < 1e-12); // True
```

The tolerance `1e-12` is for this example; choose a tolerance suitable for the scale and calculation. `double.Epsilon` is the smallest positive subnormal value, not a general comparison tolerance.

### Integer overflow — checked versus unchecked

```csharp
int largest = int.MaxValue;
Console.WriteLine(unchecked(largest + 1)); // -2147483648: wraps.

try
{
    Console.WriteLine(checked(largest + 1));
}
catch (OverflowException)
{
    Console.WriteLine("Integer overflow");
}
```

Constant overflow normally causes a compile-time error. Runtime integer overflow checking also depends on compiler settings; explicit `checked` and `unchecked` make the intended behavior clear for the expressions above.

`decimal` arithmetic overflow throws even inside `unchecked`. Integer and decimal division by zero throw `DivideByZeroException`.

### Infinity and NaN — float and double

```csharp
double zero = 0.0;
double infinity = 1.0 / zero; // Positive infinity.
double invalid = zero / zero; // NaN: Not a Number.
double largest = double.MaxValue;

Console.WriteLine(double.IsPositiveInfinity(infinity)); // True
Console.WriteLine(double.IsNaN(invalid));               // True
Console.WriteLine(double.IsInfinity(largest * 2));      // True
Console.WriteLine(invalid == double.NaN);               // False
```

Use `IsNaN` to detect NaN; `==` does not detect it. `float` has corresponding methods. Floating-point overflow is not turned into an exception by `checked`. `decimal` has neither infinity nor NaN values.
