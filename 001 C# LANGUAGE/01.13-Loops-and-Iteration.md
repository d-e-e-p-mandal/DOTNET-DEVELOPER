# 01.13 Loops and Iteration

## for loops

Use `for` when an index or counter controls repetition.

```csharp
for (int i = 0; i < 3; i++)
{
    Console.WriteLine(i); // 0, 1, 2 on separate lines.
}
```

Order: initialization once → condition → body → iterator → condition again. A false condition prevents the next body execution.

```csharp
for (int i = 5; i >= 1; i -= 2)
    Console.WriteLine(i); // 5, 3, 1
```

The counter declared in the initializer is unavailable after the loop. Initialization, condition, and iterator are individually optional; `for (;;)` has no condition that terminates it.

## while loops

`while` checks before each iteration. Its body can execute zero times.

```csharp
int remaining = 3;
while (remaining > 0)
{
    Console.WriteLine(remaining); // 3, 2, 1
    remaining--;
}
```

Use it when repetition depends on changing state rather than a known count.

## do–while loops

`do–while` checks after the body, so the body executes at least once. The final semicolon is required.

```csharp
int value = 0;
do
{
    Console.WriteLine(value); // 0
    value--;
} while (value > 0);
```

## foreach loops

`foreach` visits elements exposed by an enumerable source. It does not require an index.

```csharp
string[] names = { "Deep", "Mira" };
foreach (string name in names)
{
    Console.WriteLine(name); // Deep, Mira
}
```

- An ordinary iteration variable cannot be reassigned.
- A referenced object's writable members may still be changed.
- Enumerator cleanup is performed when required, including when leaving early.
- Modifying a `List<T>` while enumerating it normally invalidates its enumerator.

```csharp
var numbers = new List<int> { 1, 2, 3, 4 };
numbers.RemoveAll(n => n % 2 == 0); // Remove without mutating during foreach.
Console.WriteLine(string.Join(", ", numbers)); // 1, 3
```

To update array elements, use an index:

```csharp
int[] values = { 2, 4 };
for (int i = 0; i < values.Length; i++)
    values[i] *= 10;
Console.WriteLine(string.Join(", ", values)); // 20, 40
```

## Nested loops

The inner loop completes for each outer iteration.

```csharp
for (int row = 1; row <= 2; row++)
{
    for (int column = 1; column <= 3; column++)
        Console.Write($"{row},{column} ");
    Console.WriteLine();
}
```

Output:

```text
1,1 1,2 1,3
2,1 2,2 2,3
```

For independent fixed bounds, total body executions equal rows × columns. Doubling both dimensions makes four times as many iterations.

## Infinite loops and termination

A loop needs either a condition that eventually becomes false or an explicit exit path.

```csharp
int attempt = 0;
while (true)
{
    attempt++;
    Console.WriteLine(attempt); // 1, 2, 3
    if (attempt == 3)
        break;
}
```

- Incrementing away from the limit may prevent termination.
- Integer overflow can break assumptions about a growing counter.
- A `continue` before a necessary state update can prevent progress.
- Waiting for external work should use appropriate asynchronous waiting or blocking primitives, not an empty CPU-spinning loop.

## Off-by-one errors

An array of length `n` has valid indices `0` through `n - 1`.

```csharp
int[] values = { 10, 20, 30 };
for (int i = 0; i < values.Length; i++) // Use <, not <=.
    Console.WriteLine(values[i]);
```

Check empty, one-element, and full-length cases. Do not read index zero before verifying that the array is nonempty.

## Choosing a loop

| Need | Usual choice |
| --- | --- |
| Index-based updates or counted repetition | `for` |
| Read each element | `foreach` |
| Check state before doing work | `while` |
| Perform work once before checking | `do–while` |

For removal by index from a list, walking backward avoids skipping shifted elements:

```csharp
var values = new List<int> { 1, 2, 3, 4 };
for (int i = values.Count - 1; i >= 0; i--)
    if (values[i] % 2 == 0)
        values.RemoveAt(i);
Console.WriteLine(string.Join(", ", values)); // 1, 3
```
