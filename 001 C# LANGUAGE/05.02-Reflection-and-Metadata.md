# 05.02 Reflection and Metadata

## Type, Assembly, and member information

Reflection inspects runtime type metadata. `typeof(T)` obtains a known type; `value.GetType()` obtains an object's actual runtime type.

```csharp
Type type = typeof(Customer);
Console.WriteLine(type.Name); // Customer
Console.WriteLine(type.Assembly == typeof(Customer).Assembly); // True

class Customer { }
```

An assembly contains types and metadata. Loading an assembly is different from merely reading source text or a namespace name.

## Inspecting constructors, methods, fields, and properties

```csharp
using System.Reflection;

Type type = typeof(Customer);
PropertyInfo? property = type.GetProperty(nameof(Customer.Name));
MethodInfo? method = type.GetMethod(nameof(Customer.Greet));
Console.WriteLine(property!.PropertyType == typeof(string)); // True
Console.WriteLine(method!.ReturnType == typeof(string)); // True

class Customer
{
    public string Name { get; set; } = "Guest";
    public string Greet() => $"Hello, {Name}";
}
```

Use matching parameter types when a method name is overloaded. Lookup can return null or throw for ambiguity; production code should handle that explicitly rather than blindly applying `!`.

## Creating and invoking

```csharp
var instance = Activator.CreateInstance<Customer>();
typeof(Customer).GetProperty(nameof(Customer.Name))!.SetValue(instance, "Deep");
object? result = typeof(Customer).GetMethod(nameof(Customer.Greet))!.Invoke(instance, null);
Console.WriteLine(result); // Hello, Deep

class Customer
{
    public string Name { get; set; } = "Guest";
    public string Greet() => $"Hello, {Name}";
}
```

Reflection still requires valid constructors, targets, and compatible arguments. `MethodInfo.Invoke` commonly wraps exceptions from the invoked method in `TargetInvocationException`.

## BindingFlags and discovery

```csharp
using System.Reflection;

FieldInfo? field = typeof(Vault).GetField("_code",
    BindingFlags.Instance | BindingFlags.NonPublic);
Console.WriteLine(field is not null); // True

class Vault { private readonly int _code = 42; }
```

Combine instance/static and public/nonpublic flags deliberately. `DeclaredOnly` restricts discovery to members declared by that type. Private members declared on base classes need separate handling; flags are not a universal “find everything” switch.

## Costs, caching, and trimming

Metadata discovery and late invocation can cost more than direct calls. Cache validated metadata or compatible delegates when repeated calls justify it.

Trimming and Native AOT can remove members that static analysis cannot see are needed. Use supported preservation annotations or source generation, investigate analyzer warnings, and verify the published artifact. Reflection is not a reason to assume unavailable metadata will be reconstructed at runtime.
