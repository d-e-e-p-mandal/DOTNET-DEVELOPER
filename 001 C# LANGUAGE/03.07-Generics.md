# 03.07 Generics

## Generic types and methods

Generics let one implementation work with specified types while retaining compile-time checking.

```csharp
var box = new Box<int>(42);
Console.WriteLine(box.Value); // 42
Console.WriteLine(Identity("C#")); // C#

T Identity<T>(T value) => value;
class Box<T>
{
    public T Value { get; }
    public Box(T value) => Value = value;
}
```

Classes, structs, interfaces, delegates, and methods can declare type parameters. `T` is a type parameter; `int` in `Box<int>` is a type argument.

## Type inference

```csharp
Console.WriteLine(Choose(true, 10, 20)); // 10: inferred T is int.
Console.WriteLine(Choose<string>(false, "A", "B")); // B: explicit argument.

T Choose<T>(bool first, T left, T right) => first ? left : right;
```

Method inference uses argument information; a return type alone generally does not supply the missing type argument. Incompatible arguments may require a more explicit API or type choice.

## Constraints

Constraints describe operations and categories the implementation may rely on.

| Constraint | Requirement |
| --- | --- |
| `class` | Reference type; non-nullable expectation in nullable-enabled code |
| `struct` | Non-nullable value type |
| `notnull` | Non-nullable type argument; violations normally produce nullable warnings |
| `unmanaged` | Non-nullable value type containing no managed references |
| `new()` | Public parameterless constructor; must be placed last among ordinary constraints |
| Base class | That class or a derived class |
| Interface | Implements that interface |

`struct` and `unmanaged` already imply suitable construction semantics and are not combined with `new()`.

## Base-class and interface constraints

```csharp
Console.WriteLine(Max(3, 8)); // 8

T Max<T>(T left, T right) where T : IComparable<T>
    => left.CompareTo(right) >= 0 ? left : right;
```

Without the constraint, the compiler cannot assume an arbitrary `T` has `CompareTo`.

## default(T) and nullability

```csharp
Console.WriteLine(DefaultValue<int>()); // 0
Console.WriteLine(DefaultValue<string>() is null); // True

T? DefaultValue<T>() => default;
```

For unconstrained `T`, `T?` is a nullable annotation; it does not universally mean `Nullable<T>`. If `T` is `int`, this example returns `int`, not `int?`. Use `where T : struct` with `T?` when a nullable value-type result is intended.

## API design and boxing

`List<int>` stores integers without boxing each element into `object`, unlike an object-based collection. Generic code does not automatically avoid every allocation or boxing operation: converting a value to `object` or an interface can still box. Choose constraints from actual required capabilities, not speculative future needs.
