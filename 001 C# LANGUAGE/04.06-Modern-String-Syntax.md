# 04.06 Modern String Syntax

## Raw string literals

A raw string uses at least three double quotes as its delimiter. Backslashes and ordinary quotes become literal text.

```csharp
string path = """C:\Logs\app.txt""";
Console.WriteLine(path); // C:\Logs\app.txt
string json = """{"name":"Deep"}""";
Console.WriteLine(json); // {"name":"Deep"}
```

Raw strings are available from C# 11. Choose a delimiter with more quotes than any consecutive quote sequence inside the content.

## Multiline indentation

```csharp
string message = """
    First
      Second
    Third
    """;
Console.WriteLine(message);
```

Output:

```text
First
  Second
Third
```

The closing delimiter establishes the indentation removed from content lines. The newline immediately after the opening delimiter and the one before the closing delimiter are not included as content. Inconsistent indentation can be a compilation error.

## Interpolated raw strings

The number of `$` signs determines how many braces introduce an interpolation.

```csharp
string name = "Deep";
string json = $$"""{"name":"{{name}}"}""";
Console.WriteLine(json); // {"name":"Deep"}
```

Here single braces are literal JSON braces; double braces surround the C# expression. This example is formatting, not safe general JSON serialization: use a serializer for arbitrary text containing quotes or escapes.

## Quotes and delimiter selection

```csharp
string quoted = """"The sequence """ appears here."""";
Console.WriteLine(quoted); // The sequence """ appears here.
```

Four quotes delimit this string because its content contains three consecutive quotes. Raw syntax changes how source text is written; it does not change the runtime type from `string`.

## Interpolated string handler concepts

An interpolated string handler lets a receiving API process literal and formatted portions without necessarily first constructing a complete string.

```csharp
var builder = new System.Text.StringBuilder();
int count = 3;
builder.Append($"Count: {count}");
Console.WriteLine(builder); // Count: 3
```

With an appropriate handler-based overload, the receiver can format directly into its destination. Custom handlers can also decide whether expensive interpolation parts need evaluation. This depends on the selected API overload; interpolation assigned to an ordinary `string` still produces a string.

Do not rely on side effects inside interpolation expressions whose evaluation might be conditional in a custom handler API.
