# 04.03 Switch Expressions

## Arms and result values

A switch expression chooses a result. Each arm has a pattern and an expression separated by `=>`.

```csharp
int status = 404;
string message = status switch
{
    200 => "OK",
    404 => "Not found",
    _ => "Other"
};
Console.WriteLine(message); // Not found
```

Arms are comma-separated; the surrounding assignment ends with a semicolon. There is no `case` keyword or `break` in an arm.

## when guards

```csharp
int quantity = 12;
bool member = true;
string category = quantity switch
{
    <= 0 => "Invalid",
    >= 10 when member => "Member bulk order",
    >= 10 => "Bulk order",
    _ => "Small order"
};
Console.WriteLine(category); // Member bulk order
```

A guard must also be true for its arm to be selected.

## Arm ordering and unreachable patterns

Specific cases should precede broader patterns that would match them. Placing `_ => ...` before later arms makes those arms unreachable and causes a compiler diagnostic.

The first matching arm with a satisfied guard supplies the result. Only the selected result expression is evaluated.

## Exhaustiveness and fallback cases

```csharp
Console.WriteLine(Name(3)); // Other

string Name(int value) => value switch
{
    1 => "One",
    2 => "Two",
    _ => "Other"
};
```

A non-exhaustive switch expression can warn at compilation and throw `SwitchExpressionException` at runtime when no arm matches. Include a deliberate fallback or a throwing arm for invalid values.

Enums can contain unnamed numeric values, so covering all named enum members alone does not necessarily cover every runtime value.

## Statement versus expression

```csharp
int value = 1;
switch (value)
{
    case 1:
        Console.WriteLine("One");
        break;
    default:
        Console.WriteLine("Other");
        break;
}

string text = value switch { 1 => "One", _ => "Other" };
Console.WriteLine(text); // One
```

A switch statement controls statement execution and can perform several operations per section. A switch expression produces one result; move complicated multi-step work into a method rather than forcing it into a dense arm.
