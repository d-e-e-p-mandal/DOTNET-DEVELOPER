# 04.02 Pattern Matching

## Constant, type, and declaration patterns

Patterns test a value's shape or contents and may introduce variables.

```csharp
object value = 42;
Console.WriteLine(value is 42); // True: constant pattern.
Console.WriteLine(value is int); // True: type pattern.
if (value is int number)
    Console.WriteLine(number + 1); // 43: declaration pattern.
```

A declaration/type pattern does not match null. A `null` constant pattern checks absence without invoking overloaded equality operators.

## Property and extended property patterns

```csharp
var order = new Order(new Customer("Deep"), 3);
Console.WriteLine(order is { Quantity: > 0 }); // True
Console.WriteLine(order is { Customer.Name: "Deep" }); // True

record Customer(string Name);
record Order(Customer Customer, int Quantity);
```

Property patterns test non-null objects and nested property values. Getters can execute during matching; keep them predictable.

## Positional and tuple patterns

```csharp
var point = new Point(2, 3);
Console.WriteLine(point is (2, > 0)); // True: generated Deconstruct.
Console.WriteLine((2, 3) is (> 0, > 0)); // True: tuple pattern.

record Point(int X, int Y);
```

Positional matching uses an appropriate deconstruction shape. Its component order must match that shape.

## Relational and logical patterns

```csharp
int age = 20;
Console.WriteLine(age is >= 18 and <= 65); // True
char letter = 'A';
Console.WriteLine(letter is >= 'A' and <= 'Z' or >= 'a' and <= 'z'); // True
Console.WriteLine(age is not 0); // True
```

`not` binds more tightly than `and`, which binds more tightly than `or`. Add parentheses when combining patterns might be unclear. Pattern combinators are not the same syntax as `&&` and `||` expressions.

## List and slice patterns

```csharp
int[] values = { 1, 2, 3, 4 };
Console.WriteLine(values is [1, .., 4]); // True
if (values is [var first, .. var middle, var last])
    Console.WriteLine($"{first}; {middle.Length}; {last}"); // 1; 2; 4
```

A list pattern matches a supported countable/indexable shape. A slice can match zero or more elements. Capturing an array slice can allocate a new array; a slice is not universally a zero-copy view.

## var patterns, discards, and assignment

`var captured` matches any value, including null, and binds it. `_` discards a matched component. A pattern variable must be definitely assigned on the path where it is read; merely being in scope after an `if` does not prove the pattern matched.

Avoid depending on the exact order in which complex pattern tests evaluate side-effecting properties.
