# 02.02 Fields and Properties

## Instance fields and static fields

A field stores data directly. Instance fields have separate storage per object; a static field is associated with the type.

```csharp
var first = new Counter();
var second = new Counter();
first.Increment();
Console.WriteLine(first.Value); // 1
Console.WriteLine(second.Value); // 0
Console.WriteLine(Counter.TotalChanges); // 1

class Counter
{
    private int _value;
    public static int TotalChanges;
    public int Value => _value;
    public void Increment()
    {
        _value++;
        TotalChanges++;
    }
}
```

Fields receive their type's default value. Prefer private instance fields when unrestricted external assignment could invalidate state.

## Backing fields and auto-properties

A property exposes accessor code. An auto-property asks the compiler to supply storage.

```csharp
var person = new Person { Name = "Deep" };
Console.WriteLine(person.Name); // Deep

class Person
{
    public string Name { get; set; } = ""; // Compiler-generated storage.
}
```

Use an explicit backing field when reads or writes need additional logic.

## get, set, and validation

```csharp
var item = new Product();
item.Price = 25M;
Console.WriteLine(item.Price); // 25
// item.Price = -1; // Throws ArgumentOutOfRangeException.

class Product
{
    private decimal _price;
    public decimal Price
    {
        get => _price;
        set
        {
            if (value < 0)
                throw new ArgumentOutOfRangeException(nameof(value));
            _price = value;
        }
    }
}
```

Inside `set`, `value` contains the proposed value. Validate before updating storage so a failed assignment leaves the old state intact.

## Accessor accessibility

```csharp
var order = new Order();
order.Pay();
Console.WriteLine(order.IsPaid); // True
// order.IsPaid = false; // Error: setter is private.

class Order
{
    public bool IsPaid { get; private set; }
    public void Pay() => IsPaid = true;
}
```

An accessor modifier must be more restrictive than the property's accessibility. Accessor restrictions control callers, not the lifetime of the value.

## Read-only and computed properties

```csharp
var rectangle = new Rectangle(4, 3);
Console.WriteLine(rectangle.Area); // 12

class Rectangle
{
    public int Width { get; }
    public int Height { get; }
    public int Area => Width * Height; // Computed on access; no Area backing field.
    public Rectangle(int width, int height)
    {
        if (width <= 0 || height <= 0)
            throw new ArgumentOutOfRangeException(nameof(width));
        Width = width;
        Height = height;
    }
}
```

A getter-only auto-property can be initialized in its declaration or containing constructor. A getter returning a mutable object does not make that object's contents read-only.

## Property invariants

Keep related changes in methods when individual setters could temporarily create an invalid combination. For example, a `SetPeriod(start, end)` method can verify both dates before changing either one. Avoid expensive network calls or surprising state changes in ordinary getters.
