# 01.12 Conditions and Selection

## if

`if` executes a statement or block when a Boolean condition is `true`.

```csharp
int age = 20;
if (age >= 18)
{
    Console.WriteLine("Adult"); // Adult
}
```

- The condition must produce `bool`; an integer is not automatically treated as true or false.
- `=` assigns a value; `==` compares values.
- Use braces to make the controlled statements clear. Do not put `;` after the condition.

## if–else

Exactly one branch runs.

```csharp
int stock = 0;
if (stock > 0)
{
    Console.WriteLine("Available");
}
else
{
    Console.WriteLine("Sold out"); // Sold out
}
```

## else-if chains

Conditions are tested in order. The first true branch wins; later conditions are not evaluated.

```csharp
int marks = 76;
if (marks < 0 || marks > 100)
    Console.WriteLine("Invalid marks");
else if (marks >= 80)
    Console.WriteLine("A");
else if (marks >= 60)
    Console.WriteLine("B"); // B
else
    Console.WriteLine("C");
```

Place a more specific condition before a broader condition that would also match it. Independent `if` statements differ: several bodies can execute.

## Nested conditions

Use nesting when the inner decision only matters after the outer decision succeeds.

```csharp
bool signedIn = true;
bool canEdit = false;
if (signedIn)
{
    if (canEdit)
        Console.WriteLine("Editor");
    else
        Console.WriteLine("Read only"); // Read only
}
else
{
    Console.WriteLine("Sign in");
}
```

Without braces, an `else` belongs to the nearest unmatched `if`, regardless of indentation.

## switch, case, and default

A `switch` selects a matching section. Several labels can share a body.

```csharp
string command = "list";
switch (command)
{
    case "list":
    case "ls":
        Console.WriteLine("Showing items"); // Showing items
        break;
    case "quit":
        Console.WriteLine("Exiting");
        return;
    default:
        Console.WriteLine("Unknown command");
        break;
}
```

- `break` exits this `switch`; `return` exits the containing function.
- A completed nonempty section cannot implicitly fall into the next section.
- `default` handles unmatched values. Without a matching case or default, execution continues after the switch.
- String case labels match case-sensitively.
- Constant labels must be compile-time constants; use a pattern and `when` for other conditions.

```csharp
int quantity = 12;
bool wholesale = true;
switch (quantity)
{
    case <= 0:
        Console.WriteLine("Invalid quantity");
        break;
    case >= 10 when wholesale:
        Console.WriteLine("Wholesale order"); // Wholesale order
        break;
    default:
        Console.WriteLine("Retail order");
        break;
}
```

## Guard clauses and early return

Reject an invalid or uninteresting case first, keeping the main path less deeply nested.

```csharp
Console.WriteLine(GetDeliveryFee(120)); // 0

decimal GetDeliveryFee(decimal subtotal)
{
    if (subtotal < 0)
        throw new ArgumentOutOfRangeException(nameof(subtotal));
    if (subtotal == 0)
        return 0;
    if (subtotal >= 100)
        return 0;
    return 5;
}
```

## Boundary conditions and Boolean reasoning

```csharp
int age = 18;
bool allowed = age >= 18 && age <= 65; // Both endpoints included.
bool outside = age < 18 || age > 65;
Console.WriteLine(allowed); // True
Console.WriteLine(outside); // False
```

- For `age >= 18`, check values `17`, `18`, and `19` when reviewing behavior.
- `a && b`: both must hold. `a || b`: at least one must hold.
- `!(a && b)` means `!a || !b`; `!(a || b)` means `!a && !b`.
- Put a null check before a dereference with `&&`: `name != null && name.Length > 0`.
- Avoid conditions that cannot succeed, such as `age < 18 && age > 65`.
