# 02.10 Additional Type Members

## Indexers

An indexer lets an object support bracket access while controlling the underlying operation.

```csharp
var shelf = new Shelf();
shelf[0] = "C#";
Console.WriteLine(shelf[0]); // C#

class Shelf
{
    private readonly string[] _books = { "", "", "" };
    public string this[int index]
    {
        get => _books[index];
        set => _books[index] = value;
    }
}
```

The parameter need not be an integer. Indexers can be overloaded by parameter lists and can validate access. This example inherits array bounds checking.

## Nested types

A nested type belongs inside another type's declaration. It can access the containing type's private members through a suitable instance.

```csharp
var owner = new Container();
var reader = new Container.Reader();
Console.WriteLine(reader.Read(owner)); // 42

class Container
{
    private int _value = 42;
    public class Reader
    {
        public int Read(Container owner) => owner._value;
    }
}
```

Nesting does not automatically create or capture a containing object. A public nested type is still limited by the accessibility of its containing type.

## Partial classes and members

`partial` combines declarations into one type at compilation. Parts may be in one file or several files in the same compilation.

```csharp
new Customer().Print(); // Deep

partial class Customer
{
    public string Name { get; set; } = "Deep";
}
partial class Customer
{
    public void Print() => Console.WriteLine(Name);
}
```

All parts must describe the same type and compatible modifiers. They are not independently compiled extensions to an already built assembly.

A traditional optional partial method can disappear when no implementation is supplied:

```csharp
new Worker().Run(); // Working

partial class Worker
{
    partial void BeforeRun();
    public void Run()
    {
        BeforeRun(); // Removed if this optional partial method has no implementation.
        Console.WriteLine("Working");
    }
}
```

Partial methods with explicit accessibility or other requirements, such as a non-void return type, need an implementation. Newer language versions support additional partial member forms; declaration and implementation signatures must match.

## Static classes

```csharp
Console.WriteLine(PriceRules.AddTax(100M)); // 118.00

static class PriceRules
{
    public static decimal AddTax(decimal amount) => amount * 1.18M;
}
```

A static class cannot be instantiated or used as a base class. Its members are static; it can have a static constructor but no instance constructor.

## Organizing public and internal APIs

Expose the smallest useful contract. Keep implementation helpers private or internal, and place generated partial code in separate files when needed. Avoid static mutable global state when an instance with explicit dependencies better expresses ownership.
