# 01.17 Strings and Console Input / Output

## String immutability

A string's character contents cannot be changed after creation. Methods such as `Replace` and `Trim` return a result rather than modifying the original string.

```csharp
string original = "  hello  ";
string cleaned = original.Trim();
Console.WriteLine(original.Length); // 9
Console.WriteLine(cleaned); // hello
```

Assigning a new string changes the variable's reference, not the old string object. For repeated edits in a loop, `StringBuilder` can avoid constructing many intermediate strings.

## Concatenation, interpolation, and formatting

```csharp
using System.Globalization;

string item = "Book";
int quantity = 3;
decimal price = 12.5M;
Console.WriteLine(item + ": " + quantity); // Book: 3
Console.WriteLine($"{item}: {quantity}"); // Book: 3
Console.WriteLine(price.ToString("F2", CultureInfo.InvariantCulture)); // 12.50
Console.WriteLine($"[{quantity,4}]"); // [   3]: right-aligned width 4.
Console.WriteLine($"[{quantity,-4}]"); // [3   ]: left-aligned width 4.
Console.WriteLine($"{{{quantity}}}"); // {3}: doubled interpolation braces.
```

`F2` means two decimal places, `N2` also uses grouping, and `C` uses a culture's currency format. Display formatting does not change the stored numeric value.

## Escape sequences and verbatim strings

```csharp
Console.WriteLine("First\nSecond"); // Two lines.
Console.WriteLine("\"Hello\""); // "Hello"
Console.WriteLine("C:\\Logs\\app.txt"); // C:\Logs\app.txt
Console.WriteLine(@"C:\Logs\app.txt"); // Same text without doubled slashes.
Console.WriteLine(@"She said ""Hi""."); // She said "Hi".
```

- `\n`: newline character; `\t`: tab; `\\`: backslash; `\"`: quote.
- `@` preserves backslashes in a verbatim string; quotes inside it are doubled.
- `$@"..."` combines interpolation and verbatim syntax.
- A displayed Windows-style path is just text; it does not create a file or guarantee that the path works on the current OS.

## Comparison

Use an explicit comparison rule when matching identifiers, commands, or protocol text.

```csharp
string first = "ADMIN";
string second = "admin";
Console.WriteLine(first == second); // False
Console.WriteLine(string.Equals(first, second, StringComparison.OrdinalIgnoreCase)); // True
```

`Ordinal` compares by character values; `OrdinalIgnoreCase` adds case-insensitive handling. Culture-aware comparisons are useful for human-language text. Do not normalize machine identifiers with culture-sensitive casing and assume consistent behavior everywhere.

## Searching and replacing

```csharp
string text = "Learning C#";
Console.WriteLine(text.Contains("c#", StringComparison.OrdinalIgnoreCase)); // True
Console.WriteLine(text.StartsWith("Learn", StringComparison.Ordinal)); // True
Console.WriteLine(text.IndexOf("C#", StringComparison.Ordinal)); // 9
Console.WriteLine(text.IndexOf("Java", StringComparison.Ordinal)); // -1
Console.WriteLine(text.Replace("C#", ".NET")); // Learning .NET
```

`IndexOf` returns `-1` when no match exists. Check this before using its result as an index.

## Splitting and joining

```csharp
string input = " red, , blue ,green ";
string[] colors = input.Split(',', StringSplitOptions.TrimEntries |
                                   StringSplitOptions.RemoveEmptyEntries);
Console.WriteLine(colors.Length); // 3
Console.WriteLine(string.Join(" | ", colors)); // red | blue | green
```

Splitting on commas is not a complete CSV parser; CSV can contain quoted commas and embedded newlines.

## Console.Write, WriteLine, and ReadLine

```csharp
Console.Write("Name: "); // Leaves the cursor on the same line.
string? name = Console.ReadLine(); // Reads a line, or null at end of input.
Console.WriteLine($"Hello, {name ?? "Guest"}");
```

`WriteLine` appends the platform line terminator. `ReadLine` returns text without the terminating newline and can return an empty string.

## Reading and validating input

```csharp
using System.Globalization;

Console.Write("Quantity: ");
string? input = Console.ReadLine();
if (input is null)
{
    Console.WriteLine("Input ended");
    return;
}
if (!int.TryParse(input, NumberStyles.Integer, CultureInfo.InvariantCulture, out int quantity)
    || quantity < 1 || quantity > 100)
{
    Console.WriteLine("Enter a whole number from 1 to 100");
    return;
}
Console.WriteLine($"Accepted: {quantity}");
```

Input `3` produces `Accepted: 3`. Parsing checks representation; the range check separately enforces the application's rule.
