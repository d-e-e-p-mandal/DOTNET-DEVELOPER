# 04.07 Collection Expressions, Indices, and Ranges

## Collection expressions

A collection expression uses square brackets and is converted to an appropriate target collection type. The syntax is available from C# 12.

```csharp
int[] array = [1, 2, 3];
List<int> list = [4, 5];
Console.WriteLine(array.Length); // 3
Console.WriteLine(list.Count); // 2
// var unknown = [1, 2, 3]; // Error: this expression has no standalone natural type.
```

Unlike `{ ... }` in a traditional initializer, `[ ... ]` is an expression with collection conversion rules.

## Spread elements

```csharp
int[] first = [1, 2];
int[] combined = [0, .. first, 3];
Console.WriteLine(string.Join(", ", combined)); // 0, 1, 2, 3
```

Spread elements enumerate or copy the source elements into the result. They do not create a live query that automatically follows later source changes.

## Target typing and supported shapes

Common targets include arrays, spans, lists, supported collection interfaces, and appropriately configured custom collections. A custom type may need a recognized construction pattern or collection builder; arbitrary bracket syntax does not automatically construct every type.

An empty collection expression is `[]`, still requiring a suitable target type.

## Indices from the end

```csharp
string[] names = ["A", "B", "C"];
Console.WriteLine(names[^1]); // C
Console.WriteLine(names[^2]); // B
// Console.WriteLine(names[^0]); // Invalid element index: position is past the end.
```

`^1` means the final element. `^0` denotes the end position and is useful as a range boundary, not as an element index.

## Ranges and slicing

```csharp
int[] numbers = [10, 20, 30, 40];
int[] middle = numbers[1..3]; // Start inclusive, end exclusive.
Console.WriteLine(string.Join(", ", middle)); // 20, 30
Console.WriteLine(string.Join(", ", numbers[..2])); // 10, 20
Console.WriteLine(string.Join(", ", numbers[2..])); // 30, 40
```

Omitted start means the beginning; omitted end means the end. A range does not automatically work on every collection, including every list API.

## Allocation, copying, and views

```csharp
int[] original = [1, 2, 3];
int[] copy = original[1..];
Span<int> view = original.AsSpan(1);
copy[0] = 20;
view[0] = 99;
Console.WriteLine(original[1]); // 99
Console.WriteLine(copy[0]); // 20
```

Array ranges produce arrays containing copied elements. Span slices are views over existing storage. Reference-type elements are still copied as references. Readonly views prevent writes through that view, not changes by another owner.
