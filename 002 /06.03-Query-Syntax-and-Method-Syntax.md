# 06.03 — QUERY SYNTAX, METHOD SYNTAX & KEYWORDS

**Chapter:** 06 — LINQ Fundamentals  
**Namespace:** `System.Linq`

## 1. LINQ Syntax Forms

LINQ provides different ways to write queries in C#.

### 1.1 Query Syntax

Uses keywords such as `from`, `where`, and `select`.

```csharp
int[] numbers = { 1, 2, 3, 4, 5 };

var result =
    from n in numbers
    where n > 2
    select n;

// 3, 4, 5
```

### 1.2 Method Syntax

Uses LINQ methods and lambda expressions.

```csharp
var result = numbers
    .Where(n => n > 2)
    .Select(n => n);
```

### 1.3 Mixed Syntax

Combines query syntax with method syntax.

```csharp
var result = (
    from n in numbers
    where n > 2
    select n
).ToList();
```

### 1.4 Fluent Method Chaining

Connects multiple methods using `.`.

```csharp
var result = numbers
    .Where(n => n > 2)
    .OrderByDescending(n => n)
    .Select(n => n * 10)
    .ToList();
```

## 2. Query Contextual Keywords

Query contextual keywords have special meanings inside LINQ query expressions.

### 2.1 `from`

Introduces a data source and range variable.

```csharp
var result =
    from n in numbers
    select n;
```

### 2.2 `where`

Filters elements using a condition.

```csharp
var result =
    from n in numbers
    where n > 3
    select n;
```

### 2.3 `select`

Specifies the values returned by the query.

```csharp
var result =
    from n in numbers
    select n * 2;
```

### 2.4 `orderby`

Sorts elements using one or more keys.

```csharp
var result =
    from n in numbers
    orderby n
    select n;
```

### 2.5 `ascending`

Sorts values from smallest to largest.

```csharp
var result =
    from n in numbers
    orderby n ascending
    select n;
```

### 2.6 `descending`

Sorts values from largest to smallest.

```csharp
var result =
    from n in numbers
    orderby n descending
    select n;
```

### 2.7 `group`

Groups elements based on a key.

```csharp
var result =
    from n in numbers
    group n by n % 2;
```

### 2.8 `by`

Separates the grouped element from its grouping key.

```csharp
var result =
    from n in numbers
    group n by n % 2;
```

Here, `n` is the grouped element and `n % 2` is the key.

### 2.9 `join`

Combines matching elements from two data sources.

```csharp
var result =
    from s in students
    join d in departments
        on s.DepartmentId equals d.Id
    select new { s.Name, Department = d.Name };
```

### 2.10 `on`

Introduces the join-key expressions.

```csharp
join d in departments
    on s.DepartmentId equals d.Id
```

### 2.11 `equals`

Separates the two join keys for equality matching.

```csharp
join d in departments
    on s.DepartmentId equals d.Id
```

### 2.12 `into`

Creates a query continuation or group-join result.

```csharp
var result =
    from n in numbers
    group n by n % 2 into g
    select new { Key = g.Key, Count = g.Count() };
```

### 2.13 `let`

Creates a reusable intermediate value.

```csharp
var result =
    from n in numbers
    let square = n * n
    where square > 10
    select square;
```

## 4. Query Expression Structure

A query expression begins with `from` and ends with `select` or `group`, optionally followed by a continuation.

### 4.1 Initial `from` Clause

Identifies the first data source.

```csharp
from n in numbers
```

### 4.2 Query Body

Contains the operations after the initial `from`.

```csharp
var result =
    from n in numbers
    where n > 2
    orderby n descending
    select n;
```

### 4.3 Query Body Clauses

Clauses such as `where`, `let`, `join`, `orderby`, and additional `from` clauses.

```csharp
var result =
    from n in numbers
    let square = n * n
    where square > 10
    orderby square
    select square;
```

### 4.4 Terminal `select` Clause

Ends a query body by selecting values.

```csharp
var result =
    from n in numbers
    select n * 10;
```

### 4.5 Terminal `group` Clause

Ends a query body by producing groups.

```csharp
var result =
    from n in numbers
    group n by n % 2;
```

### 4.6 Query Continuation

Uses `into` to continue querying a projected or grouped result.

```csharp
var result =
    from n in numbers
    select n * 2 into doubled
    where doubled > 5
    select doubled;
```

## 5. `from` Clause

### 5.1 `from x in source`

Declares a range variable representing elements from a source.

```csharp
var result =
    from x in numbers
    select x;
```

### 5.2 Source Expression

The expression after `in` supplies the sequence.

```csharp
var result =
    from n in Enumerable.Range(1, 5)
    select n;
```

### 5.3 Range Variable

Represents one element during query evaluation.

```csharp
var result =
    from n in numbers
    select n * n;
```

### 5.4 Implicitly Typed Range Variable

The compiler infers the variable type.

```csharp
var result =
    from n in numbers
    select n;
```

Here, `n` is inferred as `int`.

### 5.5 Explicitly Typed Range Variable

Specifies the element type explicitly.

```csharp
System.Collections.ArrayList values = new()
{
    10, 20, 30
};

var result =
    from int n in values
    select n;
```

### 5.6 Multiple `from` Clauses

Enumerates multiple sequences.

```csharp
int[] a = { 1, 2 };
int[] b = { 10, 20 };

var result =
    from x in a
    from y in b
    select new { x, y };
```

### 5.7 Nested Enumeration

The inner sequence is enumerated for each outer element.

```csharp
int[][] matrix =
{
    new[] { 1, 2 },
    new[] { 3, 4 }
};

var result =
    from row in matrix
    from value in row
    select value;

// 1, 2, 3, 4
```

## 6. `where` Clause

### 6.1 Boolean Predicate

A `where` condition must produce a Boolean value.

```csharp
var result =
    from n in numbers
    where n > 2
    select n;
```

### 6.2 Comparison Expressions

Uses comparison operators.

```csharp
var result =
    from n in numbers
    where n >= 2
    select n;
```

### 6.3 Logical Expressions

Combines conditions using logical operators.

```csharp
var result =
    from n in numbers
    where n > 1 && n < 5
    select n;
```

### 6.4 Multiple Conditions

Combines several filtering rules.

```csharp
var result =
    from n in numbers
    where n > 1 && n < 5 && n % 2 == 0
    select n;
```

### 6.5 Multiple `where` Clauses

Applies filtering in multiple stages.

```csharp
var result =
    from n in numbers
    where n > 1
    where n % 2 == 0
    select n;
```

### 6.6 Predicate Translation

A query `where` clause translates to a `Where()` call.

```csharp
// Query syntax
var query =
    from n in numbers
    where n > 2
    select n;

// Equivalent method syntax
var method = numbers.Where(n => n > 2);
```

The final identity `select n` can be eliminated during query translation.

## 7. `select` Clause

### 7.1 Selecting Whole Elements

Returns the original elements.

```csharp
var result =
    from n in numbers
    select n;
```

### 7.2 Selecting Properties

Returns a property from each object.

```csharp
var result =
    from s in students
    select s.Name;
```

### 7.3 Calculated Values

Returns values calculated from source elements.

```csharp
var result =
    from n in numbers
    select n * n;
```

### 7.4 Anonymous Types

Creates objects without declaring a named class.

```csharp
var result =
    from s in students
    select new
    {
        s.Name,
        s.Age
    };
```

### 7.5 Tuples

Returns multiple values using tuples.

```csharp
var result =
    from s in students
    select (s.Name, s.Age);
```

### 7.6 Records

Projects elements into record objects.

```csharp
public record StudentInfo(string Name, int Age);
```

```csharp
var result =
    from s in students
    select new StudentInfo(s.Name, s.Age);
```

### 7.7 DTOs

Projects data into Data Transfer Objects.

```csharp
public class StudentDto
{
    public string Name { get; set; } = "";
    public int Age { get; set; }
}
```

```csharp
var result =
    from s in students
    select new StudentDto
    {
        Name = s.Name,
        Age = s.Age
    };
```

### 7.8 Nested Projection

Creates objects containing nested data.

```csharp
var result =
    from s in students
    select new
    {
        s.Name,
        Details = new
        {
            s.Age,
            s.Score
        }
    };
```

## 8. `orderby` Clause

### 8.1 Default Ascending Order

Ascending is the default direction.

```csharp
var result =
    from n in numbers
    orderby n
    select n;
```

### 8.2 `ascending`

Explicitly sorts in ascending order.

```csharp
var result =
    from n in numbers
    orderby n ascending
    select n;
```

### 8.3 `descending`

Sorts in descending order.

```csharp
var result =
    from n in numbers
    orderby n descending
    select n;
```

### 8.4 Multiple Keys

Sorts by a primary key and then secondary keys.

```csharp
var result =
    from s in students
    orderby s.Age ascending, s.Name descending
    select s;
```

### 8.5 Stable Ordering

LINQ to Objects preserves the original relative order of elements with equal sort keys.

```csharp
var result =
    from s in students
    orderby s.Score descending
    select s;
```

Students with equal scores retain their original relative order.

## 9. `group...by` Clause

### 9.1 Group Element

Specifies which value is stored inside each group.

```csharp
var result =
    from s in students
    group s.Name by s.Age;
```

Here, `s.Name` is the group element.

### 9.2 Group Key

Specifies the value used to create groups.

```csharp
var result =
    from s in students
    group s by s.Age;
```

Here, `s.Age` is the group key.

### 9.3 Composite Key

Groups elements using multiple properties.

```csharp
var result =
    from s in students
    group s by new
    {
        s.Age,
        s.DepartmentId
    };
```

### 9.4 `group x by key`

Creates groups based on a key.

```csharp
var result =
    from n in numbers
    group n by n % 2;
```

### 9.5 `group x by key into g`

Creates groups and continues querying them.

```csharp
var result =
    from s in students
    group s by s.Age into g
    select new
    {
        Age = g.Key,
        Count = g.Count()
    };
```

## 10. `join...on...equals` Clause

### 10.1 Outer Source

The sequence introduced by the outer `from`.

```csharp
from s in students
```

Here, `students` is the outer source.

### 10.2 Inner Source

The sequence introduced by `join`.

```csharp
join d in departments
    on s.DepartmentId equals d.Id
```

Here, `departments` is the inner source.

### 10.3 Outer Key

The key selected from the outer element.

```csharp
on s.DepartmentId equals d.Id
```

Here, `s.DepartmentId` is the outer key.

### 10.4 Inner Key

The key selected from the inner element.

```csharp
on s.DepartmentId equals d.Id
```

Here, `d.Id` is the inner key.

### 10.5 `equals` vs `==`

`equals` is required between the key expressions of a query-syntax join.

```csharp
// Correct
join d in departments
    on s.DepartmentId equals d.Id
```

```csharp
// Incorrect
join d in departments
    on s.DepartmentId == d.Id
```

The `equals` keyword specifies an equijoin; it is not the general C# equality operator.

### 10.6 Inner Join

Returns matching elements from both sources.

```csharp
var result =
    from s in students
    join d in departments
        on s.DepartmentId equals d.Id
    select new
    {
        Student = s.Name,
        Department = d.Name
    };
```

### 10.7 Composite-Key Join

Matches multiple properties using composite keys.

```csharp
var result =
    from s in students
    join other in students
        on new { s.Age, s.DepartmentId }
        equals new { other.Age, other.DepartmentId }
    select new
    {
        First = s.Name,
        Second = other.Name
    };
```

### 10.8 `join...into`

Creates a group join containing matching inner elements.

```csharp
var result =
    from d in departments
    join s in students
        on d.Id equals s.DepartmentId into studentGroup
    select new
    {
        Department = d.Name,
        Students = studentGroup
    };
```

## 11. `let` Clause

### 11.1 Intermediate Values

Creates a named value inside a query.

```csharp
var result =
    from n in numbers
    let square = n * n
    select square;
```

### 11.2 Calculated Values

Stores a calculation for later clauses.

```csharp
var result =
    from s in students
    let bonus = s.Score + 5
    select new { s.Name, bonus };
```

### 11.3 Reusing Expressions

Allows the same calculated value to be referenced multiple times.

```csharp
var result =
    from n in numbers
    let square = n * n
    where square > 10
    select new
    {
        Number = n,
        Square = square
    };
```

### 11.4 `let` Variable Scope

A `let` variable is available in subsequent clauses of the same query body.

```csharp
var result =
    from n in numbers
    let doubled = n * 2
    where doubled > 5
    orderby doubled
    select doubled;
```

## 12. `into` Keyword

### 12.1 Query Continuation

Continues a query after `select` or `group`.

```csharp
var result =
    from n in numbers
    select n * 2 into value
    where value > 5
    select value;
```

### 12.2 Continuation After `select`

Uses the projected result as a new range variable.

```csharp
var result =
    from n in numbers
    select n * n into square
    where square > 10
    select square;
```

### 12.3 Continuation After `group`

Continues processing grouped results.

```csharp
var result =
    from s in students
    group s by s.Age into g
    where g.Count() > 1
    select g;
```

### 12.4 Group Join Continuation

Stores matching inner elements in a group.

```csharp
var result =
    from d in departments
    join s in students
        on d.Id equals s.DepartmentId into matches
    select new
    {
        d.Name,
        Count = matches.Count()
    };
```

### 12.5 New Range Variable Scope

After `select...into`, the previous range variables are no longer directly available.

```csharp
var result =
    from n in numbers
    select n * 2 into doubled
    where doubled > 5
    select doubled;
```

Here, `doubled` is available after `into`, but `n` is not.

**Exception:** In `join...into`, the outer range variables remain available along with the new group variable.

## 13. Range Variables

### 13.1 Declaration

A range variable is declared in a query clause.

```csharp
var result =
    from n in numbers
    select n;
```

Here, `n` is the range variable.

### 13.2 Type Inference

The compiler determines the range variable's type from its source.

```csharp
var result =
    from s in students
    select s.Name;
```

Here, `s` has type `Student`.

### 13.3 Scope

A range variable is accessible only within its permitted query scope.

```csharp
var result =
    from n in numbers
    where n > 2
    select n;
```

`n` cannot be accessed outside the query as a separately declared local variable.

### 13.4 Multiple Range Variables

Multiple `from` clauses introduce multiple range variables.

```csharp
var result =
    from x in numbers
    from y in numbers
    select new { x, y };
```

### 13.5 Transparent Identifiers

The compiler uses intermediate structures to preserve multiple range variables during query translation.

```csharp
var result =
    from x in numbers
    let square = x * x
    select new { x, square };
```

Conceptual method-syntax representation:

```csharp
var result = numbers
    .Select(x => new
    {
        x,
        square = x * x
    });
```

## 14. Method Syntax

### 14.1 Extension-Method Syntax

Calls LINQ methods directly on a sequence.

```csharp
var result = numbers.Where(n => n > 2);
```

### 14.2 Static-Method Syntax

Calls LINQ methods through the `Enumerable` class.

```csharp
var result = Enumerable.Where(
    numbers,
    n => n > 2
);
```

### 14.3 Lambda Arguments

Passes lambda expressions to LINQ methods.

```csharp
var result = numbers.Select(n => n * 2);
```

### 14.4 Method Chaining

Connects multiple LINQ operations.

```csharp
var result = numbers
    .Where(n => n > 2)
    .OrderByDescending(n => n)
    .Select(n => n * 10);
```

### 14.5 Predicate Arguments

A predicate returns `true` or `false`.

```csharp
var result = numbers.Where(n => n % 2 == 0);
```

### 14.6 Selector Arguments

A selector transforms an element into another value.

```csharp
var result = students.Select(s => s.Name);
```

### 14.7 Key Selector Arguments

Selects a key for ordering, grouping, or joining.

```csharp
var result = students.OrderBy(s => s.Age);
```

### 14.8 Collection Selector Arguments

Selects a sequence from each source element.

```csharp
int[][] matrix =
{
    new[] { 1, 2 },
    new[] { 3, 4 }
};

var result = matrix.SelectMany(row => row);
```

### 14.9 Result Selector Arguments

Specifies how values are combined into result elements.

```csharp
var result = students.Join(
    departments,
    s => s.DepartmentId,
    d => d.Id,
    (s, d) => new
    {
        Student = s.Name,
        Department = d.Name
    }
);
```

### 14.10 Comparer Arguments

Supplies custom comparison rules.

```csharp
string[] names = { "amit", "AMIT", "Rahul" };

var result = names.OrderBy(
    name => name,
    StringComparer.OrdinalIgnoreCase
);
```

## 15. Query Translation

The compiler translates query syntax into method calls.

### 15.1 `where` → `Where`

```csharp
// Query
var q = from n in numbers
        where n > 2
        select n;

// Method
var m = numbers.Where(n => n > 2);
```

### 15.2 `select` → `Select`

```csharp
// Query
var q = from n in numbers
        select n * 2;

// Method
var m = numbers.Select(n => n * 2);
```

### 15.3 Multiple `from` → `SelectMany`

```csharp
int[] a = { 1, 2 };
int[] b = { 10, 20 };

// Query
var q = from x in a
        from y in b
        select new { x, y };

// Method
var m = a.SelectMany(
    x => b,
    (x, y) => new { x, y }
);
```

### 15.4 `orderby` → `OrderBy`

```csharp
// Query
var q = from n in numbers
        orderby n
        select n;

// Method
var m = numbers.OrderBy(n => n);
```

### 15.5 Secondary Ordering → `ThenBy`

Multiple keys within one `orderby` clause translate to primary and secondary ordering methods.

```csharp
// Query
var q = from s in students
        orderby s.Age, s.Name
        select s;

// Method
var m = students
    .OrderBy(s => s.Age)
    .ThenBy(s => s.Name);
```

### 15.6 `descending` → `OrderByDescending` / `ThenByDescending`

```csharp
// Query
var q = from s in students
        orderby s.Age descending, s.Name descending
        select s;

// Method
var m = students
    .OrderByDescending(s => s.Age)
    .ThenByDescending(s => s.Name);
```

### 15.7 `group...by` → `GroupBy`

```csharp
// Query
var q = from s in students
        group s by s.Age;

// Method
var m = students.GroupBy(s => s.Age);
```

### 15.8 `join` → `Join`

```csharp
// Query
var q =
    from s in students
    join d in departments
        on s.DepartmentId equals d.Id
    select new { s.Name, Department = d.Name };

// Method
var m = students.Join(
    departments,
    s => s.DepartmentId,
    d => d.Id,
    (s, d) => new
    {
        s.Name,
        Department = d.Name
    }
);
```

### 15.9 `join...into` → `GroupJoin`

```csharp
// Query
var q =
    from d in departments
    join s in students
        on d.Id equals s.DepartmentId into g
    select new { d.Name, Count = g.Count() };

// Method
var m = departments.GroupJoin(
    students,
    d => d.Id,
    s => s.DepartmentId,
    (d, g) => new
    {
        d.Name,
        Count = g.Count()
    }
);
```

### 15.10 Explicit Range Type → `Cast<T>`

```csharp
System.Collections.ArrayList values = new()
{
    10, 20, 30
};

// Query
var q = from int n in values
        select n;

// Method
var m = values.Cast<int>();
```

### 15.11 `let` → Intermediate Projection

```csharp
// Query
var q =
    from n in numbers
    let square = n * n
    where square > 10
    select square;

// Method
var m = numbers
    .Select(n => new { n, square = n * n })
    .Where(x => x.square > 10)
    .Select(x => x.square);
```

### 15.12 `into` → Query Continuation

```csharp
// Query
var q =
    from n in numbers
    select n * 2 into doubled
    where doubled > 5
    select doubled;

// Method
var m = numbers
    .Select(n => n * 2)
    .Where(doubled => doubled > 5);
```

## 16. Query Syntax vs Method Syntax

Both forms can express the same LINQ operations.

| Query Syntax | Method Syntax |
|---|---|
| Uses query keywords | Uses method calls |
| Uses range variables | Commonly uses lambda parameters |
| Similar in appearance to SQL | Uses fluent C# method calls |
| Supports selected LINQ operators | Exposes the full LINQ method API |
| Translated by the compiler | Written directly as method invocations |
| Often convenient for joins | Often convenient for chaining |

**Query syntax:**

```csharp
var result =
    from n in numbers
    where n > 2
    orderby n descending
    select n * 10;
```

**Method syntax:**

```csharp
var result = numbers
    .Where(n => n > 2)
    .OrderByDescending(n => n)
    .Select(n => n * 10);
```

## 17. Operators Without Direct Query Syntax

|---|---|

| `Any()` | Checks whether elements exist or match |
| `All()` | Checks whether all elements match |

### Example: Count

```csharp
int count = numbers.Count(n => n > 2);
```

### Example: Sum

```csharp
int total = numbers.Sum();
```

### Example: Distinct

```csharp
int[] values = { 1, 2, 2, 3, 3 };

var result = values.Distinct();
```

### Example: Take

```csharp
var result = numbers.Take(3);
```

### Example: ToList

```csharp
List<int> result = numbers
    .Where(n => n > 2)
    .ToList();
```

## 19. Nested Query Expressions

A query expression can appear inside another query.

### Example 1: Nested Filtering

```csharp
var result =
    from n in numbers
    where n > (
        from x in numbers
        select x
    ).Average()
    select n;
```

### Example 2: Nested Projection

```csharp
var result =
    from d in departments
    select new
    {
        Department = d.Name,

        Students =
            from s in students
            where s.DepartmentId == d.Id
            select s.Name
    };
```

### Example 3: Nested Query with Count

```csharp
var result =
    from d in departments
    select new
    {
        d.Name,

        StudentCount = (
            from s in students
            where s.DepartmentId == d.Id
            select s
        ).Count()
    };
```

## 20. Query Pattern

The query pattern is the set of methods that enables a type to participate in C# query expressions.

For example, the `where` clause requires an applicable `Where` operation.

```csharp
var result =
    from n in numbers
    where n > 2
    select n;
```

Equivalent method operation:

```csharp
var result = numbers.Where(n => n > 2);
```

### Query Pattern Methods

| Query Clause | Corresponding Method |
|---|---|
| `from` | Source enumeration or query pattern |
| Additional `from` | `SelectMany` |
| `where` | `Where` |
| `select` | `Select` |
| `orderby` | `OrderBy` |
| `orderby descending` | `OrderByDescending` |
| Secondary ordering | `ThenBy` |
| Secondary descending ordering | `ThenByDescending` |
| `group...by` | `GroupBy` |
| `join` | `Join` |
| `join...into` | `GroupJoin` |

Query syntax is not restricted to `IEnumerable<T>`; custom types can support queries by providing suitable query-pattern methods.

### Example: Custom Query Pattern

```csharp
public class NumberSource
{
    public IEnumerable<int> Where(Func<int, bool> predicate)
    {
        return new[] { 1, 2, 3, 4, 5 }.Where(predicate);
    }
}
```

```csharp
var source = new NumberSource();

var result =
    from n in source
    where n > 2
    select n;
```

The `where` clause uses the custom `Where` method, which returns an `IEnumerable<int>` that supports the remaining query.

## 21. Compiler Query Translation

The C# compiler translates query expressions into method calls.

### 21.1 Original Query

```csharp
var result =
    from n in numbers
    where n > 2
    orderby n descending
    select n * 10;
```

### 21.2 Translated Method Calls

```csharp
var result = numbers
    .Where(n => n > 2)
    .OrderByDescending(n => n)
    .Select(n => n * 10);
```

### 21.3 Translation of Multiple `from` Clauses

**Query syntax:**

```csharp
var result =
    from x in numbers
    from y in numbers
    select x + y;
```

**Method syntax:**

```csharp
var result = numbers.SelectMany(
    x => numbers,
    (x, y) => x + y
);
```

### 21.4 Translation of Grouping

**Query syntax:**

```csharp
var result =
    from n in numbers
    group n by n % 2;
```

**Method syntax:**

```csharp
var result = numbers.GroupBy(n => n % 2);
```

### 21.5 Translation of Joins

**Query syntax:**

```csharp
var result =
    from s in students
    join d in departments
        on s.DepartmentId equals d.Id
    select new
    {
        s.Name,
        Department = d.Name
    };
```

**Method syntax:**

```csharp
var result = students.Join(
    departments,
    s => s.DepartmentId,
    d => d.Id,
    (s, d) => new
    {
        s.Name,
        Department = d.Name
    }
);
```

### 21.6 Important Compiler Rules

1. A query expression must begin with `from`.
2. A query body must end with `select` or `group`.
3. A query can continue after `select` or `group` using `into`.
4. Query clauses are translated into query-pattern method calls.
5. A simple identity projection, such as `select n`, can be removed during translation.
6. Query syntax does not require SQL or a database.
7. Query translation does not itself execute the query.
8. Execution depends on the selected methods and query provider.

## 22. Quick Revision

| Keyword / Syntax | Meaning | Example |
|---|---|---|
| `from` | Introduces source elements | `from n in numbers` |
| `in` | Connects variable and source | `n in numbers` |
| `where` | Filters elements | `where n > 2` |
| `select` | Projects values | `select n * 2` |
| `orderby` | Orders elements | `orderby n` |
| `ascending` | Ascending order | `orderby n ascending` |
| `descending` | Descending order | `orderby n descending` |
| `group` | Creates groups | `group n by n % 2` |
| `by` | Introduces grouping key | `by n % 2` |
| `join` | Combines matching elements | `join d in departments` |
| `on` | Introduces join keys | `on s.DepartmentId` |
| `equals` | Separates equijoin keys | `equals d.Id` |
| `into` | Creates continuation/group variable | `into g` |
| `let` | Creates intermediate value | `let x = n * n` |
