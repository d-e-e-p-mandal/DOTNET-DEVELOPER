# 08.06 — DISTINCT OPERATIONS

**Chapter:** 08 — LINQ Joins & Set Operations  
**Namespace:** `System.Linq`  
**Total Syllabus Topics:** 9

Distinct operations remove duplicate elements from a sequence according to equality rules.

LINQ provides two main methods:

```csharp
Distinct()
DistinctBy()
```

**Main difference:**

- `Distinct()` removes duplicates by comparing entire elements.
- `DistinctBy()` removes duplicates by comparing selected keys.

Both methods use deferred execution and preserve the first encountered representative of each distinct value or key in LINQ to Objects.

---

## 1. Distinct

`Distinct()` returns unique elements from a sequence.

### Syntax

```csharp
source.Distinct();
```

### Method signatures

```csharp
IEnumerable<TSource> Distinct<TSource>(
    IEnumerable<TSource> source
);
```

```csharp
IEnumerable<TSource> Distinct<TSource>(
    IEnumerable<TSource> source,
    IEqualityComparer<TSource>? comparer
);
```

### Example 1: Distinct integers

```csharp
int[] numbers =
{
    10, 20, 10, 30, 20, 40
};

var result = numbers.Distinct();

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
10, 20, 30, 40
```

**Explanation:**

```text
Original: 10, 20, 10, 30, 20, 40
Unique:   10, 20,     30,     40
```

Repeated values are removed.

### Example 2: Distinct strings

```csharp
string[] names =
{
    "Amit",
    "Rahul",
    "Amit",
    "Priya",
    "Rahul"
};

var result = names.Distinct();

foreach (string name in result)
{
    Console.WriteLine(name);
}
```

**Output:**

```text
Amit
Rahul
Priya
```

### Example 3: Distinct with query syntax

`Distinct()` has no dedicated LINQ query-syntax keyword.

It can be applied to the result of a query expression.

```csharp
int[] numbers = { 1, 2, 2, 3, 3, 4 };

var result =
    (from n in numbers
     select n).Distinct();

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1, 2, 3, 4
```

**Key point:** `Distinct()` eliminates duplicate elements using equality comparison.

## 2. DistinctBy

`DistinctBy()` returns unique elements based on a selected key.

It was introduced in .NET 6.

### Syntax

```csharp
source.DistinctBy(
    element => element.Key
);
```

### Method signatures

```csharp
IEnumerable<TSource> DistinctBy<TSource, TKey>(
    IEnumerable<TSource> source,
    Func<TSource, TKey> keySelector
);
```

```csharp
IEnumerable<TSource> DistinctBy<TSource, TKey>(
    IEnumerable<TSource> source,
    Func<TSource, TKey> keySelector,
    IEqualityComparer<TKey>? comparer
);
```

### Example 1: Distinct employees by department

```csharp
record Employee(
    int Id,
    string Name,
    int DepartmentId
);

Employee[] employees =
{
    new(1, "Amit", 10),
    new(2, "Rahul", 20),
    new(3, "Priya", 10),
    new(4, "Sneha", 30)
};

var result = employees.DistinctBy(
    e => e.DepartmentId
);

foreach (var employee in result)
{
    Console.WriteLine(
        $"{employee.Name}: {employee.DepartmentId}"
    );
}
```

**Output:**

```text
Amit: 10
Rahul: 20
Sneha: 30
```

Priya is excluded because department `10` was already encountered for Amit.

### Example 2: Distinct products by category

```csharp
record Product(
    int Id,
    string Name,
    string Category
);

Product[] products =
{
    new(1, "Mouse", "Electronics"),
    new(2, "Keyboard", "Electronics"),
    new(3, "Chair", "Furniture"),
    new(4, "Table", "Furniture")
};

var result = products.DistinctBy(
    p => p.Category
);

foreach (var product in result)
{
    Console.WriteLine(
        $"{product.Name}: {product.Category}"
    );
}
```

**Output:**

```text
Mouse: Electronics
Chair: Furniture
```

### Example 3: Distinct by string length

```csharp
string[] words =
{
    "Cat",
    "Dog",
    "Apple",
    "Tiger",
    "Book"
};

var result = words.DistinctBy(
    word => word.Length
);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
Cat, Apple, Book
```

**Explanation:**

| Word | Length | Selected |
|---|---:|---|
| Cat | 3 | Yes |
| Dog | 3 | No |
| Apple | 5 | Yes |
| Tiger | 5 | No |
| Book | 4 | Yes |

**Key point:** `DistinctBy()` returns complete elements while comparing only their selected keys.

## 3. Default Equality

When no custom comparer is provided, `Distinct()` uses:

```csharp
EqualityComparer<TSource>.Default
```

`DistinctBy()` uses:

```csharp
EqualityComparer<TKey>.Default
```

The comparer determines whether values are duplicates.

### Example 1: Default integer equality

```csharp
int[] numbers =
{
    1, 2, 1, 3, 2
};

var result = numbers.Distinct();

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1, 2, 3
```

Integers are compared by value.

### Example 2: Default string equality

```csharp
string[] names =
{
    "Amit",
    "amit",
    "AMIT",
    "Rahul"
};

var result = names.Distinct();

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
Amit, amit, AMIT, Rahul
```

Default string equality is case-sensitive.

### Example 3: Default record equality

```csharp
record Student(
    int Id,
    string Name
);

Student[] students =
{
    new(1, "Amit"),
    new(1, "Amit"),
    new(2, "Rahul")
};

var result = students.Distinct();

foreach (var student in result)
{
    Console.WriteLine(
        $"{student.Id}: {student.Name}"
    );
}
```

**Output:**

```text
1: Amit
2: Rahul
```

Records provide value-based equality.

### Example 4: Default class equality

```csharp
class Student
{
    public int Id { get; set; }
    public string Name { get; set; } = "";
}
```

```csharp
Student[] students =
{
    new() { Id = 1, Name = "Amit" },
    new() { Id = 1, Name = "Amit" }
};

var result = students.Distinct();

Console.WriteLine(result.Count());
```

**Output:**

```text
2
```

The two objects are separate references.

Because the class does not implement value equality, both remain.

**Key point:** Default equality depends on the element or key type.

## 4. Custom Equality

Custom equality allows distinct operations to use different comparison rules.

The comparer must implement:

```csharp
IEqualityComparer<T>
```

### Example 1: Case-insensitive Distinct

```csharp
string[] names =
{
    "Amit",
    "amit",
    "RAHUL",
    "Rahul",
    "Priya"
};

var result = names.Distinct(
    StringComparer.OrdinalIgnoreCase
);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
Amit, RAHUL, Priya
```

### Example 2: Custom employee comparer

```csharp
record Employee(
    int Id,
    string Name,
    int DepartmentId
);

class EmployeeIdComparer : IEqualityComparer<Employee>
{
    public bool Equals(Employee? x, Employee? y)
    {
        if (ReferenceEquals(x, y))
            return true;

        if (x is null || y is null)
            return false;

        return x.Id == y.Id;
    }

    public int GetHashCode(Employee employee)
    {
        return employee.Id.GetHashCode();
    }
}
```

```csharp
Employee[] employees =
{
    new(1, "Amit", 10),
    new(2, "Rahul", 20),
    new(1, "Amit Kumar", 30)
};

var result = employees.Distinct(
    new EmployeeIdComparer()
);

foreach (var employee in result)
{
    Console.WriteLine(
        $"{employee.Id}: {employee.Name}"
    );
}
```

**Output:**

```text
1: Amit
2: Rahul
```

### Example 3: Custom equality with DistinctBy

```csharp
record Product(
    int Id,
    string Name,
    string Category
);

Product[] products =
{
    new(1, "Mouse", "Electronics"),
    new(2, "Keyboard", "ELECTRONICS"),
    new(3, "Chair", "Furniture"),
    new(4, "Table", "FURNITURE")
};

var result = products.DistinctBy(
    p => p.Category,
    StringComparer.OrdinalIgnoreCase
);

foreach (var product in result)
{
    Console.WriteLine(
        $"{product.Name}: {product.Category}"
    );
}
```

**Output:**

```text
Mouse: Electronics
Chair: Furniture
```

**Key point:** Custom equality comparers control which values or keys count as duplicates.

## 5. Key-Based Distinctness

Key-based distinctness means comparing selected properties rather than entire objects.

`DistinctBy()` is designed for this purpose.

### Example 1: Distinct by one property

```csharp
record Student(
    int Id,
    string Name,
    string City
);

Student[] students =
{
    new(1, "Amit", "Kolkata"),
    new(2, "Rahul", "Delhi"),
    new(3, "Priya", "Kolkata"),
    new(4, "Sneha", "Mumbai")
};

var result = students.DistinctBy(
    s => s.City
);

foreach (var student in result)
{
    Console.WriteLine(
        $"{student.Name}: {student.City}"
    );
}
```

**Output:**

```text
Amit: Kolkata
Rahul: Delhi
Sneha: Mumbai
```

### Example 2: Distinct by composite key

```csharp
record Employee(
    int Id,
    string Name,
    int DepartmentId,
    int Year
);

Employee[] employees =
{
    new(1, "Amit", 10, 2025),
    new(2, "Rahul", 10, 2026),
    new(3, "Priya", 10, 2025),
    new(4, "Sneha", 20, 2026)
};

var result = employees.DistinctBy(
    e => (e.DepartmentId, e.Year)
);

foreach (var employee in result)
{
    Console.WriteLine(
        $"{employee.Name}: {employee.DepartmentId}, {employee.Year}"
    );
}
```

**Output:**

```text
Amit: 10, 2025
Rahul: 10, 2026
Sneha: 20, 2026
```

### Example 3: Anonymous composite key

```csharp
var result = employees.DistinctBy(
    e => new
    {
        e.DepartmentId,
        e.Year
    }
);

foreach (var employee in result)
{
    Console.WriteLine(employee.Name);
}
```

**Output:**

```text
Amit
Rahul
Sneha
```

### Comparison

| Key Selector | Distinctness |
|---|---|
| `x => x.Id` | By ID |
| `x => x.Name` | By name |
| `x => x.DepartmentId` | By department |
| `x => (x.DepartmentId, x.Year)` | By department and year |
| `x => new { x.DepartmentId, x.Year }` | By anonymous composite key |

**Key point:** Key-based distinctness provides flexible duplicate elimination without changing the original object type.

## 6. Duplicate Elimination

Duplicate elimination removes repeated values according to a selected equality rule.

### Example 1: Eliminate repeated integers

```csharp
int[] numbers =
{
    1, 1, 2, 2, 3, 3, 3
};

var result = numbers.Distinct();

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1, 2, 3
```

### Example 2: Eliminate repeated strings

```csharp
string[] names =
{
    "Amit",
    "Rahul",
    "Amit",
    "Priya",
    "Rahul"
};

var result = names.Distinct();

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
Amit, Rahul, Priya
```

### Example 3: Duplicate elimination with DistinctBy

```csharp
record Product(
    int Id,
    string Name
);

Product[] products =
{
    new(1, "Mouse"),
    new(2, "Keyboard"),
    new(1, "Gaming Mouse"),
    new(3, "Monitor")
};

var result = products.DistinctBy(
    p => p.Id
);

foreach (var product in result)
{
    Console.WriteLine(
        $"{product.Id}: {product.Name}"
    );
}
```

**Output:**

```text
1: Mouse
2: Keyboard
3: Monitor
```

### Example 4: Deferred execution

```csharp
List<int> numbers = new()
{
    1, 2, 2
};

var query = numbers.Distinct();

numbers.Add(3);

Console.WriteLine(string.Join(", ", query));
```

**Output:**

```text
1, 2, 3
```

The query is evaluated when enumerated.

### Example 5: Materialized distinct results

```csharp
List<int> numbers = new()
{
    1, 2, 2
};

List<int> result = numbers
    .Distinct()
    .ToList();

numbers.Add(3);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1, 2
```

The result was materialized before the source changed.

**Key point:** Duplicate elimination is based on equality, and deferred queries are evaluated when enumerated.

## 7. Distinct Objects

Objects can be distinct by reference or by value, depending on their equality implementation.

### Example 1: Ordinary class objects

```csharp
class Student
{
    public int Id { get; set; }
    public string Name { get; set; } = "";
}
```

```csharp
Student[] students =
{
    new() { Id = 1, Name = "Amit" },
    new() { Id = 1, Name = "Amit" },
    new() { Id = 2, Name = "Rahul" }
};

var result = students.Distinct();

Console.WriteLine(result.Count());
```

**Output:**

```text
3
```

Each object is a separate reference.

### Example 2: Record objects

```csharp
record Student(
    int Id,
    string Name
);

Student[] students =
{
    new(1, "Amit"),
    new(1, "Amit"),
    new(2, "Rahul")
};

var result = students.Distinct();

Console.WriteLine(result.Count());
```

**Output:**

```text
2
```

Records compare their values.

### Example 3: Anonymous objects

```csharp
var students = new[]
{
    new { Id = 1, Name = "Amit" },
    new { Id = 1, Name = "Amit" },
    new { Id = 2, Name = "Rahul" }
};

var result = students.Distinct();

Console.WriteLine(result.Count());
```

**Output:**

```text
2
```

### Example 4: Custom equality for objects

```csharp
record Student(
    int Id,
    string Name
);

Student[] students =
{
    new(1, "Amit"),
    new(1, "Amit Kumar"),
    new(2, "Rahul")
};

var result = students.DistinctBy(
    s => s.Id
);

Console.WriteLine(result.Count());
```

**Output:**

```text
2
```

**Key point:** Distinctness for objects depends on reference equality, value equality, or an explicitly selected key/comparer.

## 8. Distinct by Property

Distinct by property means selecting one representative object for each unique property value.

### Example 1: Distinct employees by department

```csharp
record Employee(
    int Id,
    string Name,
    string Department
);

Employee[] employees =
{
    new(1, "Amit", "IT"),
    new(2, "Rahul", "HR"),
    new(3, "Priya", "IT"),
    new(4, "Sneha", "Finance")
};

var result = employees.DistinctBy(
    e => e.Department
);

foreach (var employee in result)
{
    Console.WriteLine(
        $"{employee.Name}: {employee.Department}"
    );
}
```

**Output:**

```text
Amit: IT
Rahul: HR
Sneha: Finance
```

### Example 2: Distinct students by city

```csharp
record Student(
    int Id,
    string Name,
    string City
);

Student[] students =
{
    new(1, "Amit", "Kolkata"),
    new(2, "Rahul", "Delhi"),
    new(3, "Priya", "Kolkata"),
    new(4, "Sneha", "Mumbai")
};

var result = students.DistinctBy(
    s => s.City
);

foreach (var student in result)
{
    Console.WriteLine(
        $"{student.Name}: {student.City}"
    );
}
```

**Output:**

```text
Amit: Kolkata
Rahul: Delhi
Sneha: Mumbai
```

### Example 3: Distinct property values only

```csharp
var result = students
    .Select(s => s.City)
    .Distinct();

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
Kolkata, Delhi, Mumbai
```

### Difference

```csharp
students.DistinctBy(s => s.City);
```

Returns:

```text
Student objects
```

Whereas:

```csharp
students.Select(s => s.City).Distinct();
```

Returns:

```text
City strings
```

### Comparison

| Expression | Result |
|---|---|
| `DistinctBy(x => x.Id)` | Unique objects by ID |
| `DistinctBy(x => x.Name)` | Unique objects by name |
| `DistinctBy(x => x.City)` | Unique objects by city |
| `Select(x => x.City).Distinct()` | Unique city values |

**Key point:** Use `DistinctBy()` to retain complete objects and `Select().Distinct()` to return only unique property values.

## 9. Distinct vs GroupBy

`Distinct()` removes duplicates.

`GroupBy()` organizes elements into groups based on matching keys.

### Example 1: Distinct

```csharp
int[] numbers =
{
    1, 1, 2, 2, 3
};

var result = numbers.Distinct();

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1, 2, 3
```

### Example 2: GroupBy

```csharp
int[] numbers =
{
    1, 1, 2, 2, 3
};

var result = numbers.GroupBy(
    n => n
);

foreach (var group in result)
{
    Console.WriteLine(
        $"{group.Key}: {group.Count()}"
    );
}
```

**Output:**

```text
1: 2
2: 2
3: 1
```

### Example 3: DistinctBy vs GroupBy

```csharp
record Employee(
    int Id,
    string Name,
    string Department
);

Employee[] employees =
{
    new(1, "Amit", "IT"),
    new(2, "Priya", "IT"),
    new(3, "Rahul", "HR"),
    new(4, "Sneha", "Finance")
};
```

**Using DistinctBy:**

```csharp
var result = employees.DistinctBy(
    e => e.Department
);

foreach (var employee in result)
{
    Console.WriteLine(
        $"{employee.Department}: {employee.Name}"
    );
}
```

**Output:**

```text
IT: Amit
HR: Rahul
Finance: Sneha
```

**Using GroupBy:**

```csharp
var result = employees.GroupBy(
    e => e.Department
);

foreach (var group in result)
{
    Console.WriteLine(group.Key);

    foreach (var employee in group)
    {
        Console.WriteLine($"  {employee.Name}");
    }
}
```

**Output:**

```text
IT
  Amit
  Priya
HR
  Rahul
Finance
  Sneha
```

### Example 4: GroupBy to select one element per key

```csharp
var result = employees
    .GroupBy(e => e.Department)
    .Select(g => g.First());

foreach (var employee in result)
{
    Console.WriteLine(
        $"{employee.Department}: {employee.Name}"
    );
}
```

**Output:**

```text
IT: Amit
HR: Rahul
Finance: Sneha
```

For this example, it produces the same representatives as `DistinctBy()`.

However, `GroupBy()` also provides access to every element in each group.

### Comparison

| Feature | Distinct | DistinctBy | GroupBy |
|---|---|---|---|
| Purpose | Remove duplicate elements | Remove duplicates by key | Group elements by key |
| Key selector | No | Yes | Yes |
| Output | Unique elements | Representative elements | Groups of elements |
| Retains all members of a group | No | No | Yes |
| Custom equality | Yes | Yes | Yes |
| Typical result type | `IEnumerable<T>` | `IEnumerable<T>` | `IEnumerable<IGrouping<TKey,T>>` |
| Suitable for counting each group | No | No | Yes |
| Suitable for selecting one representative | Yes | Yes | Yes, with additional projection |

**Key point:** `Distinct()` and `DistinctBy()` eliminate duplicates, while `GroupBy()` preserves grouped collections for further processing.
