# 08.07 — SET OPERATIONS

**Chapter:** 08 — LINQ Joins & Set Operations  
**Namespace:** `System.Linq`  
**Total Syllabus Points:** 16

LINQ set operations compare two sequences and return elements based on equality or selected keys.

The six primary operators are:

```csharp
Union()
UnionBy()
Intersect()
IntersectBy()
Except()
ExceptBy()
```

The examples below use LINQ to Objects.

---

## 1. Union

`Union()` combines two sequences and removes duplicate elements.

### Syntax

```csharp
first.Union(second);
```

### Method signatures

```csharp
IEnumerable<TSource> Union<TSource>(
    IEnumerable<TSource> first,
    IEnumerable<TSource> second
);
```

```csharp
IEnumerable<TSource> Union<TSource>(
    IEnumerable<TSource> first,
    IEnumerable<TSource> second,
    IEqualityComparer<TSource>? comparer
);
```

### Example 1: Union of integers

```csharp
int[] first = { 1, 2, 3, 4 };
int[] second = { 3, 4, 5, 6 };

var result = first.Union(second);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1, 2, 3, 4, 5, 6
```

**Explanation:**

```text
First:   1, 2, 3, 4
Second:        3, 4, 5, 6

Union:   1, 2, 3, 4, 5, 6
```

Values `3` and `4` occur in both sequences, but each appears only once in the result.

### Example 2: Union of strings

```csharp
string[] first =
{
    "Amit",
    "Rahul",
    "Priya"
};

string[] second =
{
    "Priya",
    "Sneha",
    "Amit"
};

var result = first.Union(second);

foreach (string name in result)
{
    Console.WriteLine(name);
}
```

**Output:**

```text
Amit
Rahul
Priya
Sneha
```

### Example 3: Union with duplicate elements

```csharp
int[] first = { 1, 1, 2, 2 };
int[] second = { 2, 3, 3, 4 };

var result = first.Union(second);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1, 2, 3, 4
```

Duplicates are removed within and across the input sequences.

### Example 4: Union with a custom comparer

```csharp
string[] first = { "CSharp", "Java" };
string[] second = { "csharp", "Python" };

var result = first.Union(
    second,
    StringComparer.OrdinalIgnoreCase
);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
CSharp, Java, Python
```

`"CSharp"` and `"csharp"` are considered equal.

**Key point:** `Union()` returns all distinct elements from both sequences.

## 2. UnionBy

`UnionBy()` combines two sequences and removes duplicates based on a selected key.

Unlike `Union()`, it compares the extracted keys rather than the complete elements.

### Syntax

```csharp
first.UnionBy(
    second,
    element => element.Key
);
```

### Method signatures

```csharp
IEnumerable<TSource> UnionBy<TSource, TKey>(
    IEnumerable<TSource> first,
    IEnumerable<TSource> second,
    Func<TSource, TKey> keySelector
);
```

```csharp
IEnumerable<TSource> UnionBy<TSource, TKey>(
    IEnumerable<TSource> first,
    IEnumerable<TSource> second,
    Func<TSource, TKey> keySelector,
    IEqualityComparer<TKey>? comparer
);
```

### Example 1: Union employees by ID

```csharp
record Employee(int Id, string Name);

Employee[] first =
{
    new(1, "Amit"),
    new(2, "Rahul")
};

Employee[] second =
{
    new(2, "Rahul Kumar"),
    new(3, "Priya")
};

var result = first.UnionBy(
    second,
    e => e.Id
);

foreach (var employee in result)
{
    Console.WriteLine(
        $"{employee.Id}: {employee.Name}"
    );
}
```

**Output:**

```text
1: Amit
2: Rahul
3: Priya
```

The employee with ID `2` from the second sequence is excluded because that key was already encountered.

### Example 2: Union products by category

```csharp
record Product(
    int Id,
    string Name,
    string Category
);

Product[] first =
{
    new(1, "Mouse", "Electronics"),
    new(2, "Chair", "Furniture")
};

Product[] second =
{
    new(3, "Keyboard", "Electronics"),
    new(4, "Book", "Education")
};

var result = first.UnionBy(
    second,
    p => p.Category
);

foreach (var product in result)
{
    Console.WriteLine(
        $"{product.Name}: {product.Category}"
    );
}
```

**Output:**

```text
Mouse: Electronics
Chair: Furniture
Book: Education
```

### Example 3: UnionBy with composite keys

```csharp
record Employee(
    int Id,
    int Year,
    string Name
);

Employee[] first =
{
    new(1, 2025, "Amit"),
    new(2, 2025, "Rahul")
};

Employee[] second =
{
    new(1, 2025, "Amit Kumar"),
    new(1, 2026, "Amit")
};

var result = first.UnionBy(
    second,
    e => (e.Id, e.Year)
);

foreach (var employee in result)
{
    Console.WriteLine(
        $"{employee.Id}, {employee.Year}: {employee.Name}"
    );
}
```

**Output:**

```text
1, 2025: Amit
2, 2025: Rahul
1, 2026: Amit
```

**Key point:** `UnionBy()` returns complete elements while eliminating duplicates according to selected keys.

## 3. Intersect

`Intersect()` returns distinct elements that exist in both sequences.

### Syntax

```csharp
first.Intersect(second);
```

### Method signatures

```csharp
IEnumerable<TSource> Intersect<TSource>(
    IEnumerable<TSource> first,
    IEnumerable<TSource> second
);
```

```csharp
IEnumerable<TSource> Intersect<TSource>(
    IEnumerable<TSource> first,
    IEnumerable<TSource> second,
    IEqualityComparer<TSource>? comparer
);
```

### Example 1: Integer intersection

```csharp
int[] first = { 1, 2, 3, 4 };
int[] second = { 3, 4, 5, 6 };

var result = first.Intersect(second);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
3, 4
```

**Explanation:**

```text
First:       1, 2, 3, 4
Second:            3, 4, 5, 6

Intersection:      3, 4
```

Only values present in both sequences are returned.

### Example 2: String intersection

```csharp
string[] first =
{
    "Amit",
    "Rahul",
    "Priya"
};

string[] second =
{
    "Rahul",
    "Sneha",
    "Priya"
};

var result = first.Intersect(second);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
Rahul, Priya
```

### Example 3: Intersection with duplicates

```csharp
int[] first = { 1, 2, 2, 3, 3 };
int[] second = { 2, 2, 3, 4 };

var result = first.Intersect(second);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
2, 3
```

Each common value appears only once.

### Example 4: Case-insensitive intersection

```csharp
string[] first =
{
    "CSharp",
    "Java",
    "Python"
};

string[] second =
{
    "csharp",
    "PYTHON",
    "Go"
};

var result = first.Intersect(
    second,
    StringComparer.OrdinalIgnoreCase
);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
CSharp, Python
```

**Key point:** `Intersect()` returns distinct values shared by both sequences.

## 4. IntersectBy

`IntersectBy()` returns elements from the first sequence whose selected keys appear in a second sequence of keys.

### Syntax

```csharp
first.IntersectBy(
    keys,
    element => element.Key
);
```

### Method signatures

```csharp
IEnumerable<TSource> IntersectBy<TSource, TKey>(
    IEnumerable<TSource> first,
    IEnumerable<TKey> second,
    Func<TSource, TKey> keySelector
);
```

```csharp
IEnumerable<TSource> IntersectBy<TSource, TKey>(
    IEnumerable<TSource> first,
    IEnumerable<TKey> second,
    Func<TSource, TKey> keySelector,
    IEqualityComparer<TKey>? comparer
);
```

**Important:** The second sequence contains keys of type `TKey`, not necessarily objects of type `TSource`.

### Example 1: Employees matching selected IDs

```csharp
record Employee(int Id, string Name);

Employee[] employees =
{
    new(1, "Amit"),
    new(2, "Rahul"),
    new(3, "Priya"),
    new(4, "Sneha")
};

int[] selectedIds = { 2, 4 };

var result = employees.IntersectBy(
    selectedIds,
    e => e.Id
);

foreach (var employee in result)
{
    Console.WriteLine(
        $"{employee.Id}: {employee.Name}"
    );
}
```

**Output:**

```text
2: Rahul
4: Sneha
```

### Example 2: Products matching categories

```csharp
record Product(
    int Id,
    string Name,
    string Category
);

Product[] products =
{
    new(1, "Mouse", "Electronics"),
    new(2, "Keyboard", "Electronics"),
    new(3, "Chair", "Furniture"),
    new(4, "Book", "Education")
};

string[] categories =
{
    "Electronics",
    "Furniture"
};

var result = products.IntersectBy(
    categories,
    p => p.Category
);

foreach (var product in result)
{
    Console.WriteLine(
        $"{product.Name}: {product.Category}"
    );
}
```

**Output:**

```text
Mouse: Electronics
Chair: Furniture
```

Only the first matching product for each distinct category is returned.

### Example 3: IntersectBy with composite keys

```csharp
record Employee(
    int Id,
    int Year,
    string Name
);

Employee[] employees =
{
    new(1, 2025, "Amit"),
    new(1, 2026, "Amit"),
    new(2, 2026, "Rahul")
};

var keys = new[]
{
    (Id: 1, Year: 2026),
    (Id: 2, Year: 2026)
};

var result = employees.IntersectBy(
    keys,
    e => (e.Id, e.Year)
);

foreach (var employee in result)
{
    Console.WriteLine(
        $"{employee.Id}, {employee.Year}: {employee.Name}"
    );
}
```

**Output:**

```text
1, 2026: Amit
2, 2026: Rahul
```

**Key point:** `IntersectBy()` returns first-sequence elements whose selected keys occur in the second sequence.

## 5. Except

`Except()` returns distinct elements from the first sequence that do not exist in the second sequence.

### Syntax

```csharp
first.Except(second);
```

### Method signatures

```csharp
IEnumerable<TSource> Except<TSource>(
    IEnumerable<TSource> first,
    IEnumerable<TSource> second
);
```

```csharp
IEnumerable<TSource> Except<TSource>(
    IEnumerable<TSource> first,
    IEnumerable<TSource> second,
    IEqualityComparer<TSource>? comparer
);
```

### Example 1: Integer difference

```csharp
int[] first = { 1, 2, 3, 4 };
int[] second = { 3, 4, 5, 6 };

var result = first.Except(second);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1, 2
```

### Example 2: String difference

```csharp
string[] first =
{
    "Amit",
    "Rahul",
    "Priya"
};

string[] second =
{
    "Rahul",
    "Sneha"
};

var result = first.Except(second);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
Amit, Priya
```

### Example 3: Except with duplicates

```csharp
int[] first = { 1, 1, 2, 3, 3, 4 };
int[] second = { 2, 4 };

var result = first.Except(second);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1, 3
```

Duplicates from the first sequence are eliminated.

### Example 4: Direction matters

```csharp
int[] first = { 1, 2, 3 };
int[] second = { 2, 3, 4 };

var a = first.Except(second);
var b = second.Except(first);

Console.WriteLine(string.Join(", ", a));
Console.WriteLine(string.Join(", ", b));
```

**Output:**

```text
1
4
```

Unlike `Union()` and `Intersect()`, `Except()` is directional.

**Key point:** `Except()` returns distinct values present in the first sequence but absent from the second.

## 7. Element-Based Operations

Element-based operations compare complete elements.

These operators are:

```csharp
Union()
Intersect()
Except()
```

They use equality defined for `TSource`.

### Example 1: Element-based Union

```csharp
int[] first = { 1, 2, 3 };
int[] second = { 3, 4, 5 };

var result = first.Union(second);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1, 2, 3, 4, 5
```

### Example 2: Element-based Intersect

```csharp
int[] first = { 1, 2, 3 };
int[] second = { 3, 4, 5 };

var result = first.Intersect(second);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
3
```

### Example 3: Element-based Except

```csharp
int[] first = { 1, 2, 3 };
int[] second = { 3, 4, 5 };

var result = first.Except(second);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1, 2
```

### Example 4: Element equality with records

```csharp
record Student(int Id, string Name);

Student[] first =
{
    new(1, "Amit"),
    new(2, "Rahul")
};

Student[] second =
{
    new(1, "Amit"),
    new(3, "Priya")
};

var result = first.Intersect(second);

foreach (var student in result)
{
    Console.WriteLine(student.Name);
}
```

**Output:**

```text
Amit
```

The complete record values are compared.

**Key point:** Element-based set operations compare entire elements according to their equality semantics.

## 8. Key-Based Operations

Key-based operations compare selected keys rather than complete elements.

These operators are:

```csharp
UnionBy()
IntersectBy()
ExceptBy()
```

### Example 1: UnionBy

```csharp
record Student(int Id, string Name);

Student[] first =
{
    new(1, "Amit"),
    new(2, "Rahul")
};

Student[] second =
{
    new(2, "Rahul Kumar"),
    new(3, "Priya")
};

var result = first.UnionBy(
    second,
    s => s.Id
);

foreach (var student in result)
{
    Console.WriteLine(student.Name);
}
```

**Output:**

```text
Amit
Rahul
Priya
```

### Example 2: IntersectBy

```csharp
int[] ids = { 1, 3 };

var result = first.IntersectBy(
    ids,
    s => s.Id
);

foreach (var student in result)
{
    Console.WriteLine(student.Name);
}
```

**Output:**

```text
Amit
```

### Example 3: ExceptBy

```csharp
int[] excludedIds = { 1 };

var result = first.ExceptBy(
    excludedIds,
    s => s.Id
);

foreach (var student in result)
{
    Console.WriteLine(student.Name);
}
```

**Output:**

```text
Rahul
```

### Element-based vs key-based operations

| Element-Based | Key-Based | Comparison |
|---|---|---|
| `Union()` | `UnionBy()` | Complete element vs selected key |
| `Intersect()` | `IntersectBy()` | Complete element vs selected key |
| `Except()` | `ExceptBy()` | Complete element vs selected key |

**Important difference:**

```csharp
first.UnionBy(second, x => x.Id);
```

The second argument is a sequence of complete elements.

```csharp
first.IntersectBy(ids, x => x.Id);
```

The second argument is a sequence of keys.

```csharp
first.ExceptBy(ids, x => x.Id);
```

The second argument is also a sequence of keys.

**Key point:** Key-based operators allow set comparisons using selected properties without changing the original element type.

## 9. Duplicate Elimination

LINQ set operations eliminate duplicate values or keys.

Unlike `Concat()`, set operations do not preserve every occurrence.

### Example 1: Union duplicate elimination

```csharp
int[] first = { 1, 1, 2, 2 };
int[] second = { 2, 2, 3, 3 };

var result = first.Union(second);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1, 2, 3
```

### Example 2: Intersect duplicate elimination

```csharp
int[] first = { 1, 2, 2, 3, 3 };
int[] second = { 2, 2, 3, 3 };

var result = first.Intersect(second);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
2, 3
```

### Example 3: Except duplicate elimination

```csharp
int[] first = { 1, 1, 2, 3, 3 };
int[] second = { 2 };

var result = first.Except(second);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1, 3
```

### Example 4: Duplicate elimination by key

```csharp
record Student(int Id, string Name);

Student[] students =
{
    new(1, "Amit"),
    new(1, "Amit Kumar"),
    new(2, "Rahul")
};

var result = students.ExceptBy(
    Array.Empty<int>(),
    s => s.Id
);

foreach (var student in result)
{
    Console.WriteLine(student.Name);
}
```

**Output:**

```text
Amit
Rahul
```

Even with an empty exclusion set, `ExceptBy()` returns distinct keys.

### Duplicate behavior summary

| Operator | Duplicate Elimination |
|---|---|
| `Union()` | By complete element |
| `UnionBy()` | By selected key |
| `Intersect()` | By complete element |
| `IntersectBy()` | By selected key |
| `Except()` | By complete element |
| `ExceptBy()` | By selected key |

**Key point:** Set operators return distinct values or representatives rather than preserving all repeated occurrences.

## 10. Equality Semantics

Equality semantics determine which elements or keys are considered equal.

By default, set operators use:

```csharp
EqualityComparer<T>.Default
```

Custom comparers can override this behavior.

### Example 1: Case-sensitive equality

```csharp
string[] first = { "CSharp", "Java" };
string[] second = { "csharp", "Python" };

var result = first.Intersect(second);

Console.WriteLine(result.Count());
```

**Output:**

```text
0
```

`"CSharp"` and `"csharp"` are different under default string equality.

### Example 2: Case-insensitive equality

```csharp
string[] first = { "CSharp", "Java" };
string[] second = { "csharp", "Python" };

var result = first.Intersect(
    second,
    StringComparer.OrdinalIgnoreCase
);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
CSharp
```

### Example 3: Record equality

```csharp
record Product(int Id, string Name);

Product[] first =
{
    new(1, "Mouse")
};

Product[] second =
{
    new(1, "Mouse")
};

var result = first.Intersect(second);

Console.WriteLine(result.Count());
```

**Output:**

```text
1
```

Records provide value-based equality.

### Example 4: Ordinary class equality

```csharp
class Product
{
    public int Id { get; set; }
    public string Name { get; set; } = "";
}
```

```csharp
Product[] first =
{
    new() { Id = 1, Name = "Mouse" }
};

Product[] second =
{
    new() { Id = 1, Name = "Mouse" }
};

var result = first.Intersect(second);

Console.WriteLine(result.Count());
```

**Output:**

```text
0
```

Without custom equality, the two class instances are considered different.

**Key point:** Equality rules directly determine the results of LINQ set operations.

## 11. Hashing

LINQ set operations commonly use hash-based structures internally.

Hashing supports efficient membership checks and duplicate elimination.

### Hashing process

```text
Element
   │
   ▼
GetHashCode()
   │
   ▼
Hash-Based Lookup
   │
   ▼
Equality Comparison
   │
   ├── Equal     → Existing value/key
   │
   └── Not Equal → New value/key
```

### Example 1: Equal values have equal hash codes

```csharp
int a = 10;
int b = 10;

Console.WriteLine(a.Equals(b));

Console.WriteLine(
    a.GetHashCode() == b.GetHashCode()
);
```

**Output:**

```text
True
True
```

### Example 2: HashSet and Union

```csharp
int[] first = { 1, 2, 3 };
int[] second = { 3, 4, 5 };

var result = first.Union(second);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1, 2, 3, 4, 5
```

The operation tracks previously encountered values to avoid duplicates.

### Example 3: Hashing with custom objects

```csharp
class Student : IEquatable<Student>
{
    public int Id { get; init; }

    public bool Equals(Student? other)
    {
        return other is not null &&
               Id == other.Id;
    }

    public override bool Equals(object? obj)
    {
        return obj is Student other &&
               Equals(other);
    }

    public override int GetHashCode()
    {
        return Id.GetHashCode();
    }
}
```

```csharp
Student[] first =
{
    new() { Id = 1 },
    new() { Id = 2 }
};

Student[] second =
{
    new() { Id = 2 },
    new() { Id = 3 }
};

var result = first.Union(second);

foreach (var student in result)
{
    Console.WriteLine(student.Id);
}
```

**Output:**

```text
1
2
3
```

### Hashing requirements

For hash-based equality:

- Equal values must have equal hash codes.
- Unequal values may have identical hash codes.
- Hash collisions must be resolved using equality checks.
- Equality-relevant values should remain stable during the operation.

**Key point:** Hashing enables efficient duplicate elimination and membership testing.

## 12. Custom Comparers

Custom comparers define how elements or keys are compared.

They implement:

```csharp
IEqualityComparer<T>
```

### Example 1: Custom employee comparer

```csharp
record Employee(
    int Id,
    string Name
);

class EmployeeIdComparer : IEqualityComparer<Employee>
{
    public bool Equals(Employee? x, Employee? y)
    {
        if (ReferenceEquals(x, y))
            return true;

        if (x is null || y is null)
            return false;

        return x.Id == y.Id;
    }

    public int GetHashCode(Employee employee)
    {
        return employee.Id.GetHashCode();
    }
}
```

### Example 2: Union with custom comparer

```csharp
Employee[] first =
{
    new(1, "Amit"),
    new(2, "Rahul")
};

Employee[] second =
{
    new(2, "Rahul Kumar"),

var result = first.Union(

foreach (var employee in result)
{

    );
}
```

**Output:**

```text
1: Amit
2: Rahul
3: Priya
```

### Example 3: Intersect with custom comparer

```csharp
var result = first.Intersect(
    second,
    new EmployeeIdComparer()
);

foreach (var employee in result)
{
    Console.WriteLine(employee.Name);
}
```

**Output:**


### Example 4: Except with custom comparer

```csharp
var result = first.Except(

);

foreach (var employee in result)
```

### Example 5: Custom comparer with key-based operations

```csharp
record Product(

Product[] products =
```

## 13. Deferred Execution

LINQ set operations use deferred execution.

Calling an operator constructs a query without immediately producing its final results.

The query executes when enumerated.

### Example 1: Deferred Union

```csharp
List<int> first = new()
{
    1, 2
};

List<int> second = new()
{
    3, 4
};

var query = first.Union(second);

first.Add(5);

Console.WriteLine(string.Join(", ", query));
```

**Output:**

```text
1, 2, 5, 3, 4
```

The value `5` is included because the source changed before enumeration.

### Example 2: Deferred Except

```csharp
List<int> first = new()
{
    1, 2, 3
};

List<int> second = new()
{
    3
};

var query = first.Except(second);

second.Add(2);

Console.WriteLine(string.Join(", ", query));
```

**Output:**

```text
1
```

The updated second sequence excludes both `2` and `3`.

### Example 3: Deferred Intersect

```csharp
List<int> first = new()
{
    1, 2, 3
};

List<int> second = new()
{
    2
};

var query = first.Intersect(second);

second.Add(3);

Console.WriteLine(string.Join(", ", query));
```

**Output:**

```text
2, 3
```

### Example 4: Materialization

```csharp
List<int> first = new()
{
    1, 2
};

List<int> second = new()
{
    2, 3
};

List<int> result = first
    .Union(second)
    .ToList();

first.Add(4);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1, 2, 3
```

`ToList()` executes and materializes the query.

**Key point:** Set-operation queries are deferred, so changes to their sources before enumeration can affect their results.

## 14. Buffering

Buffering means temporarily storing elements or keys during query execution.

Set operations use internal storage to track previously encountered values or keys.

### Example 1: Union buffering

```csharp
int[] first =
{
    1, 2, 2, 3
};

int[] second =
{
    3, 4, 4, 5
};

var result = first.Union(second);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1, 2, 3, 4, 5
```

The operation tracks values already produced.

### Example 2: Intersect buffering

```csharp
int[] first =
{
    1, 2, 3, 4
};

int[] second =
{
    2, 4, 6
};

var result = first.Intersect(second);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
2, 4
```

For LINQ to Objects, `Intersect()` builds an internal set from the second sequence before yielding matching elements from the first.

### Example 3: Except buffering

```csharp
int[] first =
{
    1, 2, 3, 4
};

int[] second =
{
    2, 4
};

var result = first.Except(second);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1, 3
```

The operation tracks excluded values and values already yielded.

### Example 4: Buffering and memory usage

```csharp
int[] first = Enumerable.Range(1, 1000).ToArray();
int[] second = Enumerable.Range(500, 1000).ToArray();

var result = first.Intersect(second);

Console.WriteLine(result.Count());
```

**Output:**

```text
501
```

The intersection contains integers from `500` through `1000`, inclusive.

### Buffering comparison

| Operator | Internal Tracking |
|---|---|
| `Union()` | Previously encountered elements |
| `UnionBy()` | Previously encountered keys |
| `Intersect()` | Second-sequence elements and matched values |
| `IntersectBy()` | Second-sequence keys and matched keys |
| `Except()` | Excluded elements and previously returned values |
| `ExceptBy()` | Excluded keys and previously returned keys |

### Memory considerations

The memory required generally depends on the number of distinct values or keys stored internally.

For typical LINQ to Objects implementations:

- `Union()` maintains a growing set of encountered values.
- `Intersect()` stores values from the second sequence.
- `Except()` stores excluded values and newly encountered first-sequence values.
- The `By` variants use selected keys for their sets.

**Key point:** Set operations use internal buffering for equality-based membership checks and duplicate elimination.

## 15. Ordering Considerations

LINQ set operations return sequences, so the order in which elements are produced matters.

For LINQ to Objects, current implementations generally return representatives in the order they are first encountered or selected.

However, set-operation documentation treats results as unordered, so applications requiring guaranteed ordering should use an explicit ordering operation.

### Example 1: Union ordering

```csharp
int[] first =
{
    3, 1, 2
};

int[] second =
{
    2, 5, 4
};

var result = first.Union(second);

Console.WriteLine(string.Join(", ", result));
```

**Typical LINQ to Objects output:**

```text
3, 1, 2, 5, 4
```

The first sequence is processed before new values from the second sequence.

### Example 2: Intersect ordering

```csharp
int[] first =
{
    4, 2, 1, 3
};

int[] second =
{
    3, 4, 2
};

var result = first.Intersect(second);

Console.WriteLine(string.Join(", ", result));
```

**Typical LINQ to Objects output:**

```text
4, 2, 3
```

The matching values are encountered in the first sequence.

### Example 3: Except ordering

```csharp
int[] first =
{
    5, 3, 1, 4, 2
};

int[] second =
{
    3, 4
};

var result = first.Except(second);

Console.WriteLine(string.Join(", ", result));
```

**Typical LINQ to Objects output:**

```text
5, 1, 2
```

### Example 4: Explicit ascending ordering

```csharp
int[] first =
{
    5, 1, 3
};

int[] second =
{
    4, 2, 3
};

var result = first
    .Union(second)
    .OrderBy(x => x);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1, 2, 3, 4, 5
```

### Example 5: Explicit descending ordering

```csharp
int[] first =
{
    5, 1, 3
};

int[] second =
{
    4, 2, 3
};

var result = first
    .Union(second)
    .OrderByDescending(x => x);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
5, 4, 3, 2, 1
```

### Example 6: Ordering key-based results

```csharp
record Employee(
    int Id,
    string Name
);

Employee[] first =
{
    new(3, "Priya"),
    new(1, "Amit")
};

Employee[] second =
{
    new(2, "Rahul"),
    new(3, "Priya Kumar")
};

var result = first
    .UnionBy(second, e => e.Id)
    .OrderBy(e => e.Id);

foreach (var employee in result)
{
    Console.WriteLine(
        $"{employee.Id}: {employee.Name}"
    );
}
```

**Output:**

```text
1: Amit
2: Rahul
3: Priya
```

### Ordering summary

| Operation | Typical LINQ to Objects Enumeration |
|---|---|
| `Union()` | First-sequence representatives, then new second-sequence representatives |
| `UnionBy()` | First encountered element for each key |
| `Intersect()` | First-sequence elements whose values match |
| `IntersectBy()` | First-sequence elements whose keys match |
| `Except()` | First-sequence elements not excluded |
| `ExceptBy()` | First-sequence elements whose keys are not excluded |

**Key point:** Use `OrderBy()` or `OrderByDescending()` when a specific output order is required.
