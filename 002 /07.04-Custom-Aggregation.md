# 07.04 — CUSTOM AGGREGATION

**Chapter:** 07 — LINQ Aggregation & Grouping  
**Namespace:** `System.Linq`  
**Total Syllabus Topics:** 16

Custom aggregation allows multiple elements of a sequence to be combined into a single result using developer-defined logic.

The main LINQ operator for custom aggregation is **`Aggregate()`**.

---

## 1. Aggregate

`Aggregate()` combines elements of a sequence by repeatedly applying an accumulator function.

It can calculate sums, products, concatenated strings, and custom summary objects.

### Syntax

```csharp
source.Aggregate((accumulator, current) => expression);
```

### Example 1: Sum

```csharp
int[] numbers = { 10, 20, 30, 40 };

int result = numbers.Aggregate(
    (total, number) => total + number
);

Console.WriteLine(result);
```

**Output:**

```text
100
```

### Execution

```text
10 + 20 = 30
30 + 30 = 60
60 + 40 = 100
```

### Example 2: Product

```csharp
int[] numbers = { 2, 3, 4, 5 };

int result = numbers.Aggregate(
    (product, number) => product * number
);

Console.WriteLine(result);
```

**Output:**

```text
120
```

### Example 3: Find maximum

```csharp
int[] numbers = { 10, 50, 20, 40 };

int result = numbers.Aggregate(
    (maximum, number) =>
        maximum > number ? maximum : number
);

Console.WriteLine(result);
```

**Output:**

```text
50
```

**Key point:** `Aggregate()` allows custom accumulation logic rather than relying on a predefined aggregation operator.

---

## 2. Aggregate without Seed

This overload does not require an explicitly supplied starting value.

The first element becomes the initial accumulator.

### Syntax

```csharp
source.Aggregate((accumulator, current) => expression);
```

### Example 1: Addition

```csharp
int[] numbers = { 1, 2, 3, 4 };

int result = numbers.Aggregate(
    (a, b) => a + b
);

Console.WriteLine(result);
```

**Output:**

```text
10
```

### Execution

| Step | Accumulator | Current | Result |
|---|---:|---:|---:|
| Initial | 1 | — | 1 |
| 1 | 1 | 2 | 3 |
| 2 | 3 | 3 | 6 |
| 3 | 6 | 4 | 10 |

### Example 2: Multiplication

```csharp
int[] numbers = { 2, 3, 4 };

int result = numbers.Aggregate(
    (a, b) => a * b
);

Console.WriteLine(result);
```

**Output:**

```text
24
```

### Example 3: Subtraction

```csharp
int[] numbers = { 20, 5, 3 };

int result = numbers.Aggregate(
    (a, b) => a - b
);

Console.WriteLine(result);
```

**Output:**

```text
12
```

### Important rules

- The first element is the initial accumulator.
- Processing starts with the second element.
- The accumulator has the same type as the source elements.
- An empty sequence throws `InvalidOperationException`.
- A sequence with one element returns that element without invoking the accumulator function.

## 3. Aggregate with Seed

A seed is an explicitly supplied initial accumulator value.

### Syntax

```csharp
source.Aggregate(
    seed,
    (accumulator, current) => expression
);
```

### Example 1: Sum with seed

```csharp
int[] numbers = { 10, 20, 30 };

int result = numbers.Aggregate(
    100,
    (total, number) => total + number
);

Console.WriteLine(result);
```

**Output:**

```text
160
```

### Execution

```text
Seed = 100

100 + 10 = 110
110 + 20 = 130
130 + 30 = 160
```

### Example 2: Product with seed

```csharp
int[] numbers = { 2, 3, 4 };

int result = numbers.Aggregate(
    1,
    (product, number) => product * number
);

Console.WriteLine(result);
```

**Output:**

```text
24
```

### Example 3: Different accumulator type

```csharp
int[] numbers = { 10, 20, 30 };

long result = numbers.Aggregate(
    0L,
    (total, number) => total + number
);

Console.WriteLine(result);
```

**Output:**

```text
60
```

### Example 4: Count elements

```csharp
string[] names = { "Amit", "Rahul", "Priya" };

int count = names.Aggregate(
    0,
    (total, name) => total + 1
);

Console.WriteLine(count);
```

**Output:**

```text
3
```

**Key point:** The seed determines the starting accumulator value and can establish an accumulator type different from the source element type.

## 4. Aggregate with Seed and Result Selector

This overload supports a final transformation of the accumulated value.

### Syntax

```csharp
source.Aggregate(
    seed,
    (accumulator, current) => expression,
    accumulator => finalResult
);
```

### Example 1: Sum with formatted result

```csharp
int[] numbers = { 10, 20, 30 };

string result = numbers.Aggregate(
    0,
    (total, number) => total + number,
    total => $"Total = {total}"
);

Console.WriteLine(result);
```

**Output:**

```text
Total = 60
```

### Example 2: Product with result selector

```csharp
int[] numbers = { 2, 3, 4 };

string result = numbers.Aggregate(
    1,
    (product, number) => product * number,
    product => $"Product: {product}"
);

Console.WriteLine(result);
```

**Output:**

```text
Product: 24
```

### Example 3: Average using custom aggregation

```csharp
int[] numbers = { 10, 20, 30, 40 };

double average = numbers.Aggregate(
    (Sum: 0L, Count: 0),
    (acc, number) => (
        Sum: acc.Sum + number,
        Count: acc.Count + 1
    ),
    acc => acc.Count == 0
        ? 0.0
        : (double)acc.Sum / acc.Count
);

Console.WriteLine(average);
```

**Output:**

```text
25
```

### Execution

```text
Source
   │
   ▼
Seed
   │
   ▼
Accumulator Function
   │
   ▼
Accumulated Value
   │
   ▼
Result Selector
   │
   ▼
Final Result
```

**Key point:** The result selector allows the final result type to differ from the accumulator type.

## 5. Seed

The seed is the initial value used before processing source elements.

### Syntax

```csharp
source.Aggregate(seed, accumulatorFunction);
```

### Example 1: Zero seed

```csharp
int[] numbers = { 1, 2, 3 };

int result = numbers.Aggregate(
    0,
    (a, b) => a + b
);

Console.WriteLine(result);
```

**Output:**

```text
6
```

### Example 2: Nonzero seed

```csharp
int[] numbers = { 1, 2, 3 };

int result = numbers.Aggregate(
    10,
    (a, b) => a + b
);

Console.WriteLine(result);
```

**Output:**

```text
16
```

### Example 3: Multiplication seed

```csharp
int[] numbers = { 2, 3, 4 };

int result = numbers.Aggregate(
    1,
    (a, b) => a * b
);

Console.WriteLine(result);
```

**Output:**

```text
24
```

### Example 4: String seed

```csharp
string[] words = { "C#", "LINQ" };

string result = words.Aggregate(
    "Topics:",
    (text, word) => text + " " + word
);

Console.WriteLine(result);
```

**Output:**

```text
Topics: C# LINQ
```

### Common seed values

| Operation | Typical Seed |
|---|---|
| Addition | `0` |
| Multiplication | `1` |
| String construction | `""` |
| Counting | `0` |
| List accumulation | New empty list |
| Custom summary | Initialized summary object |

The appropriate seed depends on the operation's intended behavior.

## 6. Accumulator

The accumulator is the function that combines the current accumulated state with each source element.

### Syntax

```csharp
(accumulator, current) => expression
```

### Example 1: Addition accumulator

```csharp
int[] numbers = { 10, 20, 30 };

int result = numbers.Aggregate(
    0,
    (total, number) => total + number
);
```

Here:

```csharp
(total, number) => total + number
```

is the accumulator function.

### Example 2: Maximum accumulator

```csharp
int[] numbers = { 10, 50, 20 };

int maximum = numbers.Aggregate(
    int.MinValue,
    (currentMax, number) =>
        Math.Max(currentMax, number)
);

Console.WriteLine(maximum);
```

**Output:**

```text
50
```

### Example 3: Explicit Func

```csharp
Func<int, int, int> accumulator =
    (total, number) => total + number;

int[] numbers = { 10, 20, 30 };

int result = numbers.Aggregate(
    0,
    accumulator
);

Console.WriteLine(result);
```

**Output:**

```text
60
```

### Example 4: Accumulator with conditions

```csharp
int[] numbers = { 1, 2, 3, 4, 5 };

int result = numbers.Aggregate(
    0,
    (total, number) =>
        number % 2 == 0
            ? total + number
            : total
);

Console.WriteLine(result);
```

**Output:**

```text
6
```

**Key point:** The accumulator receives the previous state and the current element, then returns the next state.

## 7. Accumulator Type

The accumulator type is the type of the intermediate state maintained during aggregation.

With a seed, it can differ from the source element type.

### Example 1: Integer accumulator

```csharp
int[] numbers = { 10, 20, 30 };

int result = numbers.Aggregate(
    0,
    (total, number) => total + number
);
```

**Accumulator type:** `int`

### Example 2: Long accumulator

```csharp
int[] numbers = { 10, 20, 30 };

long result = numbers.Aggregate(
    0L,
    (total, number) => total + number
);
```

**Accumulator type:** `long`

### Example 3: String accumulator

```csharp
int[] numbers = { 1, 2, 3 };

string result = numbers.Aggregate(
    "",
    (text, number) => text + number
);

Console.WriteLine(result);
```

**Output:**

```text
123
```

**Accumulator type:** `string`

### Example 4: Tuple accumulator

```csharp
int[] numbers = { 10, 20, 30 };

var result = numbers.Aggregate(
    (Sum: 0, Count: 0),
    (acc, number) => (
        Sum: acc.Sum + number,
        Count: acc.Count + 1
    )
);

Console.WriteLine(result.Sum);
Console.WriteLine(result.Count);
```

**Output:**

```text
60
3
```

**Accumulator type:** `(int Sum, int Count)`

### Comparison

| Source Type | Accumulator Type | Possible Result |
|---|---|---|
| `int` | `int` | Integer sum |
| `int` | `long` | Larger integer sum |
| `int` | `string` | Concatenated text |
| `int` | Tuple | Multiple statistics |
| Object | Custom class | Summary object |

## 8. Result Selector

A result selector converts the completed accumulator into the final output.

### Syntax

```csharp
accumulator => finalResult
```

### Example 1: Numeric result to string

```csharp
int[] numbers = { 10, 20, 30 };

string result = numbers.Aggregate(
    0,
    (sum, number) => sum + number,
    sum => $"Sum = {sum}"
);

Console.WriteLine(result);
```

**Output:**

```text
Sum = 60
```

### Example 2: Calculate average

```csharp
int[] numbers = { 10, 20, 30 };

double result = numbers.Aggregate(
    (Sum: 0, Count: 0),
    (acc, number) => (
        Sum: acc.Sum + number,
        Count: acc.Count + 1
    ),
    acc => (double)acc.Sum / acc.Count
);

Console.WriteLine(result);
```

**Output:**

```text
20
```

### Example 3: Boolean result

```csharp
int[] numbers = { 10, 20, 30 };

bool result = numbers.Aggregate(
    0,
    (sum, number) => sum + number,
    sum => sum > 50
);

Console.WriteLine(result);
```

**Output:**

```text
True
```

### Example 4: Anonymous result

```csharp
int[] numbers = { 10, 20, 30 };

var result = numbers.Aggregate(
    0,
    (sum, number) => sum + number,
    sum => new
    {
        Total = sum,
        IsLarge = sum > 50
    }
);

Console.WriteLine(result.Total);
Console.WriteLine(result.IsLarge);
```

**Output:**

```text
60
True
```

**Key point:** The result selector executes once after accumulation finishes.

## 9. Running Totals

A running total is the cumulative sum calculated as each element is processed.

### Example 1: Final cumulative total

```csharp
int[] numbers = { 10, 20, 30, 40 };

int result = numbers.Aggregate(
    0,
    (total, number) => total + number
);

Console.WriteLine(result);
```

**Output:**

```text
100
```

### Example 2: Observe intermediate totals

```csharp
int[] numbers = { 10, 20, 30 };

int result = numbers.Aggregate(
    0,
    (total, number) =>
    {
        int next = total + number;

        Console.WriteLine(next);

        return next;
    }
);
```

**Output:**

```text
10
30
60
```

### Example 3: Store running totals

```csharp
int[] numbers = { 10, 20, 30, 40 };

List<int> totals = numbers.Aggregate(
    new List<int>(),
    (list, number) =>
    {
        int previous = list.Count == 0
            ? 0
            : list[^1];

        list.Add(previous + number);

        return list;
    }
);

Console.WriteLine(string.Join(", ", totals));
```

**Output:**

```text
10, 30, 60, 100
```

### Example 4: Running product

```csharp
int[] numbers = { 2, 3, 4 };

List<int> products = numbers.Aggregate(
    new List<int>(),
    (list, number) =>
    {
        int previous = list.Count == 0
            ? 1
            : list[^1];

        list.Add(previous * number);

        return list;
    }
);

Console.WriteLine(string.Join(", ", products));
```

**Output:**

```text
2, 6, 24
```

**Key point:** `Aggregate()` naturally computes a final cumulative value. Collecting every intermediate value requires additional accumulator state.


### Example 3: String with seed

```csharp
int[] numbers = { 1, 2, 3 };
```

```csharp
using System.Text;

string[] words = { "C#", "LINQ", "Aggregate" };

string result = words.Aggregate(

    {

```

## 11. Composite Summaries

A composite summary contains multiple calculated values.

`Aggregate()` can compute several statistics in one pass.

### Example 1: Sum and count

```csharp
int[] numbers = { 10, 20, 30, 40 };

var result = numbers.Aggregate(
    (Sum: 0, Count: 0),
    (acc, number) => (
        Sum: acc.Sum + number,
        Count: acc.Count + 1
    )
);

Console.WriteLine(result.Sum);
Console.WriteLine(result.Count);
```

**Output:**

```text
100
4
```

### Example 2: Sum, count, and average

```csharp
int[] numbers = { 10, 20, 30, 40 };

var result = numbers.Aggregate(
    (Sum: 0, Count: 0),
    (acc, number) => (
        Sum: acc.Sum + number,
        Count: acc.Count + 1
    ),
    acc => new
    {
        acc.Sum,
        acc.Count,
        Average = acc.Count == 0
            ? 0.0
            : (double)acc.Sum / acc.Count
    }
);

Console.WriteLine(result.Sum);
Console.WriteLine(result.Count);
Console.WriteLine(result.Average);
```

**Output:**

```text
100
4
25
```

### Example 3: Minimum and maximum

```csharp
int[] numbers = { 10, 40, 20, 30 };

var result = numbers.Aggregate(
    (Min: int.MaxValue, Max: int.MinValue),
    (acc, number) => (
        Min: Math.Min(acc.Min, number),
        Max: Math.Max(acc.Max, number)
    )
);

Console.WriteLine(result.Min);
Console.WriteLine(result.Max);
```

**Output:**

```text
10
40
```

For an empty sequence, this particular implementation retains its sentinel values. It should therefore be adjusted if empty-input minimum and maximum values need special handling.

### Example 4: Custom summary record

```csharp
record Summary(int Total, int Count);

int[] numbers = { 10, 20, 30 };

Summary result = numbers.Aggregate(
    new Summary(0, 0),
    (acc, number) => new Summary(
        acc.Total + number,
        acc.Count + 1
    )
);

Console.WriteLine(result);
```

**Output:**

```text
Summary { Total = 60, Count = 3 }
```

**Key point:** Composite summaries allow several related results to be calculated during a single traversal.

## 12. Mutable Accumulator

A mutable accumulator changes the state of an existing object during aggregation.

### Example 1: Mutable list

```csharp
int[] numbers = { 1, 2, 3 };

List<int> result = numbers.Aggregate(
    new List<int>(),
    (list, number) =>
    {
        list.Add(number * 2);
        return list;
    }
);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
2, 4, 6
```

### Example 2: Mutable summary class

```csharp
class Summary
{
    public int Sum { get; set; }
    public int Count { get; set; }
}
```

```csharp
int[] numbers = { 10, 20, 30 };

Summary result = numbers.Aggregate(
    new Summary(),
    (acc, number) =>
    {
        acc.Sum += number;
        acc.Count++;

        return acc;
    }
);

Console.WriteLine(result.Sum);
Console.WriteLine(result.Count);
```

**Output:**

```text
60
3
```

### Example 3: Mutable dictionary

```csharp
string[] words = { "A", "B", "A", "C", "B", "A" };

Dictionary<string, int> result = words.Aggregate(
    new Dictionary<string, int>(),
    (dictionary, word) =>
    {
        dictionary.TryGetValue(word, out int count);

        dictionary[word] = count + 1;

        return dictionary;
    }
);

foreach (var item in result)
{
    Console.WriteLine($"{item.Key}: {item.Value}");
}
```

**Output:**

```text
A: 3
B: 2
C: 1
```

### Characteristics

- Updates the same accumulator object.
- Can reduce intermediate object allocations.
- Requires careful management of shared state.
- May be unsuitable for parallel aggregation without synchronization or separate local accumulators.

## 13. Immutable Accumulator

An immutable accumulator creates a new state value instead of modifying an existing one.

### Example 1: Integer accumulator

```csharp
int[] numbers = { 10, 20, 30 };

int result = numbers.Aggregate(
    0,
    (total, number) => total + number
);

Console.WriteLine(result);
```

**Output:**

```text
60
```

Each step calculates a new integer value.

### Example 2: Immutable record

```csharp
record Summary(int Sum, int Count);
```

```csharp
int[] numbers = { 10, 20, 30 };

Summary result = numbers.Aggregate(
    new Summary(0, 0),
    (acc, number) => acc with
    {
        Sum = acc.Sum + number,
        Count = acc.Count + 1
    }
);

Console.WriteLine(result);
```

**Output:**

```text
Summary { Sum = 60, Count = 3 }
```

### Example 3: ValueTuple accumulator

```csharp
int[] numbers = { 10, 20, 30 };

var result = numbers.Aggregate(
    (Sum: 0, Count: 0),
    (acc, number) => (
        Sum: acc.Sum + number,
        Count: acc.Count + 1
    )
);

Console.WriteLine(result);
```

**Output:**

```text
(60, 3)
```

### Comparison

| Feature | Mutable Accumulator | Immutable Accumulator |
|---|---|---|
| State changes | Existing object updated | New state produced |
| Typical examples | `List<T>`, `StringBuilder` | Records, tuples, numeric values |
| Allocation behavior | May reuse storage | May allocate new objects |
| Shared-state concerns | Greater | Generally fewer |
| Reasoning about state | Requires mutation tracking | State transitions are explicit |

**Key point:** Immutable accumulation makes state changes explicit, while mutable accumulation can be more efficient for certain workloads.

## 14. Associativity

An operation is associative when changing the grouping of operands does not change the result.

### Mathematical definition

\[
(a \circ b)\circ c=a\circ(b\circ c)
\]

### Example 1: Addition

\[
(10+20)+30=10+(20+30)
\]

Both produce:

\[
60
\]

```csharp
int a = (10 + 20) + 30;
int b = 10 + (20 + 30);

Console.WriteLine(a == b);
```

**Output:**

```text
True
```

### Example 2: Multiplication

\[
(2\times3)\times4=2\times(3\times4)
\]

Both produce:

\[
24
\]

```csharp
int a = (2 * 3) * 4;
int b = 2 * (3 * 4);

Console.WriteLine(a == b);
```

**Output:**

```text
True
```

### Example 3: Subtraction is not associative

\[
(20-5)-3=12
\]

\[
20-(5-3)=18
\]

```csharp
int a = (20 - 5) - 3;
int b = 20 - (5 - 3);

Console.WriteLine(a == b);
```

**Output:**

```text
False
```

### Example 4: Aggregate uses left accumulation

```csharp
int[] numbers = { 20, 5, 3 };

int result = numbers.Aggregate(
    (a, b) => a - b
);

Console.WriteLine(result);
```

**Output:**

```text
12
```

The calculation is:

```text
(20 - 5) - 3
```

### Important distinction

Mathematical addition is associative, but fixed-width integer overflow and floating-point rounding can affect the behavior of actual computations.

For example, floating-point addition is not strictly associative.

**Key point:** Associativity matters when determining whether partial aggregation results can be regrouped or combined safely.

## 15. Order Dependence

An aggregation is order-dependent when changing the order of source elements changes the result.

### Example 1: Addition

```csharp
int[] first = { 10, 20, 30 };
int[] second = { 30, 20, 10 };

Console.WriteLine(first.Aggregate((a, b) => a + b));
Console.WriteLine(second.Aggregate((a, b) => a + b));
```

**Output:**

```text
60
60
```

### Example 2: Subtraction

```csharp
int[] first = { 20, 5, 3 };
int[] second = { 3, 5, 20 };

Console.WriteLine(first.Aggregate((a, b) => a - b));
Console.WriteLine(second.Aggregate((a, b) => a - b));
```

**Output:**

```text
12
-22
```

### Example 3: String concatenation

```csharp
string[] first = { "A", "B", "C" };
string[] second = { "C", "B", "A" };

Console.WriteLine(first.Aggregate((a, b) => a + b));
Console.WriteLine(second.Aggregate((a, b) => a + b));
```

**Output:**

```text
ABC
CBA
```

### Example 4: Division

```csharp
double[] first = { 100, 10, 2 };
double[] second = { 2, 10, 100 };

Console.WriteLine(first.Aggregate((a, b) => a / b));
Console.WriteLine(second.Aggregate((a, b) => a / b));
```

**Output:**

```text
5
0.002
```

### Comparison

| Operation | Order-Dependent? |
|---|---|
| Integer addition without overflow | No |
| Integer multiplication without overflow | No |
| Subtraction | Yes |
| Division | Yes |
| String concatenation | Yes |
| Minimum | No |
| Maximum | No |
| Floating-point addition | Potentially |

**Key point:** Preserve source order when the accumulator logic depends on element ordering.

## 16. Empty Sequence Behavior

The behavior of `Aggregate()` on an empty sequence depends on the overload.

### Example 1: Without seed

```csharp
int[] numbers = Array.Empty<int>();

int result = numbers.Aggregate(
    (a, b) => a + b
);
```

**Result:**

```text
InvalidOperationException
```

An empty sequence has no first element to use as the initial accumulator.

### Example 2: With seed

```csharp
int[] numbers = Array.Empty<int>();

int result = numbers.Aggregate(
    100,
    (total, number) => total + number
);

Console.WriteLine(result);
```

**Output:**

```text
100
```

The seed is returned unchanged.

### Example 3: With seed and result selector

```csharp
int[] numbers = Array.Empty<int>();

string result = numbers.Aggregate(
    0,
    (total, number) => total + number,
    total => $"Total = {total}"
);

Console.WriteLine(result);
```

**Output:**

```text
Total = 0
```

The accumulator function is not called, but the result selector executes.

### Example 4: Empty string aggregation

```csharp
string[] words = Array.Empty<string>();

string result = words.Aggregate(
    "",
    (text, word) => text + word
);

Console.WriteLine(result == "");
```

**Output:**

```text
True
```

### Example 5: Empty composite summary

```csharp
int[] numbers = Array.Empty<int>();

var result = numbers.Aggregate(
    (Sum: 0, Count: 0),
    (acc, number) => (
        Sum: acc.Sum + number,
        Count: acc.Count + 1
    )
);

Console.WriteLine(result.Sum);
Console.WriteLine(result.Count);
```

**Output:**

```text
0
0
```

### Empty sequence comparison

| Aggregate Overload | Empty Sequence Behavior |
|---|---|
| Without seed | Throws `InvalidOperationException` |
| With seed | Returns seed |
| With seed and result selector | Applies result selector to seed |
