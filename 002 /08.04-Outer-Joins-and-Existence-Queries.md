# 08.04 — OUTER JOINS & EXISTENCE QUERIES

**Chapter:** 08 — LINQ Joins & Set Operations  
**Namespace:** `System.Linq`  
**Total Syllabus Topics:** 16

Outer joins combine two sequences while preserving records that do not have matching keys.

Existence queries determine whether related records exist without necessarily returning those records.

This section covers all **16 syllabus points in their original order**, with C# examples and outputs.

---

## 1. Left Outer Join

A **left outer join** returns every element from the left (outer) sequence.

When a matching element exists in the right (inner) sequence, the two elements are combined.

When no matching element exists, the left element is still included.

### Structure

```text
LEFT SOURCE                 RIGHT SOURCE

Amit  ──────────────────── IT
Rahul ──────────────────── HR
Priya ──────────────────── IT
Sneha ──────────────────── No Match

RESULT

Amit  → IT
Rahul → HR
Priya → IT
Sneha → null
```

### Example 1: Employees and departments

```csharp
record Employee(int Id, string Name, int DepartmentId);
record Department(int Id, string Name);

Employee[] employees =
{
    new(1, "Amit", 10),
    new(2, "Rahul", 20),
    new(3, "Priya", 10),
    new(4, "Sneha", 30)
};

Department[] departments =
{
    new(10, "IT"),
    new(20, "HR")
};

var result =
    from e in employees
    join d in departments
        on e.DepartmentId equals d.Id into departmentGroup
    from d in departmentGroup.DefaultIfEmpty()
    select new
    {
        Employee = e.Name,
        Department = d?.Name ?? "Not Assigned"
    };

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Employee}: {item.Department}"
    );
}
```

**Output:**

```text
Amit: IT
Rahul: HR
Priya: IT
Sneha: Not Assigned
```

### Example 2: Numeric left outer join

```csharp
int[] left = { 1, 2, 3 };
int[] right = { 2, 3 };

var result =
    from x in left
    join y in right
        on x equals y into matches
    from y in matches
        .Select(value => (int?)value)
        .DefaultIfEmpty()
    select new
    {
        Left = x,
        Right = y
    };

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Left}: {item.Right?.ToString() ?? "null"}"
    );
}
```

**Output:**

```text
1: null
2: 2
3: 3
```

**Key point:** A left outer join preserves all left-side records, including those without matches.

## 2. GroupJoin + DefaultIfEmpty

In LINQ to Objects, a left outer join can be constructed using:

```csharp
GroupJoin()
SelectMany()
DefaultIfEmpty()
```

### Syntax

```csharp
outer
    .GroupJoin(
        inner,
        outerKeySelector,
        innerKeySelector,
        (outerItem, matches) => new
        {
            Outer = outerItem,
            Matches = matches
        }
    )
    .SelectMany(
        x => x.Matches.DefaultIfEmpty(),
        (x, innerItem) => new
        {
            Outer = x.Outer,
            Inner = innerItem
        }
    );
```

### Example 1: Departments with employees

```csharp
record Department(int Id, string Name);
record Employee(string Name, int DepartmentId);

Department[] departments =
{
    new(1, "IT"),
    new(2, "HR"),
    new(3, "Finance")
};

Employee[] employees =
{
    new("Amit", 1),
    new("Priya", 1),
    new("Rahul", 2)
};

var result = departments
    .GroupJoin(
        employees,
        d => d.Id,
        e => e.DepartmentId,
        (d, matches) => new
        {
            Department = d,
            Employees = matches
        }
    )
    .SelectMany(
        x => x.Employees.DefaultIfEmpty(),
        (x, e) => new
        {
            Department = x.Department.Name,
            Employee = e?.Name ?? "No Employee"
        }
    );

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Department}: {item.Employee}"
    );
}
```

**Output:**

```text
IT: Amit
IT: Priya
HR: Rahul
Finance: No Employee
```

### Example 2: Understanding DefaultIfEmpty

```csharp
int[] numbers = Array.Empty<int>();

var result = numbers.DefaultIfEmpty();

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
0
```

For an empty `IEnumerable<int>`, `DefaultIfEmpty()` produces the default integer value, `0`.

For reference types, the default is `null`.

```csharp
string[] names = Array.Empty<string>();

var result = names.DefaultIfEmpty();

foreach (string? name in result)
{
    Console.WriteLine(name ?? "null");
}
```

**Output:**

```text
null
```

**Key point:** `DefaultIfEmpty()` ensures that an empty matching group still produces one result.

## 3. Query-Syntax Left Outer Join

Query syntax expresses a left outer join using:

```csharp
join ... into
from ... DefaultIfEmpty()
```

### Syntax

```csharp
var result =
    from outer in outerSource
    join inner in innerSource
        on outer.Key equals inner.Key into matches
    from inner in matches.DefaultIfEmpty()
    select new
    {
        Outer = outer,
        Inner = inner
    };
```

### Example 1: Students and courses

```csharp
record Student(string Name, int CourseId);
record Course(int Id, string Name);

Student[] students =
{
    new("Amit", 101),
    new("Rahul", 102),
    new("Priya", 103)
};

Course[] courses =
{
    new(101, "C#"),
    new(102, "Java")
};

var result =
    from s in students
    join c in courses
        on s.CourseId equals c.Id into courseGroup
    from c in courseGroup.DefaultIfEmpty()
    select new
    {
        Student = s.Name,
        Course = c?.Name ?? "Unknown"
    };

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Student}: {item.Course}"
    );
}
```

**Output:**

```text
Amit: C#
Rahul: Java
Priya: Unknown
```

### Example 2: Customers and orders

```csharp
record Customer(int Id, string Name);
record Order(int Id, int CustomerId);

Customer[] customers =
{
    new(1, "Amit"),
    new(2, "Rahul"),
    new(3, "Priya")
};

Order[] orders =
{
    new(101, 1),
    new(102, 1),
    new(103, 2)
};

var result =
    from c in customers
    join o in orders
        on c.Id equals o.CustomerId into orderGroup
    from o in orderGroup.DefaultIfEmpty()
    select new
    {
        Customer = c.Name,
        OrderId = o?.Id
    };

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Customer}: {item.OrderId?.ToString() ?? "No Order"}"
    );
}
```

**Output:**

```text
Amit: 101
Amit: 102
Rahul: 103
Priya: No Order
```

**Key point:** Query-syntax left outer joins combine `join...into` with `DefaultIfEmpty()`.

## 4. Method-Syntax Left Outer Join

Method syntax uses `GroupJoin()` and `SelectMany()` to construct a left outer join.

### Example 1: Employees and departments

```csharp
record Employee(string Name, int DepartmentId);
record Department(int Id, string Name);

Employee[] employees =
{
    new("Amit", 1),
    new("Rahul", 2),
    new("Priya", 3)
};

Department[] departments =
{
    new(1, "IT"),
    new(2, "HR")
};

var result = employees
    .GroupJoin(
        departments,
        e => e.DepartmentId,
        d => d.Id,
        (e, matches) => new
        {
            Employee = e,
            Departments = matches
        }
    )
    .SelectMany(
        x => x.Departments.DefaultIfEmpty(),
        (x, d) => new
        {
            Employee = x.Employee.Name,
            Department = d?.Name ?? "Unknown"
        }
    );

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Employee}: {item.Department}"
    );
}
```

**Output:**

```text
Amit: IT
Rahul: HR
Priya: Unknown
```

### Example 2: Numeric method-syntax join

```csharp
int[] left = { 1, 2, 3 };
int[] right = { 2, 3 };

var result = left
    .GroupJoin(
        right,
        x => x,
        y => y,
        (x, matches) => new
        {
            Left = x,
            Matches = matches
        }
    )
    .SelectMany(
        x => x.Matches
            .Select(y => (int?)y)
            .DefaultIfEmpty(),
        (x, y) => new
        {
            x.Left,
            Right = y
        }
    );

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Left}: {item.Right?.ToString() ?? "null"}"
    );
}
```

**Output:**

```text
1: null
2: 2
3: 3
```

**Key point:** Method syntax gives explicit control over grouped matches and their flattening.

## 5. Missing Inner Elements

Missing inner elements occur when an outer element has no matching key in the inner sequence.

### Example 1: Missing department

```csharp
record Employee(string Name, int DepartmentId);
record Department(int Id, string Name);

Employee[] employees =
{
    new("Amit", 10),
    new("Rahul", 20),
    new("Priya", 30)
};

Department[] departments =
{
    new(10, "IT"),
    new(20, "HR")
};

var result =
    from e in employees
    join d in departments
        on e.DepartmentId equals d.Id into matches
    from d in matches.DefaultIfEmpty()
    select new
    {
        e.Name,
        Department = d?.Name
    };

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Name}: {item.Department ?? "Missing"}"
    );
}
```

**Output:**

```text
Amit: IT
Rahul: HR
Priya: Missing
```

### Example 2: Identify unmatched records

```csharp
var unmatched =
    from e in employees
    join d in departments
        on e.DepartmentId equals d.Id into matches
    from d in matches.DefaultIfEmpty()
    where d is null
    select e.Name;

Console.WriteLine(string.Join(", ", unmatched));
```

**Output:**

```text
Priya
```

**Key point:** Missing inner elements can be retained, identified, or assigned default values.

## 6. Null Handling

Outer joins can produce `null` for unmatched reference-type elements.

Null handling prevents invalid member access.

### Null-conditional operator

```csharp
department?.Name
```

### Null-coalescing operator

```csharp
department?.Name ?? "Unknown"
```

### Example 1: Null-safe projection

```csharp
record Employee(string Name, int DepartmentId);
record Department(int Id, string Name);

Employee[] employees =
{
    new("Amit", 1),
    new("Rahul", 2)
};

Department[] departments =
{
    new(1, "IT")
};

var result =
    from e in employees
    join d in departments
        on e.DepartmentId equals d.Id into matches
    from d in matches.DefaultIfEmpty()
    select new
    {
        e.Name,
        Department = d?.Name ?? "Not Assigned"
    };

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Name}: {item.Department}"
    );
}
```

**Output:**

```text
Amit: IT
Rahul: Not Assigned
```

### Example 2: Nullable numeric result

```csharp
int[] left = { 1, 2 };
int[] right = { 2 };

var result =
    from x in left
    join y in right
        on x equals y into matches
    from y in matches
        .Select(value => (int?)value)
        .DefaultIfEmpty()
    select new
    {
        Left = x,
        Right = y
    };

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Left}: {item.Right?.ToString() ?? "null"}"
    );
}
```

**Output:**

```text
1: null
2: 2
```

**Important:** When joining non-nullable value types, `DefaultIfEmpty()` produces their default value, such as `0`. Use nullable values when you need to distinguish an unmatched element from a valid zero.

**Key point:** Null-safe projection is essential when working with unmatched reference-type records.

## 7. Right Outer Join by Reversing Sources

A right outer join preserves every element from the right sequence.

In LINQ, it can be expressed by reversing the sources of a left outer join.

### Structure

```text
Original:

LEFT:  Employees
RIGHT: Departments

Right Outer Join:
Preserve all Departments
```

### Example 1: Departments without employees

```csharp
record Employee(string Name, int DepartmentId);
record Department(int Id, string Name);

Employee[] employees =
{
    new("Amit", 1),
    new("Rahul", 2)
};

Department[] departments =
{
    new(1, "IT"),
    new(2, "HR"),
    new(3, "Finance")
};

var result =
    from d in departments
    join e in employees
        on d.Id equals e.DepartmentId into matches
    from e in matches.DefaultIfEmpty()
    select new
    {
        Department = d.Name,
        Employee = e?.Name ?? "No Employee"
    };

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Department}: {item.Employee}"
    );
}
```

**Output:**

```text
IT: Amit
HR: Rahul
Finance: No Employee
```

### Example 2: Numeric right outer join

```csharp
int[] left = { 1, 2 };
int[] right = { 2, 3 };

var result =
    from y in right
    join x in left
        on y equals x into matches
    from x in matches
        .Select(value => (int?)value)
        .DefaultIfEmpty()
    select new
    {
        Left = x,
        Right = y
    };

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Left?.ToString() ?? "null"}: {item.Right}"
    );
}
```

**Output:**

```text
2: 2
null: 3
```

**Key point:** Reversing the sources of a left outer join provides right outer join behavior.

## 8. Full Outer Join Construction

A full outer join preserves records from both sequences.

It includes:

1. Matching records
2. Left records without matches
3. Right records without matches

### Example 1: Full outer join using two queries

```csharp
record Employee(int Id, string Name, int DepartmentId);
record Department(int Id, string Name);

Employee[] employees =
{
    new(1, "Amit", 10),
    new(2, "Rahul", 20),
    new(3, "Priya", 30)
};

Department[] departments =
{
    new(10, "IT"),
    new(20, "HR"),
    new(40, "Finance")
};

var leftJoin =
    from e in employees
    join d in departments
        on e.DepartmentId equals d.Id into matches
    from d in matches.DefaultIfEmpty()
    select new
    {
        Employee = e.Name,
        Department = d?.Name
    };

var rightOnly =
    from d in departments
    join e in employees
        on d.Id equals e.DepartmentId into matches
    where !matches.Any()
    select new
    {
        Employee = (string?)null,
        Department = (string?)d.Name
    };

var fullJoin = leftJoin.Concat(rightOnly);

foreach (var item in fullJoin)
{
    Console.WriteLine(
        $"{item.Employee ?? "No Employee"}: " +
        $"{item.Department ?? "No Department"}"
    );
}
```

**Output:**

```text
Amit: IT
Rahul: HR
Priya: No Department
No Employee: Finance
```

`Concat()` preserves all produced records, including duplicates.

### Example 2: Full outer join with numeric keys

```csharp
int[] left = { 1, 2, 3 };
int[] right = { 2, 3, 4 };

var leftJoin =
    from x in left
    join y in right
        on x equals y into matches
    from y in matches
        .Select(value => (int?)value)
        .DefaultIfEmpty()
    select new
    {
        Left = (int?)x,
        Right = y
    };

var rightOnly =
    from y in right
    join x in left
        on y equals x into matches
    where !matches.Any()
    select new
    {
        Left = (int?)null,
        Right = (int?)y
    };

var result = leftJoin.Concat(rightOnly);

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Left?.ToString() ?? "null"}: " +
        $"{item.Right?.ToString() ?? "null"}"
    );
}
```

**Output:**

```text
1: null
2: 2
3: 3
null: 4
```

**Key point:** A full outer join can be constructed by combining a left outer join with unmatched right-side records.

## 9. Semi Join

A semi join returns records from one sequence only when a matching record exists in another sequence.

Unlike an inner join, it does not return matching pairs.

### Syntax

```csharp
outer.Where(
    x => inner.Any(y => x.Key == y.Key)
);
```

### Example 1: Customers with orders

```csharp
record Customer(int Id, string Name);
record Order(int CustomerId, int Amount);

Customer[] customers =
{
    new(1, "Amit"),
    new(2, "Rahul"),
    new(3, "Priya")
};

Order[] orders =
{
    new(1, 100),
    new(1, 200),
    new(2, 300)
};

var result = customers.Where(
    c => orders.Any(o => o.CustomerId == c.Id)
);

foreach (var customer in result)
{
    Console.WriteLine(customer.Name);
}
```

**Output:**

```text
Amit
Rahul
```

### Example 2: Numeric semi join

```csharp
int[] left = { 1, 2, 3, 4 };
int[] right = { 2, 2, 4 };

var result = left.Where(
    x => right.Contains(x)
);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
2, 4
```

**Key point:** A semi join returns qualifying outer records, not every matching pair.

## 10. Records with a Match

Existence queries identify records having at least one corresponding record.

### Example 1: Employees with valid departments

```csharp
record Employee(string Name, int DepartmentId);
record Department(int Id, string Name);

Employee[] employees =
{
    new("Amit", 1),
    new("Rahul", 2),
    new("Priya", 3)
};

Department[] departments =
{
    new(1, "IT"),
    new(2, "HR")
};

var result = employees.Where(
    e => departments.Any(d => d.Id == e.DepartmentId)
);

foreach (var employee in result)
{
    Console.WriteLine(employee.Name);
}
```

**Output:**

```text
Amit
Rahul
```

### Example 2: Matching IDs

```csharp
int[] first = { 10, 20, 30, 40 };
int[] second = { 20, 40, 50 };

var result = first.Where(
    x => second.Contains(x)
);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
20, 40
```

**Key point:** Existence filtering keeps records that have at least one match.

## 11. Anti Join

An anti join returns records from one sequence that have no matching records in another sequence.

### Syntax

```csharp
outer.Where(
    x => !inner.Any(y => x.Key == y.Key)
);
```

### Example 1: Customers without orders

```csharp
record Customer(int Id, string Name);
record Order(int CustomerId);

Customer[] customers =
{
    new(1, "Amit"),
    new(2, "Rahul"),
    new(3, "Priya")
};

Order[] orders =
{
    new(1),
    new(2)
};

var result = customers.Where(
    c => !orders.Any(o => o.CustomerId == c.Id)
);

foreach (var customer in result)
{
    Console.WriteLine(customer.Name);
}
```

**Output:**

```text
Priya
```

### Example 2: Numeric anti join

```csharp
int[] left = { 1, 2, 3, 4 };
int[] right = { 2, 4 };

var result = left.Where(
    x => !right.Contains(x)
);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1, 3
```

**Key point:** Anti joins identify records without matching relationships.

## 12. Records without a Match

Records without a match can be found using either an anti join or a group join with an empty-group condition.

### Example 1: GroupJoin with !Any()

```csharp
record Department(int Id, string Name);
record Employee(string Name, int DepartmentId);

Department[] departments =
{
    new(1, "IT"),
    new(2, "HR"),
    new(3, "Finance")
};

Employee[] employees =
{
    new("Amit", 1),
    new("Rahul", 2)
};

var result = departments
    .GroupJoin(
        employees,
        d => d.Id,
        e => e.DepartmentId,
        (d, matches) => new
        {
            Department = d,
            Matches = matches
        }
    )
    .Where(x => !x.Matches.Any())
    .Select(x => x.Department.Name);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
Finance
```

### Example 2: Query syntax

```csharp
var result =
    from d in departments
    join e in employees
        on d.Id equals e.DepartmentId into matches
    where !matches.Any()
    select d.Name;

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
Finance
```

**Key point:** Empty matching groups can identify missing relationships.

## 13. Any-Based Existence Query

`Any()` checks whether a sequence contains at least one element satisfying a condition.

### Syntax

```csharp
source.Any(predicate);
```

### Example 1: Check for a matching value

```csharp
int[] numbers = { 10, 20, 30 };

bool exists = numbers.Any(n => n == 20);

Console.WriteLine(exists);
```

**Output:**

```text
True
```

### Example 2: Check related records

```csharp
record Customer(int Id, string Name);
record Order(int CustomerId);

Customer[] customers =
{
    new(1, "Amit"),
    new(2, "Rahul")
};

Order[] orders =
{
    new(1),
    new(1)
};

var result = customers.Select(c => new
{
    c.Name,
    HasOrders = orders.Any(o => o.CustomerId == c.Id)
});

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Name}: {item.HasOrders}"
    );
}
```

**Output:**

```text
Amit: True
Rahul: False
```

### Example 3: Any with negation

```csharp
int[] first = { 1, 2, 3 };
int[] second = { 2 };

var result = first.Where(
    x => !second.Any(y => x == y)
);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1, 3
```

**Key point:** `Any()` supports efficient existence checks and stops searching once a match is found.

## 14. Correlated Queries

A correlated query uses a value from an outer query inside an inner query.

### Syntax

```csharp
outer.Where(
    x => inner.Any(y => y.Key == x.Key)
);
```

The inner predicate depends on the current outer element.

### Example 1: Correlated customer query

```csharp
record Customer(int Id, string Name);
record Order(int CustomerId, decimal Amount);

Customer[] customers =
{
    new(1, "Amit"),
    new(2, "Rahul"),
    new(3, "Priya")
};

Order[] orders =
{
    new(1, 500m),
    new(1, 200m),
    new(2, 100m)
};

var result = customers.Where(
    c => orders.Any(
        o => o.CustomerId == c.Id && o.Amount >= 300m
    )
);

foreach (var customer in result)
{
    Console.WriteLine(customer.Name);
}
```

**Output:**

```text
Amit
```

### Example 2: Correlated count

```csharp
var result = customers.Select(c => new
{
    Customer = c.Name,
    OrderCount = orders.Count(o => o.CustomerId == c.Id)
});

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Customer}: {item.OrderCount}"
    );
}
```

**Output:**

```text
Amit: 2
Rahul: 1
Priya: 0
```

**Key point:** A correlated query evaluates a relationship using values from the current outer element.

## 15. Preserving Duplicates

Different join operations handle duplicates differently.

A regular join produces every matching pair.

Semi joins and anti joins preserve qualifying outer records without multiplying them by the number of inner matches.

### Example 1: Inner join duplicates

```csharp
int[] outer = { 1, 1, 2 };
int[] inner = { 1, 1, 2 };

var result = outer.Join(
    inner,
    x => x,
    y => y,
    (x, y) => x
);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1, 1, 1, 1, 2
```

### Example 2: Semi join duplicates

```csharp
int[] outer = { 1, 1, 2, 3 };
int[] inner = { 1, 1, 2 };

var result = outer.Where(
    x => inner.Contains(x)
);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1, 1, 2
```

The two outer occurrences of `1` remain, but they are not multiplied by the two inner occurrences.

### Example 3: Anti join duplicates

```csharp
int[] outer = { 1, 1, 2, 3, 3 };
int[] inner = { 2 };

var result = outer.Where(
    x => !inner.Contains(x)
);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1, 1, 3, 3
```

### Duplicate behavior

| Operation | Duplicate Behavior |
|---|---|
| Inner Join | Produces every matching pair |
| Left Outer Join | Produces every match, or one unmatched result |
| Full Outer Join | Preserves matching combinations and unmatched occurrences |
| Semi Join | Preserves qualifying outer occurrences |
| Anti Join | Preserves unmatched outer occurrences |
| `Distinct()` | Removes duplicate values according to equality |

**Key point:** Existence queries preserve the multiplicity of qualifying outer records without multiplying them by inner matches.

## 16. Preserving Ordering Semantics

Ordering determines the sequence in which joined results are returned.

For LINQ to Objects, `Join()` and `GroupJoin()` preserve outer-source order and the relative order of matching inner elements.

However, database query providers do not guarantee result ordering unless an explicit ordering operation is specified.

### Example 1: Inner join ordering

```csharp
int[] outer = { 3, 1, 2 };
int[] inner = { 2, 1, 3 };

var result = outer.Join(
    inner,
    x => x,
    y => y,
    (x, y) => x
);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
3, 1, 2
```

### Example 2: Matching inner ordering

```csharp
record Item(int Key, string Value);

Item[] outer =
{
    new(1, "A")
};

Item[] inner =
{
    new(1, "First"),
    new(1, "Second"),
    new(1, "Third")
};

var result = outer.Join(
    inner,
    x => x.Key,
    y => y.Key,
    (x, y) => y.Value
);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
First, Second, Third
```

### Example 3: Explicit ordering

```csharp
int[] outer = { 3, 1, 2 };
int[] inner = { 1, 2, 3 };

var result = outer
    .Join(
        inner,
        x => x,
        y => y,
        (x, y) => x
    )
    .OrderBy(x => x);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1, 2, 3
```

### Example 4: Ordering an outer join

```csharp
record Employee(string Name, int DepartmentId);
record Department(int Id, string Name);

Employee[] employees =
{
    new("Priya", 3),
    new("Amit", 1),
    new("Rahul", 2)
};

Department[] departments =
{
    new(1, "IT"),
    new(2, "HR")
};

var result =
    (from e in employees
     join d in departments
         on e.DepartmentId equals d.Id into matches
     from d in matches.DefaultIfEmpty()
     select new
     {
         Employee = e.Name,
         Department = d?.Name ?? "Unknown"
     })
    .OrderBy(x => x.Employee);

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Employee}: {item.Department}"
    );
}
```

**Output:**

```text
Amit: IT
Priya: Unknown
Rahul: HR
```

**Key point:** Use explicit `OrderBy()` or `OrderByDescending()` when deterministic result ordering is required.
