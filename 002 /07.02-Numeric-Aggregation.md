# 07.02 — NUMERIC AGGREGATION

**Chapter:** 07 — LINQ Aggregation & Grouping  
**Namespace:** `System.Linq`  
**Total Syllabus Topics:** 19

Numeric aggregation means calculating a single numeric result from a sequence of values.

This section covers the **19 topics in your syllabus**, in their original order.

---

## 1. Sum

`Sum()` calculates the total of numeric values in a sequence.

### Syntax

```csharp
source.Sum();
```

### Example 1: Integer array

```csharp
int[] numbers = { 10, 20, 30, 40 };

int result = numbers.Sum();

Console.WriteLine(result);
```

**Output:**

```text
100
```

### Example 2: List

```csharp
List<int> numbers = new()
{
    5, 10, 15, 20
};

int result = numbers.Sum();

Console.WriteLine(result);
```

**Output:**

```text
50
```

### Example 3: Negative numbers

```csharp
int[] numbers = { -10, 20, -30, 40 };

int result = numbers.Sum();

Console.WriteLine(result);
```

**Output:**

```text
20
```

### Formula

\[
\text{Sum}=\sum_{i=1}^{n}x_i
\]

For:

```text
10, 20, 30, 40
```

\[
10+20+30+40=100
\]


\[

\]

**Important:** `Average()` on an integer sequence returns `double`, not `int`.

## 5. Numeric Overloads

LINQ provides numeric overloads for aggregation methods.

The supported overload depends on the numeric type of the source.

### Example 1: Integer

```csharp
int[] numbers = { 10, 20, 30 };

int result = numbers.Sum();
```

### Example 2: Long

```csharp
long[] numbers = { 10L, 20L, 30L };

long result = numbers.Sum();
```

### Example 3: Float

```csharp
float[] numbers = { 10.5f, 20.5f };

float result = numbers.Sum();
```

### Example 4: Double

```csharp
double[] numbers = { 10.5, 20.5 };

double result = numbers.Sum();
```

### Example 5: Decimal

```csharp
decimal[] numbers = { 10.5m, 20.5m };

decimal result = numbers.Sum();
```

### Return types

| Source Type | Sum | Average | Min | Max |
|---|---|---|---|---|
| `int` | `int` | `double` | `int` | `int` |
| `long` | `long` | `double` | `long` | `long` |
| `float` | `float` | `float` | `float` | `float` |
| `double` | `double` | `double` | `double` | `double` |
| `decimal` | `decimal` | `decimal` | `decimal` | `decimal` |

These are the standard non-nullable numeric overloads.

## 6. Selector-Based Sum

Selector-based `Sum()` calculates a total from a property or expression.

### Syntax

```csharp
source.Sum(x => x.Property);
```

### Example 1: Product prices

```csharp
record Product(string Name, decimal Price);

Product[] products =
{
    new("Mouse", 500m),
    new("Keyboard", 1200m),
    new("Monitor", 8000m)
};

decimal total = products.Sum(p => p.Price);

Console.WriteLine(total);
```

**Output:**

```text
9700
```

### Example 2: Student marks

```csharp
record Student(string Name, int Marks);

Student[] students =
{
    new("Amit", 90),
    new("Rahul", 75),
    new("Priya", 95)
};

int total = students.Sum(s => s.Marks);

Console.WriteLine(total);
```

**Output:**

```text
260
```

### Example 3: Calculated value

```csharp
record OrderItem(int Quantity, decimal UnitPrice);

OrderItem[] items =
{
    new(2, 100m),
    new(3, 50m)
};

decimal total = items.Sum(
    item => item.Quantity * item.UnitPrice
);

Console.WriteLine(total);
```

**Output:**

```text
350
```

## 15. Nullable Numeric Values

LINQ numeric aggregation methods support nullable numeric types.

### Example 1: Nullable Sum

```csharp
int?[] numbers = { 10, null, 20, null, 30 };

int? total = numbers.Sum();

Console.WriteLine(total);
```

**Output:**

```text
60
```

`Sum()` ignores null values.

### Example 2: Nullable Average

```csharp
int?[] numbers = { 10, null, 20, 30 };

double? average = numbers.Average();

Console.WriteLine(average);
```

**Output:**

```text
20
```

`Average()` calculates the average of non-null values.

### Example 3: Nullable Min

```csharp
int?[] numbers = { null, 20, 10, 30 };

int? minimum = numbers.Min();

Console.WriteLine(minimum);
```

**Output:**

```text
10
```

### Example 4: Nullable Max

```csharp
int?[] numbers = { null, 20, 10, 30 };

int? maximum = numbers.Max();

Console.WriteLine(maximum);
```

**Output:**

```text
30
```

### Example 5: All null values

```csharp
int?[] numbers = { null, null };

Console.WriteLine(numbers.Sum());
Console.WriteLine(numbers.Average() is null);
Console.WriteLine(numbers.Min() is null);
Console.WriteLine(numbers.Max() is null);
```

**Output:**

```text
0
True
True
True
```

### Nullable aggregation behavior

| Operator | Null Handling |
|---|---|
| `Sum()` | Ignores null; returns zero if no non-null values |
| `Average()` | Ignores null; returns null if no non-null values |
| `Min()` | Ignores null; returns null if no non-null values |
| `Max()` | Ignores null; returns null if no non-null values |

## 17. Overflow

Overflow occurs when a numeric result exceeds the representable range of its type.

### Example 1: Integer Sum overflow

```csharp
int[] numbers =
{
    int.MaxValue,
    1
};

int total = numbers.Sum();
```

**Result:**

```text
OverflowException
```

### Example 2: Use long aggregation

```csharp
int[] numbers =
{
    int.MaxValue,
    1
};

long total = numbers.Sum(n => (long)n);

Console.WriteLine(total);
```

**Output:**

```text
2147483648
```

### Example 3: Long overflow

```csharp
long[] numbers =
{
    long.MaxValue,
    1
};

long total = numbers.Sum();
```

**Result:**

```text
OverflowException
```

### Example 4: Decimal overflow

```csharp
decimal[] numbers =
{
    decimal.MaxValue,
    1m
};

decimal total = numbers.Sum();
```

**Result:**

```text
OverflowException
```

### Example 5: Floating-point overflow

```csharp
double[] numbers =
{
    double.MaxValue,
    double.MaxValue
};

double total = numbers.Sum();

Console.WriteLine(double.IsPositiveInfinity(total));
```

**Output:**

```text
True
```

### Overflow comparison

| Type | Overflow Behavior |
|---|---|
| `int` | `Sum()` throws `OverflowException` |
| `long` | `Sum()` throws `OverflowException` |
| `decimal` | Throws `OverflowException` |
| `float` | May produce infinity |
| `double` | May produce infinity |

**Key point:** Choose an aggregation result type capable of representing the expected total.

## 18. Precision

Precision describes how accurately numeric values are represented and calculated.

### Example 1: Double precision

```csharp
double[] numbers = { 0.1, 0.2 };

double total = numbers.Sum();

Console.WriteLine(total == 0.3);
```

**Output:**

```text
False
```

Binary floating-point values cannot represent every decimal fraction exactly.

### Example 2: Decimal precision

```csharp
decimal[] numbers = { 0.1m, 0.2m };

decimal total = numbers.Sum();

Console.WriteLine(total == 0.3m);
```

**Output:**

```text
True
```

### Example 3: Floating-point aggregation

```csharp
double[] numbers =
{
    1e16,
    1.0,
    -1e16
};

double total = numbers.Sum();

Console.WriteLine(total);
```

**Typical output:**

```text
0
```

The small value may be lost because of floating-point precision limitations. Exact behavior can depend on the aggregation implementation.

### Example 4: Decimal aggregation

```csharp
decimal[] numbers =
{
    10000000000000000m,
    1m,
    -10000000000000000m
};

decimal total = numbers.Sum();

Console.WriteLine(total);
```

**Output:**

```text
1
```

### Precision comparison

| Type | Representation |
|---|---|
| `int` | Exact integer |
| `long` | Exact integer |
| `float` | Binary floating point |
| `double` | Binary floating point |
| `decimal` | Decimal floating point |

**Key point:** Use `decimal` when exact decimal arithmetic is important and values fit within its range and precision.

## 19. Rounding

Rounding reduces the number of decimal places or significant digits in a numeric result.

LINQ aggregation methods do not automatically round results to a specified number of decimal places.

Use `Math.Round()` when rounding is required.

### Example 1: Round an average

```csharp
int[] numbers = { 10, 20, 25 };

double average = numbers.Average();

double rounded = Math.Round(average, 2);

Console.WriteLine(rounded);
```

**Output:**

```text
18.33
```

### Example 2: Decimal rounding

```csharp
decimal[] prices =
{
    10.25m,
    20.35m,
    30.45m
};

decimal average = prices.Average();

decimal rounded = Math.Round(average, 2);

Console.WriteLine(rounded);
```

**Output:**

```text
20.35
```

### Example 3: MidpointRounding.ToEven

```csharp
double number = 2.5;

double result = Math.Round(
    number,
    0,
    MidpointRounding.ToEven
);

Console.WriteLine(result);
```

**Output:**

```text
2
```

### Example 4: MidpointRounding.AwayFromZero

```csharp
double number = 2.5;

double result = Math.Round(
    number,
    0,
    MidpointRounding.AwayFromZero
);

Console.WriteLine(result);
```

**Output:**

```text
3
```

### Example 5: Round Sum

```csharp
decimal[] prices =
{
    10.125m,
    20.235m
};

decimal total = prices.Sum();

decimal rounded = Math.Round(
    total,
    2,
    MidpointRounding.AwayFromZero
);

Console.WriteLine(rounded);
```

**Output:**

```text
30.36
```

### Rounding modes

| Mode | Behavior |
|---|---|
| `ToEven` | Midpoint rounds toward the nearest even result |
| `AwayFromZero` | Midpoint rounds away from zero |
| `ToZero` | Rounds toward zero |
| `ToNegativeInfinity` | Rounds toward negative infinity |
| `ToPositiveInfinity` | Rounds toward positive infinity |

**Important:** Rounding each value before aggregation can produce a different result from aggregating first and rounding afterward.
