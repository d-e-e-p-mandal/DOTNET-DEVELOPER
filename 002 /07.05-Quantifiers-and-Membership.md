# 07.05 — QUANTIFIERS & MEMBERSHIP

**Chapter:** 07 — LINQ Aggregation & Grouping  
**Namespace:** `System.Linq`

Quantifiers determine whether elements exist or satisfy conditions. Membership operations determine whether a particular value exists in a sequence.

This section follows the exact topic order of your syllabus.

---

## 1. Any

`Any()` determines whether a sequence contains at least one element or whether at least one element satisfies a condition.

**Return type:** `bool`

### 1.1 Any()

`Any()` without a predicate checks whether a sequence contains at least one element.

**Syntax**

```csharp
source.Any();
```

**Example 1: Non-empty sequence**

```csharp
int[] numbers = { 10, 20, 30 };

bool result = numbers.Any();

Console.WriteLine(result);
```

**Output:**

```text
True
```

**Example 2: Empty sequence**

```csharp
int[] numbers = Array.Empty<int>();

bool result = numbers.Any();

Console.WriteLine(result);
```

**Output:**

```text
False
```

**Example 3: List**

```csharp
List<string> names = new()
{
    "Amit",
    "Rahul"
};

bool result = names.Any();

Console.WriteLine(result);
```

**Output:**

```text
True
```

**Example 4: Query result**

```csharp
int[] numbers = { 10, 20, 30 };

var query = numbers.Where(n => n > 50);

Console.WriteLine(query.Any());
```

**Output:**

```text
False
```

**Key point:** `Any()` returns `true` when at least one element exists.

---

### 1.2 Any(predicate)

`Any(predicate)` checks whether at least one element satisfies a condition.

**Syntax**

```csharp
source.Any(x => condition);
```

**Example 1: Even number**

```csharp
int[] numbers = { 1, 3, 5, 8, 9 };

bool result = numbers.Any(n => n % 2 == 0);

Console.WriteLine(result);
```

**Output:**

```text
True
```

**Example 2: Number greater than 100**

```csharp
int[] numbers = { 10, 20, 30 };

bool result = numbers.Any(n => n > 100);

Console.WriteLine(result);
```

**Output:**

```text
False
```

**Example 3: String condition**

```csharp
string[] names =
{
    "Amit",
    "Rahul",
    "Priya"
};

bool result = names.Any(
    name => name.StartsWith("P")
);

Console.WriteLine(result);
```

**Output:**

```text
True
```

**Example 4: Object condition**

```csharp
record Student(string Name, int Marks);

Student[] students =
{
    new("Amit", 90),
    new("Rahul", 65),
    new("Priya", 95)
};

bool result = students.Any(s => s.Marks < 70);

Console.WriteLine(result);
```

**Output:**

```text
True
```

**Key point:** `Any(predicate)` returns `true` as soon as a matching element is found.

---

### 1.3 Existence Checking

Existence checking determines whether a sequence contains any element meeting a requirement.

**Example 1: Check whether data exists**

```csharp
List<int> numbers = new();

if (numbers.Any())
{
    Console.WriteLine("Data exists");
}
else
{
    Console.WriteLine("No data");
}
```

**Output:**

```text
No data
```

**Example 2: Check whether a matching product exists**

```csharp
record Product(string Name, bool Available);

Product[] products =
{
    new("Mouse", false),
    new("Keyboard", true),
    new("Monitor", false)
};

bool available = products.Any(p => p.Available);

Console.WriteLine(available);
```

**Output:**

```text
True
```

**Example 3: Check nested collections**

```csharp
record Department(string Name, int[] EmployeeIds);

Department[] departments =
{
    new("IT", new[] { 1, 2 }),
    new("HR", Array.Empty<int>())
};

bool result = departments.Any(
    d => d.EmployeeIds.Any()
);

Console.WriteLine(result);
```

**Output:**

```text
True
```

**Key point:** Existence checking needs only a Boolean answer, not the total number of matching elements.

## 2. All

`All()` determines whether every element in a sequence satisfies a condition.

**Return type:** `bool`

### 2.1 All(predicate)

`All(predicate)` returns `true` only when every element satisfies the supplied predicate.

**Syntax**

```csharp
source.All(x => condition);
```

**Example 1: All positive**

```csharp
int[] numbers = { 10, 20, 30, 40 };

bool result = numbers.All(n => n > 0);

Console.WriteLine(result);
```

**Output:**

```text
True
```

**Example 2: Not all positive**

```csharp
int[] numbers = { 10, -20, 30 };

bool result = numbers.All(n => n > 0);

Console.WriteLine(result);
```

**Output:**

```text
False
```

**Example 3: All even**

```csharp
int[] numbers = { 2, 4, 6, 8 };

bool result = numbers.All(n => n % 2 == 0);

Console.WriteLine(result);
```

**Output:**

```text
True
```

**Example 4: All students passed**

```csharp
record Student(string Name, int Marks);

Student[] students =
{
    new("Amit", 80),
    new("Rahul", 65),
    new("Priya", 90)
};

bool result = students.All(s => s.Marks >= 40);

Console.WriteLine(result);
```

**Output:**

```text
True
```

**Example 5: All strings non-empty**

```csharp
string[] names = { "Amit", "Rahul", "" };

bool result = names.All(
    name => !string.IsNullOrEmpty(name)
);

Console.WriteLine(result);
```

**Output:**

```text
False
```

**Key point:** `All()` stops evaluating when it encounters the first element that fails the condition.

---

### 2.2 Vacuous Truth on Empty Sequences

`All(predicate)` returns `true` when the source sequence is empty.

This behavior is called **vacuous truth**.

**Example 1: Empty integer array**

```csharp
int[] numbers = Array.Empty<int>();

bool result = numbers.All(n => n > 100);

Console.WriteLine(result);
```

**Output:**

```text
True
```

No element violates the condition.

**Example 2: Empty string array**

```csharp
string[] names = Array.Empty<string>();

bool result = names.All(
    name => name.Length > 5
);

Console.WriteLine(result);
```

**Output:**

```text
True
```

**Example 3: Compare Any and All**

```csharp
int[] numbers = Array.Empty<int>();

Console.WriteLine(numbers.Any());
Console.WriteLine(numbers.All(n => n > 0));
```

**Output:**

```text
False
True
```

**Example 4: Require a non-empty sequence**

```csharp
int[] numbers = Array.Empty<int>();

bool result =
    numbers.Any() &&
    numbers.All(n => n > 0);

Console.WriteLine(result);
```

**Output:**

```text
False
```

**Comparison**

| Sequence | `Any()` | `All(predicate)` |
|---|---|---|
| Empty | `false` | `true` |
| All elements match | `true` | `true` |
| Some elements match | `true` | `false` |
| No elements match, non-empty | `true` | `false` |

**Key point:** Use `Any() && All(predicate)` when at least one element must exist and every element must satisfy the condition.

## 3. Contains

`Contains()` determines whether a sequence contains a specified value.

**Return type:** `bool`

**Syntax**

```csharp
source.Contains(value);
```

**Example 1: Integer membership**

```csharp
int[] numbers = { 10, 20, 30, 40 };

bool result = numbers.Contains(30);

Console.WriteLine(result);
```

**Output:**

```text
True
```

**Example 2: Missing value**

```csharp
int[] numbers = { 10, 20, 30 };

bool result = numbers.Contains(50);

Console.WriteLine(result);
```

**Output:**

```text
False
```

**Example 3: String membership**

```csharp
string[] names =
{
    "Amit",
    "Rahul",
    "Priya"
};

bool result = names.Contains("Rahul");

Console.WriteLine(result);
```

**Output:**

```text
True
```

---

### 3.1 Default Equality

Without a custom comparer, LINQ `Contains()` uses the default equality behavior for the element type.

The relevant comparer is:

```csharp
EqualityComparer<T>.Default
```

**Example 1: Integer equality**

```csharp
int[] numbers = { 10, 20, 30 };

Console.WriteLine(numbers.Contains(20));
```

**Output:**

```text
True
```

**Example 2: Case-sensitive string equality**

```csharp
string[] names = { "Amit", "Rahul" };

Console.WriteLine(names.Contains("amit"));
```

**Output:**

```text
False
```

**Example 3: Record value equality**

```csharp
record Student(int Id, string Name);

Student[] students =
{
    new(1, "Amit"),
    new(2, "Rahul")
};

bool result = students.Contains(
    new Student(1, "Amit")
);

Console.WriteLine(result);
```

**Output:**

```text
True
```

Records provide value-based equality by default.

**Example 4: Class reference equality**

```csharp
class Student
{
    public int Id { get; set; }
}
```

```csharp
Student[] students =
{
    new Student { Id = 1 }
};

bool result = students.Contains(
    new Student { Id = 1 }
);

Console.WriteLine(result);
```

**Output:**

```text
False
```

This class does not override equality, so the two different instances are not considered equal.

**Key point:** Default equality depends on the element type's equality implementation.

---

### 3.2 Custom Equality Comparer

`Contains()` supports an `IEqualityComparer<T>` to customize equality.

**Syntax**

```csharp
source.Contains(value, comparer);
```

**Example 1: Case-insensitive strings**

```csharp
string[] names =
{
    "Amit",
    "Rahul",
    "Priya"
};

bool result = names.Contains(
    "amit",
    StringComparer.OrdinalIgnoreCase
);

Console.WriteLine(result);
```

**Output:**

```text
True
```

**Example 2: Custom object comparer**

```csharp
record Student(int Id, string Name);

class StudentIdComparer : IEqualityComparer<Student>
{
    public bool Equals(Student? x, Student? y)
    {
        if (ReferenceEquals(x, y))
            return true;

        if (x is null || y is null)
            return false;

        return x.Id == y.Id;
    }

    public int GetHashCode(Student obj)
    {
        return obj.Id.GetHashCode();
    }
}
```

```csharp
Student[] students =
{
    new(1, "Amit"),
    new(2, "Rahul")
};

bool result = students.Contains(
    new Student(1, "Different Name"),
    new StudentIdComparer()
);

Console.WriteLine(result);
```

**Output:**

```text
True
```

The comparer compares student IDs rather than the complete records.

**Example 3: Custom string equality**

```csharp
string[] values =
{
    "APPLE",
    "BANANA",
    "MANGO"
};

bool result = values.Contains(
    "apple",
    StringComparer.OrdinalIgnoreCase
);

Console.WriteLine(result);
```

**Output:**

```text
True
```

**Key point:** A custom equality comparer changes the rules used to determine whether an element matches the requested value.

## 4. Short-Circuit Evaluation

Short-circuit evaluation means stopping sequence processing as soon as the final Boolean result is known.

`Any()` and `All()` support short-circuit evaluation.

### Example 1: Any stops at first match

```csharp
int[] numbers = { 10, 20, 30, 40 };

bool result = numbers.Any(n =>
{
    Console.WriteLine($"Checking {n}");

    return n >= 20;
});

Console.WriteLine(result);
```

**Output:**

```text
Checking 10
Checking 20
True
```

The remaining elements are not checked.

### Example 2: All stops at first failure

```csharp
int[] numbers = { 10, 20, -30, 40 };

bool result = numbers.All(n =>
{
    Console.WriteLine($"Checking {n}");

    return n > 0;
});

Console.WriteLine(result);
```

**Output:**

```text
Checking 10
Checking 20
Checking -30
False
```

### Example 3: Contains stops at a match

```csharp
IEnumerable<int> Generate()
{
    for (int i = 1; i <= 5; i++)
    {
        Console.WriteLine($"Generating {i}");
        yield return i;
    }
}

bool result = Generate().Contains(3);

Console.WriteLine(result);
```

**Output:**

```text
Generating 1
Generating 2
Generating 3
True
```

### Comparison

| Operator | Stops When |
|---|---|
| `Any()` | First element is found |
| `Any(predicate)` | First matching element is found |
| `All(predicate)` | First non-matching element is found |
| `Contains(value)` | Matching value is found |

If no early result is possible, the sequence must be examined until its end.

## 5. Membership Lookup Cost

Membership lookup cost describes the time required to determine whether a value exists.

The cost depends on the collection type and its implementation.

### Example 1: Array

```csharp
int[] numbers = { 10, 20, 30, 40 };

bool result = numbers.Contains(30);
```

An array generally requires a linear search.

**Typical complexity:**

\[
O(n)
\]

### Example 2: List

```csharp
List<int> numbers = new()
{
    10, 20, 30, 40
};

bool result = numbers.Contains(30);
```

A list generally performs a linear search.

**Typical complexity:**

\[
O(n)
\]

### Example 3: HashSet

```csharp
HashSet<int> numbers = new()
{
    10, 20, 30, 40
};

bool result = numbers.Contains(30);

Console.WriteLine(result);
```

**Output:**

```text
True
```

A hash set normally provides average constant-time membership lookup.

**Average complexity:**

\[
O(1)
\]

### Example 4: Repeated membership checks

```csharp
int[] numbers = Enumerable.Range(1, 1000).ToArray();

HashSet<int> lookup = numbers.ToHashSet();

Console.WriteLine(lookup.Contains(500));
Console.WriteLine(lookup.Contains(900));
```

**Output:**

```text
True
True
```

### Comparison

| Collection | Typical Membership Lookup |
|---|---|
| Array | \(O(n)\) |
| `List<T>` | \(O(n)\) |
| `HashSet<T>` | Average \(O(1)\) |
| `SortedSet<T>` | \(O(\log n)\) |
| General `IEnumerable<T>` | Usually \(O(n)\) |

These costs describe typical collection membership operations. A LINQ extension method may use a collection's specialized implementation when available.

**Key point:** For repeated membership checks, an appropriate lookup collection can reduce search costs.

## 6. Any vs Count

`Any()` checks whether elements exist.

`Count()` calculates the number of elements.

### Example 1: Any

```csharp
int[] numbers = { 10, 20, 30 };

bool result = numbers.Any();

Console.WriteLine(result);
```

**Output:**

```text
True
```

### Example 2: Count

```csharp
int[] numbers = { 10, 20, 30 };

int result = numbers.Count();

Console.WriteLine(result);
```

**Output:**

```text
3
```

### Example 3: Predicate comparison

```csharp
int[] numbers = { 10, 20, 30, 40 };

bool exists = numbers.Any(n => n > 20);

int count = numbers.Count(n => n > 20);

Console.WriteLine(exists);
Console.WriteLine(count);
```

**Output:**

```text
True
2
```

### Example 4: Execution difference

```csharp
int[] numbers = { 10, 20, 30, 40 };

bool exists = numbers.Any(n =>
{
    Console.WriteLine($"Any: {n}");
    return n >= 20;
});

int count = numbers.Count(n =>
{
    Console.WriteLine($"Count: {n}");
    return n >= 20;
});
```

**Output:**

```text
Any: 10
Any: 20
Count: 10
Count: 20
Count: 30
Count: 40
```

`Any(predicate)` stops at the first match.

`Count(predicate)` examines the sequence to count every match.

### Comparison

| Feature | Any | Count |
|---|---|---|
| Return type | `bool` | `int` |
| Purpose | Existence | Quantity |
| Predicate overload | Yes | Yes |
| Can stop at first match | Yes | No, when counting matches |
| Empty sequence result | `false` | `0` |
| Best for existence checking | Yes | No |

**Key point:** Use `Any()` when only existence matters. Use `Count()` when the number of elements is required.

## 7. Equality Semantics

Equality semantics define when two values are considered equal.

These rules are particularly important for `Contains()`.

### Example 1: Value equality

```csharp
int[] numbers = { 10, 20, 30 };

bool result = numbers.Contains(20);

Console.WriteLine(result);
```

**Output:**

```text
True
```

### Example 2: String equality

```csharp
string[] names = { "Amit", "Rahul" };

Console.WriteLine(names.Contains("Amit"));
Console.WriteLine(names.Contains("amit"));
```

**Output:**

```text
True
False
```

### Example 3: Case-insensitive equality

```csharp
string[] names = { "Amit", "Rahul" };

bool result = names.Contains(
    "amit",
    StringComparer.OrdinalIgnoreCase
);

Console.WriteLine(result);
```

**Output:**

```text
True
```

### Example 4: Record equality

```csharp
record Product(int Id, string Name);

Product first = new(1, "Mouse");
Product second = new(1, "Mouse");

Console.WriteLine(first == second);
```

**Output:**

```text
True
```

### Example 5: Reference equality

```csharp
class Product
{
    public int Id { get; set; }
}

Product first = new() { Id = 1 };
Product second = new() { Id = 1 };

Console.WriteLine(first == second);
```

**Output:**

```text
False
```

### Example 6: Custom equality

```csharp
string[] values = { "HELLO", "WORLD" };

bool result = values.Contains(
    "hello",
    StringComparer.OrdinalIgnoreCase
);

Console.WriteLine(result);
```

**Output:**

```text
True
```

### Equality comparison

| Equality Type | Description |
|---|---|
| Value equality | Compares values |
| Reference equality | Compares object identity |
| Default equality | Uses `EqualityComparer<T>.Default` |
| Custom equality | Uses `IEqualityComparer<T>` |
| Case-sensitive equality | Distinguishes uppercase and lowercase |
| Case-insensitive equality | Ignores case differences according to the comparer |

**Key point:** Membership results depend on the equality rules used for the element type.
