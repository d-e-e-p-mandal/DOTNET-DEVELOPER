# 07.06 — ELEMENT RETRIEVAL

**Chapter:** 07 — LINQ Aggregation & Grouping  
**Namespace:** `System.Linq`  
**Total Syllabus Topics:** 22

Element retrieval operators select individual elements from a sequence.

This section covers all **22 topics from your syllabus**, in their original order.

---

## 1. First

`First()` returns the first element of a sequence.

### Syntax

```csharp
source.First();
```

### Example 1: Integer array

```csharp
int[] numbers = { 10, 20, 30, 40 };

int result = numbers.First();

Console.WriteLine(result);
```

**Output:**

```text
10
```

### Example 2: String array

```csharp
string[] names = { "Amit", "Rahul", "Priya" };

string result = names.First();

Console.WriteLine(result);
```

**Output:**

```text
Amit
```

### Example 3: Object collection

```csharp
record Student(int Id, string Name);

Student[] students =
{
    new(1, "Amit"),
    new(2, "Rahul"),
    new(3, "Priya")
};

Student result = students.First();

Console.WriteLine(result.Name);
```

**Output:**

```text
Amit
```

### Empty sequence

```csharp
int[] numbers = Array.Empty<int>();

int result = numbers.First();
```

**Result:**

```text
InvalidOperationException
```

**Key point:** `First()` requires at least one element.

## 2. First(predicate)

`First(predicate)` returns the first element satisfying a condition.

### Syntax

```csharp
source.First(x => condition);
```

### Example 1: First even number

```csharp
int[] numbers = { 1, 3, 6, 8, 10 };

int result = numbers.First(n => n % 2 == 0);

Console.WriteLine(result);
```

**Output:**

```text
6
```

### Example 2: First number greater than 20

```csharp
int[] numbers = { 10, 15, 25, 30 };

int result = numbers.First(n => n > 20);

Console.WriteLine(result);
```

**Output:**

```text
25
```

### Example 3: First matching student

```csharp
record Student(string Name, int Marks);

Student[] students =
{
    new("Amit", 65),
    new("Rahul", 85),
    new("Priya", 95)
};

Student result = students.First(s => s.Marks >= 80);

Console.WriteLine(result.Name);
```

**Output:**

```text
Rahul
```

### No matching element

```csharp
int[] numbers = { 10, 20, 30 };

int result = numbers.First(n => n > 100);
```

**Result:**

```text
InvalidOperationException
```

**Key point:** `First(predicate)` returns the first match, not every match.


### Example 1: Non-empty sequence

```csharp

```

```csharp

Console.WriteLine(result is null);
```

**Output:**

```text
True
```

### Default values

| Element Type | Default Value |
|---|---|
| `int` | `0` |
| `long` | `0` |

| Nullable value type | `null` |

`FirstOrDefault(predicate)` returns the first matching element or the default value when no match exists.

### Syntax


### Example 1: Matching element

```csharp
int[] numbers = { 10, 20, 30, 40 };

int result = numbers.FirstOrDefault(n => n > 25);

```

**Output:**

```text

```

### Example 2: No matching element

```csharp

int result = numbers.FirstOrDefault(n => n > 100);

Console.WriteLine(result);
```

**Output:**

```text
0
```

### Example 3: Object collection

```csharp
record Student(string Name, int Marks);

Student[] students =
{
    new("Amit", 70),
    new("Rahul", 85)
```

## 5. FirstOrDefault with Explicit Default

`FirstOrDefault()` supports an explicit fallback value.

### Syntax

```csharp
source.FirstOrDefault(defaultValue);
```

With a predicate:

```csharp
source.FirstOrDefault(
    x => condition,
    defaultValue
);
```

### Example 1: Explicit integer default

```csharp
int[] numbers = Array.Empty<int>();

int result = numbers.FirstOrDefault(-1);

Console.WriteLine(result);
```

**Output:**

```text
-1
```

### Example 2: Explicit default with predicate

```csharp
int[] numbers = { 10, 20, 30 };

int result = numbers.FirstOrDefault(
    n => n > 100,
    -1
);

Console.WriteLine(result);
```

**Output:**

```text
-1
```

### Example 3: Explicit string default

```csharp
string[] names = Array.Empty<string>();

string result = names.FirstOrDefault("Unknown");

Console.WriteLine(result);
```

**Output:**

```text
Unknown
```

### Example 4: Matching element takes priority

```csharp
int[] numbers = { 10, 20, 30 };

int result = numbers.FirstOrDefault(
    n => n > 15,
    -1
);

Console.WriteLine(result);
```

**Output:**

```text
20
```

**Key point:** The explicit default is returned only when no qualifying element exists.


```text

```

| Element Count | Result |

## 16. Index-Based Element Access

Index-based access retrieves an element using its position in a sequence.

### Example 1: Array indexer

```csharp
int[] numbers = { 10, 20, 30 };

Console.WriteLine(numbers[1]);
```

**Output:**

```text
20
```

### Example 2: List indexer

```csharp
List<int> numbers = new()
{
    10, 20, 30
};

Console.WriteLine(numbers[2]);
```

**Output:**

```text
30
```

### Example 3: LINQ ElementAt

```csharp
IEnumerable<int> numbers = Enumerable.Range(10, 5);

Console.WriteLine(numbers.ElementAt(2));
```

**Output:**

```text
12
```

### Example 4: Index-from-end syntax

```csharp
int[] numbers = { 10, 20, 30, 40 };

Console.WriteLine(numbers[^1]);
Console.WriteLine(numbers[^2]);
```

**Output:**

```text
40
30
```

### Example 5: ElementAt with Index

```csharp
int[] numbers = { 10, 20, 30, 40 };

Console.WriteLine(numbers.ElementAt(^1));
Console.WriteLine(numbers.ElementAt(^2));
```

**Output:**

```text
40
30
```

### Comparison

| Access Method | Description |
|---|---|
| `array[index]` | Direct array access |
| `list[index]` | Direct list access |
| `ElementAt(index)` | LINQ positional retrieval |
| `ElementAtOrDefault(index)` | Positional retrieval with fallback |
| `[^1]` | Last element using index-from-end |
| `ElementAt(^1)` | Last element through LINQ |

**Key point:** Arrays and lists provide direct indexed access. General `IEnumerable<T>` sequences may require enumeration to reach an index.


**Output:**

```text
0
```

### Example 3: Last

```csharp

```

## 19. Default Values as Valid Data

A default value can also be a legitimate element of a sequence.

This can make it difficult to distinguish a missing result from an actual matching value.

### Example 1: Zero as valid data

```csharp
int[] numbers = { 0, 10, 20 };

int result = numbers.FirstOrDefault();

Console.WriteLine(result);
```

**Output:**

```text
0
```

### Example 2: Zero from no match

```csharp
int[] numbers = { 10, 20 };

int result = numbers.FirstOrDefault(n => n > 100);

Console.WriteLine(result);
```

**Output:**

```text
0
```

Both examples return zero, but for different reasons.

### Example 3: Explicit fallback

```csharp
int[] numbers = { 0, 10, 20 };

int result = numbers.FirstOrDefault(
    n => n > 100,
    -1
);

Console.WriteLine(result);
```

**Output:**

```text
-1
```

### Example 4: Nullable result

```csharp
int[] numbers = { 0, 10, 20 };

int? result = numbers
    .Where(n => n > 100)
    .Select(n => (int?)n)
    .FirstOrDefault();

Console.WriteLine(result is null);
```

**Output:**

```text
True
```

### Example 5: Check existence separately

```csharp
int[] numbers = { 0, 10, 20 };

bool exists = numbers.Any(n => n == 0);

int result = numbers.FirstOrDefault(n => n == 0);

Console.WriteLine(exists);
Console.WriteLine(result);
```

**Output:**

```text
True
0
```

**Key point:** A returned default value does not necessarily mean no element was found.

## 21. First vs Single

`First()` selects the first element.

`Single()` requires exactly one element.

### Example 1: One element

```csharp
int[] numbers = { 10 };

Console.WriteLine(numbers.First());
Console.WriteLine(numbers.Single());
```

**Output:**

```text
10
10
```

### Example 2: Multiple elements

```csharp
int[] numbers = { 10, 20, 30 };

Console.WriteLine(numbers.First());
```

**Output:**

```text
10
```

But:

```csharp
int result = numbers.Single();
```

**Result:**

```text
InvalidOperationException
```

### Example 3: First matching element

```csharp
int[] numbers = { 10, 20, 30, 40 };

int result = numbers.First(n => n > 15);

Console.WriteLine(result);
```

**Output:**

```text
20
```

### Example 4: Single matching element

```csharp
int[] numbers = { 10, 20, 30, 40 };

int result = numbers.Single(n => n == 30);

Console.WriteLine(result);
```

**Output:**

```text
30
```

### Comparison

| Feature | First | Single |
|---|---|---|
| Returns | First qualifying element | Only qualifying element |
| Zero matches | Throws | Throws |
| One match | Returns element | Returns element |
| Multiple matches | Returns first | Throws |
| Checks uniqueness | No | Yes |
| Typical requirement | At least one match | Exactly one match |

**Key point:** Use `First()` when multiple matches are acceptable. Use `Single()` when multiple matches indicate invalid data.

## 22. Expressing Expected Cardinality

Cardinality describes the number of elements expected from a query.

Element retrieval operators communicate different cardinality requirements.

### 22.1 Exactly One

Use `Single()` when exactly one element must exist.

```csharp
record Student(int Id, string Name);

Student[] students =
{
    new(1, "Amit"),
    new(2, "Rahul")
};

Student result = students.Single(s => s.Id == 1);

Console.WriteLine(result.Name);
```

**Output:**

```text
Amit
```

**Expected cardinality:**

\[
1
\]

---

### 22.2 Zero or One

Use `SingleOrDefault()` when an element may be missing but duplicates are not allowed.

```csharp
Student? result = students.SingleOrDefault(
    s => s.Id == 10
);

Console.WriteLine(result is null);
```

**Output:**

```text
True
```

**Expected cardinality:**

\[
0 \text{ or } 1
\]

---

### 22.3 One or More

Use `First()` when at least one element is required and additional matches are acceptable.

```csharp
int[] numbers = { 10, 20, 30 };

int result = numbers.First();

Console.WriteLine(result);
```

**Output:**

```text
10
```

**Expected cardinality:**

\[
1 \text{ or more}
\]

---

### 22.4 Zero or More

Use `FirstOrDefault()` when zero or more elements are acceptable and only the first is needed.

```csharp
int[] numbers = Array.Empty<int>();

int result = numbers.FirstOrDefault();

Console.WriteLine(result);
```

**Output:**

```text
0
```

**Expected cardinality:**

\[
0 \text{ or more}
\]

---

### Cardinality comparison

| Requirement | Operator | Zero Matches | Multiple Matches |
|---|---|---|---|
| Exactly one | `Single()` | Exception | Exception |
| Zero or one | `SingleOrDefault()` | Default | Exception |
| At least one | `First()` | Exception | First match |
| Zero or more | `FirstOrDefault()` | Default | First match |
| Last required | `Last()` | Exception | Last match |
| Last optional | `LastOrDefault()` | Default | Last match |

**Key point:** Choose retrieval operators according to the number of matching elements your program expects.
