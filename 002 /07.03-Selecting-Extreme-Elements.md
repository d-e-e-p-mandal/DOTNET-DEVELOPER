## 1. MinBy

`MinBy()` returns the **element that has the smallest key value**.

Unlike `Min()`, which normally returns the minimum selected value, `MinBy()` returns the original element.

**Available since:** .NET 6

### Syntax

```csharp
source.MinBy(x => x.Property);
```

### Example 1: Minimum by marks

```csharp
record Student(string Name, int Marks);

Student[] students =
{
    new("Amit", 90),
    new("Rahul", 70),
    new("Priya", 95)
};

Student? result = students.MinBy(s => s.Marks);

Console.WriteLine(result?.Name);
Console.WriteLine(result?.Marks);
```

**Output:**

```text
Rahul
70
```

### Example 2: Cheapest product

```csharp
record Product(string Name, decimal Price);

Product[] products =
{
    new("Mouse", 500m),
    new("Keyboard", 1200m),
    new("Monitor", 8000m)
};

Product? cheapest = products.MinBy(p => p.Price);

Console.WriteLine(cheapest?.Name);
```

**Output:**

```text
Mouse
```

### Example 3: Shortest string

```csharp
string[] names =
{
    "Alexander",
    "Amit",
    "Rahul"
};

string? result = names.MinBy(name => name.Length);

Console.WriteLine(result);
```

**Output:**

```text
Amit
```

### Example 4: Minimum by date

```csharp
record Order(int Id, DateTime OrderDate);

Order[] orders =
{
    new(1, new DateTime(2026, 5, 10)),
    new(2, new DateTime(2026, 2, 15)),
    new(3, new DateTime(2026, 8, 20))
};

Order? earliest = orders.MinBy(o => o.OrderDate);

Console.WriteLine(earliest?.Id);
```

**Output:**

```text
2
```

**Key point:** `MinBy()` returns the element associated with the minimum key.

## 2. MaxBy

`MaxBy()` returns the **element that has the largest key value**.

### Syntax

```csharp
source.MaxBy(x => x.Property);
```

### Example 1: Maximum marks

```csharp
record Student(string Name, int Marks);

Student[] students =
{
    new("Amit", 90),
    new("Rahul", 70),
    new("Priya", 95)
};

Student? result = students.MaxBy(s => s.Marks);

Console.WriteLine(result?.Name);
Console.WriteLine(result?.Marks);
```

**Output:**

```text
Priya
95
```

### Example 2: Most expensive product

```csharp
record Product(string Name, decimal Price);

Product[] products =
{
    new("Mouse", 500m),
    new("Keyboard", 1200m),
    new("Monitor", 8000m)
};

Product? expensive = products.MaxBy(p => p.Price);

Console.WriteLine(expensive?.Name);
```

**Output:**

```text
Monitor
```

### Example 3: Longest string

```csharp
string[] names =
{
    "Amit",
    "Alexander",
    "Rahul"
};

string? result = names.MaxBy(name => name.Length);

Console.WriteLine(result);
```

**Output:**

```text
Alexander
```

### Example 4: Latest order

```csharp
record Order(int Id, DateTime OrderDate);

Order[] orders =
{
    new(1, new DateTime(2026, 5, 10)),
    new(2, new DateTime(2026, 2, 15)),
    new(3, new DateTime(2026, 8, 20))
};

Order? latest = orders.MaxBy(o => o.OrderDate);

Console.WriteLine(latest?.Id);
```

**Output:**

```text
3
```

**Key point:** `MaxBy()` returns the element associated with the maximum key.

## 3. Key Selector

A **key selector** is a function that extracts the value used for comparison.

### Syntax

```csharp
Func<TSource, TKey> keySelector
```

In LINQ:

```csharp
source.MinBy(x => x.Property);
source.MaxBy(x => x.Property);
```

The expressions `x => x.Property` are key selectors.

### Example 1: Select numeric key

```csharp
record Employee(string Name, int Salary);

Employee[] employees =
{
    new("Amit", 50000),
    new("Rahul", 70000),
    new("Priya", 60000)
};

Employee? result = employees.MaxBy(e => e.Salary);

Console.WriteLine(result?.Name);
```

**Output:**

```text
Rahul
```

Here:

```csharp
e => e.Salary
```

is the key selector.

### Example 2: Select string length

```csharp
string[] words =
{
    "C#",
    "Java",
    "Python"
};

string? result = words.MaxBy(word => word.Length);

Console.WriteLine(result);
```

**Output:**

```text
Python
```

### Example 3: Calculated key

```csharp
record Product(string Name, int Quantity, decimal Price);

Product[] products =
{
    new("Mouse", 2, 500m),
    new("Keyboard", 3, 1200m),
    new("Monitor", 1, 8000m)
};

Product? result = products.MaxBy(
    p => p.Quantity * p.Price
);

Console.WriteLine(result?.Name);
```

**Output:**

```text
Monitor
```

### Example 4: Explicit key selector

```csharp
Func<Product, decimal> selector =
    p => p.Quantity * p.Price;

Product? result = products.MaxBy(selector);
```

### Key selector structure

```text
Source Element
      │
      ▼
Key Selector
      │
      ▼
Comparison Key
      │
      ▼
MinBy / MaxBy
      │
      ▼
Selected Source Element
```

**Key point:** The key selector determines which property or calculated value is compared.

## 4. Selecting Element vs Key

`Min()` and `Max()` can return selected key values.

`MinBy()` and `MaxBy()` return the original elements associated with those keys.

### Example 1: Select minimum key

```csharp
record Student(string Name, int Marks);

Student[] students =
{
    new("Amit", 90),
    new("Rahul", 70),
    new("Priya", 95)
};

int minimumMarks = students.Min(s => s.Marks);

Console.WriteLine(minimumMarks);
```

**Output:**

```text
70
```

### Example 2: Select minimum element

```csharp
Student? student = students.MinBy(s => s.Marks);

Console.WriteLine(student?.Name);
Console.WriteLine(student?.Marks);
```

**Output:**

```text
Rahul
70
```

### Example 3: Select maximum key

```csharp
int maximumMarks = students.Max(s => s.Marks);

Console.WriteLine(maximumMarks);
```

**Output:**

```text
95
```

### Example 4: Select maximum element

```csharp
Student? student = students.MaxBy(s => s.Marks);

Console.WriteLine(student?.Name);
Console.WriteLine(student?.Marks);
```

**Output:**

```text
Priya
95
```

### Comparison

| Operation | Returns |
|---|---|
| `Min(s => s.Marks)` | Minimum marks |
| `Max(s => s.Marks)` | Maximum marks |
| `MinBy(s => s.Marks)` | Student with minimum marks |
| `MaxBy(s => s.Marks)` | Student with maximum marks |

**Key point:** Use `MinBy()` or `MaxBy()` when the complete source element is required.

## 5. Custom Key Comparer

`MinBy()` and `MaxBy()` support custom key comparers.

A comparer determines how keys are ordered.

### Syntax

```csharp
source.MinBy(keySelector, comparer);

source.MaxBy(keySelector, comparer);
```

The comparer implements:

```csharp
IComparer<TKey>
```

### Example 1: Case-insensitive comparison

```csharp
string[] names =
{
    "zebra",
    "Apple",
    "banana"
};

string? result = names.MinBy(
    name => name,
    StringComparer.OrdinalIgnoreCase
);

Console.WriteLine(result);
```

**Output:**

```text
Apple
```

### Example 2: Maximum with custom comparer

```csharp
string[] names =
{
    "zebra",
    "Apple",
    "banana"
};

string? result = names.MaxBy(
    name => name,
    StringComparer.OrdinalIgnoreCase
);

Console.WriteLine(result);
```

**Output:**

```text
zebra
```

### Example 3: Reverse numeric comparison

```csharp
int[] numbers = { 10, 20, 30 };

IComparer<int> reverseComparer =
    Comparer<int>.Create((a, b) => b.CompareTo(a));

int minimum = numbers.MinBy(
    n => n,
    reverseComparer
);

Console.WriteLine(minimum);
```

**Output:**

```text
30
```

Because the comparer reverses the ordering, the largest numeric value is considered the smallest key.

### Example 4: Reverse comparison with MaxBy

```csharp
int maximum = numbers.MaxBy(
    n => n,
    reverseComparer
);

Console.WriteLine(maximum);
```

**Output:**

```text
10
```

### Comparison

| Comparer | Behavior |
|---|---|
| Default comparer | Uses default key ordering |
| `StringComparer.Ordinal` | Ordinal string comparison |
| `StringComparer.OrdinalIgnoreCase` | Case-insensitive ordinal comparison |
| Custom `IComparer<T>` | Developer-defined ordering |

**Key point:** A custom comparer changes how keys are ordered, not which key the selector extracts.

## 6. Equal Keys

Equal keys occur when two or more elements produce the same comparison key.

### Example 1: Equal marks

```csharp
record Student(string Name, int Marks);

Student[] students =
{
    new("Amit", 90),
    new("Rahul", 70),
    new("Priya", 70)
};

Student? result = students.MinBy(s => s.Marks);

Console.WriteLine(result?.Name);
```

**Output:**

```text
Rahul
```

Both Rahul and Priya have the minimum marks.

`MinBy()` selects the first encountered element among equal minimum keys.

### Example 2: Equal maximum keys

```csharp
Student[] students =
{
    new("Amit", 95),
    new("Rahul", 80),
    new("Priya", 95)
};

Student? result = students.MaxBy(s => s.Marks);

Console.WriteLine(result?.Name);
```

**Output:**

```text
Amit
```

### Example 3: Equal string lengths

```csharp
string[] names =
{
    "Amit",
    "John",
    "Rahul"
};

string? result = names.MinBy(n => n.Length);

Console.WriteLine(result);
```

**Output:**

```text
Amit
```

Both `"Amit"` and `"John"` have length 4.

### Example 4: All equal keys

```csharp
int[] numbers = { 10, 10, 10 };

Console.WriteLine(numbers.MinBy(n => n));
Console.WriteLine(numbers.MaxBy(n => n));
```

**Output:**

```text
10
10
```

**Key point:** Equal keys are allowed. `MinBy()` and `MaxBy()` do not require unique keys.

## 7. Tie Behavior

A tie occurs when multiple elements share the minimum or maximum key.

For LINQ to Objects, `MinBy()` and `MaxBy()` return the **first encountered element** among tied keys.

### Example 1: MinBy tie

```csharp
record Student(string Name, int Marks);

Student[] students =
{
    new("Rahul", 70),
    new("Priya", 70),
    new("Amit", 90)
};

Student? result = students.MinBy(s => s.Marks);

Console.WriteLine(result?.Name);
```

**Output:**

```text
Rahul
```

### Example 2: MaxBy tie

```csharp
Student[] students =
{
    new("Amit", 95),
    new("Priya", 95),
    new("Rahul", 80)
};

Student? result = students.MaxBy(s => s.Marks);

Console.WriteLine(result?.Name);
```

**Output:**

```text
Amit
```

### Example 3: Change source order

```csharp
Student[] students =
{
    new("Priya", 95),
    new("Amit", 95),
    new("Rahul", 80)
};

Student? result = students.MaxBy(s => s.Marks);

Console.WriteLine(result?.Name);
```

**Output:**

```text
Priya
```

### Example 4: Explicit tie-breaking

To choose the student with the highest marks and then the alphabetically smallest name:

```csharp
Student? result = students
    .OrderByDescending(s => s.Marks)
    .ThenBy(s => s.Name, StringComparer.Ordinal)
    .FirstOrDefault();

Console.WriteLine(result?.Name);
```

**Output:**

```text
Amit
```

### Tie behavior comparison

| Situation | Result |
|---|---|
| One minimum key | Element with minimum key |
| Multiple equal minimum keys | First encountered tied element |
| One maximum key | Element with maximum key |
| Multiple equal maximum keys | First encountered tied element |
| Explicit secondary ordering | Determined by specified ordering |

**Important:** If the source does not have a guaranteed order, the identity of the first tied element may not be predictable.

## 8. Null Keys

A key selector can return null when the key type supports null values.

### Example 1: Nullable numeric keys

```csharp
record Student(string Name, int? Marks);

Student[] students =
{
    new("Amit", null),
    new("Rahul", 70),
    new("Priya", 90)
};

Student? result = students.MinBy(s => s.Marks);

Console.WriteLine(result?.Name);
```

**Output:**

```text
Rahul
```

With the default nullable-key comparer, null keys are skipped by `MinBy()` when selecting the minimum among non-null keys.

### Example 2: Nullable keys with MaxBy

```csharp
Student? result = students.MaxBy(s => s.Marks);

Console.WriteLine(result?.Name);
```

**Output:**

```text
Priya
```

### Example 3: All null keys

```csharp
Student[] students =
{
    new("Amit", null),
    new("Rahul", null)
};

Student? result = students.MinBy(s => s.Marks);

Console.WriteLine(result is null);
```

**Output:**

```text
True
```

### Example 4: Exclude null keys explicitly

```csharp
Student? result = students
    .Where(s => s.Marks.HasValue)
    .MinBy(s => s.Marks);
```

If all keys are null, the filtered sequence is empty and the result is null because `Student` is a reference type.

### Example 5: Null string keys

```csharp
record Product(string Name, string? Category);

Product[] products =
{
    new("Mouse", null),
    new("Keyboard", "Accessories"),
    new("Monitor", "Displays")
};

Product? result = products.MinBy(p => p.Category);

Console.WriteLine(result?.Name);
```

**Output:**

```text
Keyboard
```

### Important rules

- With the default comparer, null keys are skipped for nullable or reference-type keys.
- If every key is null, the result is `default(TSource)`.
- A custom comparer can define different null-key ordering.
- Null source elements and null keys are different situations.

## 9. Empty Sequence Behavior

`MinBy()` and `MaxBy()` behave differently for empty sequences depending on the source element type.

### Example 1: Empty reference-type sequence

```csharp
record Student(string Name, int Marks);

Student[] students = Array.Empty<Student>();

Student? result = students.MinBy(s => s.Marks);

Console.WriteLine(result is null);
```

**Output:**

```text
True
```

### Example 2: Empty reference-type MaxBy

```csharp
Student[] students = Array.Empty<Student>();

Student? result = students.MaxBy(s => s.Marks);

Console.WriteLine(result is null);
```

**Output:**

```text
True
```

### Example 3: Empty value-type sequence

```csharp
int[] numbers = Array.Empty<int>();

int result = numbers.MinBy(n => n);
```

**Result:**

```text
InvalidOperationException
```

### Example 4: Empty value-type MaxBy

```csharp
int[] numbers = Array.Empty<int>();

int result = numbers.MaxBy(n => n);
```

**Result:**

```text
InvalidOperationException
```

### Example 5: Nullable value-type sequence

```csharp
int?[] numbers = Array.Empty<int?>();

int? minimum = numbers.MinBy(n => n);
int? maximum = numbers.MaxBy(n => n);

Console.WriteLine(minimum is null);
Console.WriteLine(maximum is null);
```

**Output:**

```text
True
True
```

### Empty sequence comparison

| Source Element Type | MinBy | MaxBy |
|---|---|---|
| Reference type | Returns `null` | Returns `null` |
| Non-nullable value type | Throws | Throws |
| Nullable value type | Returns `null` | Returns `null` |

**Key point:** Empty-sequence behavior depends on whether `TSource` can represent null.

## 10. Min/Max vs MinBy/MaxBy

`Min()` and `Max()` find extreme values.

`MinBy()` and `MaxBy()` find the original elements associated with extreme keys.

### Example 1: Min

```csharp
record Student(string Name, int Marks);

Student[] students =
{
    new("Amit", 90),
    new("Rahul", 70),
    new("Priya", 95)
};

int result = students.Min(s => s.Marks);

Console.WriteLine(result);
```

**Output:**

```text
70
```

### Example 2: Max

```csharp
int result = students.Max(s => s.Marks);

Console.WriteLine(result);
```

**Output:**

```text
95
```

### Example 3: MinBy

```csharp
Student? result = students.MinBy(s => s.Marks);

Console.WriteLine(result?.Name);
```

**Output:**

```text
Rahul
```

### Example 4: MaxBy

```csharp
Student? result = students.MaxBy(s => s.Marks);

Console.WriteLine(result?.Name);
```

**Output:**

```text
Priya
```

### Example 5: Compare return types

```csharp
int minimumMarks = students.Min(s => s.Marks);

Student? minimumStudent = students.MinBy(s => s.Marks);
```

Here:

```text
Min()   → int
MinBy() → Student
```

### Complete comparison

| Feature | Min | Max | MinBy | MaxBy |
|---|---|---|---|---|
| Finds | Minimum value | Maximum value | Minimum key | Maximum key |
| Returns | Value | Value | Source element | Source element |
| Key selector | Optional | Optional | Required | Required |
| Custom comparer | Supported for comparable element types | Supported for comparable element types | Supported | Supported |
| Returns complete object | Only if the object itself is the selected value | Only if the object itself is the selected value | Yes | Yes |
| Introduced | Earlier .NET versions | Earlier .NET versions | .NET 6 | .NET 6 |
| Typical use | Lowest numeric value | Highest numeric value | Object with lowest property | Object with highest property |

### Final example

```csharp
record Product(string Name, decimal Price);

Product[] products =
{
    new("Mouse", 500m),
    new("Keyboard", 1200m),
    new("Monitor", 8000m)
};

decimal minimumPrice = products.Min(p => p.Price);
decimal maximumPrice = products.Max(p => p.Price);

Product? cheapestProduct = products.MinBy(p => p.Price);
Product? expensiveProduct = products.MaxBy(p => p.Price);

Console.WriteLine(minimumPrice);
Console.WriteLine(maximumPrice);
Console.WriteLine(cheapestProduct?.Name);
Console.WriteLine(expensiveProduct?.Name);
```

**Output:**

```text
500
8000
Mouse
Monitor
```
