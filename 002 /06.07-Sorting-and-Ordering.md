# 06.07 — FLATTENING NESTED SEQUENCES

**Chapter:** 06 — LINQ Fundamentals  
**Namespace:** `System.Linq`

## 1. SelectMany

`SelectMany()` transforms each source element into a sequence and combines those sequences into one sequence.

### Syntax

```csharp
source.SelectMany(x => collection);
```

### Example

```csharp
int[][] numbers =
{
    new[] { 1, 2 },
    new[] { 3, 4 },
    new[] { 5, 6 }
};

var result = numbers.SelectMany(x => x);

// Output: 1, 2, 3, 4, 5, 6
```

### Example: List of Lists

```csharp
List<List<int>> numbers = new()
{
    new() { 10, 20 },
    new() { 30, 40 },
    new() { 50, 60 }
};

var result = numbers.SelectMany(list => list);

// Output: 10, 20, 30, 40, 50, 60
```

---

## 2. Select vs SelectMany

`Select()` preserves nested sequences, while `SelectMany()` combines their elements into one sequence.

### 2.1 Select

```csharp
int[][] numbers =
{
    new[] { 1, 2 },
    new[] { 3, 4 }
};

var result = numbers.Select(x => x);

// Result type: IEnumerable<int[]>
// Result: [1, 2], [3, 4]
```

### 2.2 SelectMany

```csharp
var result = numbers.SelectMany(x => x);

// Result type: IEnumerable<int>
// Output: 1, 2, 3, 4
```

### Comparison

| Feature | Select | SelectMany |
|---|---|---|
| Purpose | Projection | Projection and flattening |
| Nested collections | Preserved | Flattened |
| Output | One result per source element | Zero or more results per source element |
| Example result type | `IEnumerable<int[]>` | `IEnumerable<int>` |

## 3. Collection Selector

A collection selector specifies which inner sequence to enumerate for each outer element.

### Syntax

```csharp
source.SelectMany(x => x.Collection);
```

### Example 1: Student Subjects

```csharp
record Student(string Name, string[] Subjects);

Student[] students =
{
    new("Amit", new[] { "C#", "SQL" }),
    new("Rahul", new[] { "Java", "Python" })
};

var result = students.SelectMany(s => s.Subjects);

// Output: C#, SQL, Java, Python
```

Here, `s => s.Subjects` is the collection selector.

### Example 2: Department Employees

```csharp
record Department(string Name, string[] Employees);

Department[] departments =
{
    new("IT", new[] { "Amit", "Rahul" }),
    new("HR", new[] { "Priya", "Neha" })
};

var result = departments.SelectMany(d => d.Employees);

// Output: Amit, Rahul, Priya, Neha
```

---

## 4. Result Selector

A result selector combines an outer element with each selected inner element.

### Syntax

```csharp
source.SelectMany(
    outer => outer.Collection,
    (outer, inner) => result
);
```

### Example 1: Student and Subject

```csharp
record Student(string Name, string[] Subjects);

Student[] students =
{
    new("Amit", new[] { "C#", "SQL" }),
    new("Rahul", new[] { "Java", "Python" })
};

var result = students.SelectMany(
    s => s.Subjects,
    (s, subject) => new
    {
        Student = s.Name,
        Subject = subject
    }
);
```

**Output:**

```text
Amit  C#
Amit  SQL
Rahul Java
Rahul Python
```

### Example 2: Number Pairs

```csharp
int[] a = { 1, 2 };
int[] b = { 10, 20 };

var result = a.SelectMany(
    x => b,
    (x, y) => x + y
);

// Output: 11, 21, 12, 22
```

---

## 5. Indexed SelectMany

Indexed `SelectMany()` passes the outer element's zero-based index to the collection selector.

### Syntax

```csharp
source.SelectMany((element, index) => collection);
```

### Example 1: Using Index

```csharp
string[] words = { "Cat", "Dog", "Bird" };

var result = words.SelectMany(
    (word, index) => word.Take(index + 1)
);

// Output: C, D, o, B, i, r
```

**Explanation:**

```text
Index 0 → Cat  → C
Index 1 → Dog  → D, o
Index 2 → Bird → B, i, r
```

### Example 2: Indexed Result Selector

```csharp
string[][] groups =
{
    new[] { "A", "B" },
    new[] { "C", "D" }
};

var result = groups.SelectMany(
    (group, index) => group.Select(
        value => $"{index}: {value}"
    )
);

// Output: 0: A, 0: B, 1: C, 1: D
```

## 6. Nested Collections

Nested collections contain collections inside other collections.

### Example 1: Nested Arrays

```csharp
int[][] numbers =
{
    new[] { 1, 2 },
    new[] { 3, 4 },
    new[] { 5, 6 }
};

var result = numbers.SelectMany(row => row);

// Output: 1, 2, 3, 4, 5, 6
```

### Example 2: Nested Lists

```csharp
List<List<string>> names = new()
{
    new() { "Amit", "Rahul" },
    new() { "Priya", "Neha" }
};

var result = names.SelectMany(list => list);

// Output: Amit, Rahul, Priya, Neha
```

### Example 3: Nested Object Collections

```csharp
record Order(int Id, int[] ProductIds);

Order[] orders =
{
    new(1, new[] { 101, 102 }),
    new(2, new[] { 103, 104 })
};

var result = orders.SelectMany(o => o.ProductIds);

// Output: 101, 102, 103, 104
```

## 7. Flattening

Flattening converts nested sequences into a single sequence.

### Example 1: Two-Dimensional Array

```csharp
int[,] matrix =
{
    { 1, 2 },
    { 3, 4 }
};

var result = matrix
    .Cast<int>()
    .ToArray();

// Output: 1, 2, 3, 4
```

A rectangular array can be enumerated directly; `SelectMany()` is more commonly used with nested sequences.

### Example 2: Three-Level Nested Collections

```csharp
int[][][] numbers =
{
    new[]
    {
        new[] { 1, 2 },
        new[] { 3, 4 }
    },
    new[]
    {
        new[] { 5, 6 }
    }
};

var result = numbers
    .SelectMany(group => group)
    .SelectMany(row => row);

// Output: 1, 2, 3, 4, 5, 6
```

## 8. Multiple from Clauses

Multiple `from` clauses provide query syntax for flattening and combining sequences.

### Example 1: Nested Arrays

```csharp
int[][] numbers =
{
    new[] { 1, 2 },
    new[] { 3, 4 }
};

var result =
    from row in numbers
    from n in row
    select n;

// Output: 1, 2, 3, 4
```

### Example 2: Method Syntax

```csharp
var result = numbers.SelectMany(row => row);

// Output: 1, 2, 3, 4
```

### Example 3: Student Subjects

```csharp
var result =
    from student in students
    from subject in student.Subjects
    select subject;

// Output: C#, SQL, Java, Python
```

## 9. Parent–Child Projection

Parent–child projection creates one result for each child while retaining information from its parent.

### Example 1: Student and Subjects

```csharp
record Student(string Name, string[] Subjects);

Student[] students =
{
    new("Amit", new[] { "C#", "SQL" }),
    new("Rahul", new[] { "Java", "Python" })
};

var result = students.SelectMany(
    student => student.Subjects,
    (student, subject) => new
    {
        StudentName = student.Name,
        SubjectName = subject
    }
);
```

**Output:**

```text
Amit  C#
Amit  SQL
Rahul Java
Rahul Python
```

### Example 2: Department and Employee

```csharp
record Department(string Name, string[] Employees);

Department[] departments =
{
    new("IT", new[] { "Amit", "Rahul" }),
    new("HR", new[] { "Priya", "Neha" })
};

var result = departments.SelectMany(
    department => department.Employees,
    (department, employee) => new
    {
        Department = department.Name,
        Employee = employee
    }
);
```

**Output:**

```text
IT Amit
IT Rahul
HR Priya
HR Neha
```

## 10. Outer-Source Correlation

Outer-source correlation means the inner sequence depends on the current outer element.

### Example 1: Inner Collection Based on Outer Value

```csharp
int[] numbers = { 1, 2, 3 };

var result = numbers.SelectMany(
    n => Enumerable.Range(1, n),
    (n, value) => new { n, value }
);
```

**Output:**

```text
1 1
2 1
2 2
3 1
3 2
3 3
```

### Example 2: Query Syntax

```csharp
var result =
    from n in numbers
    from value in Enumerable.Range(1, n)
    select new { n, value };
```

### Example 3: Correlated Filtering

```csharp
int[] a = { 1, 2, 3 };
int[] b = { 2, 3, 4 };

var result = a.SelectMany(
    x => b.Where(y => y > x),
    (x, y) => new { x, y }
);
```

The inner sequence is filtered using the current value of `x`.

## 11. Cartesian Products

A Cartesian product combines every element of one sequence with every element of another sequence.

### Example 1: Two Collections

```csharp
int[] a = { 1, 2 };
string[] b = { "A", "B" };

var result = a.SelectMany(
    x => b,
    (x, y) => new { x, y }
);
```

**Output:**

```text
1 A
1 B
2 A
2 B
```

### Example 2: Query Syntax

```csharp
var result =
    from x in a
    from y in b
    select new { x, y };
```

### Example 3: Three Collections

```csharp
int[] a = { 1, 2 };
string[] b = { "A", "B" };
char[] c = { 'X', 'Y' };

var result =
    from x in a
    from y in b
    from z in c
    select new { x, y, z };
```

**Result count:**

```text
2 × 2 × 2 = 8
```

## 12. Nested SelectMany

Nested `SelectMany()` combines more than two sequence levels.

### Example 1: Three Collections

```csharp
int[] a = { 1, 2 };
int[] b = { 10, 20 };
int[] c = { 100, 200 };

var result = a.SelectMany(
    x => b.SelectMany(
        y => c,
        (y, z) => new { y, z }
    ),
    (x, pair) => x + pair.y + pair.z
);
```

**Output:**

```text
111, 211, 121, 221,
112, 212, 122, 222
```

### Example 2: Three-Level Flattening

```csharp
int[][][] data =
{
    new[]
    {
        new[] { 1, 2 },
        new[] { 3, 4 }
    },
    new[]
    {
        new[] { 5, 6 }
    }
};

var result = data.SelectMany(
    group => group.SelectMany(row => row)
);

// Output: 1, 2, 3, 4, 5, 6
```

## 13. SelectMany-Based Joins

`SelectMany()` can combine matching elements by filtering an inner collection.

### Example 1: Matching IDs

```csharp
record Student(int Id, string Name, int DepartmentId);
record Department(int Id, string Name);

Student[] students =
{
    new(1, "Amit", 101),
    new(2, "Rahul", 102),
    new(3, "Priya", 101)
};

Department[] departments =
{
    new(101, "IT"),
    new(102, "HR")
};

var result = students.SelectMany(
    s => departments.Where(d => d.Id == s.DepartmentId),
    (s, d) => new
    {
        Student = s.Name,
        Department = d.Name
    }
);
```

**Output:**

```text
Amit  IT
Rahul HR
Priya IT
```

### Example 2: Query Syntax

```csharp
var result =
    from s in students
    from d in departments
    where s.DepartmentId == d.Id
    select new
    {
        Student = s.Name,
        Department = d.Name
    };
```

**Note:** For ordinary equality joins, `Join()` is generally more appropriate; its detailed behavior belongs to Chapter 08.

## 14. Empty Inner Collections

When an inner collection is empty, `SelectMany()` produces no result for that outer element.

### Example 1: Empty Array

```csharp
int[][] numbers =
{
    new[] { 1, 2 },
    Array.Empty<int>(),
    new[] { 3, 4 }
};

var result = numbers.SelectMany(row => row);

// Output: 1, 2, 3, 4
```

### Example 2: Parent Without Children

```csharp
record Student(string Name, string[] Subjects);

Student[] students =
{
    new("Amit", new[] { "C#", "SQL" }),
    new("Rahul", Array.Empty<string>()),
    new("Priya", new[] { "Java" })
};

var result = students.SelectMany(
    s => s.Subjects,
    (s, subject) => new { s.Name, Subject = subject }
);
```

**Output:**

```text
Amit  C#
Amit  SQL
Priya Java
```

Rahul produces no result because his subject collection is empty.

## 15. Null Inner Collections

A null inner collection must be handled before `SelectMany()` tries to enumerate it.

### Example 1: Null-Coalescing Operator

```csharp
record Student(string Name, string[]? Subjects);

Student[] students =
{
    new("Amit", new[] { "C#", "SQL" }),
    new("Rahul", null),
    new("Priya", new[] { "Java" })
};

var result = students.SelectMany(
    s => s.Subjects ?? Array.Empty<string>()
);

// Output: C#, SQL, Java
```

### Example 2: Parent–Child Projection

```csharp
var result = students.SelectMany(
    s => s.Subjects ?? Array.Empty<string>(),
    (s, subject) => new
    {
        Student = s.Name,
        Subject = subject
    }
);
```

**Output:**

```text
Amit  C#
Amit  SQL
Priya Java
```

### Example 3: Null-Coalescing with Enumerable.Empty

```csharp
var result = students.SelectMany(
    s => s.Subjects ?? Enumerable.Empty<string>()
);

// Output: C#, SQL, Java
```

## 16. Quick Revision

| Topic | Purpose | Example |
|---|---|---|
| `SelectMany()` | Flattens sequences | `SelectMany(x => x)` |

| SelectMany-Based Joins | Combines matching elements | `SelectMany(x => b.Where(...))` |
| Empty Inner Collections | Produces no inner results | `Array.Empty<int>()` |
| Null Inner Collections | Safely handles null sequences | `x.Items ?? Enumerable.Empty<T>()` |
