# 08.08 — SEQUENCE COMBINATION

**Chapter:** 08 — LINQ Joins & Set Operations  
**Namespace:** `System.Linq`

LINQ sequence combination operations combine, extend, or pair elements from sequences.

The main methods are:

```csharp
Concat()
Append()
Prepend()
Zip()
```

## 1. Concat

`Concat()` combines two sequences into one sequence.

It returns all elements from the first sequence, followed by all elements from the second sequence.

**Duplicates are preserved.**

### Syntax

```csharp
first.Concat(second);
```

### Method signature

```csharp
IEnumerable<TSource> Concat<TSource>(
    IEnumerable<TSource> first,
    IEnumerable<TSource> second
);
```

### Example 1: Combining integer sequences

```csharp
int[] first = { 1, 2, 3 };
int[] second = { 4, 5, 6 };

var result = first.Concat(second);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1, 2, 3, 4, 5, 6
```

### Example 2: Combining strings

```csharp
string[] first =
{
    "Amit",
    "Rahul"
};

string[] second =
{
    "Priya",
    "Sneha"
};

var result = first.Concat(second);

foreach (string name in result)
{
    Console.WriteLine(name);
}
```

**Output:**

```text
Amit
Rahul
Priya
Sneha
```

### Example 3: Preserving duplicates

```csharp
int[] first = { 1, 2, 2 };
int[] second = { 2, 3, 3 };

var result = first.Concat(second);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1, 2, 2, 2, 3, 3
```

`Concat()` does not eliminate duplicates.

### Example 4: Concatenating objects

```csharp
record Student(int Id, string Name);

Student[] first =
{
    new(1, "Amit"),
    new(2, "Rahul")
};

Student[] second =
{
    new(3, "Priya"),
    new(4, "Sneha")
};

var result = first.Concat(second);

foreach (var student in result)
{
    Console.WriteLine(
        $"{student.Id}: {student.Name}"
    );
}
```

**Output:**

```text
1: Amit
2: Rahul
3: Priya
4: Sneha
```

### Important characteristics

| Property | Concat |
|---|---|
| Input | Two sequences |
| Output | One sequence |
| Duplicates | Preserved |
| Order | First sequence, then second |
| Deferred execution | Yes |
| Equality comparer | Not required |

**Key point:** `Concat()` combines sequences without removing duplicates.

## 2. Append

`Append()` adds one element to the end of a sequence.

It does not modify the original collection.

### Syntax

```csharp
source.Append(element);
```

### Method signature

```csharp
IEnumerable<TSource> Append<TSource>(
    IEnumerable<TSource> source,
    TSource element
);
```

### Example 1: Append an integer

```csharp
int[] numbers = { 1, 2, 3 };

var result = numbers.Append(4);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1, 2, 3, 4
```

### Example 2: Append a string

```csharp
string[] names =
{
    "Amit",
    "Rahul"
};

var result = names.Append("Priya");

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
Amit, Rahul, Priya
```

### Example 3: Append multiple elements

```csharp
int[] numbers = { 1, 2 };

var result = numbers
    .Append(3)
    .Append(4)
    .Append(5);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1, 2, 3, 4, 5
```

### Example 4: Original collection remains unchanged

```csharp
int[] numbers = { 10, 20 };

var result = numbers.Append(30);

Console.WriteLine(
    $"Original: {string.Join(", ", numbers)}"
);

Console.WriteLine(
    $"Result: {string.Join(", ", result)}"
);
```

**Output:**

```text
Original: 10, 20
Result: 10, 20, 30
```

### Example 5: Append an object

```csharp
record Student(int Id, string Name);

Student[] students =
{
    new(1, "Amit"),
    new(2, "Rahul")
};

var result = students.Append(
    new Student(3, "Priya")
);

foreach (var student in result)
{
    Console.WriteLine(student.Name);
}
```

**Output:**

```text
Amit
Rahul
Priya
```

**Key point:** `Append()` returns a sequence containing the original elements followed by one additional element.

## 3. Prepend

`Prepend()` adds one element to the beginning of a sequence.

It does not modify the original collection.

### Syntax

```csharp
source.Prepend(element);
```

### Method signature

```csharp
IEnumerable<TSource> Prepend<TSource>(
    IEnumerable<TSource> source,
    TSource element
);
```

### Example 1: Prepend an integer

```csharp
int[] numbers = { 2, 3, 4 };

var result = numbers.Prepend(1);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1, 2, 3, 4
```

### Example 2: Prepend a string

```csharp
string[] names =
{
    "Rahul",
    "Priya"
};

var result = names.Prepend("Amit");

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
Amit, Rahul, Priya
```

### Example 3: Multiple Prepend operations

```csharp
int[] numbers = { 4, 5 };

var result = numbers
    .Prepend(3)
    .Prepend(2)
    .Prepend(1);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1, 2, 3, 4, 5
```

Each new element is placed before the existing sequence.

### Example 4: Prepend and Append together

```csharp
int[] numbers = { 2, 3, 4 };

var result = numbers
    .Prepend(1)
    .Append(5);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1, 2, 3, 4, 5
```

### Example 5: Original collection remains unchanged

```csharp
int[] numbers = { 20, 30 };

var result = numbers.Prepend(10);

Console.WriteLine(
    string.Join(", ", numbers)
);

Console.WriteLine(
    string.Join(", ", result)
);
```

**Output:**

```text
20, 30
10, 20, 30
```

**Key point:** `Prepend()` returns a sequence with one additional element at the beginning.

## 4. Zip

`Zip()` combines elements from two sequences based on their positions.

The first element of one sequence is paired with the first element of the other sequence.

The second elements are paired together, and so on.

### Syntax

```csharp
first.Zip(second);
```

Or:

```csharp
first.Zip(
    second,
    (x, y) => result
);
```

### Method signatures

```csharp
IEnumerable<(TFirst First, TSecond Second)> Zip<TFirst, TSecond>(
    IEnumerable<TFirst> first,
    IEnumerable<TSecond> second
);
```

```csharp
IEnumerable<TResult> Zip<TFirst, TSecond, TResult>(
    IEnumerable<TFirst> first,
    IEnumerable<TSecond> second,
    Func<TFirst, TSecond, TResult> resultSelector
);
```

### Example 1: Pair integers

```csharp
int[] first = { 1, 2, 3 };
int[] second = { 10, 20, 30 };

var result = first.Zip(
    second,
    (x, y) => $"{x}-{y}"
);

foreach (var item in result)
{
    Console.WriteLine(item);
}
```

**Output:**

```text
1-10
2-20
3-30
```

### Example 2: Pair names and ages

```csharp
string[] names =
{
    "Amit",
    "Rahul",
    "Priya"
};

int[] ages =
{
    20,
    22,
    21
};

var result = names.Zip(
    ages,
    (name, age) => new
    {
        Name = name,
        Age = age
    }
);

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Name}: {item.Age}"
    );
}
```

**Output:**

```text
Amit: 20
Rahul: 22
Priya: 21
```

### Example 3: Add corresponding elements

```csharp
int[] first = { 1, 2, 3 };
int[] second = { 4, 5, 6 };

var result = first.Zip(
    second,
    (x, y) => x + y
);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
5, 7, 9
```

### Example 4: Multiply corresponding elements

```csharp
int[] first = { 2, 3, 4 };
int[] second = { 5, 6, 7 };

var result = first.Zip(
    second,
    (x, y) => x * y
);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
10, 18, 28
```

**Key point:** `Zip()` combines elements by position rather than by matching keys.

## 5. Zip with Tuples

`Zip()` can return tuples containing paired elements.

### Syntax

```csharp
first.Zip(second);
```

The result contains tuples with:

```csharp
pair.First
pair.Second
```

### Example 1: Tuple pairs

```csharp
int[] first = { 1, 2, 3 };
int[] second = { 10, 20, 30 };

var result = first.Zip(second);

foreach (var pair in result)
{
    Console.WriteLine(
        $"{pair.First}: {pair.Second}"
    );
}
```

**Output:**

```text
1: 10
2: 20
3: 30
```

### Example 2: Names and marks

```csharp
string[] names =
{
    "Amit",
    "Rahul",
    "Priya"
};

int[] marks =
{
    85,
    90,
    95
};

var result = names.Zip(marks);

foreach (var pair in result)
{
    Console.WriteLine(
        $"{pair.First}: {pair.Second}"
    );
}
```

**Output:**

```text
Amit: 85
Rahul: 90
Priya: 95
```

### Example 3: Tuple deconstruction

```csharp
string[] names =
{
    "Amit",
    "Rahul"

int[] ages =
{
    20,
    22
};

foreach (var (name, age) in names.Zip(ages))
{
    Console.WriteLine($"{name}: {age}");

```

**Output:**


### Example 4: Zip three sequences into tuples

```csharp
{
    20,
    22

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.First}, {item.Second}, {item.Third}"
    );
}
```

**Output:**

```text
Amit, 20, Kolkata
Rahul, 22, Delhi
```

**Key point:** Tuple-based `Zip()` pairs values without requiring a custom result selector.

## 6. Pairing by Position

Pairing by position means matching elements according to their indexes.

For example:

```text
First Sequence     Second Sequence

Index 0: Amit      Index 0: 85
Index 1: Rahul     Index 1: 90
Index 2: Priya     Index 2: 95
```

The resulting pairs are:

```text
Amit  → 85
Rahul → 90
Priya → 95
```

### Example 1: Pair names with scores

```csharp
string[] names =
{
    "Amit",
    "Rahul",
    "Priya"
};

int[] scores =
{
    85,
    90,
    95
};

var result = names.Zip(
    scores,
    (name, score) => $"{name}: {score}"
);

foreach (var item in result)
{
    Console.WriteLine(item);
}
```

**Output:**

```text
Amit: 85
Rahul: 90
Priya: 95
```

### Example 2: Pair indexes with values

```csharp
string[] names =
{
    "Amit",
    "Rahul",
    "Priya"
};

var indexes = Enumerable.Range(
    0,
    names.Length
);

var result = indexes.Zip(
    names,
    (index, name) => new
    {
        Index = index,
        Name = name
    }
);

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Index}: {item.Name}"
    );
}
```

**Output:**

```text
0: Amit
1: Rahul
2: Priya
```

### Example 3: Pair corresponding measurements

```csharp
double[] heights =
{
    170,
    180,
    160
};

double[] weights =
{
    65,
    75,
    55
};

var result = heights.Zip(
    weights,
    (height, weight) => new
    {
        Height = height,
        Weight = weight
    }
);

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Height}: {item.Weight}"
    );
}
```

**Output:**

```text
170: 65
180: 75
160: 55
```

**Key point:** `Zip()` uses corresponding positions, not equality comparisons.

## 7. Result Projection

Result projection determines how paired elements are transformed into output values.

`Zip()` supports a result selector:

```csharp
(firstElement, secondElement) => result
```

### Example 1: Project into an anonymous object

```csharp
string[] names =
{
    "Amit",
    "Rahul"
};

int[] ages =
{
    20,
    22
};

var result = names.Zip(
    ages,
    (name, age) => new
    {
        Name = name,
        Age = age
    }
);

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Name}: {item.Age}"
    );
}
```

**Output:**

```text
Amit: 20
Rahul: 22
```

### Example 2: Project into a record

```csharp
record Student(
    string Name,
    int Marks
);

string[] names =
{
    "Amit",
    "Rahul"
};

int[] marks =
{
    85,
    90
};

var result = names.Zip(
    marks,
    (name, mark) => new Student(name, mark)
);

foreach (var student in result)
{
    Console.WriteLine(
        $"{student.Name}: {student.Marks}"
    );
}
```

**Output:**

```text
Amit: 85
Rahul: 90
```

### Example 3: Project into a calculated value

```csharp
int[] quantities =
{
    2,
    3,
    4
};

decimal[] prices =
{
    100m,
    200m,
    50m
};

var result = quantities.Zip(
    prices,
    (quantity, price) => quantity * price
);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
200, 600, 200
```

### Example 4: Project into formatted strings

```csharp
string[] subjects =
{
    "C#",
    "Java",
    "Python"
};

int[] marks =
{
    90,
    85,
    95
};

var result = subjects.Zip(
    marks,
    (subject, mark) => $"{subject} = {mark}"
);

foreach (var item in result)
{
    Console.WriteLine(item);
}
```

**Output:**

```text
C# = 90
Java = 85
Python = 95
```

**Key point:** Result projection transforms paired elements into the required output structure.

## 8. Unequal Sequence Lengths

When sequences have different lengths, `Zip()` stops when the shortest sequence ends.

It does not automatically add default values for missing elements.

### Example 1: First sequence is longer

```csharp
int[] first =
{
    1, 2, 3, 4, 5
};

int[] second =
{
    10, 20, 30
};

var result = first.Zip(
    second,
    (x, y) => x + y
);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
11, 22, 33
```

Elements `4` and `5` are not included.

### Example 2: Second sequence is longer

```csharp
string[] names =
{
    "Amit",
    "Rahul"
};

int[] ages =
{
    20,
    22,
    24,
    26
};

var result = names.Zip(
    ages,
    (name, age) => $"{name}: {age}"
);

foreach (var item in result)
{
    Console.WriteLine(item);
}
```

**Output:**

```text
Amit: 20
Rahul: 22
```

The extra ages are ignored.

### Example 3: One empty sequence

```csharp
int[] first =
{
    1, 2, 3
};

int[] second = Array.Empty<int>();

var result = first.Zip(second);

Console.WriteLine(result.Count());
```

**Output:**

```text
0
```

### Example 4: Three unequal sequences

```csharp
string[] names =
{
    "Amit",
    "Rahul",
    "Priya"
};

int[] ages =
{
    20,
    22
};

string[] cities =
{
    "Kolkata",
    "Delhi",
    "Mumbai",
    "Pune"
};

var result = names.Zip(
    ages,
    cities
);

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.First}: {item.Second}, {item.Third}"
    );
}
```

**Output:**

```text
Amit: 20, Kolkata
Rahul: 22, Delhi
```

### Result length

For two sequences:

\[
\text{Zip Result Count} = \min(n,m)
\]

For three sequences:

\[
\text{Zip Result Count} = \min(n,m,p)
\]

Where `n`, `m`, and `p` represent the sequence lengths.

**Key point:** `Zip()` stops at the shortest input sequence.

```csharp
var result = first

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text

```

```csharp
string[] names =

int[] ages =

string[] cities =

    "Delhi"

var result = names.Zip(

);

    Console.WriteLine(

    );
}
```

**Output:**

```text

Rahul, 22, Delhi
```

### Example 4: Nested Zip

```csharp
string[] names =
{
    "Amit",
    "Rahul"
};

int[] ages =
{
    20,
    22
};

string[] cities =
{
    "Kolkata",
    "Delhi"
};

var result = names
    .Zip(ages)
    .Zip(
        cities,
        (pair, city) => new
        {
            Name = pair.First,
            Age = pair.Second,

        }

foreach (var item in result)

    Console.WriteLine(

    );
}
```

**Output:**

```text
Amit, 20, Kolkata
Rahul, 22, Delhi
```

### Example 5: Combining a collection of sequences

```csharp
int[][] sequences =
{
    new[] { 1, 2 },
    new[] { 3, 4 },
    new[] { 5, 6 }
};

var result = sequences.SelectMany(
    sequence => sequence
);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1, 2, 3, 4, 5, 6
```

`SelectMany()` flattens multiple nested sequences into one sequence.

**Key point:** Multiple sequences can be combined by chaining `Concat()`, using `Zip()`, or flattening nested sequences with `SelectMany()`.

## 10. Concat vs Union

`Concat()` and `Union()` both combine two sequences, but they handle duplicates differently.

### Concat

```csharp
first.Concat(second);
```

Returns every element from both sequences.

### Union

```csharp
first.Union(second);
```

Returns distinct elements from both sequences.

### Example 1: Concat

```csharp
int[] first =
{
    1, 2, 3
};

int[] second =
{
    3, 4, 5
};

var result = first.Concat(second);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1, 2, 3, 3, 4, 5
```

### Example 2: Union

```csharp
int[] first =
{
    1, 2, 3
};

int[] second =
{
    3, 4, 5
};

var result = first.Union(second);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1, 2, 3, 4, 5
```

### Example 3: Concat followed by Distinct

```csharp
int[] first =
{
    1, 2, 3
};

int[] second =
{
    3, 4, 5
};

var result = first
    .Concat(second)
    .Distinct();

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1, 2, 3, 4, 5
```

For LINQ to Objects, this produces the same distinct values as `Union()` under the same equality rules.

### Example 4: Union with custom equality

```csharp
string[] first =
{
    "Amit",
    "Rahul"
};

string[] second =
{
    "amit",
    "Priya"
};

var result = first.Union(
    second,
    StringComparer.OrdinalIgnoreCase
);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
Amit, Rahul, Priya
```

### Comparison

| Feature | Concat | Union |
|---|---|---|
| Purpose | Combine sequences | Combine distinct elements |
| Duplicates | Preserved | Removed |
| Equality comparison | Not required | Required |
| Custom comparer | No | Yes |
| Deferred execution | Yes | Yes |
| Internal duplicate tracking | No | Yes |
| Result count | Sum of input counts | Number of distinct values |
| Typical use | Combining all records | Combining unique values |

**Key point:** Use `Concat()` when duplicates must be preserved and `Union()` when duplicates must be removed.

## 11. Zip vs Join

`Zip()` and `Join()` both combine data from two sequences.

However, they use different matching rules.

**Zip:**

```text
Match by position
```

**Join:**

```text
Match by key
```

### Example 1: Zip by position

```csharp
string[] names =
{
    "Amit",
    "Rahul",
    "Priya"
};

int[] marks =
{
    85,
    90,
    95
};

var result = names.Zip(
    marks,
    (name, mark) => $"{name}: {mark}"
);

foreach (var item in result)
{
    Console.WriteLine(item);
}
```

**Output:**

```text
Amit: 85
Rahul: 90
Priya: 95
```

The elements are matched according to their positions.

### Example 2: Join by key

```csharp
record Student(
    int Id,
    string Name
);

record Mark(
    int StudentId,
    int Score
);

Student[] students =
{
    new(1, "Amit"),
    new(2, "Rahul"),
    new(3, "Priya")
};

Mark[] marks =
{
    new(3, 95),
    new(1, 85),
    new(2, 90)
};

var result = students.Join(
    marks,
    s => s.Id,
    m => m.StudentId,
    (s, m) => new
    {
        Student = s.Name,
        Score = m.Score
    }
);

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Student}: {item.Score}"
    );
}
```

**Output:**

```text
Amit: 85
Rahul: 90
Priya: 95
```

Although the marks are stored in a different order, `Join()` matches them using student IDs.

### Example 3: Zip does not match keys

```csharp
int[] first =
{
    1, 2, 3
};

int[] second =
{
    3, 1, 2
};

var result = first.Zip(
    second,
    (x, y) => $"{x}-{y}"
);

foreach (var item in result)
{
    Console.WriteLine(item);
}
```

**Output:**

```text
1-3
2-1
3-2
```

`Zip()` does not search for equal values.

### Example 4: Join matches keys

```csharp
int[] first =
{
    1, 2, 3
};

int[] second =
{
    3, 1, 2
};

var result = first.Join(
    second,
    x => x,
    y => y,
    (x, y) => $"{x}-{y}"
);

foreach (var item in result)
{
    Console.WriteLine(item);
}
```

**Output:**

```text
1-1
2-2
3-3
```

### Example 5: Different sequence lengths

**Zip:**

```csharp
int[] first = { 1, 2, 3 };
int[] second = { 2, 3 };

var result = first.Zip(
    second,
    (x, y) => $"{x}-{y}"
);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1-2, 2-3
```

**Join:**

```csharp
int[] first = { 1, 2, 3 };
int[] second = { 2, 3 };

var result = first.Join(
    second,
    x => x,
    y => y,
    (x, y) => $"{x}-{y}"
);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
2-2, 3-3
```

### Comparison

| Feature | Zip | Join |
|---|---|---|
| Matching rule | Position | Equality of keys |
| Key selectors | Not required | Required |
| Result selector | Optional | Required |
| Unequal sequence lengths | Stops at shortest | Depends on matching keys |
| Duplicate matching keys | Does not multiply matches | Produces matching combinations |
| Unmatched elements | Not returned beyond shortest sequence | Not returned in inner join |
| Typical use | Pairing parallel sequences | Matching related records |
| LINQ query syntax | No dedicated keyword | `join...on...equals` |

**Key point:** `Zip()` pairs elements by position, while `Join()` matches elements by key equality.
