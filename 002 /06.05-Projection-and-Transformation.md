# 06.05 — FILTERING & TYPE SELECTION

**Chapter:** 06 — LINQ Fundamentals  
**Namespace:** `System.Linq`

## 1. Where

`Where()` filters elements from a collection based on a condition.

### Syntax

```csharp
source.Where(predicate);
```

### Example

```csharp
int[] numbers = { 1, 2, 3, 4, 5, 6 };

var result = numbers.Where(n => n > 3);

// Output: 4, 5, 6
```

---

### 1.1 Predicate Filtering

A predicate is a function that returns `true` or `false` to decide whether an element should be included.

```csharp
var result = numbers.Where(n => n % 2 == 0);

// Output: 2, 4, 6
```

**Named predicate:**

```csharp
bool IsEven(int n)
{
    return n % 2 == 0;
}

var result = numbers.Where(IsEven);

// Output: 2, 4, 6
```

---

### 1.2 `Where(Func<T, bool>)`

Accepts a function that takes an element of type `T` and returns a Boolean value.

**Syntax:**

```csharp
IEnumerable<T> Where<T>(
    IEnumerable<T> source,
    Func<T, bool> predicate
);
```

**Example:**

```csharp
Func<int, bool> condition = n => n > 3;

var result = numbers.Where(condition);

// Output: 4, 5, 6
```

**Direct lambda:**

```csharp
var result = numbers.Where(n => n > 3);

// Output: 4, 5, 6
```

---

### 1.3 Indexed Where

Filters elements using both their values and zero-based indexes.

**Syntax:**

```csharp
source.Where((element, index) => condition);
```

**Example 1: Even Indexes**

```csharp
var result = numbers.Where(
    (n, index) => index % 2 == 0
);

// Output: 1, 3, 5
```

**Example 2: Index Greater Than 2**

```csharp
var result = numbers.Where(
    (n, index) => index > 2
);

// Output: 4, 5, 6
```

**Example 3: Element and Index Conditions**

```csharp
var result = numbers.Where(
    (n, index) => n > 2 && index < 5
);

// Output: 3, 4, 5
```

---

### 1.4 Multiple Conditions

Combines multiple conditions using logical operators.

**Example 1: AND (`&&`)**

```csharp
var result = numbers.Where(
    n => n > 2 && n < 6
);

// Output: 3, 4, 5
```

**Example 2: OR (`||`)**

```csharp
var result = numbers.Where(
    n => n < 3 || n > 5
);

// Output: 1, 2, 6
```

**Example 3: NOT (`!`)**

```csharp
var result = numbers.Where(
    n => !(n % 2 == 0)
);

// Output: 1, 3, 5
```

---

### 1.5 Multiple Where Calls

Applies multiple filters sequentially.

```csharp
var result = numbers
    .Where(n => n > 2)
    .Where(n => n < 6)
    .Where(n => n % 2 == 0);

// Output: 4
```

**Equivalent single Where:**

```csharp
var result = numbers.Where(
    n => n > 2 && n < 6 && n % 2 == 0
);

// Output: 4
```

---

### 1.6 Predicate Composition

Combines multiple predicate functions into one filtering condition.

**Example 1: Combining Predicates**

```csharp
Func<int, bool> greaterThanTwo = n => n > 2;
Func<int, bool> isEven = n => n % 2 == 0;

var result = numbers.Where(
    n => greaterThanTwo(n) && isEven(n)
);

// Output: 4, 6
```

**Example 2: Reusable Predicate**

```csharp
Func<int, bool> condition =
    n => n > 2 && n % 2 == 0;

var result = numbers.Where(condition);

// Output: 4, 6
```

**Example 3: Predicate with OR**

```csharp
Func<int, bool> isSmall = n => n < 3;
Func<int, bool> isLarge = n => n > 5;

var result = numbers.Where(
    n => isSmall(n) || isLarge(n)
);

// Output: 1, 2, 6
```

---

### 1.7 Conditional Filtering

Applies a filter only when a condition is satisfied.

**Example 1: Using If**

```csharp
bool filterEven = true;

IEnumerable<int> result = numbers;

if (filterEven)
{
    result = result.Where(n => n % 2 == 0);
}

// Output: 2, 4, 6
```

**Example 2: Using a Conditional Expression**

```csharp
bool filterEven = false;

var result = filterEven
    ? numbers.Where(n => n % 2 == 0)
    : numbers.AsEnumerable();

// Output: 1, 2, 3, 4, 5, 6
```

**Example 3: Optional Minimum Value**

```csharp
int? minimum = 3;

IEnumerable<int> result = numbers;

if (minimum.HasValue)
{
    result = result.Where(n => n >= minimum.Value);
}

// Output: 3, 4, 5, 6
```

---

### 1.8 Null Filtering

Removes null values from a sequence.

**Example 1: Null Check**

```csharp
string?[] names =
{
    "Amit",
    null,
    "Rahul",
    null,
    "Priya"
};

var result = names.Where(name => name != null);

// Output: Amit, Rahul, Priya
```

**Example 2: Null and Empty Strings**

```csharp
string?[] names =
{
    "Amit",
    null,
    "",
    "Rahul",
    " "
};

var result = names.Where(
    name => !string.IsNullOrEmpty(name)
);

// Output: Amit, Rahul, " "
```

**Example 3: Null, Empty, and Whitespace**

```csharp
var result = names.Where(
    name => !string.IsNullOrWhiteSpace(name)
);

// Output: Amit, Rahul
```

**Example 4: Nullable Integers**

```csharp
int?[] values = { 10, null, 20, null, 30 };

var result = values
    .Where(n => n.HasValue)
    .Select(n => n.Value);

// Output: 10, 20, 30
```

---

### 1.9 Short-Circuit Expressions

`&&` and `||` evaluate the second condition only when necessary.

**Example 1: AND (`&&`)**

```csharp
string?[] names =
{
    "Amit",
    null,
    "Rahul"
};

var result = names.Where(
    name => name != null && name.Length > 4
);

// Output: Rahul
```

Here, `name.Length` is not evaluated when `name` is null.

**Example 2: OR (`||`)**

```csharp
var result = numbers.Where(
    n => n < 3 || n > 5
);

// Output: 1, 2, 6
```

**Example 3: Safe Nullable Access**

```csharp
string?[] names =
{
    null,
    "Amit",
    "Rahul"
};

var result = names.Where(
    name => name != null && name.StartsWith("A")
);

// Output: Amit
```

## 2. `OfType<T>()`

`OfType<T>()` returns only elements compatible with the specified type.

### Syntax

```csharp
source.OfType<T>();
```

### Example

```csharp
object[] values =
{
    10,
    "Hello",
    20,
    true,
    "World"
};

var result = values.OfType<int>();

// Output: 10, 20
```

---

### 2.1 Runtime Type Filtering

Filters elements according to their runtime types.

**Example 1: Integers**

```csharp
object[] values =
{
    10,
    "Hello",
    20,
    3.14,
    true
};

var result = values.OfType<int>();

// Output: 10, 20
```

**Example 2: Strings**

```csharp
var result = values.OfType<string>();

// Output: Hello
```

**Example 3: Doubles**

```csharp
var result = values.OfType<double>();

// Output: 3.14
```

---

### 2.2 Mixed Collections

Extracts elements of a particular type from collections containing different types.

**Example 1: ArrayList**

```csharp
using System.Collections;

ArrayList values = new()
{
    10,
    "Amit",
    20,
    "Rahul",
    true
};

var result = values.OfType<string>();

// Output: Amit, Rahul
```

**Example 2: Object Array**

```csharp
object[] data =
{
    100,
    "C#",
    200,
    "LINQ",
    false
};

var result = data.OfType<int>();

// Output: 100, 200
```

**Example 3: Null Values**

```csharp
object?[] data =
{
    10,
    null,
    "Hello",
    20
};

var result = data.OfType<int>();

// Output: 10, 20
```

`OfType<T>()` excludes null elements, including when `T` is a reference or nullable value type.

---

### 2.3 Inheritance Hierarchies

Selects objects compatible with a base class, derived class, or interface.

**Example Classes:**

```csharp
class Animal
{
    public string Name { get; set; } = "";
}

class Dog : Animal
{
}

class Cat : Animal
{
}
```

**Example 1: Selecting Dogs**

```csharp
Animal[] animals =
{
    new Dog { Name = "Tommy" },
    new Cat { Name = "Kitty" },
    new Dog { Name = "Rocky" }
};

var result = animals.OfType<Dog>();

// Output: Tommy, Rocky
```

**Example 2: Selecting Cats**

```csharp
var result = animals.OfType<Cat>();

// Output: Kitty
```

**Example 3: Selecting Base-Class Objects**

```csharp
var result = animals.OfType<Animal>();

// Output: Tommy, Kitty, Rocky
```

## 3. `Cast<T>()`

`Cast<T>()` converts each element of a non-generic sequence to the specified type.

### Syntax

```csharp
source.Cast<T>();
```

### Example

```csharp
ArrayList values = new()
{
    10, 20, 30
};

var result = values.Cast<int>();

// Output: 10, 20, 30
```

---

### 3.1 Sequence Casting

Casts every element of a sequence to a specified type.

**Example 1: ArrayList to IEnumerable<int>**

```csharp
ArrayList values = new()
{
    1, 2, 3, 4
};

IEnumerable<int> result = values.Cast<int>();

// Output: 1, 2, 3, 4
```

**Example 2: ArrayList to List<int>**

```csharp
List<int> result = values
    .Cast<int>()
    .ToList();

// Output: 1, 2, 3, 4
```

**Example 3: Explicitly Typed Query**

```csharp
var result =
    from int n in values
    select n * 2;

// Output: 2, 4, 6, 8
```

An explicitly typed range variable introduces a cast operation.

---

### 3.2 Runtime Cast

Each element is cast when the sequence is enumerated.

**Example 1: Valid Cast**

```csharp
object[] values = { 10, 20, 30 };

var result = values.Cast<int>();

// Output: 10, 20, 30
```

**Example 2: Derived Class Cast**

```csharp
Animal[] animals =
{
    new Dog { Name = "Tommy" },
    new Dog { Name = "Rocky" }
};

var result = animals.Cast<Dog>();

// Output: Tommy, Rocky
```

**Example 3: Incompatible Type**

```csharp
object[] values = { 10, "Hello", 20 };

var result = values.Cast<int>();

// InvalidCastException during enumeration
```

`Cast<T>()` does not perform general type conversions such as converting `"10"` into `10`.

---

### 3.3 `InvalidCastException`

Occurs when an element cannot be cast to the requested type.

**Example 1: Invalid Element**

```csharp
object[] values =
{
    10,
    "Hello",
    20
};

try
{
    var result = values.Cast<int>().ToList();
}
catch (InvalidCastException)
{
    Console.WriteLine("Invalid cast");
}

// Output: Invalid cast
```

**Example 2: Mixed Collection**

```csharp
ArrayList values = new()
{
    10,
    20,
    "30"
};

var result = values.Cast<int>();

// Throws InvalidCastException when "30" is reached
```

**Example 3: Invalid Inheritance Cast**

```csharp
Animal[] animals =
{
    new Dog(),
    new Cat()
};

var result = animals.Cast<Dog>();

// Throws InvalidCastException when Cat is reached
```

---

### 3.4 Deferred Cast Failure

An invalid cast usually throws when the sequence is enumerated, not when `Cast<T>()` is called.

**Example 1: Deferred Execution**

```csharp
object[] values =
{
    10,
    "Hello",
    20
};

var result = values.Cast<int>();

// No exception yet

foreach (int n in result)
{
    Console.WriteLine(n);
}

// Output: 10
// Then InvalidCastException
```

**Example 2: ToList Executes Casting**

```csharp
object[] values =
{
    10,
    "Hello",
    20
};

var result = values
    .Cast<int>()
    .ToList();

// InvalidCastException
```

**Example 3: Take Limits Enumeration**

```csharp
object[] values =
{
    10,
    20,
    "Hello"
};

var result = values
    .Cast<int>()
    .Take(2)
    .ToList();

// Output: 10, 20
// No exception
```

## 4. `Where()` vs `OfType<T>()`

`Where()` filters by a Boolean condition, while `OfType<T>()` filters by runtime type.

| Feature | `Where()` | `OfType<T>()` |
|---|---|---|
| Purpose | Condition-based filtering | Type-based filtering |
| Predicate | Required | Not required |
| Runtime type checking | Possible with `is` | Built in |
| Removes incompatible types | Only when specified | Yes |
| Result type | Same element type | Requested type `T` |
| Deferred execution | Yes | Yes |

### Example 1: Where

```csharp
object[] values =
{
    10,
    "Hello",
    20,
    true
};

var result = values.Where(x => x is int);

// Result type: IEnumerable<object>
```

### Example 2: OfType

```csharp
var result = values.OfType<int>();

// Result type: IEnumerable<int>
// Output: 10, 20
```

### Example 3: Where with Pattern Matching

```csharp
var result = values
    .Where(x => x is int)
    .Select(x => (int)x);

// Output: 10, 20
```

### Example 4: Equivalent OfType

```csharp
var result = values.OfType<int>();

// Output: 10, 20
```

---

## 5. `Cast<T>()` vs `OfType<T>()`

`Cast<T>()` attempts to cast every element, while `OfType<T>()` skips incompatible elements.

| Feature | `Cast<T>()` | `OfType<T>()` |
|---|---|---|
| Purpose | Cast all elements | Select compatible elements |
| Incompatible elements | Throws exception | Skips elements |
| `InvalidCastException` | Possible | Not for incompatible elements |
| Null elements | Depends on target type | Skipped |
| Result type | `IEnumerable<T>` | `IEnumerable<T>` |
| Deferred execution | Yes | Yes |

### Example 1: Cast

```csharp
object[] values =
{
    10,
    "Hello",
    20
};

var result = values.Cast<int>().ToList();

// InvalidCastException
```

### Example 2: OfType

```csharp
var result = values.OfType<int>().ToList();

// Output: 10, 20
```

### Example 3: All Compatible Elements

```csharp
object[] values = { 10, 20, 30 };

var castResult = values.Cast<int>();

var typeResult = values.OfType<int>();

// Both output: 10, 20, 30
```

### Example 4: Null Handling

```csharp
object?[] values =
{
    "Amit",
    null,
    "Rahul"
};

var castResult = values.Cast<string?>();

// Output: Amit, null, Rahul
```

```csharp
var typeResult = values.OfType<string>();

// Output: Amit, Rahul
```

## 6. Predicate Ordering

Predicate ordering means arranging filtering conditions to control evaluation order, performance, and safety.

### 6.1 Cheap Condition First

Place inexpensive conditions before expensive conditions when appropriate.

```csharp
var result = numbers.Where(
    n => n > 2 && IsPrime(n)
);
```

```csharp
bool IsPrime(int n)
{
    if (n < 2)
        return false;

    for (int i = 2; i * i <= n; i++)
    {
        if (n % i == 0)
            return false;
    }

    return true;
}
```

Here, `IsPrime(n)` runs only when `n > 2`.

---

### 6.2 Null Check First

Check for null before accessing object members.

```csharp
string?[] names =
{
    null,
    "Amit",
    "Rahul"
};

var result = names.Where(
    name => name != null && name.Length > 4
);

// Output: Rahul
```

**Incorrect ordering:**

```csharp
var result = names.Where(
    name => name.Length > 4 && name != null
);

// May throw NullReferenceException
```

---

### 6.3 Multiple Where Ordering

Filters execute in their specified order for LINQ to Objects.

```csharp
var result = numbers
    .Where(n => n > 2)
    .Where(n => n % 2 == 0);

// Output: 4, 6
```

Equivalent combined condition:

```csharp
var result = numbers.Where(
    n => n > 2 && n % 2 == 0
);

// Output: 4, 6
```

---

### 6.4 Filtering Before Projection

Filtering before expensive transformations can reduce unnecessary work.

```csharp
var result = numbers
    .Where(n => n > 3)
    .Select(n => n * n);

// Output: 16, 25, 36
```

---

### 6.5 Predicate Order with Side Effects

Changing predicate order can change observable behavior when predicates have side effects.

```csharp
bool Check(int n)
{
    Console.WriteLine($"Checking {n}");
    return n % 2 == 0;
}

var result = numbers
    .Where(n => n > 3)
    .Where(Check)
    .ToList();
```

**Output:**

```text
Checking 4
Checking 5
Checking 6
```

**Result:**

```text
4, 6
```
