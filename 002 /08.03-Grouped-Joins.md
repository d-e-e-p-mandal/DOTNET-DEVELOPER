# 08.03 — GROUP JOINS

**Chapter:** 08 — LINQ Joins & Set Operations  
**Namespace:** `System.Linq`  
**Total Syllabus Topics:** 11

A **group join** combines two sequences by matching keys, but unlike an inner join, it keeps each outer element together with a collection of its matching inner elements.

It is useful for representing relationships such as:

- Department → Employees
- Customer → Orders
- Student → Enrollments
- Category → Products

This section covers all **11 syllabus points in their original order**, with explanations, C# examples, and outputs.

---

## 1. GroupJoin

`GroupJoin()` performs a grouped join between two sequences.

For every element in the outer sequence, it creates a result containing that element and its matching inner elements.

### Syntax

```csharp
outer.GroupJoin(
    inner,
    outerKeySelector,
    innerKeySelector,
    resultSelector
);
```

### Method signature

```csharp
IEnumerable<TResult> GroupJoin<TOuter, TInner, TKey, TResult>(
    IEnumerable<TOuter> outer,
    IEnumerable<TInner> inner,
    Func<TOuter, TKey> outerKeySelector,
    Func<TInner, TKey> innerKeySelector,
    Func<TOuter, IEnumerable<TInner>, TResult> resultSelector
);
```

### Example 1: Departments and employees

```csharp
record Department(int Id, string Name);
record Employee(int Id, string Name, int DepartmentId);

Department[] departments =
{
    new(1, "IT"),
    new(2, "HR"),
    new(3, "Finance")
};

Employee[] employees =
{
    new(101, "Amit", 1),
    new(102, "Priya", 1),
    new(103, "Rahul", 2)
};

var result = departments.GroupJoin(
    employees,
    d => d.Id,
    e => e.DepartmentId,
    (d, matchingEmployees) => new
    {
        Department = d.Name,
        Employees = matchingEmployees
    }
);

foreach (var group in result)
{
    Console.WriteLine(group.Department);

    foreach (var employee in group.Employees)
    {
        Console.WriteLine($"  {employee.Name}");
    }
}
```

**Output:**

```text
IT
  Amit
  Priya
HR
  Rahul
Finance
```

### Structure

```text
Departments
    │
    ▼
GroupJoin
    │
    ├── IT
    │    ├── Amit
    │    └── Priya
    │
    ├── HR
    │    └── Rahul
    │
    └── Finance
         └── Empty
```

**Key point:** `GroupJoin()` produces one result for every outer element, even when it has no matching inner elements.

## 2. join...into Query Syntax

LINQ query syntax supports group joins using `join...into`.

### Syntax

```csharp
var result =
    from outer in outerSource
    join inner in innerSource
        on outer.Key equals inner.Key into matchingGroup
    select new
    {
        Outer = outer,
        Matches = matchingGroup
    };
```

### Example 1: Departments and employees

```csharp
record Department(int Id, string Name);
record Employee(string Name, int DepartmentId);

Department[] departments =
{
    new(1, "IT"),
    new(2, "HR"),
    new(3, "Finance")
};

Employee[] employees =
{
    new("Amit", 1),
    new("Priya", 1),
    new("Rahul", 2)
};

var result =
    from d in departments
    join e in employees
        on d.Id equals e.DepartmentId into employeeGroup
    select new
    {
        Department = d.Name,
        Employees = employeeGroup
    };

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Department}: {item.Employees.Count()}"
    );
}
```

**Output:**

```text
IT: 2
HR: 1
Finance: 0
```

### Example 2: Customers and orders

```csharp
record Customer(int Id, string Name);
record Order(int Id, int CustomerId);

Customer[] customers =
{
    new(1, "Amit"),
    new(2, "Rahul"),
    new(3, "Priya")
};

Order[] orders =
{
    new(101, 1),
    new(102, 1),
    new(103, 2)
};

var result =
    from c in customers
    join o in orders
        on c.Id equals o.CustomerId into customerOrders
    select new
    {
        Customer = c.Name,
        OrderCount = customerOrders.Count()
    };

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Customer}: {item.OrderCount}"
    );
}
```

**Output:**

```text
Amit: 2
Rahul: 1
Priya: 0
```

### Method syntax equivalent

```csharp
var result = customers.GroupJoin(
    orders,
    c => c.Id,
    o => o.CustomerId,
    (c, customerOrders) => new
    {
        Customer = c.Name,
        OrderCount = customerOrders.Count()
    }
);
```

**Key point:** `join...into` creates a group of matching inner elements for each outer element.

## 3. Outer Element

The outer element is an individual element from the first sequence.

In a group join, every outer element contributes one result.

### Example 1: Outer element with matches

```csharp
int[] outer = { 1, 2, 3 };
int[] inner = { 1, 1, 2 };

var result = outer.GroupJoin(
    inner,
    x => x,
    y => y,
    (x, matches) => new
    {
        Outer = x,
        MatchCount = matches.Count()
    }
);

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Outer}: {item.MatchCount}"
    );
}
```

**Output:**

```text
1: 2
2: 1
3: 0
```

### Example 2: Preserve outer properties

```csharp
record Department(int Id, string Name);
record Employee(string Name, int DepartmentId);

Department[] departments =
{
    new(1, "IT"),
    new(2, "HR")
};

Employee[] employees =
{
    new("Amit", 1),
    new("Priya", 1)
};

var result = departments.GroupJoin(
    employees,
    d => d.Id,
    e => e.DepartmentId,
    (d, matches) => new
    {
        DepartmentId = d.Id,
        DepartmentName = d.Name,
        EmployeeCount = matches.Count()
    }
);

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.DepartmentId}, {item.DepartmentName}: {item.EmployeeCount}"
    );
}
```

**Output:**

```text
1, IT: 2
2, HR: 0
```

**Key point:** The outer element is preserved in the group-join result, regardless of whether matching inner elements exist.

## 4. Matching Inner Sequence

The matching inner sequence contains all inner elements whose keys match the current outer element's key.

Its type is:

```csharp
IEnumerable<TInner>
```

### Example 1: Multiple matching elements

```csharp
int[] outer = { 1, 2 };
int[] inner = { 1, 1, 1, 2 };

var result = outer.GroupJoin(
    inner,
    x => x,
    y => y,
    (x, matches) => new
    {
        Key = x,
        Values = matches
    }
);

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Key}: {string.Join(", ", item.Values)}"
    );
}
```

**Output:**

```text
1: 1, 1, 1
2: 2
```

### Example 2: Matching employee names

```csharp
record Department(int Id, string Name);
record Employee(string Name, int DepartmentId);

Department[] departments =
{
    new(1, "IT"),
    new(2, "HR")
};

Employee[] employees =
{
    new("Amit", 1),
    new("Priya", 1),
    new("Rahul", 2)
};

var result = departments.GroupJoin(
    employees,
    d => d.Id,
    e => e.DepartmentId,
    (d, matches) => new
    {
        Department = d.Name,
        Names = matches.Select(e => e.Name)
    }
);

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Department}: {string.Join(", ", item.Names)}"
    );
}
```

**Output:**

```text
IT: Amit, Priya
HR: Rahul
```

**Key point:** The matching inner sequence contains zero or more inner elements for each outer element.

## 5. Parent with Child Collection

`GroupJoin()` is useful for creating parent objects containing child collections.

### Structure

```text
Parent
   │
   ├── Child 1
   ├── Child 2
   └── Child 3
```

### Example 1: Department with employee collection

```csharp
record Department(int Id, string Name);
record Employee(string Name, int DepartmentId);

record DepartmentDto(
    string Name,
    List<string> Employees
);

Department[] departments =
{
    new(1, "IT"),
    new(2, "HR")
};

Employee[] employees =
{
    new("Amit", 1),
    new("Priya", 1),
    new("Rahul", 2)
};

var result = departments.GroupJoin(
    employees,
    d => d.Id,
    e => e.DepartmentId,
    (d, matches) => new DepartmentDto(
        d.Name,
        matches.Select(e => e.Name).ToList()
    )
);

foreach (var department in result)
{
    Console.WriteLine(department.Name);

    foreach (string name in department.Employees)
    {
        Console.WriteLine($"  {name}");
    }
}
```

**Output:**

```text
IT
  Amit
  Priya
HR
  Rahul
```

### Example 2: Customer with orders

```csharp
record Customer(int Id, string Name);
record Order(int Id, int CustomerId, decimal Amount);

Customer[] customers =
{
    new(1, "Amit"),
    new(2, "Rahul")
};

Order[] orders =
{
    new(101, 1, 500m),
    new(102, 1, 300m),
    new(103, 2, 700m)
};

var result = customers.GroupJoin(
    orders,
    c => c.Id,
    o => o.CustomerId,
    (c, matches) => new
    {
        Customer = c.Name,
        Orders = matches.ToList()
    }
);

foreach (var customer in result)
{
    Console.WriteLine(customer.Customer);

    foreach (var order in customer.Orders)
    {
        Console.WriteLine(
            $"  Order {order.Id}: {order.Amount}"
        );
    }
}
```

**Output:**

```text
Amit
  Order 101: 500
  Order 102: 300
Rahul
  Order 103: 700
```

**Key point:** A group join naturally represents one-to-many parent-child relationships.

## 6. Empty Matching Groups

When an outer element has no matching inner elements, `GroupJoin()` supplies an empty sequence.

The outer element remains in the result.

### Example 1: Missing matches

```csharp
int[] outer = { 1, 2, 3 };
int[] inner = { 1, 2 };

var result = outer.GroupJoin(
    inner,
    x => x,
    y => y,
    (x, matches) => new
    {
        Key = x,
        Count = matches.Count()
    }
);

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Key}: {item.Count}"
    );
}
```

**Output:**

```text
1: 1
2: 1
3: 0
```

### Example 2: Detect empty groups

```csharp
int[] outer = { 1, 2, 3 };
int[] inner = { 1, 2 };

var result = outer.GroupJoin(
    inner,
    x => x,
    y => y,
    (x, matches) => new
    {
        Key = x,
        HasMatches = matches.Any()
    }
);

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Key}: {item.HasMatches}"
    );
}
```

**Output:**

```text
1: True
2: True
3: False
```

### Example 3: Display a default message

```csharp
var result = outer.GroupJoin(
    inner,
    x => x,
    y => y,
    (x, matches) => new
    {
        Key = x,
        Status = matches.Any()
            ? "Matched"
            : "No matches"
    }
);

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Key}: {item.Status}"
    );
}
```

**Output:**

```text
1: Matched
2: Matched
3: No matches
```

**Key point:** Empty matching groups are represented by empty sequences, not by missing outer results.

## 7. GroupJoin Result Selector

The result selector determines the output structure for each outer element and its matching inner sequence.

### Syntax

```csharp
(outerElement, matchingInnerElements) => result
```

### Delegate type

```csharp
Func<TOuter, IEnumerable<TInner>, TResult>
```

### Example 1: Return match counts

```csharp
int[] outer = { 1, 2, 3 };
int[] inner = { 1, 1, 2 };

var result = outer.GroupJoin(
    inner,
    x => x,
    y => y,
    (x, matches) => new
    {
        Value = x,
        Count = matches.Count()
    }
);

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Value}: {item.Count}"
    );
}
```

**Output:**

```text
1: 2
2: 1
3: 0
```

### Example 2: Aggregate matching values

```csharp
record Customer(int Id, string Name);
record Order(int CustomerId, decimal Amount);

Customer[] customers =
{
    new(1, "Amit"),
    new(2, "Rahul"),
    new(3, "Priya")
};

Order[] orders =
{
    new(1, 100m),
    new(1, 200m),
    new(2, 300m)
};

var result = customers.GroupJoin(
    orders,
    c => c.Id,
    o => o.CustomerId,
    (c, matches) => new
    {
        Customer = c.Name,
        OrderCount = matches.Count(),
        TotalAmount = matches.Sum(o => o.Amount)
    }
);

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Customer}: Count={item.OrderCount}, Total={item.TotalAmount}"
    );
}
```

**Output:**

```text
Amit: Count=2, Total=300
Rahul: Count=1, Total=300
Priya: Count=0, Total=0
```

### Example 3: Return a custom DTO

```csharp
record CustomerReport(
    string Name,
    int OrderCount,
    decimal Total
);

var result = customers.GroupJoin(
    orders,
    c => c.Id,
    o => o.CustomerId,
    (c, matches) => new CustomerReport(
        c.Name,
        matches.Count(),
        matches.Sum(o => o.Amount)
    )
);

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Name}: {item.OrderCount}, {item.Total}"
    );
}
```

**Output:**

```text
Amit: 2, 300
Rahul: 1, 300
Priya: 0, 0
```

**Key point:** The result selector receives one outer element and its matching inner sequence.

## 8. GroupJoin vs Join

`Join()` and `GroupJoin()` both match elements using keys.

Their output structures are different.

### Example 1: Join

```csharp
int[] outer = { 1, 2, 3 };
int[] inner = { 1, 1, 2 };

var result = outer.Join(
    inner,
    x => x,
    y => y,
    (x, y) => $"{x}-{y}"
);

foreach (var item in result)
{
    Console.WriteLine(item);
}
```

**Output:**

```text
1-1
1-1
2-2
```

Each matching pair becomes a separate result.

The unmatched outer element `3` is excluded.

### Example 2: GroupJoin

```csharp
int[] outer = { 1, 2, 3 };
int[] inner = { 1, 1, 2 };

var result = outer.GroupJoin(
    inner,
    x => x,
    y => y,
    (x, matches) => new
    {
        Key = x,
        Values = matches
    }
);

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Key}: {string.Join(", ", item.Values)}"
    );
}
```

**Output:**

```text
1: 1, 1
2: 2
3:
```

Each outer element becomes one result containing a collection.

### Comparison

| Feature | Join | GroupJoin |
|---|---|---|
| Join type | Inner join | Grouped join |
| Output | Matching pairs | Outer element with matching collection |
| Unmatched outer elements | Excluded | Preserved |
| Matching inner elements | Separate results | Grouped together |
| Empty matching sequence | No result | Empty collection |
| Result selector | `(outer, inner)` | `(outer, IEnumerable<inner>)` |
| Result count | Number of matching pairs | Number of outer elements |
| Typical use | Flat matching records | Parent-child relationships |

**Key point:** `Join()` produces individual matching pairs; `GroupJoin()` produces grouped matching collections.

## 9. GroupJoin vs GroupBy

`GroupJoin()` and `GroupBy()` both produce grouped data, but they operate differently.

`GroupBy()` groups elements from one sequence.

`GroupJoin()` matches elements from two sequences.

### Example 1: GroupBy

```csharp
record Employee(string Name, int DepartmentId);

Employee[] employees =
{
    new("Amit", 1),
    new("Priya", 1),
    new("Rahul", 2)
};

var result = employees.GroupBy(
    e => e.DepartmentId
);

foreach (var group in result)
{
    Console.WriteLine(
        $"{group.Key}: {group.Count()}"
    );
}
```

**Output:**

```text
1: 2
2: 1
```

### Example 2: GroupJoin

```csharp
record Department(int Id, string Name);
record Employee(string Name, int DepartmentId);

Department[] departments =
{
    new(1, "IT"),
    new(2, "HR"),
    new(3, "Finance")
};

Employee[] employees =
{
    new("Amit", 1),
    new("Priya", 1),
    new("Rahul", 2)
};

var result = departments.GroupJoin(
    employees,
    d => d.Id,
    e => e.DepartmentId,
    (d, matches) => new
    {
        Department = d.Name,
        Count = matches.Count()
    }
);

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Department}: {item.Count}"
    );
}
```

**Output:**

```text
IT: 2
HR: 1
Finance: 0
```

### Comparison

| Feature | GroupBy | GroupJoin |
|---|---|---|
| Number of source sequences | One | Two |
| Grouping basis | Common key within one sequence | Matching keys between sequences |
| Output | `IGrouping<TKey,TElement>` sequences | Custom result per outer element |
| Empty groups | Not generated for absent keys | Possible for unmatched outer elements |
| Result count | Number of distinct keys | Number of outer elements |
| Typical use | Grouping and aggregation | Parent-child matching |

**Key point:** `GroupBy()` organizes one sequence; `GroupJoin()` associates one sequence with grouped matches from another.

## 10. Flattening GroupJoin

Flattening converts grouped matching collections into individual result elements.

A grouped structure:

```text
IT
 ├── Amit
 └── Priya

HR
 └── Rahul
```

Can be flattened into:

```text
IT: Amit
IT: Priya
HR: Rahul
```

### Example 1: Flatten using nested foreach

```csharp
record Department(int Id, string Name);
record Employee(string Name, int DepartmentId);

Department[] departments =
{
    new(1, "IT"),
    new(2, "HR")
};

Employee[] employees =
{
    new("Amit", 1),
    new("Priya", 1),
    new("Rahul", 2)
};

var groups = departments.GroupJoin(
    employees,
    d => d.Id,
    e => e.DepartmentId,
    (d, matches) => new
    {
        Department = d.Name,
        Employees = matches
    }
);

foreach (var group in groups)
{
    foreach (var employee in group.Employees)
    {
        Console.WriteLine(
            $"{group.Department}: {employee.Name}"
        );
    }
}
```

**Output:**

```text
IT: Amit
IT: Priya
HR: Rahul
```

### Example 2: Flatten using SelectMany

```csharp
var result = groups.SelectMany(
    g => g.Employees,
    (g, e) => new
    {
        Department = g.Department,
        Employee = e.Name
    }
);

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Department}: {item.Employee}"
    );
}
```

**Output:**

```text
IT: Amit
IT: Priya
HR: Rahul
```

**Key point:** Flattening transforms a grouped result into a sequence of individual matching records.

## 11. GroupJoin + SelectMany

`GroupJoin()` and `SelectMany()` can be combined to flatten matching groups into individual results.

### Syntax

```csharp
outer
    .GroupJoin(
        inner,
        outerKeySelector,
        innerKeySelector,
        (outerItem, matches) => new
        {
            Outer = outerItem,
            Matches = matches
        }
    )
    .SelectMany(
        x => x.Matches,
        (x, innerItem) => new
        {
            Outer = x.Outer,
            Inner = innerItem
        }
    );
```

### Example 1: Flatten matching departments and employees

```csharp
record Department(int Id, string Name);
record Employee(string Name, int DepartmentId);

Department[] departments =
{
    new(1, "IT"),
    new(2, "HR"),
    new(3, "Finance")
};

Employee[] employees =
{
    new("Amit", 1),
    new("Priya", 1),
    new("Rahul", 2)
};

var result = departments
    .GroupJoin(
        employees,
        d => d.Id,
        e => e.DepartmentId,
        (d, matches) => new
        {
            Department = d,
            Employees = matches
        }
    )
    .SelectMany(
        x => x.Employees,
        (x, e) => new
        {
            Department = x.Department.Name,
            Employee = e.Name
        }
    );

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Department}: {item.Employee}"
    );
}
```

**Output:**

```text
IT: Amit
IT: Priya
HR: Rahul
```

Notice that Finance does not appear because its matching collection is empty.

### Example 2: Flatten customer orders

```csharp
record Customer(int Id, string Name);
record Order(int Id, int CustomerId, decimal Amount);

Customer[] customers =
{
    new(1, "Amit"),
    new(2, "Rahul")
};

Order[] orders =
{
    new(101, 1, 500m),
    new(102, 1, 300m),
    new(103, 2, 700m)
};

var result = customers
    .GroupJoin(
        orders,
        c => c.Id,
        o => o.CustomerId,
        (c, matches) => new
        {
            Customer = c,
            Orders = matches
        }
    )
    .SelectMany(
        x => x.Orders,
        (x, o) => new
        {
            Customer = x.Customer.Name,
            OrderId = o.Id,
            Amount = o.Amount
        }
    );

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Customer}: Order {item.OrderId}, {item.Amount}"
    );
}
```

**Output:**

```text
Amit: Order 101, 500
Amit: Order 102, 300
Rahul: Order 103, 700
```

### Example 3: GroupJoin + SelectMany compared with Join

```csharp
int[] outer = { 1, 2, 3 };
int[] inner = { 1, 1, 2 };

var groupJoinResult = outer
    .GroupJoin(
        inner,
        x => x,
        y => y,
        (x, matches) => new
        {
            Outer = x,
            Matches = matches
        }
    )
    .SelectMany(
        x => x.Matches,
        (x, y) => $"{x.Outer}-{y}"
    );

var joinResult = outer.Join(
    inner,
    x => x,
    y => y,
    (x, y) => $"{x}-{y}"
);

Console.WriteLine(
    string.Join(", ", groupJoinResult)
);

Console.WriteLine(
    string.Join(", ", joinResult)
);
```

**Output:**

```text
1-1, 1-1, 2-2
1-1, 1-1, 2-2
```

For LINQ to Objects, flattening a `GroupJoin()` directly with `SelectMany()` produces the same matching pairs as an inner `Join()`.

**Key point:** `GroupJoin()` followed by `SelectMany()` flattens grouped matches into individual results.
