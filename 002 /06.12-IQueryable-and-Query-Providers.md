# 06.12 — MATERIALIZATION & CONVERSION

**Chapter:** 06 — LINQ Fundamentals  
**Namespace:** `System.Linq`

LINQ materialization converts a sequence into a concrete collection, while conversion methods can change how a sequence is represented or queried without necessarily copying its elements.

This section follows all **17 topics** in your master syllabus. Concepts already explained in Sections 06.05 and 06.11 are kept brief to avoid duplicate notes.

---

## 1. ToArray

`ToArray()` enumerates a sequence and stores its elements in a new array.

### Syntax

```csharp
T[] result = source.ToArray();
```

### Example 1: Convert to Array

```csharp
IEnumerable<int> numbers = Enumerable.Range(1, 5);

int[] result = numbers.ToArray();

// Output: 1, 2, 3, 4, 5
// Type: int[]
```

### Example 2: Array of Strings

```csharp
IEnumerable<string> names = new List<string>
{
    "Amit", "Rahul", "Priya"
};

string[] result = names.ToArray();

// Output: Amit, Rahul, Priya
```

### Example 3: Array Length

```csharp
var result = Enumerable.Range(1, 5).ToArray();

Console.WriteLine(result.Length);

// Output: 5
```

### Example 4: Array Indexing

```csharp
int[] result = Enumerable.Range(10, 3).ToArray();

Console.WriteLine(result[0]);
Console.WriteLine(result[2]);

// Output:
// 10
// 12
```

**Key points:** `ToArray()` executes immediately, creates a fixed-length array, and stores the sequence elements.

---

## 2. ToList

`ToList()` enumerates a sequence and stores its elements in a new `List<T>`.

### Syntax

```csharp
List<T> result = source.ToList();
```

### Example 1: Convert to List

```csharp
IEnumerable<int> numbers = Enumerable.Range(1, 5);

List<int> result = numbers.ToList();

// Output: 1, 2, 3, 4, 5
```

### Example 2: Modify the Result List

```csharp
var result = Enumerable.Range(1, 3).ToList();

result.Add(4);
result.Remove(2);

// Output: 1, 3, 4
```

### Example 3: Access by Index

```csharp
var result = Enumerable.Range(10, 3).ToList();

Console.WriteLine(result[1]);

// Output: 11
```

### Example 4: List Count

```csharp
var result = Enumerable.Range(1, 5).ToList();

Console.WriteLine(result.Count);

// Output: 5
```

### ToArray vs ToList

| Feature | `ToArray()` | `ToList()` |
|---|---|---|
| Result type | `T[]` | `List<T>` |
| Collection length | Fixed | Resizable |
| Indexed access | Yes | Yes |
| Add or remove elements | No | Yes |
| Immediate execution | Yes | Yes |

## 3. ToDictionary

`ToDictionary()` converts a sequence into a dictionary containing unique keys and associated values.

### Syntax

```csharp
source.ToDictionary(keySelector);

source.ToDictionary(
    keySelector,
    elementSelector
);
```

### Example 1: Key and Value

```csharp
record Student(int Id, string Name);

Student[] students =
{
    new(1, "Amit"),
    new(2, "Rahul"),
    new(3, "Priya")
};

Dictionary<int, string> result = students.ToDictionary(
    s => s.Id,
    s => s.Name
);
```

**Result:**

```text
1 → Amit
2 → Rahul
3 → Priya
```

### Example 2: Store Complete Objects

```csharp
Dictionary<int, Student> result = students.ToDictionary(
    s => s.Id
);

Console.WriteLine(result[2].Name);

// Output: Rahul
```

### Example 3: Dictionary Lookup

```csharp
var result = students.ToDictionary(
    s => s.Id,
    s => s.Name
);

Console.WriteLine(result[1]);

// Output: Amit
```

### Example 4: Safe Key Access

```csharp
if (result.TryGetValue(3, out string? name))
{
    Console.WriteLine(name);
}

// Output: Priya
```

**Key point:** Every dictionary key must be unique according to the dictionary's key comparer.

## 4. ToHashSet

`ToHashSet()` converts a sequence into a `HashSet<T>` containing distinct elements.

### Syntax

```csharp
source.ToHashSet();

source.ToHashSet(comparer);
```

### Example 1: Remove Duplicate Integers

```csharp
int[] numbers = { 1, 2, 2, 3, 3, 4 };

HashSet<int> result = numbers.ToHashSet();

// Elements: 1, 2, 3, 4
```

### Example 2: Check Membership

```csharp
var result = new[] { 10, 20, 30 }.ToHashSet();

Console.WriteLine(result.Contains(20));

// Output: True
```

### Example 3: Case-Insensitive HashSet

```csharp
string[] names =
{
    "Amit",
    "AMIT",
    "Rahul",
    "RAHUL"
};

var result = names.ToHashSet(
    StringComparer.OrdinalIgnoreCase
);

Console.WriteLine(result.Count);

// Output: 2
```

### Example 4: Add Elements

```csharp
var result = new[] { 1, 2, 3 }.ToHashSet();

result.Add(4);
result.Add(2);

Console.WriteLine(result.Count);

// Output: 4
```

**Important:** `HashSet<T>` does not guarantee element enumeration order.

## 5. ToLookup

`ToLookup()` creates a lookup that associates each key with a collection of matching elements.

Unlike a dictionary, a lookup naturally supports multiple elements under the same key.

### Syntax

```csharp
source.ToLookup(keySelector);

source.ToLookup(
    keySelector,
    elementSelector
);
```

### Example 1: Group Students by Department

```csharp
record Student(
    string Name,
    string Department
);

Student[] students =
{
    new("Amit", "IT"),
    new("Rahul", "HR"),
    new("Priya", "IT"),
    new("Neha", "HR")
};

ILookup<string, Student> result = students.ToLookup(
    s => s.Department
);
```

### Example 2: Access a Group

```csharp
foreach (Student student in result["IT"])
{
    Console.WriteLine(student.Name);
}
```

**Output:**

```text
Amit
Priya
```

### Example 3: Project Lookup Values

```csharp
var result = students.ToLookup(
    s => s.Department,
    s => s.Name
);

foreach (string name in result["HR"])
{
    Console.WriteLine(name);
}
```

**Output:**

```text
Rahul
Neha
```

### Example 4: Missing Key

```csharp
var result = students.ToLookup(
    s => s.Department,
    s => s.Name
);

Console.WriteLine(result["Finance"].Count());

// Output: 0
```

A missing lookup key returns an empty sequence rather than throwing `KeyNotFoundException`.

### ToDictionary vs ToLookup

| Feature | `ToDictionary()` | `ToLookup()` |
|---|---|---|
| Key relationship | One key → one value | One key → multiple values |
| Duplicate keys | Exception | Supported |
| Missing key indexer | Throws exception | Returns empty sequence |
| Mutable result | Yes | No public mutation methods |
| Execution | Immediate | Immediate |

## 6. AsEnumerable

`AsEnumerable()` exposes a sequence as `IEnumerable<T>` without copying its elements.

### Syntax

```csharp
source.AsEnumerable();
```

### Example 1: List as IEnumerable

```csharp
List<int> numbers = new() { 1, 2, 3 };

IEnumerable<int> result = numbers.AsEnumerable();

// Output: 1, 2, 3
```

### Example 2: No New Collection

```csharp
List<int> numbers = new() { 1, 2, 3 };

var result = numbers.AsEnumerable();

Console.WriteLine(
    ReferenceEquals(numbers, result)
);

// Output: True
```

### Example 3: Source Changes Remain Visible

```csharp
List<int> numbers = new() { 1, 2, 3 };

var result = numbers.AsEnumerable();

numbers.Add(4);

Console.WriteLine(string.Join(", ", result));

// Output: 1, 2, 3, 4
```

### Example 4: Select Enumerable Extensions

```csharp
var result = numbers
    .AsEnumerable()
    .Where(n => n > 2);
```

`AsEnumerable()` can also force subsequent LINQ calls to bind to `Enumerable` methods instead of `Queryable` methods.

**Key point:** `AsEnumerable()` is not a materialization operation.

---

## 7. AsQueryable

`AsQueryable()` exposes a sequence as `IQueryable<T>`.

### Syntax

```csharp
source.AsQueryable();
```

### Example 1: Convert an Array

```csharp
int[] numbers = { 1, 2, 3, 4, 5 };

IQueryable<int> query = numbers.AsQueryable();

var result = query.Where(n => n > 2);

// Output when enumerated: 3, 4, 5
```

### Example 2: Inspect Expression

```csharp
IQueryable<int> query = numbers
    .AsQueryable()
    .Where(n => n > 2);

Console.WriteLine(query.Expression);
```

The expression represents the query for its provider to process.

### Example 3: Inspect Provider

```csharp
IQueryable<int> query = numbers.AsQueryable();

Console.WriteLine(query.Provider.GetType().Name);
```

### Example 4: AsQueryable Does Not Create a Database

```csharp
List<int> numbers = new() { 1, 2, 3 };

IQueryable<int> query = numbers.AsQueryable();
```

The query still uses an in-memory source.

**Important:** Calling `AsQueryable()` on a list does not automatically make the query execute in SQL or improve performance.

The detailed differences between `IEnumerable<T>`, `IQueryable<T>`, expression trees, and query providers belong to **Section 06.13**.

## 8. Cast

`Cast<T>()` exposes a non-generic sequence as a typed sequence by casting its elements.

This operator was covered in **Section 06.05**; here, the focus is its role in sequence conversion.

### Example: Convert ArrayList to Typed List

```csharp
using System.Collections;

ArrayList values = new()
{
    10, 20, 30
};

List<int> result = values
    .Cast<int>()
    .ToList();

// Output: 10, 20, 30
```

### Example: Convert to Typed Array

```csharp
ArrayList values = new()
{
    "Amit", "Rahul", "Priya"
};

string[] result = values
    .Cast<string>()
    .ToArray();

// Output: Amit, Rahul, Priya
```

**Key point:** `Cast<T>()` alone is deferred. Combining it with `ToList()` or `ToArray()` performs the casts and materializes the results.

## 9. OfType

`OfType<T>()` selects compatible elements from a non-generic or mixed-type sequence.

This operator was covered in **Section 06.05**; here, the focus is creating a typed result collection.

### Example: Mixed Objects to Integer Array

```csharp
object[] values =
{
    10,
    "Hello",
    20,
    true,
    30
};

int[] result = values
    .OfType<int>()
    .ToArray();

// Output: 10, 20, 30
```

### Example: Mixed Objects to String List

```csharp
object[] values =
{
    "Amit",
    10,
    "Rahul",
    false
};

List<string> result = values
    .OfType<string>()
    .ToList();

// Output: Amit, Rahul
```

**Key point:** `OfType<T>()` filters compatible types; materialization stores the filtered elements in the requested collection.

## 10. Immediate Materialization

Immediate materialization enumerates a sequence and stores its results when a materialization method is called.

### Example 1: Execution Timing

```csharp
int[] numbers = { 1, 2, 3 };

var query = numbers.Select(n =>
{
    Console.WriteLine($"Processing {n}");
    return n * 10;
});

Console.WriteLine("Before ToList");

var result = query.ToList();

Console.WriteLine("After ToList");
```

**Output:**

```text
Before ToList
Processing 1
Processing 2
Processing 3
After ToList
```

### Example 2: Materialize Once

```csharp
int[] numbers = { 1, 2, 3, 4 };

List<int> result = numbers
    .Select(n => n * 10)
    .ToList();

Console.WriteLine(result.Count);
Console.WriteLine(result.Sum());

// Output:
// 4
// 100
```

### Example 3: Materialization Requires Memory

```csharp
var result = Enumerable.Range(1, 100000)
    .ToArray();
```

All 100,000 elements are stored in the array.

**Key point:** Materialization trades memory usage for reusable, concrete results.

## 11. Snapshot Behavior

Snapshot behavior means a materialized collection contains the sequence elements obtained at the time of materialization.

### Example 1: Source Changes After ToList

```csharp
List<int> numbers = new() { 1, 2, 3 };

List<int> result = numbers.ToList();

numbers.Add(4);

// Source: 1, 2, 3, 4
// Result: 1, 2, 3
```

### Example 2: Source Changes After ToArray

```csharp
int[] numbers = { 1, 2, 3 };

int[] result = numbers.ToArray();

numbers[0] = 100;

// Source: 100, 2, 3
// Result: 1, 2, 3
```

### Example 3: Independent Collection Structure

```csharp
List<int> numbers = new() { 1, 2, 3 };

List<int> result = numbers.ToList();

result.Add(10);

// Source: 1, 2, 3
// Result: 1, 2, 3, 10
```

**Important:** A snapshot preserves the collection's element values or references at that moment. It does not automatically preserve the internal state of referenced objects.

## 12. Duplicate Dictionary Keys

`ToDictionary()` throws `ArgumentException` when two source elements produce equal keys.

### Example 1: Duplicate Integer Keys

```csharp
record Student(int Id, string Name);

Student[] students =
{
    new(1, "Amit"),
    new(1, "Rahul")
};

var result = students.ToDictionary(
    s => s.Id,
    s => s.Name
);

// Throws ArgumentException
```

### Example 2: Handle Duplicate Keys by Grouping

```csharp
Student[] students =
{
    new(1, "Amit"),
    new(1, "Rahul"),
    new(2, "Priya")
};

var result = students
    .GroupBy(s => s.Id)
    .ToDictionary(
        group => group.Key,
        group => group.First().Name
    );
```

**Result:**

```text
1 → Amit
2 → Priya
```

This example intentionally keeps the first student for each key.

### Example 3: Preserve All Duplicate-Key Values

```csharp
var result = students.ToLookup(
    s => s.Id,
    s => s.Name
);

// 1 → Amit, Rahul
// 2 → Priya
```

**Key point:** Use a dictionary when keys must be unique; use a lookup when multiple values per key are required.

## 13. Dictionary Key Comparers

Dictionary key comparers determine whether two keys are considered equal.

### Syntax

```csharp
source.ToDictionary(
    keySelector,
    elementSelector,
    comparer
);
```

### Example 1: Case-Insensitive Keys

```csharp
string[] names =
{
    "Amit",
    "Rahul",
    "Priya"
};

var result = names.ToDictionary(
    name => name,
    name => name.Length,
    StringComparer.OrdinalIgnoreCase
);

Console.WriteLine(result["AMIT"]);

// Output: 4
```

### Example 2: Case-Sensitive Keys

```csharp
string[] names =
{
    "Amit",
    "AMIT"
};

var result = names.ToDictionary(
    name => name,
    name => name.Length,
    StringComparer.Ordinal
);

Console.WriteLine(result.Count);

// Output: 2
```

### Example 3: Duplicate Keys with IgnoreCase

```csharp
string[] names =
{
    "Amit",
    "AMIT"
};

var result = names.ToDictionary(
    name => name,
    name => name.Length,
    StringComparer.OrdinalIgnoreCase
);

// Throws ArgumentException
```

Both strings are considered the same key by the comparer.

### Example 4: Numeric Key Comparer

```csharp
int[] numbers = { 1, 2, 3 };

var result = numbers.ToDictionary(
    n => n,
    n => n * 10,
    EqualityComparer<int>.Default
);
```

**Important:** Dictionary keys use `IEqualityComparer<TKey>`, not the ordering interface `IComparer<TKey>`.

## 14. Shallow Copies

A shallow copy creates a new collection but does not clone the objects referenced by its elements.

### Example 1: Copy Object Collection

```csharp
class Student
{
    public string Name { get; set; } = "";
}

List<Student> students = new()
{
    new Student { Name = "Amit" },
    new Student { Name = "Rahul" }
};

List<Student> result = students.ToList();
```

### Example 2: Different Collection Instances

```csharp
Console.WriteLine(
    ReferenceEquals(students, result)
);

// Output: False
```

### Example 3: Same Referenced Objects

```csharp
Console.WriteLine(
    ReferenceEquals(students[0], result[0])
);

// Output: True
```

### Example 4: Create Independent Objects

```csharp
List<Student> result = students
    .Select(s => new Student
    {
        Name = s.Name
    })
    .ToList();

Console.WriteLine(
    ReferenceEquals(students[0], result[0])
);

// Output: False
```

This creates new `Student` objects. It is sufficient for this simple class, but copying classes with nested mutable references may require deeper copying.

## 15. Shared Element References

Shared element references mean different collections contain references to the same objects.

### Example 1: Modify an Object Through the Copy

```csharp
class Student
{
    public string Name { get; set; } = "";
}

List<Student> students = new()
{
    new Student { Name = "Amit" }
};

List<Student> result = students.ToList();

result[0].Name = "Rahul";

Console.WriteLine(students[0].Name);

// Output: Rahul
```

### Example 2: Replace an Element Reference

```csharp
result[0] = new Student
{
    Name = "Priya"
};

Console.WriteLine(students[0].Name);
Console.WriteLine(result[0].Name);

// Output:
// Rahul
// Priya
```

Replacing an element in the copied list does not replace the corresponding element in the original list.

### Example 3: Value-Type Elements

```csharp
List<int> numbers = new() { 1, 2, 3 };

List<int> result = numbers.ToList();

result[0] = 100;

// Source: 1, 2, 3
// Result: 100, 2, 3
```

**Key point:** Collection independence and object independence are different properties.

## 16. Deferred Sequence vs Materialized Result

A deferred sequence represents work to perform during enumeration, while a materialized result stores elements already obtained.

### Example

```csharp
List<int> numbers = new() { 1, 2, 3 };

IEnumerable<int> deferred = numbers.Where(n => n > 1);

List<int> materialized = numbers
    .Where(n => n > 1)
    .ToList();

numbers.Add(4);
```

### Deferred Result

```csharp
Console.WriteLine(string.Join(", ", deferred));

// Output: 2, 3, 4
```

### Materialized Result

```csharp
Console.WriteLine(string.Join(", ", materialized));

// Output: 2, 3
```

### Comparison

| Feature | Deferred Sequence | Materialized Result |
|---|---|---|
| Typical type | `IEnumerable<T>` | `List<T>`, `T[]` |
| Execution | During enumeration | At materialization |
| Stores computed results | Not necessarily | Yes |
| Source changes | May be observed | Collection membership is captured |
| Repeated enumeration | May repeat work | Reuses stored elements |
| Memory usage | Often lower | Stores results |
| Suitable for | Streaming and query composition | Reuse and snapshots |

**Note:** `IEnumerable<T>` is an interface, not a guarantee of deferred execution. Arrays and lists also implement it.

## 17. Choosing the Correct Result Collection

Choose a result collection according to how the data will be accessed, modified, or reused.

### 17.1 IEnumerable\<T>

Use `IEnumerable<T>` when only sequential enumeration is required.

```csharp
IEnumerable<int> result = Enumerable.Range(1, 5);
```

### 17.2 Array

Use an array when a fixed-length indexed collection is appropriate.

```csharp
int[] result = Enumerable.Range(1, 5).ToArray();
```

### 17.3 List

Use `List<T>` when elements must be added, removed, or accessed by index.

```csharp
List<int> result = Enumerable.Range(1, 5).ToList();

result.Add(6);
```

### 17.4 Dictionary

Use `Dictionary<TKey,TValue>` when retrieving one value by a unique key.

```csharp
var result = new[]
{
    new { Id = 1, Name = "Amit" },
    new { Id = 2, Name = "Rahul" }
}
.ToDictionary(x => x.Id, x => x.Name);
```

### 17.5 HashSet

Use `HashSet<T>` when uniqueness and membership checks are important.

```csharp
HashSet<int> result = new[]
{
    1, 2, 2, 3
}
.ToHashSet();
```

### 17.6 Lookup

Use `ILookup<TKey,TElement>` when one key must reference multiple elements.

```csharp
var result = new[]
{
    new { Department = "IT", Name = "Amit" },
    new { Department = "IT", Name = "Priya" },
    new { Department = "HR", Name = "Rahul" }
}
.ToLookup(x => x.Department, x => x.Name);
```

### Collection Selection Table

| Requirement | Recommended Result |
|---|---|
| Enumerate elements | `IEnumerable<T>` |
| Fixed-length indexed collection | `T[]` |
| Resizable indexed collection | `List<T>` |
| Unique-key lookup | `Dictionary<TKey,TValue>` |
| Distinct elements and membership checks | `HashSet<T>` |
| Multiple elements per key | `ILookup<TKey,TElement>` |
| Query provider representation | `IQueryable<T>` |
| Convert non-generic elements to a typed collection | `Cast<T>().ToList()` |
| Extract compatible types into a collection | `OfType<T>().ToArray()` |
