### 1. Count

`Count` represents the number of elements in a sequence or collection.

In C#, counting can be performed using a collection property or the LINQ `Count()` method.

```csharp
int[] numbers = { 10, 20, 30, 40, 50 };

int count = numbers.Count();

Console.WriteLine(count);
```

**Output:**

```text
5
```

For a sequence containing \(n\) elements:

\[
Count = n
\]

An empty sequence has a count of zero.

```csharp
int[] numbers = Array.Empty<int>();

Console.WriteLine(numbers.Count());
```

**Output:**

```text
0
```

---

### 2. LongCount

`LongCount()` counts elements and returns a `long` (`Int64`) value.

```csharp
int[] numbers = { 10, 20, 30, 40 };

long count = numbers.LongCount();

Console.WriteLine(count);
```

**Output:**

```text
4
```

The result type is:

```csharp
long
```

`LongCount()` is useful when a count may exceed the maximum value of `int`.

---

### 3. Count()

`Count()` is a LINQ extension method that returns the number of elements in a sequence.

**Syntax**

```csharp
int count = source.Count();
```

**Example 1: Array**

```csharp
int[] numbers = { 1, 2, 3, 4, 5 };

int result = numbers.Count();

Console.WriteLine(result);
```

**Output:**

```text
5
```

**Example 2: List**

```csharp
List<string> names = new()
{
    "Amit",
    "Rahul",
    "Priya"
};

int result = names.Count();

Console.WriteLine(result);
```

**Output:**

```text
3
```

**Example 3: Empty sequence**

```csharp
IEnumerable<int> numbers = Enumerable.Empty<int>();

Console.WriteLine(numbers.Count());
```

**Output:**

```text
0
```

**Return type:** `int`

---

### 4. Count(predicate)

`Count(predicate)` returns the number of elements satisfying a condition.

**Syntax**

```csharp
int count = source.Count(x => condition);
```

**Example 1: Count even numbers**

```csharp
int[] numbers = { 1, 2, 3, 4, 5, 6 };

int result = numbers.Count(n => n % 2 == 0);

Console.WriteLine(result);
```

**Output:**

```text
3
```

**Example 2: Count values greater than 10**

```csharp
int[] numbers = { 5, 10, 15, 20, 25 };

int result = numbers.Count(n => n > 10);

Console.WriteLine(result);
```

**Output:**

```text
3
```

**Example 3: Count matching strings**

```csharp
string[] names =
{
    "Amit",
    "Ankit",
    "Rahul",
    "Arjun"
};

int result = names.Count(
    name => name.StartsWith("A")
);

Console.WriteLine(result);
```

**Output:**

```text
3
```

**Return type:** `int`

**Output:**

```text

```

**Example 2**

```csharp
List<int> numbers = new()
{
    10, 20, 30

long result = numbers.LongCount();

Console.WriteLine(result);
```

**Output:**

```text
3
```

**Return type:** `long`

### 6. LongCount(predicate)

`LongCount(predicate)` counts matching elements and returns a `long`.

**Syntax**

```csharp
long count = source.LongCount(x => condition);
```

**Example 1: Count even numbers**

```csharp
int[] numbers = { 1, 2, 3, 4, 5, 6 };

long result = numbers.LongCount(n => n % 2 == 0);

Console.WriteLine(result);
```

**Output:**

```text
3
```

**Example 2: Count positive numbers**

```csharp
int[] numbers = { -10, 20, -30, 40, 50 };

long result = numbers.LongCount(n => n > 0);

Console.WriteLine(result);
```

**Output:**

```text
3
```

**Example 3: Count matching objects**

```csharp
record Student(string Name, int Marks);

Student[] students =
{
    new("Amit", 90),
    new("Rahul", 70),
    new("Priya", 95)
};

long result = students.LongCount(
    student => student.Marks >= 80
);

Console.WriteLine(result);
```

**Output:**

```text
2
```

### 7. Predicate-Based Counting

Predicate-based counting counts only elements for which a condition returns `true`.

A predicate has the general form:

```csharp
Func<T, bool>
```

**Example 1: Explicit predicate**

```csharp
int[] numbers = { 10, 15, 20, 25, 30 };

Func<int, bool> predicate = n => n >= 20;

int count = numbers.Count(predicate);

Console.WriteLine(count);
```

**Output:**

```text
3
```

**Example 2: Multiple conditions**

```csharp
int[] numbers = { 5, 10, 15, 20, 25, 30 };

int count = numbers.Count(
    n => n > 10 && n % 2 == 0
);

Console.WriteLine(count);
```

**Output:**

```text
2
```

The matching elements are `20` and `30`.

**Example 3: Object properties**

```csharp
record Product(string Name, decimal Price, bool Available);

Product[] products =
{
    new("Mouse", 500, true),
    new("Keyboard", 1200, true),
    new("Monitor", 8000, false)
};

int count = products.Count(
    p => p.Available && p.Price >= 1000
);

Console.WriteLine(count);
```

**Output:**

```text
1
```

### 8. Collection Count Property

Many .NET collections expose a `Count` property.

Unlike LINQ `Count()`, this property is a member of the collection itself.

**Syntax**

```csharp
collection.Count
```

**Example 1: List**

```csharp
List<int> numbers = new() { 10, 20, 30 };

Console.WriteLine(numbers.Count);
```

**Output:**

```text
3
```

**Example 2: Dictionary**

```csharp
Dictionary<int, string> students = new()
{
    { 1, "Amit" },
    { 2, "Rahul" }
};

Console.WriteLine(students.Count);
```

**Output:**

```text
2
```

**Example 3: HashSet**

```csharp
HashSet<int> numbers = new()
{
    10, 20, 20, 30
};

Console.WriteLine(numbers.Count);
```

**Output:**

```text
3
```

**Difference**

```csharp
numbers.Count
```

Accesses the collection property.

```csharp
numbers.Count()
```

Calls the LINQ extension method.

For collections with an efficient `Count` property, prefer the property when no filtering is required.

### 9. Array Length

Arrays expose a `Length` property instead of a `Count` property.

**Syntax**

```csharp
array.Length
```

**Example 1: One-dimensional array**

```csharp
int[] numbers = { 10, 20, 30, 40 };

Console.WriteLine(numbers.Length);
```

**Output:**

```text
4
```

**Example 2: String array**

```csharp
string[] names = { "Amit", "Rahul", "Priya" };

Console.WriteLine(names.Length);
```

**Output:**

```text
3
```

**Example 3: Multidimensional array**

```csharp
int[,] matrix =
{
    { 1, 2, 3 },
    { 4, 5, 6 }
};

Console.WriteLine(matrix.Length);
Console.WriteLine(matrix.GetLength(0));
Console.WriteLine(matrix.GetLength(1));
```

**Output:**

```text
6
2
3
```

`Length` returns the total number of elements.

`GetLength(dimension)` returns the size of a particular dimension.

**Comparison**

| Source | Preferred Member |
|---|---|
| Array | `Length` |
| `List<T>` | `Count` |
| `Dictionary<TKey,TValue>` | `Count` |
| `HashSet<T>` | `Count` |
| General `IEnumerable<T>` | `Count()` |

### 10. Query Counting

Query counting calculates the number of elements produced by a LINQ query.

**Example 1: Count filtered elements**

```csharp
int[] numbers = { 10, 20, 30, 40, 50 };

var query = numbers.Where(n => n >= 30);

int count = query.Count();

Console.WriteLine(count);
```

**Output:**

```text
3
```

**Example 2: Count using query syntax**

```csharp
int[] numbers = { 10, 20, 30, 40, 50 };

var query =
    from n in numbers
    where n > 20
    select n;

int count = query.Count();

Console.WriteLine(count);
```

**Output:**

```text
3
```

**Example 3: Count a database query**

```csharp
int count = db.Students
    .Where(s => s.Marks >= 80)
    .Count();
```

With Entity Framework Core, a relational query provider can translate the counting operation into SQL.

**Conceptual SQL:**

```sql
SELECT COUNT(*)
FROM Students
WHERE Marks >= 80;
```

**Key point:** Counting a query does not require creating a list of all matching elements.

### 11. Enumeration Costs

Counting can require traversing a sequence.

The cost depends on the source and whether its count can be obtained directly.

**Example 1: Iterator sequence**

```csharp
IEnumerable<int> GenerateNumbers()
{
    for (int i = 1; i <= 5; i++)
    {
        Console.WriteLine($"Generating {i}");
        yield return i;
    }
}

int count = GenerateNumbers().Count();

Console.WriteLine($"Count: {count}");
```

**Output:**

```text
Generating 1
Generating 2
Generating 3
Generating 4
Generating 5
Count: 5
```

**Example 2: Predicate evaluation**

```csharp
int[] numbers = { 10, 20, 30, 40 };

int count = numbers.Count(n =>
{
    Console.WriteLine($"Checking {n}");
    return n > 20;
});
```

**Output:**

```text
Checking 10
Checking 20
Checking 30
Checking 40
```

**Example 3: Repeated counting**

```csharp
IEnumerable<int> query = GenerateNumbers();

int first = query.Count();
int second = query.Count();
```

For this iterator, the sequence is enumerated twice.

**Typical complexity:**

| Source | Counting Cost |
|---|---|
| Array | \(O(1)\) when length is accessed directly |
| List | \(O(1)\) using its count |
| General iterator | Usually \(O(n)\) |
| `Count(predicate)` | Usually \(O(n)\) |
| Database query | Depends on database execution |

### 12. Fast Count Paths

LINQ `Count()` can use optimized paths when the source exposes its element count.

**Example 1: Array**

```csharp
int[] numbers = { 1, 2, 3, 4, 5 };

int count = numbers.Count();
```

The count can be obtained without traversing every array element.

**Example 2: List**

```csharp
List<int> numbers = new() { 1, 2, 3, 4 };

int count = numbers.Count();
```

LINQ can use the collection's count information.

**Example 3: ICollection**

```csharp
ICollection<int> numbers = new List<int>
{
    10, 20, 30
};

int count = numbers.Count();
```

**Example 4: Predicate counting**

```csharp
int[] numbers = { 10, 20, 30, 40 };

int count = numbers.Count(n => n > 20);
```

A predicate requires determining which elements match, so counting generally examines the elements.

**Key point:** Fast counting depends on the collection or LINQ implementation. Not every `IEnumerable<T>` supports a constant-time count.

### 13. TryGetNonEnumeratedCount

`TryGetNonEnumeratedCount()` attempts to obtain the number of elements without enumerating the sequence.

**Syntax**

```csharp
bool success = source.TryGetNonEnumeratedCount(
    out int count
);
```

**Example 1: List**

```csharp
List<int> numbers = new() { 10, 20, 30 };

bool success = numbers.TryGetNonEnumeratedCount(
    out int count
);

Console.WriteLine(success);
Console.WriteLine(count);
```

**Output:**

```text
True
3
```

**Example 2: Array**

```csharp
int[] numbers = { 1, 2, 3, 4 };

bool success = numbers.TryGetNonEnumeratedCount(
    out int count
);

Console.WriteLine(success);
Console.WriteLine(count);
```

**Output:**

```text
True
4
```

**Example 3: Custom iterator**

```csharp
IEnumerable<int> Generate()
{
    yield return 10;
    yield return 20;
    yield return 30;
}

bool success = Generate().TryGetNonEnumeratedCount(
    out int count
);

Console.WriteLine(success);
```

**Output:**

```text
False
```

**Example 4: Fallback**

```csharp
IEnumerable<int> source = Generate();

if (!source.TryGetNonEnumeratedCount(out int count))
{
    count = source.Count();
}

Console.WriteLine(count);
```

**Output:**

```text
3
```

**Important:** `false` means the count could not be determined without enumeration. It does not mean the sequence is empty.

### 14. Count vs LongCount

Both operators count elements, but their return types differ.

**Count**

```csharp
int count = source.Count();
```

**LongCount**

```csharp
long count = source.LongCount();
```

**Example**

```csharp
int[] numbers = { 10, 20, 30 };

int count = numbers.Count();

long longCount = numbers.LongCount();

Console.WriteLine(count);
Console.WriteLine(longCount);
```

**Output:**

```text
3
3
```

**Comparison**

| Feature | `Count()` | `LongCount()` |
|---|---|---|
| Return type | `int` | `long` |
| Integer size | 32-bit | 64-bit |
| Maximum representable count | 2,147,483,647 | 9,223,372,036,854,775,807 |
| Predicate overload | Yes | Yes |
| Empty sequence result | 0 | 0 |
| Primary purpose | Ordinary counting | Counting beyond `int` range |

**Important:** `LongCount()` does not automatically make enumeration faster. It primarily provides a larger result type.

### 15. Count vs Any

`Count()` calculates how many elements exist.

`Any()` determines whether at least one element exists.

**Example 1: Count**

```csharp
int[] numbers = { 10, 20, 30 };

bool exists = numbers.Count() > 0;

Console.WriteLine(exists);
```

**Output:**

```text
True
```

**Example 2: Any**

```csharp
int[] numbers = { 10, 20, 30 };

bool exists = numbers.Any();

Console.WriteLine(exists);
```

**Output:**

```text
True
```

**Example 3: Predicate-based Count**

```csharp
int[] numbers = { 10, 20, 30, 40 };

bool exists = numbers.Count(n => n > 20) > 0;
```

**Example 4: Predicate-based Any**

```csharp
int[] numbers = { 10, 20, 30, 40 };

bool exists = numbers.Any(n => n > 20);
```

`Any(predicate)` can stop as soon as it finds a matching element.

**Comparison**

| Requirement | Operator |
|---|---|
| Total number of elements | `Count()` |
| Total number of matching elements | `Count(predicate)` |
| Whether sequence contains any elements | `Any()` |
| Whether at least one element matches | `Any(predicate)` |
| Count beyond `int` range | `LongCount()` |

**Key point:** Use `Count()` when the number of elements is required and `Any()` when only existence matters.
