# 09.01 — FUNCTIONAL PROGRAMMING FOUNDATIONS

**Chapter:** 09 — Functional C#  
**Total Syllabus Points:** 19  
**Language:** C#

Functional programming is a programming approach that emphasizes functions, explicit data transformations, immutability, and minimizing side effects.

C# supports functional programming through methods, delegates, lambda expressions, LINQ, records, and other language features.

---

## 1. Functional Programming

Functional programming organizes computations around functions that receive inputs and produce outputs.

A function ideally calculates a result without unexpectedly modifying external state.

### Example 1: Traditional imperative programming

```csharp
int[] numbers = { 1, 2, 3, 4, 5 };

List<int> squares = new();

foreach (int number in numbers)
{
    squares.Add(number * number);
}

Console.WriteLine(string.Join(", ", squares));
```

**Output:**

```text
1, 4, 9, 16, 25
```

The program explicitly controls the loop and modifies a result collection.

### Example 2: Functional programming with LINQ

```csharp
int[] numbers = { 1, 2, 3, 4, 5 };

var squares = numbers.Select(
    number => number * number
);

Console.WriteLine(string.Join(", ", squares));
```

**Output:**

```text
1, 4, 9, 16, 25
```

The program describes the transformation rather than manually managing the loop.

### Example 3: Functional method

```csharp
static int Square(int number)
{
    return number * number;
}

Console.WriteLine(Square(5));
Console.WriteLine(Square(10));
```

**Output:**

```text
25
100
```

### Main characteristics

| Characteristic | Description |
|---|---|
| Functions | Represent computations |
| Explicit inputs | Supply required data |
| Explicit outputs | Return calculated results |
| Immutability | Avoid changing existing values |
| Pure functions | Avoid observable side effects |
| Composition | Combine smaller functions |
| Declarative style | Describe desired results |

**Key point:** Functional programming emphasizes composing functions to transform data while minimizing unnecessary state changes.

## 2. Functions as Values

In C#, functions can be represented by delegate values.

A function can be assigned to a variable, passed to another method, or returned from a method.

### Example 1: Assign a function to a variable

```csharp
Func<int, int> square = x => x * x;

Console.WriteLine(square(5));
```

**Output:**

```text
25
```

Here:

```csharp
Func<int, int>
```

represents a function that receives an `int` and returns an `int`.

### Example 2: Store different functions

```csharp
Func<int, int> square = x => x * x;
Func<int, int> cube = x => x * x * x;

Console.WriteLine(square(3));
Console.WriteLine(cube(3));
```

**Output:**

```text
9
27
```

### Example 3: Pass a function as an argument

```csharp
static int Apply(
    int value,
    Func<int, int> operation
)
{
    return operation(value);
}

Console.WriteLine(
    Apply(5, x => x * 2)
);

Console.WriteLine(
    Apply(5, x => x * x)
);
```

**Output:**

```text
10
25
```

### Example 4: Return a function

```csharp
static Func<int, int> CreateMultiplier(int factor)
{
    return x => x * factor;
}

Func<int, int> multiplyByThree =
    CreateMultiplier(3);

Console.WriteLine(multiplyByThree(10));
```

**Output:**

```text
30
```

**Key point:** Delegates allow functions to be treated as values in C#.

## 3. First-Class Function Concepts

A first-class function can be manipulated similarly to other values.

In C#, delegates provide first-class function behavior.

Functions can be:

1. Assigned to variables.
2. Passed as parameters.
3. Returned from methods.
4. Stored in collections.
5. Selected dynamically.

### Example 1: Store functions in a collection

```csharp
List<Func<int, int>> operations = new()
{
    x => x + 10,
    x => x * 2,
    x => x * x
};

foreach (var operation in operations)
{
    Console.WriteLine(operation(5));
}
```

**Output:**

```text
15
10
25
```

### Example 2: Select a function dynamically

```csharp
Func<int, int> operation;

bool useSquare = true;

if (useSquare)
{
    operation = x => x * x;
}
else
{
    operation = x => x * 2;
}

Console.WriteLine(operation(6));
```

**Output:**

```text
36
```

### Example 3: Return different functions

```csharp
static Func<int, int> GetOperation(string name)
{
    return name switch
    {
        "square" => x => x * x,
        "double" => x => x * 2,
        _ => x => x
    };
}

var operation = GetOperation("square");

Console.WriteLine(operation(4));
```

**Output:**

```text
16
```

**Key point:** First-class function concepts allow behavior to be stored, passed, selected, and returned.

## 4. Declarative Programming

Declarative programming describes **what result is required** rather than explicitly specifying every step used to produce it.

LINQ is a common declarative feature in C#.

### Example 1: Imperative filtering

```csharp
int[] numbers = { 1, 2, 3, 4, 5, 6 };

List<int> result = new();

foreach (int number in numbers)
{
    if (number % 2 == 0)
    {
        result.Add(number);
    }
}

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
2, 4, 6
```

### Example 2: Declarative filtering

```csharp
int[] numbers = { 1, 2, 3, 4, 5, 6 };

var result = numbers.Where(
    number => number % 2 == 0
);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
2, 4, 6
```

### Example 3: Declarative sorting

```csharp
int[] numbers = { 5, 2, 4, 1, 3 };

var result = numbers.OrderBy(x => x);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1, 2, 3, 4, 5
```

### Example 4: Declarative aggregation

```csharp
int[] numbers = { 10, 20, 30 };

int total = numbers.Sum();

Console.WriteLine(total);
```

**Output:**

```text
60
```

**Key point:** Declarative programming focuses on expressing the intended computation rather than manually controlling each step.

## 5. Declarative Data Transformation

Declarative data transformation converts source data into a desired result using expressions and transformation operators.

Common LINQ operators include:

```csharp
Where()
Select()
SelectMany()
OrderBy()
GroupBy()
```

### Example 1: Filter and transform numbers

```csharp
int[] numbers = { 1, 2, 3, 4, 5, 6 };

var result = numbers
    .Where(x => x % 2 == 0)
    .Select(x => x * x);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
4, 16, 36
```

### Example 2: Transform objects

```csharp
record Employee(
    int Id,
    string Name,
    decimal Salary
);

Employee[] employees =
{
    new(1, "Amit", 30000),
    new(2, "Rahul", 40000)
};

var result = employees.Select(
    e => new
    {
        e.Name,
        AnnualSalary = e.Salary * 12
    }
);

foreach (var employee in result)
{
    Console.WriteLine(
        $"{employee.Name}: {employee.AnnualSalary}"
    );
}
```

**Output:**

```text
Amit: 360000
Rahul: 480000
```

### Example 3: Group data declaratively

```csharp
record Employee(string Name, string Department);

Employee[] employees =
{
    new("Amit", "IT"),
    new("Rahul", "HR"),
    new("Priya", "IT")
};

var result = employees
    .GroupBy(e => e.Department)
    .Select(g => new
    {
        Department = g.Key,
        Count = g.Count()
    });

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Department}: {item.Count}"
    );
}
```

**Output:**

```text
IT: 2
HR: 1
```

**Key point:** Declarative transformations express filtering, projection, grouping, and other operations as composable expressions.

## 6. Pure Functions

A pure function has two essential properties:

1. Its result depends only on its explicit inputs.
2. It produces no observable side effects.

For the same input values, a pure function always produces the same result.

### Example 1: Pure addition

```csharp
static int Add(int a, int b)
{
    return a + b;
}

Console.WriteLine(Add(10, 20));
Console.WriteLine(Add(10, 20));
```

**Output:**

```text
30
30
```

### Example 2: Pure square function

```csharp
static int Square(int number)
{
    return number * number;
}

Console.WriteLine(Square(4));
Console.WriteLine(Square(4));
```

**Output:**

```text
16
16
```

### Example 3: Pure string transformation

```csharp
static string NormalizeName(string name)
{
    return name.Trim().ToUpperInvariant();
}

Console.WriteLine(
    NormalizeName("  amit  ")
);
```

**Output:**

```text
AMIT
```

### Example 4: Pure transformation with immutable records

```csharp
record Product(
    string Name,
    decimal Price
);

static Product ApplyDiscount(
    Product product,
    decimal discount
)
{
    return product with
    {
        Price = product.Price - discount
    };
}

Product original = new("Mouse", 500);

Product updated = ApplyDiscount(original, 100);

Console.WriteLine(original.Price);
Console.WriteLine(updated.Price);
```

**Output:**

```text
500
400
```

The function creates a new record instead of changing the original.

**Key point:** Pure functions are predictable because they depend on explicit inputs and do not modify external state.

## 7. Impure Functions

An impure function depends on external state, modifies state, or performs observable side effects.

Examples include functions that:

- Read mutable global variables.
- Modify shared collections.
- Write to the console.
- Access external systems.
- Depend on the current time.

### Example 1: Function depending on external state

```csharp
int bonus = 100;

int CalculateTotal(int salary)
{
    return salary + bonus;
}

Console.WriteLine(CalculateTotal(1000));

bonus = 200;

Console.WriteLine(CalculateTotal(1000));
```

**Output:**

```text
1100
1200
```

The same explicit argument produces different results because `bonus` changes.

### Example 2: Function modifying external state

```csharp
int counter = 0;

int Increment()
{
    counter++;
    return counter;
}

Console.WriteLine(Increment());
Console.WriteLine(Increment());
```

**Output:**

```text
1
2
```

### Example 3: Function depending on time

```csharp
static DateTime GetCurrentTime()
{
    return DateTime.Now;
}

Console.WriteLine(
    GetCurrentTime().Year
);
```

**Output:**

```text
2026
```

The displayed year depends on the execution date.

### Example 4: Function modifying a collection

```csharp
List<int> numbers = new();

void AddNumber(int number)
{
    numbers.Add(number);
}

AddNumber(10);
AddNumber(20);

Console.WriteLine(
    string.Join(", ", numbers)
);
```

**Output:**

```text
10, 20
```

**Key point:** Impure functions interact with mutable state or the external environment.

## 8. Side Effects

A side effect occurs when a function changes observable state or interacts with the outside world beyond returning a value.

### Example 1: Console output

```csharp
static int Square(int number)
{
    Console.WriteLine("Calculating...");
    return number * number;
}

Console.WriteLine(Square(5));
```

**Output:**

```text
Calculating...
25
```

The console output is a side effect.

### Example 2: Modifying a variable

```csharp
int total = 0;

void Add(int value)
{
    total += value;
}

Add(10);
Add(20);

Console.WriteLine(total);
```

**Output:**

```text
30
```

### Example 3: Modifying a collection

```csharp
List<int> numbers = new()
{
    1, 2, 3
};

void AddValue(int value)
{
    numbers.Add(value);
}

AddValue(4);

Console.WriteLine(
    string.Join(", ", numbers)
);
```

**Output:**

```text
1, 2, 3, 4
```

### Example 4: Side effects inside LINQ

```csharp
int counter = 0;

int[] numbers = { 1, 2, 3 };

var query = numbers.Select(x =>
{
    counter++;
    return x * 2;
});

Console.WriteLine(counter);

var result = query.ToList();

Console.WriteLine(counter);
Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
0
3
2, 4, 6
```

The selector executes during enumeration.

### Example 5: Repeated enumeration repeats side effects

```csharp
int counter = 0;

int[] numbers = { 1, 2, 3 };

var query = numbers.Select(x =>
{
    counter++;
    return x * 2;
});

query.ToList();
query.ToList();

Console.WriteLine(counter);
```

**Output:**

```text
6
```

**Key point:** Side effects make behavior depend on more than returned values and can complicate deferred LINQ queries.

## 9. Referential Transparency

An expression is referentially transparent when it can be replaced by its result without changing the program's observable behavior.

Pure functions support referential transparency.

### Example 1: Referentially transparent expression

```csharp
static int Square(int x)
{
    return x * x;
}

int result = Square(5) + Square(5);

Console.WriteLine(result);
```

**Output:**

```text
50
```

The calls can be replaced with their results:

```csharp
int result = 25 + 25;
```

The behavior remains the same.

### Example 2: Pure expression

```csharp
static int Add(int a, int b)
{
    return a + b;
}

int result = Add(10, 20) * 2;

Console.WriteLine(result);
```

**Output:**

```text
60
```

Equivalent expression:

```csharp
int result = 30 * 2;
```

### Example 3: Non-transparent expression

```csharp
int counter = 0;

int Next()
{
    counter++;
    return counter;
}

int result = Next() + Next();

Console.WriteLine(result);
```

**Output:**

```text
3
```

The calls return `1` and `2`, so replacing both with one fixed value would change the result.

**Key point:** Referential transparency makes expressions easier to reason about because they can be replaced by their computed values.

## 10. Determinism

A deterministic function produces the same result whenever it receives the same inputs under the same relevant conditions.

Pure functions are deterministic, but determinism alone does not guarantee purity.

### Example 1: Deterministic calculation

```csharp
static int Multiply(int a, int b)
{
    return a * b;
}

Console.WriteLine(Multiply(4, 5));
Console.WriteLine(Multiply(4, 5));
```

**Output:**

```text
20
20
```

### Example 2: Deterministic string transformation

```csharp
static string Normalize(string value)
{
    return value.Trim().ToLowerInvariant();
}

Console.WriteLine(Normalize(" HELLO "));
Console.WriteLine(Normalize(" HELLO "));
```

**Output:**

```text
hello
hello
```

### Example 3: Nondeterministic function

```csharp
static int GenerateNumber()
{
    return Random.Shared.Next(1, 100);
}

Console.WriteLine(GenerateNumber());
Console.WriteLine(GenerateNumber());
```

**Output:** Varies between executions.

The function depends on random state.

### Example 4: Deterministic but impure function

```csharp
int counter = 0;

int Calculate(int value)
{
    counter++;
    return value * 2;
}

Console.WriteLine(Calculate(5));
Console.WriteLine(Calculate(5));
Console.WriteLine(counter);
```

**Output:**

```text
10
10
2
```

The return value is deterministic, but the function modifies external state.

**Key point:** Determinism concerns predictable results; purity additionally requires the absence of observable side effects.

## 11. Explicit Inputs

Explicit inputs are values passed directly to a function through parameters.

A function should receive the data required for its computation instead of relying unnecessarily on hidden external state.

### Example 1: Hidden input

```csharp
decimal taxRate = 0.10m;

decimal CalculateTotal(decimal price)
{
    return price + price * taxRate;
}

Console.WriteLine(CalculateTotal(100));
```

**Output:**

```text
110.00
```

The calculation depends on the external variable `taxRate`.

### Example 2: Explicit input

```csharp
static decimal CalculateTotal(
    decimal price,
    decimal taxRate
)
{
    return price + price * taxRate;
}

Console.WriteLine(
    CalculateTotal(100, 0.10m)
);
```

**Output:**

```text
110.00
```

Both dependencies are explicit.

### Example 3: Multiple explicit inputs

```csharp
static decimal CalculateSalary(
    decimal baseSalary,
    decimal bonus,
    decimal deduction
)
{
    return baseSalary + bonus - deduction;
}

Console.WriteLine(
    CalculateSalary(30000, 5000, 2000)
);
```

**Output:**

```text
33000
```

### Example 4: Explicit collection input

```csharp
static int CalculateSum(
    IEnumerable<int> numbers
)
{
    return numbers.Sum();
}

int[] values = { 10, 20, 30 };

Console.WriteLine(
    CalculateSum(values)
);
```

**Output:**

```text
60
```

**Key point:** Explicit inputs make a function's dependencies visible and easier to test.

## 12. Explicit Outputs

Explicit outputs are values returned directly from functions.

Functional design generally favors returning results instead of communicating results through mutations to external state.

### Example 1: Mutation-based output

```csharp
int result = 0;

void Calculate(int a, int b)
{
    result = a + b;
}

Calculate(10, 20);

Console.WriteLine(result);
```

**Output:**

```text
30
```

### Example 2: Return-based output

```csharp
static int Calculate(int a, int b)
{
    return a + b;
}

int result = Calculate(10, 20);

Console.WriteLine(result);
```

**Output:**

```text
30
```

### Example 3: Return multiple values using tuples

```csharp
static (int Sum, int Product) Calculate(
    int a,
    int b
)
{
    return (a + b, a * b);
}

var result = Calculate(5, 4);

Console.WriteLine(result.Sum);
Console.WriteLine(result.Product);
```

**Output:**

```text
9
20
```

### Example 4: Return a new collection

```csharp
static int[] GetEvenNumbers(
    IEnumerable<int> numbers
)
{
    return numbers
        .Where(x => x % 2 == 0)
        .ToArray();
}

int[] result = GetEvenNumbers(
    new[] { 1, 2, 3, 4, 5, 6 }
);

Console.WriteLine(
    string.Join(", ", result)
);
```

**Output:**

```text
2, 4, 6
```

**Key point:** Explicit outputs make the results of computations directly available to callers.

## 13. Immutability

Immutability means that a value or object's state does not change after creation.

Functional programming favors immutable data because it reduces unexpected state changes.

### Example 1: Immutable local value

```csharp
const int number = 10;

Console.WriteLine(number);
```

**Output:**

```text
10
```

The constant cannot be reassigned.

### Example 2: Immutable record properties

```csharp
record Employee(
    int Id,
    string Name
);

Employee employee = new(1, "Amit");

Console.WriteLine(employee.Name);
```

**Output:**

```text
Amit
```

The positional properties of this record use `init` accessors.

### Example 3: Create a modified record using `with`

```csharp
record Employee(
    int Id,
    string Name
);

Employee original = new(1, "Amit");

Employee updated = original with
{
    Name = "Amit Kumar"
};

Console.WriteLine(original.Name);
Console.WriteLine(updated.Name);
```

**Output:**

```text
Amit
Amit Kumar
```

The original record remains unchanged.

### Example 4: Immutable collection transformation

```csharp
int[] numbers = { 1, 2, 3 };

int[] updated = numbers
    .Append(4)
    .ToArray();

Console.WriteLine(
    string.Join(", ", numbers)
);

Console.WriteLine(
    string.Join(", ", updated)
);
```

**Output:**

```text
1, 2, 3
1, 2, 3, 4
```

The original array is not modified by this transformation. Arrays themselves remain mutable, however.

### Example 5: Immutable data structure

```csharp
using System.Collections.Immutable;

ImmutableList<int> original =
    ImmutableList.Create(1, 2, 3);

ImmutableList<int> updated =
    original.Add(4);

Console.WriteLine(
    string.Join(", ", original)
);

Console.WriteLine(
    string.Join(", ", updated)
);
```

**Output:**

```text
1, 2, 3
1, 2, 3, 4
```

**Key point:** Immutable transformations create new values rather than changing existing data.

## 14. Function Composition

Function composition combines multiple functions so that the output of one becomes the input of another.

Mathematically:

\[
(f \circ g)(x) = f(g(x))
\]

### Example 1: Compose two functions

```csharp
Func<int, int> doubleValue = x => x * 2;
Func<int, int> addTen = x => x + 10;

Func<int, int> composed =
    x => addTen(doubleValue(x));

Console.WriteLine(composed(5));
```

**Output:**

```text
20
```

Calculation:

```text
5 → Double → 10 → AddTen → 20
```

### Example 2: Compose three functions

```csharp
Func<int, int> addTwo = x => x + 2;
Func<int, int> multiplyThree = x => x * 3;
Func<int, int> square = x => x * x;

Func<int, int> composed =
    x => square(multiplyThree(addTwo(x)));

Console.WriteLine(composed(2));
```

**Output:**

```text
144
```

### Example 3: Generic composition

```csharp
static Func<TInput, TOutput> Compose<TInput, TMiddle, TOutput>(
    Func<TInput, TMiddle> first,
    Func<TMiddle, TOutput> second
)
{
    return input => second(first(input));
}

Func<int, int> doubleValue = x => x * 2;
Func<int, string> format = x => $"Value: {x}";

var composed = Compose(doubleValue, format);

Console.WriteLine(composed(5));
```

**Output:**

```text
Value: 10
```

**Key point:** Function composition creates larger transformations by combining smaller functions.

## 15. Higher-Order Functions

A higher-order function is a function that accepts another function as an argument, returns a function, or both.

C# supports higher-order functions using delegates.

### Example 1: Function accepting another function

```csharp
static int Apply(
    int value,
    Func<int, int> operation
)
{
    return operation(value);
}

Console.WriteLine(
    Apply(5, x => x * x)
);
```

**Output:**

```text
25
```

### Example 2: Function returning another function

```csharp
static Func<int, int> CreateAdder(int amount)
{
    return x => x + amount;
}

var addTen = CreateAdder(10);

Console.WriteLine(addTen(5));
```

**Output:**

```text
15
```

### Example 3: LINQ Where

```csharp
int[] numbers = { 1, 2, 3, 4, 5 };

var result = numbers.Where(
    x => x > 2
);

Console.WriteLine(
    string.Join(", ", result)
);
```

**Output:**

```text
3, 4, 5
```

`Where()` accepts a predicate function.

### Example 4: LINQ Select

```csharp
int[] numbers = { 1, 2, 3 };

var result = numbers.Select(
    x => x * x
);

Console.WriteLine(
    string.Join(", ", result)
);
```

**Output:**

```text
1, 4, 9
```

`Select()` accepts a transformation function.

**Key point:** Higher-order functions allow reusable algorithms to accept or produce behavior.

## 16. Expression-Oriented Design

Expression-oriented design emphasizes computations that produce values.

C# supports this style using expression-bodied members, conditional expressions, switch expressions, and lambdas.

### Example 1: Expression-bodied method

```csharp
static int Square(int x) => x * x;

Console.WriteLine(Square(5));
```

**Output:**

```text
25
```

### Example 2: Conditional expression

```csharp
int number = 10;

string result = number % 2 == 0
    ? "Even"
    : "Odd";

Console.WriteLine(result);
```

**Output:**

```text
Even
```

### Example 3: Switch expression

```csharp
static string GetGrade(int marks) =>
    marks switch
    {
        >= 90 => "A",
        >= 75 => "B",
        >= 50 => "C",
        _ => "F"
    };

Console.WriteLine(GetGrade(85));
```

**Output:**

```text
B
```

### Example 4: Lambda expression

```csharp
Func<int, int> cube = x => x * x * x;

Console.WriteLine(cube(3));
```

**Output:**

```text
27
```

### Example 5: Expression-oriented transformation

```csharp
int[] numbers = { 1, 2, 3, 4, 5 };

var result = numbers.Select(
    x => x % 2 == 0 ? x * 2 : x
);

Console.WriteLine(
    string.Join(", ", result)
);
```

**Output:**

```text
1, 4, 3, 8, 5
```

**Key point:** Expression-oriented design favors constructing results from expressions rather than relying on repeated state mutation.

## 17. Data Transformation Pipelines

A data transformation pipeline passes data through multiple processing stages.

Each stage performs a specific transformation.

### Example 1: Filter, transform, and sort

```csharp
int[] numbers =
{
    5, 2, 8, 1, 4, 6
};

var result = numbers
    .Where(x => x % 2 == 0)
    .Select(x => x * x)
    .OrderBy(x => x);

Console.WriteLine(
    string.Join(", ", result)
);
```

**Output:**

```text
4, 16, 36, 64
```

Pipeline:

```text
Source
  ↓
Where
  ↓
Select
  ↓
OrderBy
  ↓
Result
```

### Example 2: Employee transformation pipeline

```csharp
record Employee(
    string Name,
    string Department,
    decimal Salary
);

Employee[] employees =
{
    new("Amit", "IT", 30000),
    new("Rahul", "HR", 25000),
    new("Priya", "IT", 40000)
};

var result = employees
    .Where(e => e.Department == "IT")
    .Select(e => new
    {
        e.Name,
        AnnualSalary = e.Salary * 12
    })
    .OrderByDescending(e => e.AnnualSalary);

foreach (var employee in result)
{
    Console.WriteLine(
        $"{employee.Name}: {employee.AnnualSalary}"
    );
}
```

**Output:**

```text
Priya: 480000
Amit: 360000
```

### Example 3: Grouping pipeline

```csharp
record Product(
    string Category,
    decimal Price
);

Product[] products =
{
    new("Electronics", 500),
    new("Electronics", 1000),
    new("Furniture", 2000)
};

var result = products
    .GroupBy(p => p.Category)
    .Select(g => new
    {
        Category = g.Key,
        Total = g.Sum(p => p.Price)
    })
    .OrderBy(x => x.Category);

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Category}: {item.Total}"
    );
}
```

**Output:**

```text
Electronics: 1500
Furniture: 2000
```

**Key point:** Transformation pipelines build complex computations from smaller, composable processing stages.

## 18. Functional Core

A functional core contains the application's calculation and business logic expressed primarily through pure functions.

It receives data, applies rules, and returns results without directly performing external operations.

### Example 1: Pure business calculation

```csharp
static decimal CalculateDiscountedPrice(
    decimal price,
    decimal discountPercent
)
{
    return price - price * discountPercent / 100;
}

Console.WriteLine(
    CalculateDiscountedPrice(1000, 10)
);
```

**Output:**

```text
900
```

### Example 2: Functional business rule

```csharp
static bool IsEligible(
    int age,
    decimal income
)
{
    return age >= 18 && income >= 20000;
}

Console.WriteLine(
    IsEligible(25, 30000)
);

Console.WriteLine(
    IsEligible(16, 30000)
);
```

**Output:**

```text
True
False
```

### Example 3: Functional data transformation

```csharp
record Product(
    string Name,
    decimal Price
);

static Product ApplyDiscount(
    Product product,
    decimal discountPercent
)
{
    return product with
    {
        Price = product.Price *
                (1 - discountPercent / 100)
    };
}

Product original = new("Mouse", 1000);

Product discounted = ApplyDiscount(original, 10);

Console.WriteLine(original.Price);
Console.WriteLine(discounted.Price);
```

**Output:**

```text
1000
900.0
```

### Example 4: Functional collection processing

```csharp
static int[] GetSquaresOfEvenNumbers(
    IEnumerable<int> numbers
)
{
    return numbers
        .Where(x => x % 2 == 0)
        .Select(x => x * x)
        .ToArray();
}

int[] result = GetSquaresOfEvenNumbers(
    new[] { 1, 2, 3, 4, 5, 6 }
);

Console.WriteLine(
    string.Join(", ", result)
);
```

**Output:**

```text
4, 16, 36
```

**Key point:** A functional core keeps business rules and transformations independent of external input/output operations.

## 19. Imperative Shell

An imperative shell handles interactions with the outside world.

It commonly performs input/output operations, obtains external data, and invokes the functional core.

### Example 1: Separate calculation from console output

**Functional core:**

```csharp
static int Square(int number)
{
    return number * number;
}
```

**Imperative shell:**

```csharp
int input = 5;

int result = Square(input);

Console.WriteLine(result);
```

**Output:**

```text
25
```

The calculation is pure, while console output is performed outside it.

### Example 2: Separate input from business logic

**Functional core:**

```csharp
static decimal CalculateTotal(
    decimal price,
    int quantity
)
{
    return price * quantity;
}
```

**Imperative shell:**

```csharp
decimal price = 500;
int quantity = 3;

decimal total = CalculateTotal(price, quantity);

Console.WriteLine(total);
```

**Output:**

```text
1500
```

### Example 3: Functional core with record transformation

```csharp
record Employee(
    string Name,
    decimal Salary
);

static Employee IncreaseSalary(
    Employee employee,
    decimal amount
)
{
    return employee with
    {
        Salary = employee.Salary + amount
    };
}
```

**Imperative shell:**

```csharp
Employee employee = new("Amit", 30000);

Employee updated = IncreaseSalary(employee, 5000);

Console.WriteLine(
    $"{updated.Name}: {updated.Salary}"
);
```

**Output:**

```text
Amit: 35000
```

**Key point:** The imperative shell manages external interactions, while the functional core performs calculations and business transformations.

## 20. Functional + Object-Oriented C#

C# supports combining functional programming principles with object-oriented programming.

Object-oriented programming provides classes, objects, encapsulation, and interfaces.

Functional programming contributes pure methods, immutable transformations, higher-order functions, and composition.

### Example 1: Functional methods inside a class

```csharp
class Calculator
{
    public int Add(int a, int b)
    {
        return a + b;
    }

    public int Multiply(int a, int b)
    {
        return a * b;
    }
}

Calculator calculator = new();

Console.WriteLine(calculator.Add(10, 20));
Console.WriteLine(calculator.Multiply(5, 4));
```

**Output:**

```text
30
20
```

The class provides object-oriented organization, while its methods perform pure calculations.

### Example 2: Immutable record with functional transformation

```csharp
record Product(
    int Id,
    string Name,
    decimal Price
);

static Product ApplyDiscount(
    Product product,
    decimal discount
)
{
    return product with
    {
        Price = product.Price - discount
    };
}

Product product = new(1, "Mouse", 500);

Product updated = ApplyDiscount(product, 100);

Console.WriteLine(product.Price);
Console.WriteLine(updated.Price);
```

**Output:**

```text
500
400
```

### Example 3: Functional behavior with an interface

```csharp
interface IPriceCalculator
{
    decimal Calculate(decimal price);
}

class DiscountCalculator : IPriceCalculator
{
    private readonly decimal discountPercent;

    public DiscountCalculator(decimal discountPercent)
    {
        this.discountPercent = discountPercent;
    }

    public decimal Calculate(decimal price)
    {
        return price * (1 - discountPercent / 100);
    }
}
```

```csharp
IPriceCalculator calculator =
    new DiscountCalculator(10);

Console.WriteLine(
    calculator.Calculate(1000)
);
```

**Output:**

```text
900.0
```

The interface provides an object-oriented contract.

The calculation uses a functional transformation of its input and the calculator's configured value.

### Example 4: LINQ inside an object-oriented class

```csharp
class NumberService
{
    public IEnumerable<int> GetEvenSquares(
        IEnumerable<int> numbers
    )
    {
        return numbers
            .Where(x => x % 2 == 0)
            .Select(x => x * x);
    }
}
```

```csharp
NumberService service = new();

var result = service.GetEvenSquares(
    new[] { 1, 2, 3, 4, 5, 6 }
);

Console.WriteLine(
    string.Join(", ", result)
);
```

**Output:**

```text
4, 16, 36
```

**Key point:** C# allows functional transformations and object-oriented abstractions to work together within the same application.
