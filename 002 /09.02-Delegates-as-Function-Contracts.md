# 09.02 — DELEGATES AS FUNCTION CONTRACTS

**Chapter:** 09 — Functional C#  
**Total Syllabus Points:** 20  
**Language:** C#  
**Namespace:** `System`

A delegate is a type-safe reference to a method. Delegates allow C# programs to store functions in variables, pass functions as arguments, return functions from methods, and define contracts for executable behavior.

This section covers all 20 syllabus points in their original order.

---

## 1. Delegate Concept

A **delegate** is a type that represents references to methods with a particular parameter list and return type.

A delegate specifies a method's signature.

### Syntax

```csharp
delegate ReturnType DelegateName(ParameterTypes);
```

### Example 1: Basic delegate

```csharp
delegate int MathOperation(int a, int b);

class Program
{
    static int Add(int a, int b)
    {
        return a + b;
    }

    static void Main()
    {
        MathOperation operation = Add;

        Console.WriteLine(operation(10, 20));
    }
}
```

**Output:**

```text
30
```

**Explanation:**

```csharp
delegate int MathOperation(int a, int b);
```

Defines a delegate accepting two integers and returning an integer.

```csharp
MathOperation operation = Add;
```

Assigns a compatible method to the delegate.

```csharp
operation(10, 20);
```

Invokes the referenced method.

### Example 2: Multiple methods with the same delegate

```csharp
delegate int MathOperation(int a, int b);

class Program
{
    static int Add(int a, int b) => a + b;

    static int Multiply(int a, int b) => a * b;

    static void Main()
    {
        MathOperation operation = Add;

        Console.WriteLine(operation(5, 4));

        operation = Multiply;

        Console.WriteLine(operation(5, 4));
    }
}
```

**Output:**

```text
9
20
```

### Example 3: Delegate with no return value

```csharp
delegate void MessageHandler(string message);

class Program
{
    static void PrintMessage(string message)
    {
        Console.WriteLine(message);
    }

    static void Main()
    {
        MessageHandler handler = PrintMessage;

        handler("Hello C#");
    }
}
```

**Output:**

```text
Hello C#
```

### Delegate characteristics

| Property | Description |
|---|---|
| Type safety | Enforces compatible method signatures |
| Method reference | Stores a reference to executable behavior |
| Parameters | Can accept zero or more parameters |
| Return type | Can return a value or `void` |
| Invocation | Called using delegate invocation syntax |
| Named methods | Supported |
| Anonymous functions | Supported |
| Lambda expressions | Supported |
| Multicast delegates | Supported |

**Key point:** A delegate defines a type-safe contract for methods.

## 2. Func\<TResult>

`Func<TResult>` represents a function that accepts **no parameters** and returns a value of type `TResult`.

### Syntax

```csharp
Func<TResult> function;
```

### Signature

```csharp
TResult Function();
```

### Example 1: Return an integer

```csharp
Func<int> getNumber = () => 100;

Console.WriteLine(getNumber());
```

**Output:**

```text
100
```

### Example 2: Return a string

```csharp
Func<string> getMessage = () => "Hello C#";

Console.WriteLine(getMessage());
```

**Output:**

```text
Hello C#
```

### Example 3: Return a Boolean

```csharp
Func<bool> isAvailable = () => true;

Console.WriteLine(isAvailable());
```

**Output:**

```text
True
```

### Example 4: Named method

```csharp
static int GetValue()
{
    return 500;
}

Func<int> function = GetValue;

Console.WriteLine(function());
```

**Output:**

```text
500
```

### Example 5: Return a calculated value

```csharp
Func<int> calculate = () => 10 * 20;

Console.WriteLine(calculate());
```

**Output:**

```text
200
```

**Key point:** `Func<TResult>` represents a function with zero parameters and one return value.

## 3. Func\<T,TResult>

`Func<T,TResult>` represents a function that accepts **one parameter** of type `T` and returns a value of type `TResult`.

### Syntax

```csharp
Func<T, TResult> function;
```

### Signature

```csharp
TResult Function(T input);
```

### Example 1: Square an integer

```csharp
Func<int, int> square = x => x * x;

Console.WriteLine(square(5));
```

**Output:**

```text
25
```

### Example 2: Convert an integer to a string

```csharp
Func<int, string> format =
    number => $"Number: {number}";

Console.WriteLine(format(10));
```

**Output:**

```text
Number: 10
```

### Example 3: Check whether a number is even

```csharp
Func<int, bool> isEven =
    number => number % 2 == 0;

Console.WriteLine(isEven(10));
Console.WriteLine(isEven(7));
```

**Output:**

```text
True
False
```

### Example 4: Convert a string to uppercase

```csharp
Func<string, string> upper =
    text => text.ToUpperInvariant();

Console.WriteLine(upper("hello"));
```

**Output:**

```text
HELLO
```

### Example 5: Named method

```csharp
static int Double(int number)
{
    return number * 2;
}

Func<int, int> operation = Double;

Console.WriteLine(operation(15));
```

**Output:**

```text
30
```

**Key point:** `Func<T,TResult>` represents a function with one input and one output.

## 4. Func\<T1,T2,TResult>

`Func<T1,T2,TResult>` represents a function that accepts **two parameters** and returns a value.

### Syntax

```csharp

```

### Signature

```csharp

```

### Example 1: Addition

```csharp

    (a, b) => a + b;

```

**Output:**

```text
30
```

```csharp

    (a, b) => a * b;

Console.WriteLine(multiply(5, 6));
```

**Output:**

```text
30
```

### Example 3: Compare two integers

```csharp
Func<int, int, bool> isGreater =
    (a, b) => a > b;

Console.WriteLine(isGreater(10, 5));

```

**Output:**

```text
True
False
```

### Example 4: Combine strings

**Output:**

```text
Hello World
```

**Output:**

```text
900
```

**Key point:** `Func<T1,T2,TResult>` represents a function with two inputs and one output.

## 5. Multi-Parameter Func

`Func` supports multiple input parameters.

The **last generic type argument is always the return type**.

### Syntax

```csharp
Func<T1, T2, T3, TResult>
```

```csharp
Func<T1, T2, T3, T4, TResult>
```

```csharp
Func<T1, T2, T3, T4, T5, TResult>
```

The standard `Func` delegate family supports up to 16 input parameters.

### Example 1: Three input parameters

```csharp
Func<int, int, int, int> sum =
    (a, b, c) => a + b + c;

Console.WriteLine(sum(10, 20, 30));
```

**Output:**

```text
60
```

### Example 2: Four input parameters

```csharp
Func<int, int, int, int, int> multiply =
    (a, b, c, d) => a * b * c * d;

Console.WriteLine(multiply(2, 3, 4, 5));
```

**Output:**

```text
120
```

### Example 3: Different parameter types

```csharp
Func<string, int, decimal, string> employee =
    (name, age, salary) =>
        $"{name}, Age: {age}, Salary: {salary}";

Console.WriteLine(
    employee("Amit", 25, 30000)
);
```

**Output:**

```text
Amit, Age: 25, Salary: 30000
```

### Example 4: Salary calculation

```csharp
Func<decimal, decimal, decimal, decimal> calculate =
    (salary, bonus, deduction) =>
        salary + bonus - deduction;

Console.WriteLine(
    calculate(30000, 5000, 2000)
);
```

**Output:**

```text
33000
```

### Example 5: Multiple inputs with Boolean output

```csharp
Func<int, int, int, bool> isBetween =
    (value, minimum, maximum) =>
        value >= minimum && value <= maximum;

Console.WriteLine(isBetween(15, 10, 20));
Console.WriteLine(isBetween(25, 10, 20));
```

**Output:**

```text
True
False
```

**Key point:** Multi-parameter `Func` delegates support functions with multiple inputs and a single return value.

## 6. Action

`Action` represents a function that accepts **no parameters** and returns **no value**.

Its return type is `void`.

### Syntax

```csharp
Action action;
```

### Signature

```csharp
void Method();
```

### Example 1: Print a message

```csharp
Action greet = () =>
{
    Console.WriteLine("Hello C#");
};

greet();
```

**Output:**

```text
Hello C#
```

### Example 2: Multiple statements

```csharp
Action display = () =>
{
    Console.WriteLine("First");
    Console.WriteLine("Second");
    Console.WriteLine("Third");
};

display();
```

**Output:**

```text
First
Second
Third
```

### Example 3: Named method

```csharp
static void Welcome()
{
    Console.WriteLine("Welcome");
}

Action action = Welcome;

action();
```

**Output:**

```text
Welcome
```

### Example 4: Assign another action

```csharp
Action action = () =>
    Console.WriteLine("Operation A");

action();

action = () =>
    Console.WriteLine("Operation B");

action();
```

**Output:**

```text
Operation A
Operation B
```

**Key point:** `Action` represents parameterless behavior that does not return a value.

## 9. Predicate\<T>

`Predicate<T>` represents a function that accepts one parameter of type `T` and returns a `bool`.

### Syntax

```csharp
Predicate<T> predicate;
```

### Signature

```csharp
bool Method(T value);
```

### Example 1: Check even numbers

```csharp
Predicate<int> isEven =
    number => number % 2 == 0;

Console.WriteLine(isEven(10));
Console.WriteLine(isEven(7));
```

**Output:**

```text
True
False
```

### Example 2: Check positive numbers

```csharp
Predicate<int> isPositive =
    number => number > 0;

Console.WriteLine(isPositive(10));
Console.WriteLine(isPositive(-5));
```

**Output:**

```text
True
False
```

### Example 3: Validate string length

```csharp
Predicate<string> isValid =
    text => text.Length >= 5;

Console.WriteLine(isValid("Hello"));
Console.WriteLine(isValid("Hi"));
```

**Output:**

```text
True
False
```

### Example 4: List.FindAll

```csharp
List<int> numbers = new()
{
    1, 2, 3, 4, 5, 6
};

Predicate<int> isEven =
    number => number % 2 == 0;

List<int> result = numbers.FindAll(isEven);

Console.WriteLine(
    string.Join(", ", result)
);
```

**Output:**

```text
2, 4, 6
```

### Example 5: List.Exists

```csharp
List<int> numbers = new()
{
    10, 20, 30
};

Predicate<int> greaterThan25 =
    number => number > 25;

Console.WriteLine(
    numbers.Exists(greaterThan25)
);
```

**Output:**

```text
True
```

### Predicate vs Func

```csharp
Predicate<int> predicate =
    x => x > 10;
```

```csharp
Func<int, bool> function =
    x => x > 10;
```

Both represent Boolean-returning functions with one input, but they are different delegate types.

For example, LINQ `Where()` expects a `Func<T,bool>` for `IEnumerable<T>`.

**Key point:** `Predicate<T>` represents a Boolean condition over one input.

## 10. Named Methods

A named method is a method declared with an explicit name.

A delegate can reference a named method when the signatures are compatible.

### Example 1: Named method with Func

```csharp
static int Square(int number)
{
    return number * number;
}

Func<int, int> operation = Square;

Console.WriteLine(operation(5));
```

**Output:**

```text
25
```

### Example 2: Named method with Action

```csharp
static void Print(string message)
{
    Console.WriteLine(message);
}

Action<string> action = Print;

action("Hello");
```

**Output:**

```text
Hello
```

### Example 3: Named method with Predicate

```csharp
static bool IsEven(int number)
{
    return number % 2 == 0;
}

Predicate<int> predicate = IsEven;

Console.WriteLine(predicate(8));
```

**Output:**

```text
True
```

### Example 4: Named method in LINQ

```csharp
static bool IsPositive(int number)
{
    return number > 0;
}

int[] numbers = { -2, -1, 0, 1, 2 };

var result = numbers.Where(IsPositive);

Console.WriteLine(
    string.Join(", ", result)
);
```

**Output:**

```text
1, 2
```

**Key point:** Named methods can be supplied wherever a compatible delegate is expected.

## 11. Anonymous Functions

An anonymous function is a function without an explicitly declared method name.

C# supports anonymous functions through anonymous method expressions and lambda expressions.

### Example 1: Anonymous method

```csharp
Func<int, int> square = delegate(int x)
{
    return x * x;
};

Console.WriteLine(square(5));
```

**Output:**

```text
25
```

### Example 2: Anonymous method with two parameters

```csharp
Func<int, int, int> add =
    delegate(int a, int b)
    {
        return a + b;
    };

Console.WriteLine(add(10, 20));
```

**Output:**

```text
30
```

### Example 3: Anonymous Action

```csharp
Action<string> print =
    delegate(string message)
    {
        Console.WriteLine(message);
    };

print("Hello C#");
```

**Output:**

```text
Hello C#
```

### Example 4: Anonymous Predicate

```csharp
Predicate<int> isEven =
    delegate(int number)
    {
        return number % 2 == 0;
    };

Console.WriteLine(isEven(6));
```

**Output:**

```text
True
```

**Key point:** Anonymous functions define executable behavior without requiring a separately named method.

## 12. Lambda Expressions

A lambda expression is a concise syntax for defining an anonymous function.

### Syntax

```csharp
parameters => expression
```

Or:

```csharp
parameters =>
{
    statements;
}
```

### Example 1: Expression lambda

```csharp

Console.WriteLine(square(5));
```

**Output:**

```text
25
```

### Example 2: Multiple parameters

```csharp
Func<int, int, int> add =
    (a, b) => a + b;

Console.WriteLine(add(10, 20));
```

**Output:**

```text
30
```

### Example 3: Statement lambda

```csharp
Func<int, int> calculate = x =>
{
    int square = x * x;
    return square + 10;
};

Console.WriteLine(calculate(5));
```

**Output:**

```text
35
```

### Example 4: Lambda with Action

```csharp
Action<string> greet =
    name => Console.WriteLine($"Hello {name}");

greet("Amit");
```

**Output:**

```text
Hello Amit
```

### Example 5: Lambda with Predicate

```csharp
Predicate<int> isAdult =
    age => age >= 18;

Console.WriteLine(isAdult(20));
Console.WriteLine(isAdult(15));
```

**Output:**

```text
True
False
```

### Example 6: Lambda with LINQ


**Output:**

```text

```

**Key point:** Lambda expressions provide concise anonymous functions compatible with delegate types.

## 13. Passing Functions as Arguments

A function can accept another function through a delegate parameter.

This allows callers to choose the behavior performed by a method.

### Example 1: Pass a transformation

```csharp
static int Apply(
    int value,
    Func<int, int> operation
)
{
    return operation(value);
}

Console.WriteLine(
    Apply(5, x => x * 2)
);

Console.WriteLine(
    Apply(5, x => x * x)
);
```

**Output:**

```text
10
25
```

### Example 2: Pass a condition

```csharp
static bool Check(
    int value,
    Predicate<int> condition
)
{
    return condition(value);
}

Console.WriteLine(
    Check(10, x => x > 5)
);

Console.WriteLine(
    Check(3, x => x > 5)
);
```

**Output:**

```text
True
False
```

### Example 3: Pass an Action

```csharp
static void Execute(
    string message,
    Action<string> handler
)
{
    handler(message);
}

Execute(
    "Hello",
    text => Console.WriteLine(text)
);
```

**Output:**

```text
Hello
```

### Example 4: Pass a function to collection processing

```csharp
static IEnumerable<int> Transform(
    IEnumerable<int> numbers,
    Func<int, int> operation
)
{
    return numbers.Select(operation);
}

int[] numbers = { 1, 2, 3 };

var result = Transform(
    numbers,
    x => x * x
);

Console.WriteLine(
    string.Join(", ", result)
);
```

**Output:**

```text
1, 4, 9
```

**Key point:** Passing functions as arguments makes algorithms configurable without rewriting their internal logic.

A method can return a delegate.

The returned function can later be invoked by the caller.


**Output:**

```text
30
```

### Example 2: Return an addition function

```csharp
static Func<int, int> CreateAdder(int amount)
{
    return number => number + amount;
}

var addTen = CreateAdder(10);

Console.WriteLine(addTen(5));
```

**Output:**

```text
15
```

### Example 3: Return different operations

```csharp

    return name switch
    {
        "square" => x => x * x,
        "double" => x => x * 2,

```

**Output:**

```text
15
```

### Example 4: Return a predicate


**Output:**

```text
True
False
```

**Key point:** Returning delegates allows methods to create configurable functions.

## 16. Storing Functions in Collections

Delegates can be stored in arrays, lists, dictionaries, and other collections.

This allows multiple behaviors to be organized and selected dynamically.

### Example 1: List of functions

```csharp

    x => x * 2,
    x => x * x
};

foreach (var operation in operations)
{
    Console.WriteLine(operation(5));
}
```

**Output:**

```text
15
10
25
```

### Example 2: Array of functions

```csharp
Func<int, int>[] operations =
{
    x => x + 1,
    x => x * 2,
    x => x * x
};

Console.WriteLine(operations[0](5));
Console.WriteLine(operations[1](5));
Console.WriteLine(operations[2](5));
```

**Output:**

```text
6
10
25
```

### Example 3: Dictionary of functions

```csharp
Dictionary<string, Func<int, int, int>> operations =
    new()
    {
        ["add"] = (a, b) => a + b,
        ["subtract"] = (a, b) => a - b,
        ["multiply"] = (a, b) => a * b
    };

Console.WriteLine(operations["add"](10, 5));
Console.WriteLine(operations["subtract"](10, 5));
Console.WriteLine(operations["multiply"](10, 5));
```

**Output:**

```text
15
5
50
```

### Example 4: Collection of predicates

```csharp
List<Predicate<int>> conditions = new()
{
    x => x > 0,
    x => x % 2 == 0,
    x => x < 100
};

int number = 20;

foreach (var condition in conditions)
{
    Console.WriteLine(condition(number));
}
```

**Output:**

```text
True
True
True
```

**Key point:** Collections of delegates allow applications to organize and select different behaviors.

## 17. Function Contracts

A function contract specifies the input parameter types and return type required by a function.

Delegates define these contracts in C#.

### Example 1: Func contract

```csharp
Func<int, int, int> operation =
    (a, b) => a + b;

Console.WriteLine(operation(10, 20));
```

**Output:**

```text
30
```

The contract requires:

```text
Input 1: int
Input 2: int
Output:  int
```

### Example 2: Action contract

```csharp
Action<string> print =
    message => Console.WriteLine(message);

print("Hello");
```

**Output:**

```text
Hello
```

Contract:

```text
Input:  string
Output: void
```

### Example 3: Predicate contract

```csharp
Predicate<int> isValid =
    number => number > 0;

Console.WriteLine(isValid(10));
```

**Output:**

```text
True
```

Contract:

```text
Input:  int
Output: bool
```

### Example 4: Custom delegate contract

```csharp
delegate decimal PriceCalculator(
    decimal price,
    decimal discount
);

class Program
{
    static decimal Calculate(
        decimal price,
        decimal discount
    )
    {
        return price - discount;
    }

    static void Main()
    {
        PriceCalculator calculator = Calculate;

        Console.WriteLine(
            calculator(1000, 100)
        );
    }
}
```

**Output:**

```text
900
```

### Function contract comparison

| Delegate | Input | Output |
|---|---|---|
| `Func<int>` | None | `int` |
| `Func<int,int>` | `int` | `int` |
| `Func<int,int,bool>` | `int`, `int` | `bool` |
| `Action` | None | `void` |
| `Action<string>` | `string` | `void` |
| `Predicate<int>` | `int` | `bool` |
| Custom delegate | Defined by declaration | Defined by declaration |

**Key point:** Delegate types enforce compatible function signatures at compile time.

## 18. Transformation Functions

A transformation function receives an input and produces a transformed output.

`Func<TInput,TOutput>` commonly represents transformation behavior.

### Example 1: Integer transformation

```csharp
Func<int, int> square =
    number => number * number;

Console.WriteLine(square(5));
```

**Output:**

```text
25
```

### Example 2: String transformation

```csharp
Func<string, string> normalize =
    text => text.Trim().ToUpperInvariant();

Console.WriteLine(
    normalize("  hello  ")
);
```

**Output:**

```text
HELLO
```

### Example 3: Object transformation

```csharp
record Employee(
    string Name,
    decimal Salary
);

Func<Employee, decimal> annualSalary =
    employee => employee.Salary * 12;

Employee employee = new("Amit", 30000);

Console.WriteLine(
    annualSalary(employee)
);
```

**Output:**

```text
360000
```

### Example 4: Transformation with LINQ

```csharp
int[] numbers = { 1, 2, 3, 4 };

Func<int, int> doubleValue =
    number => number * 2;

var result = numbers.Select(doubleValue);

Console.WriteLine(
    string.Join(", ", result)
);
```

**Output:**

```text
2, 4, 6, 8
```

### Example 5: Generic transformation method

```csharp
static IEnumerable<TResult> Transform<TSource, TResult>(
    IEnumerable<TSource> source,
    Func<TSource, TResult> transformer
)
{
    return source.Select(transformer);
}

int[] numbers = { 1, 2, 3 };

var result = Transform(
    numbers,
    x => $"Value: {x}"
);

foreach (string value in result)
{
    Console.WriteLine(value);
}
```

**Output:**

```text
Value: 1
Value: 2
Value: 3
```

**Key point:** Transformation functions convert inputs into outputs and can be reused across different data-processing operations.

## 19. Predicate Functions

A predicate function evaluates a condition and returns `true` or `false`.

Predicates are commonly used for filtering, validation, and decision-making.

### Example 1: Even-number predicate

```csharp
Predicate<int> isEven =
    number => number % 2 == 0;

Console.WriteLine(isEven(10));
```

**Output:**

```text
True
```

### Example 2: Age validation

```csharp
Predicate<int> isAdult =
    age => age >= 18;

Console.WriteLine(isAdult(20));
Console.WriteLine(isAdult(15));
```

**Output:**

```text
True
False
```

### Example 3: Predicate with List.FindAll

```csharp
List<int> numbers = new()
{
    1, 2, 3, 4, 5, 6
};

Predicate<int> greaterThanThree =
    number => number > 3;

var result = numbers.FindAll(greaterThanThree);

Console.WriteLine(
    string.Join(", ", result)
);
```

**Output:**

```text
4, 5, 6
```

### Example 4: Predicate with LINQ

```csharp
int[] numbers = { 1, 2, 3, 4, 5 };

Func<int, bool> isOdd =
    number => number % 2 != 0;

var result = numbers.Where(isOdd);

Console.WriteLine(
    string.Join(", ", result)
);
```

**Output:**

```text
1, 3, 5
```

### Example 5: Predicate composition

```csharp
Predicate<int> isPositive =
    x => x > 0;

Predicate<int> isEven =
    x => x % 2 == 0;

Predicate<int> combined =

Console.WriteLine(combined(-2));

```

**Output:**

```text
True
False
False
```

**Key point:** Predicate functions represent reusable Boolean conditions.

## 20. Behavior Injection

Behavior injection means supplying executable behavior to a method instead of hardcoding that behavior inside it.

Delegates make this possible by allowing functions to be passed as parameters.

### Example 1: Inject calculation behavior

```csharp
static int Calculate(
    int a,
    int b,
    Func<int, int, int> operation
)
{
    return operation(a, b);
}

Console.WriteLine(
    Calculate(10, 5, (a, b) => a + b)
);

Console.WriteLine(
    Calculate(10, 5, (a, b) => a * b)
);
```

**Output:**

```text
15
50
```

The same method supports different calculations.

### Example 2: Inject filtering behavior

```csharp
static IEnumerable<int> Filter(
    IEnumerable<int> numbers,
    Func<int, bool> condition
)
{
    return numbers.Where(condition);
}

int[] numbers = { 1, 2, 3, 4, 5, 6 };

var even = Filter(
    numbers,
    x => x % 2 == 0
);

var greaterThanThree = Filter(
    numbers,
    x => x > 3
);

Console.WriteLine(
    string.Join(", ", even)
);

Console.WriteLine(
    string.Join(", ", greaterThanThree)
);
```

**Output:**

```text
2, 4, 6
4, 5, 6
```

### Example 3: Inject transformation behavior

```csharp
static IEnumerable<int> Process(
    IEnumerable<int> numbers,
    Func<int, int> transformer
)
{
    return numbers.Select(transformer);
}

int[] numbers = { 1, 2, 3 };

var doubled = Process(
    numbers,
    x => x * 2
);

var squared = Process(
    numbers,
    x => x * x
);

Console.WriteLine(
    string.Join(", ", doubled)
);

Console.WriteLine(
    string.Join(", ", squared)
);
```

**Output:**

```text
2, 4, 6
1, 4, 9
```

### Example 4: Inject output behavior

```csharp
static void ProcessMessage(
    string message,
    Action<string> handler
)
{
    handler(message);
}

ProcessMessage(
    "Hello",
    message => Console.WriteLine(message)
);

ProcessMessage(
    "Hello",
    message => Console.WriteLine(
        message.ToUpperInvariant()
    )
);
```

**Output:**

```text
Hello
HELLO
```

### Example 5: Inject validation behavior

```csharp
static bool Validate(
    string value,
    Predicate<string> rule
)
{
    return rule(value);
}

bool minimumLength = Validate(
    "Hello",
    text => text.Length >= 5
);

bool notEmpty = Validate(
    "Hello",
    text => !string.IsNullOrWhiteSpace(text)
);

Console.WriteLine(minimumLength);
Console.WriteLine(notEmpty);
```

**Output:**

```text
True
True
```

**Key point:** Behavior injection makes methods reusable and configurable by supplying operations through delegate parameters.
