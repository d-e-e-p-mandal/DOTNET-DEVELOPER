# 07.08 — LOOKUPS WITH ToLookup

**Chapter:** 07 — LINQ Aggregation & Grouping  
**Namespace:** `System.Linq`  
**Total Syllabus Topics:** 13

`ToLookup()` organizes elements into a lookup structure where each key can be associated with multiple values.

Unlike `GroupBy()`, `ToLookup()` immediately processes the source sequence and constructs the lookup.

This section covers all **13 syllabus points in their original order**.

---

## 1. ToLookup

`ToLookup()` converts a sequence into a lookup collection.

Each lookup key can contain multiple elements.

### Syntax

```csharp
source.ToLookup(x => x.Key);
```

### Example 1: Group numbers by parity

```csharp
int[] numbers = { 1, 2, 3, 4, 5, 6 };

var lookup = numbers.ToLookup(
    n => n % 2 == 0 ? "Even" : "Odd"
);

foreach (var group in lookup)
{
    Console.WriteLine(
        $"{group.Key}: {string.Join(", ", group)}"
    );
}
```

**Output:**

```text
Odd: 1, 3, 5
Even: 2, 4, 6
```

### Example 2: Employees by department

```csharp
record Employee(string Name, string Department);

Employee[] employees =
{
    new("Amit", "IT"),
    new("Rahul", "HR"),
    new("Priya", "IT"),
    new("Sneha", "HR")
};

var lookup = employees.ToLookup(e => e.Department);

foreach (var group in lookup)
{
    Console.WriteLine(group.Key);

    foreach (var employee in group)
    {
        Console.WriteLine(employee.Name);
    }
}
```

**Output:**

```text
IT
Amit
Priya
HR
Rahul
Sneha
```

### Example 3: Direct key access

```csharp
int[] numbers = { 1, 2, 3, 4, 5 };

var lookup = numbers.ToLookup(n => n % 2);

foreach (int number in lookup[0])
{
    Console.WriteLine(number);
}
```

**Output:**

```text
2
4
```

**Key point:** `ToLookup()` creates a collection that supports direct access to groups through their keys.

## 2. ILookup<TKey, TElement>

`ToLookup()` returns an object implementing:

```csharp
ILookup<TKey, TElement>
```

Where:

- `TKey` represents the type of the key.
- `TElement` represents the type of each stored element.

### Syntax

```csharp
ILookup<TKey, TElement>
```

### Example 1: Explicit lookup type

```csharp
int[] numbers = { 1, 2, 3, 4 };

ILookup<string, int> lookup = numbers.ToLookup(
    n => n % 2 == 0 ? "Even" : "Odd"
);

Console.WriteLine(lookup.Count);
```

**Output:**

```text
2
```

`Count` represents the number of distinct lookup keys.

### Example 2: String lookup

```csharp
string[] names =
{
    "Amit",
    "Ankit",
    "Rahul"
};

ILookup<char, string> lookup =
    names.ToLookup(name => name[0]);

foreach (string name in lookup['A'])
{
    Console.WriteLine(name);
}
```

**Output:**

```text
Amit
Ankit
```

### Example 3: Lookup members

```csharp
int[] numbers = { 10, 11, 12, 13 };

ILookup<int, int> lookup =
    numbers.ToLookup(n => n % 2);

Console.WriteLine(lookup.Count);
Console.WriteLine(lookup.Contains(0));
Console.WriteLine(lookup.Contains(5));
```

**Output:**

```text
2
True
False
```

### Important members

| Member | Purpose |
|---|---|
| `Count` | Number of distinct keys |
| `Contains(key)` | Checks whether a key exists |
| `lookup[key]` | Retrieves values associated with a key |
| `GetEnumerator()` | Enumerates groups |

**Key point:** `ILookup<TKey, TElement>` represents a read-only, one-to-many mapping.

## 3. Key Selector

The key selector determines which key is assigned to each source element.

### Syntax

```csharp
source.ToLookup(x => x.Property);
```

### Example 1: Department key

```csharp
record Employee(string Name, string Department);

Employee[] employees =
{
    new("Amit", "IT"),
    new("Rahul", "HR"),
    new("Priya", "IT")
};

var lookup = employees.ToLookup(
    employee => employee.Department
);

Console.WriteLine(lookup["IT"].Count());
```

**Output:**

```text
2
```

### Example 2: Calculated key

```csharp
int[] numbers = { 5, 12, 17, 24, 29 };

var lookup = numbers.ToLookup(n => n / 10);

foreach (var group in lookup)
{
    Console.WriteLine(
        $"{group.Key}: {string.Join(", ", group)}"
    );
}
```

**Output:**

```text
0: 5
1: 12, 17
2: 24, 29
```

### Example 3: Character key

```csharp
string[] words =
{
    "Apple",
    "Ant",
    "Banana"
};

var lookup = words.ToLookup(word => word[0]);

Console.WriteLine(
    string.Join(", ", lookup['A'])
);
```

**Output:**

```text
Apple, Ant
```

**Key point:** The key selector determines how source elements are classified.

## 4. Element Selector

An element selector determines which values are stored for each lookup key.

### Syntax

```csharp
source.ToLookup(
    keySelector,
    elementSelector
);
```

### Example 1: Store employee names

```csharp
record Employee(string Name, string Department);

Employee[] employees =
{
    new("Amit", "IT"),
    new("Rahul", "HR"),
    new("Priya", "IT")
};

var lookup = employees.ToLookup(
    e => e.Department,
    e => e.Name
);

Console.WriteLine(
    string.Join(", ", lookup["IT"])
);
```

**Output:**

```text
Amit, Priya
```

### Example 2: Store calculated values

```csharp
int[] numbers = { 1, 2, 3, 4 };

var lookup = numbers.ToLookup(
    n => n % 2 == 0 ? "Even" : "Odd",
    n => n * 10
);

Console.WriteLine(
    string.Join(", ", lookup["Even"])
);
```

**Output:**

```text
20, 40
```

### Example 3: Store anonymous objects

```csharp
record Product(
    string Name,
    string Category,
    decimal Price
);

Product[] products =
{
    new("Mouse", "Electronics", 500m),
    new("Keyboard", "Electronics", 1200m),
    new("Chair", "Furniture", 3000m)
};

var lookup = products.ToLookup(
    p => p.Category,
    p => new
    {
        p.Name,
        p.Price
    }
);

foreach (var product in lookup["Electronics"])
{
    Console.WriteLine(
        $"{product.Name}: {product.Price}"
    );
}
```

**Output:**

```text
Mouse: 500
Keyboard: 1200
```

**Key point:** The key selector chooses the group, while the element selector chooses the stored value.

## 5. Equality Comparer

`ToLookup()` uses equality comparisons to determine whether keys are equivalent.

By default, it uses:

```csharp
EqualityComparer<TKey>.Default
```

A custom equality comparer can be supplied.

### Syntax

```csharp
source.ToLookup(
    keySelector,
    comparer
);
```

### Example 1: Default equality

```csharp
string[] departments =
{
    "IT",
    "it",
    "HR"
};

var lookup = departments.ToLookup(d => d);

Console.WriteLine(lookup.Count);
```

**Output:**

```text
3
```

### Example 2: Case-insensitive equality

```csharp
string[] departments =
{
    "IT",
    "it",
    "HR"
};

var lookup = departments.ToLookup(
    d => d,
    StringComparer.OrdinalIgnoreCase
);

Console.WriteLine(lookup.Count);
```

**Output:**

```text
2
```

### Example 3: Case-insensitive key access

```csharp
string[] names =
{
    "Amit",
    "amit",
    "Rahul"
};

var lookup = names.ToLookup(
    name => name,
    StringComparer.OrdinalIgnoreCase
);

Console.WriteLine(lookup["AMIT"].Count());
```

**Output:**

```text
2
```

### Example 4: Element selector with comparer

```csharp
record Employee(string Name, string Department);

Employee[] employees =
{
    new("Amit", "IT"),
    new("Rahul", "it"),
    new("Priya", "HR")
};

var lookup = employees.ToLookup(
    e => e.Department,
    e => e.Name,
    StringComparer.OrdinalIgnoreCase
);

Console.WriteLine(
    string.Join(", ", lookup["IT"])
);
```

**Output:**

```text
Amit, Rahul
```

**Key point:** A custom comparer changes how lookup keys are matched.

## 6. Immediate Lookup Construction

`ToLookup()` executes immediately.

The source is enumerated when `ToLookup()` is called.

### Example 1: Immediate execution

```csharp
IEnumerable<int> Generate()
{
    Console.WriteLine("Enumeration started");

    yield return 1;
    yield return 2;
    yield return 3;
}

Console.WriteLine("Before ToLookup");

var lookup = Generate().ToLookup(n => n % 2);

Console.WriteLine("After ToLookup");
```

**Output:**

```text
Before ToLookup
Enumeration started
After ToLookup
```

### Example 2: Source modification

```csharp
List<int> numbers = new()
{
    1, 2, 3
};

var lookup = numbers.ToLookup(n => n % 2);

numbers.Add(4);

Console.WriteLine(
    string.Join(", ", lookup[0])
);
```

**Output:**

```text
2
```

The value `4` is not included because the lookup was already constructed.

### Example 3: Repeated access

```csharp
int[] numbers = { 1, 2, 3, 4 };

var lookup = numbers.ToLookup(n => n % 2);

Console.WriteLine(lookup[0].Count());
Console.WriteLine(lookup[0].Count());
```

**Output:**

```text
2
2
```

The source is not regrouped for each lookup access.

**Key point:** `ToLookup()` immediately materializes its grouping structure.

## 7. One Key → Multiple Values

A lookup supports a one-to-many relationship.

One key can be associated with several values.

### Structure

```text
Lookup
   │
   ├── IT
   │    ├── Amit
   │    ├── Priya
   │    └── Sneha
   │
   └── HR
        ├── Rahul
        └── Rohan
```

### Example 1: Multiple employee names

```csharp
record Employee(string Name, string Department);

Employee[] employees =
{
    new("Amit", "IT"),
    new("Priya", "IT"),
    new("Rahul", "HR"),
    new("Sneha", "IT")
};

var lookup = employees.ToLookup(
    e => e.Department,
    e => e.Name
);

foreach (string name in lookup["IT"])
{
    Console.WriteLine(name);
}
```

**Output:**

```text
Amit
Priya
Sneha
```

### Example 2: Numbers by remainder

```csharp
int[] numbers = { 1, 4, 7, 2, 5, 8 };

var lookup = numbers.ToLookup(n => n % 3);

Console.WriteLine(
    string.Join(", ", lookup[1])
);
```

**Output:**

```text
1, 4, 7
```

**Key point:** Each lookup key maps to a sequence of values rather than a single value.

## 8. Missing Keys

A missing key is a key that has no associated values in the lookup.

Use `Contains(key)` to determine whether a key exists.

### Syntax

```csharp
lookup.Contains(key);
```

### Example 1: Existing key

```csharp
int[] numbers = { 1, 2, 3, 4 };

var lookup = numbers.ToLookup(n => n % 2);

Console.WriteLine(lookup.Contains(0));
```

**Output:**

```text
True
```

### Example 2: Missing key

```csharp
int[] numbers = { 1, 2, 3, 4 };

var lookup = numbers.ToLookup(n => n % 2);

Console.WriteLine(lookup.Contains(5));
```

**Output:**

```text
False
```

### Example 3: String key

```csharp
string[] words =
{
    "Apple",
    "Ant",
    "Banana"
};

var lookup = words.ToLookup(w => w[0]);

Console.WriteLine(lookup.Contains('A'));
Console.WriteLine(lookup.Contains('Z'));
```

**Output:**

```text
True
False
```

**Key point:** `Contains(key)` checks whether the lookup contains the specified key.

## 9. Empty Results for Missing Keys

Accessing a missing key through a lookup indexer returns an empty sequence.

It does not throw a missing-key exception.

### Syntax

```csharp
lookup[key];
```

### Example 1: Missing integer key

```csharp
int[] numbers = { 1, 2, 3, 4 };

var lookup = numbers.ToLookup(n => n % 2);

var result = lookup[5];

Console.WriteLine(result.Count());
```

**Output:**

```text
0
```

### Example 2: Missing string key

```csharp
string[] departments =
{
    "IT",
    "HR",
    "IT"
};

var lookup = departments.ToLookup(d => d);

Console.WriteLine(
    lookup["Finance"].Any()
);
```

**Output:**

```text
False
```

### Example 3: Iterate a missing key

```csharp
int[] numbers = { 1, 2, 3 };

var lookup = numbers.ToLookup(n => n % 2);

foreach (int number in lookup[10])
{
    Console.WriteLine(number);
}

Console.WriteLine("Completed");
```

**Output:**

```text
Completed
```

### Comparison

| Operation | Missing Key |
|---|---|
| `lookup.Contains(key)` | `false` |
| `lookup[key]` | Empty sequence |
| `lookup[key].Count()` | `0` |
| `lookup[key].Any()` | `false` |

**Key point:** Missing lookup keys produce empty sequences.

## 10. Duplicate Keys

`ToLookup()` supports multiple source elements with the same key.

Duplicate keys do not cause exceptions.

### Example 1: Repeated department keys

```csharp
record Employee(string Name, string Department);

Employee[] employees =
{
    new("Amit", "IT"),
    new("Priya", "IT"),
    new("Rahul", "HR")
};

var lookup = employees.ToLookup(
    e => e.Department,
    e => e.Name
);

Console.WriteLine(lookup["IT"].Count());
```

**Output:**

```text
2
```

### Example 2: Repeated integer keys

```csharp
int[] numbers = { 10, 20, 30, 40 };

var lookup = numbers.ToLookup(n => n % 20);

foreach (var group in lookup)
{
    Console.WriteLine(
        $"{group.Key}: {string.Join(", ", group)}"
    );
}
```

**Output:**

```text
10: 10, 30
0: 20, 40
```

### Example 3: Duplicate values

```csharp
int[] numbers = { 10, 10, 20, 20 };

var lookup = numbers.ToLookup(n => n);

Console.WriteLine(lookup[10].Count());
Console.WriteLine(lookup[20].Count());
```

**Output:**

```text
2
2
```

Duplicate values are preserved.

**Key point:** `ToLookup()` supports duplicate keys and preserves repeated elements.

## 11. ToLookup vs GroupBy

Both `ToLookup()` and `GroupBy()` organize elements by keys.

Their main difference is execution behavior.

### Example 1: GroupBy

```csharp
List<int> numbers = new()
{
    1, 2, 3
};

var groups = numbers.GroupBy(n => n % 2);

numbers.Add(4);

Console.WriteLine(
    string.Join(", ", groups.First(g => g.Key == 0))
);
```

**Output:**

```text
2, 4
```

`GroupBy()` executes when enumerated.

### Example 2: ToLookup

```csharp
List<int> numbers = new()
{
    1, 2, 3
};

var lookup = numbers.ToLookup(n => n % 2);

numbers.Add(4);

Console.WriteLine(
    string.Join(", ", lookup[0])
);
```

**Output:**

```text
2
```

`ToLookup()` constructs the lookup immediately.

### Example 3: Direct key access

```csharp
int[] numbers = { 1, 2, 3, 4 };

var lookup = numbers.ToLookup(n => n % 2);

Console.WriteLine(
    string.Join(", ", lookup[0])
);
```

**Output:**

```text
2, 4
```

### Comparison

| Feature | GroupBy | ToLookup |
|---|---|---|
| Execution | Deferred | Immediate |
| Return type | `IEnumerable<IGrouping<TKey, TElement>>` | `ILookup<TKey, TElement>` |
| Grouping construction | During enumeration | During method call |
| Direct key indexer | No | Yes |
| `Contains(key)` member | No | Yes |
| Duplicate keys | Supported | Supported |
| Multiple values per key | Supported | Supported |
| Repeated enumeration | Recreates groups | Reuses lookup |
| Reflects later source changes | On subsequent execution | No |

**Key point:** Use `GroupBy()` for deferred grouping queries and `ToLookup()` when an immediately constructed, reusable key-based lookup is required.

## 12. ToLookup vs Dictionary

A lookup and a dictionary both associate keys with values.

However, their structures differ.

### Dictionary structure

```text
Dictionary<TKey, TValue>
        │
        ├── Key1 → Value1
        └── Key2 → Value2
```

### Lookup structure

```text
ILookup<TKey, TElement>
        │
        ├── Key1 → Value1, Value2
        └── Key2 → Value3, Value4
```

### Example 1: Dictionary

```csharp
Dictionary<string, string> employees = new()
{
    ["IT"] = "Amit",
    ["HR"] = "Rahul"
};

Console.WriteLine(employees["IT"]);
```

**Output:**

```text
Amit
```

### Example 2: Lookup

```csharp
record Employee(string Name, string Department);

Employee[] employees =
{
    new("Amit", "IT"),
    new("Priya", "IT"),
    new("Rahul", "HR")
};

var lookup = employees.ToLookup(
    e => e.Department,
    e => e.Name
);

Console.WriteLine(
    string.Join(", ", lookup["IT"])
);
```

**Output:**

```text
Amit, Priya
```

### Example 3: Missing dictionary key

```csharp
Dictionary<string, int> dictionary = new()
{
    ["A"] = 10
};

Console.WriteLine(dictionary.ContainsKey("B"));
```

**Output:**

```text
False
```

Accessing `dictionary["B"]` would throw `KeyNotFoundException`.

### Example 4: Missing lookup key

```csharp
string[] values = { "A", "A", "B" };

var lookup = values.ToLookup(x => x);

Console.WriteLine(lookup["C"].Count());
```

**Output:**

```text
0
```

### Comparison

| Feature | ToLookup | Dictionary |
|---|---|---|
| Interface/type | `ILookup<TKey, TElement>` | `Dictionary<TKey, TValue>` |
| Values per key | Multiple | One value |
| Duplicate keys during construction | Grouped together | `Add()` rejects duplicates |
| Missing key indexer | Empty sequence | Exception |
| Key existence | `Contains(key)` | `ContainsKey(key)` |
| Mutable collection | No | Yes |
| Key-based access | Yes | Yes |
| Typical purpose | One-to-many mapping | One-to-one key mapping |

**Key point:** A lookup naturally represents one-to-many relationships. A dictionary maps each key to one value, although that value can itself be a collection.

## 13. Repeated Lookup Performance

A lookup is useful when values must be retrieved repeatedly using the same keys.

`ToLookup()` builds a key-based structure once, allowing efficient subsequent access.

### Example 1: Repeated key access

```csharp
int[] numbers = Enumerable.Range(1, 100);

var lookup = numbers.ToLookup(n => n % 10);

Console.WriteLine(lookup[0].Count());
Console.WriteLine(lookup[1].Count());
Console.WriteLine(lookup[2].Count());
```

**Output:**

```text
10
10
10
```

### Example 2: Repeated filtering

```csharp
int[] numbers = Enumerable.Range(1, 100);

var first = numbers.Where(n => n % 10 == 0);
var second = numbers.Where(n => n % 10 == 1);

Console.WriteLine(first.Count());
Console.WriteLine(second.Count());
```

**Output:**

```text
10
10
```

Each query independently examines the source.

### Example 3: Lookup construction once

```csharp
int[] numbers = Enumerable.Range(1, 100);

var lookup = numbers.ToLookup(n => n % 10);

for (int key = 0; key < 3; key++)
{
    Console.WriteLine(
        $"Key {key}: {lookup[key].Count()}"
    );
}
```

**Output:**

```text
Key 0: 10
Key 1: 10
Key 2: 10
```

### Example 4: Employees by department

```csharp
record Employee(string Name, string Department);

Employee[] employees =
{
    new("Amit", "IT"),
    new("Priya", "IT"),
    new("Rahul", "HR"),
    new("Sneha", "HR"),
    new("Rohan", "Finance")
};

var lookup = employees.ToLookup(
    e => e.Department,
    e => e.Name
);

string[] departments =
{
    "IT",
    "HR",
    "Finance",
    "Sales"
};

foreach (string department in departments)
{
    Console.WriteLine(
        $"{department}: {string.Join(", ", lookup[department])}"
    );
}
```

**Output:**

```text
IT: Amit, Priya
HR: Rahul, Sneha
Finance: Rohan
Sales:
```

### Performance comparison

Let:

- \(n\) = number of source elements
- \(k\) = number of repeated key lookups
- \(m\) = number of values returned for a key

| Operation | Typical Time Complexity |
|---|---|
| `ToLookup()` construction | \(O(n)\) average |
| Lookup key access | \(O(1)\) average |
| Enumerating values for a key | \(O(m)\) |
| Repeated `Where()` filtering | \(O(kn)\) |
| Build lookup and perform repeated accesses | \(O(n + k)\) average, excluding value enumeration |

The lookup also requires additional memory, generally proportional to the number of stored elements.

**Key point:** `ToLookup()` can improve repeated key-based retrieval by building the grouping structure once.
