# 06.04 — LAMBDA EXPRESSIONS & DELEGATES IN LINQ

**Chapter:** 06 — LINQ Fundamentals  
**Namespace:** `System.Linq`

## 1. Lambda Role in LINQ

Lambda expressions define functions used by LINQ methods for filtering, selecting, sorting, grouping, and other operations.

```csharp
int[] numbers = { 1, 2, 3, 4, 5 };

var result = numbers.Where(n => n > 2);

// Output: 3, 4, 5
```

Here:
- `n` — Lambda parameter
- `=>` — Lambda operator
- `n > 2` — Lambda expression
- `Where()` — LINQ filtering method

---

## 2. Expression Lambda

An expression lambda contains a single expression whose result is returned automatically.

### Syntax

```csharp
x => expression
```

### Example 1: Square

```csharp
Func<int, int> square = x => x * x;

Console.WriteLine(square(5));

// Output: 25
```

### Example 2: Filtering

```csharp
var result = numbers.Where(n => n > 3);

// Output: 4, 5
```

### Example 3: Projection

```csharp
var result = numbers.Select(n => n * 10);

// Output: 10, 20, 30, 40, 50
```

---

## 3. Statement Lambda

A statement lambda contains multiple statements enclosed in `{ }`.

### Syntax

```csharp
x =>
{
    statements;
}
```

### Example 1: Multiple Statements

```csharp
Func<int, int> calculate = x =>
{
    int square = x * x;
    return square + 10;
};

Console.WriteLine(calculate(5));

// Output: 35
```

### Example 2: LINQ Filtering

```csharp
var result = numbers.Where(n =>
{
    bool isEven = n % 2 == 0;
    return isEven;
});

// Output: 2, 4
```

### Example 3: LINQ Projection

```csharp
var result = numbers.Select(n =>
{
    int square = n * n;
    return square;
});

// Output: 1, 4, 9, 16, 25
```

**Note:** Statement lambdas work with LINQ to Objects delegates but cannot be converted directly into expression trees for `IQueryable<T>`.

---

## 4. Multiple Parameters

A lambda can accept two or more parameters.

### Syntax

```csharp
(x, y) => expression
```

### Example 1: Addition

```csharp
Func<int, int, int> add = (x, y) => x + y;

Console.WriteLine(add(10, 20));

// Output: 30
```

### Example 2: Multiplication

```csharp
Func<int, int, int> multiply = (x, y) => x * y;

Console.WriteLine(multiply(5, 4));

// Output: 20
```

### Example 3: LINQ Join

```csharp
int[] a = { 1, 2, 3 };
int[] b = { 2, 3, 4 };

var result = a.Join(
    b,
    x => x,
    y => y,
    (x, y) => new { x, y }
);
```

Here, `(x, y)` represents the two matching elements.

## 5. Explicit Parameter Types

Lambda parameter types can be declared explicitly.

### Example 1: Single Parameter

```csharp
Func<int, int> square = (int x) => x * x;

Console.WriteLine(square(5));

// Output: 25
```

### Example 2: Multiple Parameters

```csharp
Func<int, int, int> add =
    (int x, int y) => x + y;

Console.WriteLine(add(10, 20));

// Output: 30
```

### Example 3: LINQ

```csharp
var result = numbers.Where((int n) => n > 2);

// Output: 3, 4, 5
```

## 6. Type Inference

The compiler can infer lambda parameter types from the expected delegate type.

### Example 1: Implicit Type

```csharp
Func<int, int> square = x => x * x;
```

Here, `x` is inferred as `int`.

### Example 2: Multiple Parameters

```csharp
Func<int, int, int> add = (x, y) => x + y;
```

Both `x` and `y` are inferred as `int`.

### Example 3: LINQ

```csharp
var result = numbers.Where(n => n > 2);
```

Here, `n` is inferred as `int` from the source collection.

## 7. `Func<T, TResult>`

`Func<T, TResult>` represents a function accepting one input and returning one result.

### Syntax

```csharp
Func<T, TResult>
```

- `T` — Input type
- `TResult` — Return type

### Example 1: Square

```csharp
Func<int, int> square = n => n * n;

Console.WriteLine(square(4));

// Output: 16
```

### Example 2: Convert to String

```csharp
Func<int, string> convert = n => n.ToString();

Console.WriteLine(convert(100));

// Output: 100
```

### Example 3: LINQ Select

```csharp
Func<int, int> doubleNumber = n => n * 2;

var result = numbers.Select(doubleNumber);

// Output: 2, 4, 6, 8, 10
```

---

## 8. `Func<T, bool>`

`Func<T, bool>` represents a function accepting one input and returning a Boolean result.

### Syntax

```csharp
Func<T, bool>
```

### Example 1: Even Number

```csharp

```

### Example 2: Greater Than

```csharp
Func<int, bool> isGreater = n => n > 3;

```

### Example 3: LINQ Where


## 9. `Func<T, int, TResult>`

`Func<T, int, TResult>` represents a function accepting an element and an integer parameter, commonly its index.

### Syntax

```csharp
Func<T, int, TResult>
```

### Example 1: Element and Index

```csharp
Func<string, int, string> format =
    (name, index) => $"{index}: {name}";

Console.WriteLine(format("Amit", 0));

// Output: 0: Amit
```

### Example 2: Indexed Select

```csharp
string[] names = { "Amit", "Rahul", "Priya" };

var result = names.Select(
    (name, index) => $"{index}: {name}"
);

// Output:
// 0: Amit
// 1: Rahul
// 2: Priya
```

### Example 3: Indexed Where

```csharp
var result = numbers.Where(
    (n, index) => index % 2 == 0
);

// Output: 1, 3, 5
```

### Example 1: Even Numbers

```csharp
// Output: 2, 4
```

### Example 2: Greater Than

```csharp
var result = numbers.Where(n => n > 3);

```

### Example 3: Named Predicate

```csharp
bool IsEven(int n)

    return n % 2 == 0;

```

## 11. Selectors

A selector function extracts or transforms a value from each element.

### Example 1: Square

```csharp
var result = numbers.Select(n => n * n);

// Output: 1, 4, 9, 16, 25
```

### Example 2: String Conversion

```csharp
var result = numbers.Select(n => n.ToString());

// Output: "1", "2", "3", "4", "5"
```

### Example 3: Object Property

```csharp
string[] names = { "Amit", "Rahul", "Priya" };

var result = names.Select(name => name.Length);

// Output: 4, 5, 5
```

---

## 12. Key Selectors

A key selector extracts the value used for sorting, grouping, or joining.

### Example 1: OrderBy

```csharp
string[] names = { "Rahul", "Amit", "Priya" };

var result = names.OrderBy(name => name.Length);

// Output: Amit, Rahul, Priya
```

### Example 2: GroupBy

```csharp
var result = numbers.GroupBy(n => n % 2);
```

Here, `n % 2` is the grouping key.

### Example 3: OrderByDescending

```csharp
var result = numbers.OrderByDescending(n => n);

// Output: 5, 4, 3, 2, 1
```

---

## 13. Element Selectors

An element selector determines which value is stored in each group or result.

### Example 1: GroupBy

```csharp
string[] names = { "Amit", "Rahul", "Priya" };

var result = names.GroupBy(
    name => name.Length,
    name => name.ToUpper()
);
```

Here:

- `name => name.Length` — Key selector
- `name => name.ToUpper()` — Element selector

### Example 2: Grouping Numbers

```csharp
var result = numbers.GroupBy(
    n => n % 2,
    n => n * n
);
```

Each group contains squared values.

## 14. Collection Selectors

A collection selector returns a sequence for each source element.

### Example 1: Flatten Nested Arrays

```csharp
int[][] matrix =
{
    new[] { 1, 2 },
    new[] { 3, 4 }
};

var result = matrix.SelectMany(row => row);

// Output: 1, 2, 3, 4
```

### Example 2: Flatten Words

```csharp
string[] words = { "Hi", "Cat" };

var result = words.SelectMany(word => word);

// Output: H, i, C, a, t
```

### Example 3: Multiple Collections

```csharp
int[][] groups =
{
    new[] { 10, 20 },
    new[] { 30, 40 }
};

var result = groups.SelectMany(group => group);

// Output: 10, 20, 30, 40
```

---

## 15. Result Selectors

A result selector determines how multiple values are combined into the final result.

### Example 1: SelectMany

```csharp
int[] a = { 1, 2 };
int[] b = { 10, 20 };

var result = a.SelectMany(
    x => b,
    (x, y) => x + y
);

// Output: 11, 21, 12, 22
```

### Example 2: Join

```csharp
int[] a = { 1, 2, 3 };
int[] b = { 2, 3, 4 };

var result = a.Join(
    b,
    x => x,
    y => y,
    (x, y) => new { x, y }
);
```

### Example 3: Zip

```csharp
int[] a = { 1, 2, 3 };
int[] b = { 10, 20, 30 };

var result = a.Zip(
    b,
    (x, y) => x + y
);

// Output: 11, 22, 33
```

## 16. Accumulator Functions

An accumulator function combines the current accumulated value with the next element.

### Example 1: Sum Using Aggregate

```csharp

Console.WriteLine(result);

// Output: 15
```

### Example 2: Aggregate with Seed

```csharp
var result = numbers.Aggregate(
    10,
    (total, n) => total + n

Console.WriteLine(result);

// Output: 25
```

### Example 3: Multiplication

```csharp
var result = numbers.Aggregate(
    1,
    (product, n) => product * n
);

Console.WriteLine(result);

// Output: 120
```

## 19. Captured Variables

A lambda can access variables declared outside its body.

### Example 1: Capturing a Variable

```csharp
int limit = 3;

var result = numbers.Where(n => n > limit);

// Output: 4, 5
```

Here, `limit` is a captured variable.

### Example 2: Capturing a String

```csharp
string prefix = "A";

string[] names = { "Amit", "Rahul", "Arjun" };

var result = names.Where(
    name => name.StartsWith(prefix)
);

// Output: Amit, Arjun
```

### Example 3: Capturing a Multiplier

```csharp
int multiplier = 10;

var result = numbers.Select(
    n => n * multiplier
);

// Output: 10, 20, 30, 40, 50
```

## 20. Closures

A closure is a function that retains access to captured variables from its surrounding scope.

### Example 1: Basic Closure

```csharp
Func<int, int> CreateMultiplier(int multiplier)
{
    return n => n * multiplier;
}

var multiplyBy10 = CreateMultiplier(10);

Console.WriteLine(multiplyBy10(5));

// Output: 50
```

### Example 2: Closure with LINQ

```csharp
Func<int, bool> GreaterThan(int limit)
{
    return n => n > limit;
}

var condition = GreaterThan(3);

var result = numbers.Where(condition);

// Output: 4, 5
```

### Example 3: Closure Retaining State

```csharp
Func<int> CreateCounter()
{
    int count = 0;

    return () => ++count;
}

var counter = CreateCounter();

Console.WriteLine(counter()); // 1
Console.WriteLine(counter()); // 2
Console.WriteLine(counter()); // 3
```

## 21. Mutable Captures

A captured variable can change after the lambda is created.

### Example 1: Changing Captured Value

```csharp
int limit = 2;

var result = numbers.Where(n => n > limit);

limit = 4;

Console.WriteLine(string.Join(", ", result));

// Output: 5
```

The query uses the updated value when enumerated.

### Example 2: Changing Multiplier

```csharp
int multiplier = 2;

var result = numbers.Select(n => n * multiplier);

multiplier = 10;

Console.WriteLine(string.Join(", ", result));

// Output: 10, 20, 30, 40, 50
```

### Example 3: Materialization

```csharp
int limit = 2;

var result = numbers
    .Where(n => n > limit)
    .ToList();

limit = 4;

Console.WriteLine(string.Join(", ", result));

// Output: 3, 4, 5
```

`ToList()` executes the query immediately and stores the resulting elements.

## 22. Static Lambdas

A static lambda cannot capture local variables or instance state.

### Syntax

```csharp
static x => expression
```

### Example 1: Static Lambda

```csharp
Func<int, int> square = static n => n * n;

Console.WriteLine(square(5));

// Output: 25
```

### Example 2: Static Lambda in LINQ

```csharp
var result = numbers.Where(
    static n => n % 2 == 0
);

// Output: 2, 4
```

### Example 3: Static Select

```csharp
var result = numbers.Select(
    static n => n * 10
);

// Output: 10, 20, 30, 40, 50
```

### Example 4: Invalid Capture

```csharp
int limit = 3;

// Compilation error
var result = numbers.Where(
    static n => n > limit
);
```

A static lambda cannot capture `limit`.

## 23. Delegate Allocation

Delegate allocation is the creation of a delegate object representing a method or lambda.

### Example 1: Delegate Variable

```csharp
Func<int, bool> condition = n => n > 2;

var result = numbers.Where(condition);
```

### Example 2: Reusing a Delegate

```csharp
Func<int, bool> isEven = n => n % 2 == 0;

var result1 = numbers.Where(isEven);

var result2 = numbers.Where(isEven);
```

Both queries reuse the same delegate instance.

### Example 3: Capturing Lambda

```csharp
int limit = 3;

Func<int, bool> condition = n => n > limit;

var result = numbers.Where(condition);
```

A capturing lambda may require an additional closure object to store captured state.

### Example 4: Non-Capturing Lambda

```csharp
var result = numbers.Where(
    static n => n > 3
);
```

Non-capturing lambdas can often reuse cached delegates, reducing allocations.

**Note:** `static` prevents captures but does not guarantee zero delegate allocations.
