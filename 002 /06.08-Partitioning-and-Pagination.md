# 06.08 — SORTING & ORDERING

**Chapter:** 06 — LINQ Fundamentals  
**Namespace:** `System.Linq`

## 1. OrderBy

`OrderBy()` sorts elements in ascending order using a specified key.

### Syntax

```csharp
source.OrderBy(x => key);
```

### Example 1: Sorting Numbers

```csharp
int[] numbers = { 5, 2, 8, 1, 3 };

var result = numbers.OrderBy(n => n);

// Output: 1, 2, 3, 5, 8
```

### Example 2: Sorting Strings

```csharp
string[] names = { "Rahul", "Amit", "Priya" };

var result = names.OrderBy(name => name);

// Output: Amit, Priya, Rahul
```

### Example 3: Sorting Objects

```csharp
record Student(string Name, int Age, int Marks);

Student[] students =
{
    new("Rahul", 22, 85),
    new("Amit", 20, 90),
    new("Priya", 21, 80)
};

var result = students.OrderBy(s => s.Age);

// Output:
// Amit  20
// Priya 21
// Rahul 22
```

## 2. OrderByDescending

`OrderByDescending()` sorts elements in descending order using a specified key.

### Syntax

```csharp
source.OrderByDescending(x => key);
```

### Example 1: Numbers

```csharp
int[] numbers = { 5, 2, 8, 1, 3 };

var result = numbers.OrderByDescending(n => n);

// Output: 8, 5, 3, 2, 1
```

### Example 2: Strings

```csharp
string[] names = { "Rahul", "Amit", "Priya" };

var result = names.OrderByDescending(name => name);

// Output: Rahul, Priya, Amit
```

### Example 3: Objects

```csharp
var result = students.OrderByDescending(s => s.Marks);

// Output:
// Amit  90
// Rahul 85
// Priya 80
```

## 3. ThenBy

`ThenBy()` applies ascending secondary ordering to an already ordered sequence.

### Syntax

```csharp
source
    .OrderBy(x => primaryKey)
    .ThenBy(x => secondaryKey);
```

### Example 1: Multiple Properties

```csharp
record Student(string Name, int Age);

Student[] students =
{
    new("Rahul", 20),
    new("Amit", 21),
    new("Priya", 20),
    new("Neha", 21)
};

var result = students
    .OrderBy(s => s.Age)
    .ThenBy(s => s.Name);

// Output:
// Priya 20
// Rahul 20
// Amit  21
// Neha  21
```

### Example 2: Number Ordering

```csharp
int[] numbers = { 21, 12, 23, 14, 11 };

var result = numbers
    .OrderBy(n => n / 10)
    .ThenBy(n => n % 10);

// Output: 11, 12, 14, 21, 23
```

---

## 4. ThenByDescending

`ThenByDescending()` applies descending secondary ordering to an already ordered sequence.

### Syntax

```csharp
source
    .OrderBy(x => primaryKey)
    .ThenByDescending(x => secondaryKey);
```

### Example 1: Students

```csharp
record Student(string Name, int Age, int Marks);

Student[] students =
{
    new("Amit", 20, 80),
    new("Rahul", 21, 90),
    new("Priya", 20, 95),
    new("Neha", 21, 85)
};

var result = students
    .OrderBy(s => s.Age)
    .ThenByDescending(s => s.Marks);

// Output:
// Priya 20 95
// Amit  20 80
// Rahul 21 90
// Neha  21 85
```

### Example 2: String Length and Alphabetical Order

```csharp
string[] names = { "Cat", "Dog", "Apple", "Ball" };

var result = names
    .OrderBy(name => name.Length)
    .ThenByDescending(name => name);

// Output: Dog, Cat, Ball, Apple
```

## 5. Reverse

`Reverse()` returns the elements of a sequence in reverse order.

### Syntax

```csharp
source.Reverse();
```

### Example 1: Numbers

```csharp
int[] numbers = { 10, 20, 30, 40 };

var result = numbers.Reverse();

// Output: 40, 30, 20, 10
```

### Example 2: Strings

```csharp
string[] names = { "Amit", "Rahul", "Priya" };

var result = names.Reverse();

// Output: Priya, Rahul, Amit
```

### Example 3: Reverse After Sorting

```csharp
int[] numbers = { 5, 1, 4, 2, 3 };

var result = numbers
    .OrderBy(n => n)
    .Reverse();

// Output: 5, 4, 3, 2, 1
```

**Note:** `Enumerable.Reverse()` returns a reversed sequence; `List<T>.Reverse()` modifies the list itself.

## 6. Primary Sort Key

The primary sort key determines the first level of ordering.

### Example

```csharp
var result = students
    .OrderBy(s => s.Age)
    .ThenBy(s => s.Name);
```

Here:

```text
Primary Key   → Age
Secondary Key → Name
```

### Example: Sorting by Department

```csharp
record Employee(string Name, string Department, int Salary);

Employee[] employees =
{
    new("Amit", "IT", 50000),
    new("Rahul", "HR", 40000),
    new("Priya", "IT", 60000)
};

var result = employees.OrderBy(e => e.Department);

// Output:
// Rahul HR
// Amit  IT
// Priya IT
```

---

## 7. Secondary Sort Key

The secondary sort key orders elements that have equal primary keys.

### Example

```csharp
var result = employees
    .OrderBy(e => e.Department)
    .ThenBy(e => e.Salary);

// Output:
// Rahul HR 40000
// Amit  IT 50000
// Priya IT 60000
```

Here:

```text
Primary Key   → Department
Secondary Key → Salary
```

---

## 8. Multiple Sort Keys

Multiple sort keys arrange elements using three or more ordering levels.

### Syntax

```csharp
source
    .OrderBy(x => key1)
    .ThenBy(x => key2)
    .ThenBy(x => key3);
```

### Example 1: Three Properties

```csharp
record Employee(
    string Name,
    string Department,
    int Age,
    int Salary
);

Employee[] employees =
{
    new("Amit", "IT", 25, 50000),
    new("Rahul", "HR", 30, 45000),
    new("Priya", "IT", 25, 60000),
    new("Neha", "IT", 28, 55000)
};

var result = employees
    .OrderBy(e => e.Department)
    .ThenBy(e => e.Age)
    .ThenByDescending(e => e.Salary);

// Output:
// Rahul HR 30 45000
// Priya IT 25 60000
// Amit  IT 25 50000
// Neha  IT 28 55000
```

### Example 2: Query Syntax

```csharp
var result =
    from e in employees
    orderby e.Department,
            e.Age,
            e.Salary descending
    select e;
```

## 9. IOrderedEnumerable<T>

`IOrderedEnumerable<T>` represents an ordered sequence produced by LINQ to Objects.

### Example 1: OrderBy

```csharp
int[] numbers = { 5, 2, 8, 1, 3 };

IOrderedEnumerable<int> result =
    numbers.OrderBy(n => n);

// Output: 1, 2, 3, 5, 8
```

### Example 2: ThenBy

```csharp
string[] names = { "Cat", "Apple", "Dog", "Ball" };

IOrderedEnumerable<string> result = names
    .OrderBy(name => name.Length)
    .ThenBy(name => name);
```

### Example 3: Explicit Declaration

```csharp
IOrderedEnumerable<Employee> result = employees
    .OrderBy(e => e.Department)
    .ThenByDescending(e => e.Salary);
```

`OrderBy()` and `ThenBy()` return `IOrderedEnumerable<T>` when operating on `IEnumerable<T>` through LINQ to Objects.

## 10. IComparer<T>

`IComparer<T>` defines how two values are compared for ordering.

### Syntax

```csharp
public interface IComparer<T>
{
    int Compare(T? x, T? y);
}
```

### Comparison Result

| Return Value | Meaning |
|---|---|
| Negative | `x` comes before `y` |
| Zero | Both have equal ordering |
| Positive | `x` comes after `y` |

### Example: Custom Number Comparer

```csharp
class DescendingComparer : IComparer<int>
{
    public int Compare(int x, int y)
    {
        return y.CompareTo(x);
    }
}
```

```csharp
int[] numbers = { 5, 2, 8, 1, 3 };

var result = numbers.OrderBy(
    n => n,
    new DescendingComparer()
);

// Output: 8, 5, 3, 2, 1
```

---

## 11. Comparer<T>

`Comparer<T>` provides comparison functionality and supports creating comparers from functions.

### Example 1: Default Comparer

```csharp
int[] numbers = { 5, 2, 8, 1, 3 };

var result = numbers.OrderBy(
    n => n,
    Comparer<int>.Default
);

// Output: 1, 2, 3, 5, 8
```

### Example 2: Comparer.Create

```csharp
var comparer = Comparer<int>.Create(
    (x, y) => y.CompareTo(x)
);

var result = numbers.OrderBy(n => n, comparer);

// Output: 8, 5, 3, 2, 1
```

### Example 3: String Length Comparer

```csharp
var comparer = Comparer<string>.Create(
    (x, y) => x.Length.CompareTo(y.Length)
);

string[] names = { "Rahul", "Amit", "Priya" };

var result = names.OrderBy(n => n, comparer);

// Output: Amit, Rahul, Priya
```

## 12. Custom Comparers

A custom comparer defines application-specific ordering rules.

### Example 1: Sort by Absolute Value

```csharp
int[] numbers = { -10, 3, -2, 8, -5 };

var comparer = Comparer<int>.Create(
    (x, y) => Math.Abs(x).CompareTo(Math.Abs(y))
);

var result = numbers.OrderBy(n => n, comparer);

// Output: -2, 3, -5, 8, -10
```

### Example 2: Sort by Last Character

```csharp
string[] names = { "Amit", "Rahul", "Priya" };

var comparer = Comparer<string>.Create(
    (x, y) => x[^1].CompareTo(y[^1])
);

var result = names.OrderBy(n => n, comparer);

// Output: Priya, Rahul, Amit
```

### Example 3: Sort Employees by Salary

```csharp
var comparer = Comparer<Employee>.Create(
    (x, y) => x.Salary.CompareTo(y.Salary)
);

var result = employees.OrderBy(e => e, comparer);
```

## 13. StringComparer

`StringComparer` provides built-in string comparison rules.

### Common Comparers

| Comparer | Purpose |
|---|---|
| `StringComparer.Ordinal` | Case-sensitive ordinal comparison |
| `StringComparer.OrdinalIgnoreCase` | Case-insensitive ordinal comparison |
| `StringComparer.CurrentCulture` | Current-culture comparison |
| `StringComparer.CurrentCultureIgnoreCase` | Current-culture case-insensitive comparison |
| `StringComparer.InvariantCulture` | Invariant-culture comparison |
| `StringComparer.InvariantCultureIgnoreCase` | Invariant-culture case-insensitive comparison |

### Example 1: Ordinal Ordering

```csharp
string[] names = { "apple", "Banana", "cherry" };

var result = names.OrderBy(
    name => name,
    StringComparer.Ordinal
);

// Output: Banana, apple, cherry
```

### Example 2: Ignore Case

```csharp
var result = names.OrderBy(
    name => name,
    StringComparer.OrdinalIgnoreCase
);

// Output: apple, Banana, cherry
```

## 14. Case-Sensitive Ordering

Case-sensitive ordering treats uppercase and lowercase letters differently.

### Example 1: Ordinal

```csharp
string[] names = { "apple", "Banana", "Apple", "banana" };

var result = names.OrderBy(
    name => name,
    StringComparer.Ordinal
);

// Output: Apple, Banana, apple, banana
```

### Example 2: Descending

```csharp
var result = names.OrderByDescending(
    name => name,
    StringComparer.Ordinal
);

// Output: banana, apple, Banana, Apple
```

---

## 15. Case-Insensitive Ordering

Case-insensitive ordering ignores letter casing when comparing strings.

### Example 1: Ascending

```csharp
string[] names = { "banana", "Apple", "apple", "Banana" };

var result = names.OrderBy(
    name => name,
    StringComparer.OrdinalIgnoreCase
);

// Output: Apple, apple, banana, Banana
```

### Example 2: Descending

```csharp
var result = names.OrderByDescending(
    name => name,
    StringComparer.OrdinalIgnoreCase
);

// Output: banana, Banana, Apple, apple
```

### Example 3: Object Property

```csharp
record Student(string Name);

Student[] students =
{
    new("rahul"),
    new("Amit"),
    new("PRIYA")
};

var result = students.OrderBy(
    s => s.Name,
    StringComparer.OrdinalIgnoreCase
);

// Output: Amit, PRIYA, rahul
```

## 16. Culture-Aware Ordering

Culture-aware ordering compares strings according to a specified language or culture.

### Example 1: Current Culture

```csharp
string[] words = { "apple", "Banana", "cherry" };

var result = words.OrderBy(
    word => word,
    StringComparer.CurrentCulture
);
```

### Example 2: Specific Culture

```csharp
using System.Globalization;

string[] words = { "ä", "z", "a" };

var comparer = StringComparer.Create(
    new CultureInfo("de-DE"),
    ignoreCase: false
);

var result = words.OrderBy(
    word => word,
    comparer
);
```

### Example 3: Invariant Culture

```csharp
var result = words.OrderBy(
    word => word,
    StringComparer.InvariantCulture
);
```

Culture-aware results may vary depending on the culture and globalization implementation.

## 17. Null Ordering

Null ordering determines where null values appear in sorted results.

### Example 1: Default Nullable Number Ordering

```csharp
int?[] numbers = { 5, null, 2, null, 8 };

var result = numbers.OrderBy(n => n);

// Output: null, null, 2, 5, 8
```

### Example 2: Nulls Last

```csharp
var result = numbers
    .OrderBy(n => n is null)
    .ThenBy(n => n);

// Output: 2, 5, 8, null, null
```

### Example 3: Nulls First

```csharp
var result = numbers
    .OrderByDescending(n => n is null)
    .ThenBy(n => n);

// Output: null, null, 2, 5, 8
```

### Example 4: Nullable Strings

```csharp
string?[] names = { "Rahul", null, "Amit" };

var result = names
    .OrderBy(n => n is null)
    .ThenBy(n => n);

// Output: Amit, Rahul, null
```

## 18. Stable Ordering

Stable ordering preserves the original relative order of elements with equal sorting keys.

### Example

```csharp
record Student(string Name, int Marks);

Student[] students =
{
    new("Amit", 90),
    new("Rahul", 80),
    new("Priya", 90),
    new("Neha", 80)
};

var result = students.OrderBy(s => s.Marks);

// Output:
// Rahul 80
// Neha  80
// Amit  90
// Priya 90
```

Here, Rahul remains before Neha, and Amit remains before Priya.

### Example: Stable Descending Ordering

```csharp
var result = students.OrderByDescending(s => s.Marks);

// Output:
// Amit  90
// Priya 90
// Rahul 80
// Neha  80
```

**Note:** LINQ to Objects ordering is stable. Database query providers do not necessarily guarantee the order of rows with equal keys.

## 19. Replacing an Ordering

Calling `OrderBy()` again starts a new primary ordering rather than adding a secondary key.

### Example

```csharp
record Student(string Name, int Age);

Student[] students =
{
    new("Rahul", 20),
    new("Amit", 21),
    new("Priya", 20)
};

var result = students
    .OrderBy(s => s.Age)
    .OrderBy(s => s.Name);

// Output:
// Amit  21
// Priya 20
// Rahul 20
```

The second `OrderBy()` establishes `Name` as the new primary key.

### Example: OrderByDescending Replacement

```csharp
var result = students
    .OrderBy(s => s.Age)
    .OrderByDescending(s => s.Name);

// Output:
// Rahul 20
// Priya 20
// Amit  21
```

## 20. Extending an Ordering

Calling `ThenBy()` or `ThenByDescending()` adds another ordering level without replacing the primary ordering.

### Example 1: ThenBy

```csharp
var result = students
    .OrderBy(s => s.Age)
    .ThenBy(s => s.Name);

// Output:
// Priya 20
// Rahul 20
// Amit  21
```

### Example 2: ThenByDescending

```csharp
var result = students
    .OrderBy(s => s.Age)
    .ThenByDescending(s => s.Name);

// Output:
// Rahul 20
// Priya 20
// Amit  21
```

### Example 3: Multiple Levels

```csharp
var result = employees
    .OrderBy(e => e.Department)
    .ThenBy(e => e.Age)
    .ThenByDescending(e => e.Salary);
```

## 21. OrderBy vs ThenBy

`OrderBy()` starts a new ordering, while `ThenBy()` extends an existing ordering.

| Feature | OrderBy | ThenBy |
|---|---|---|
| Purpose | Primary ordering | Secondary ordering |
| Requires ordered source | No | Yes |
| Sorting direction | Ascending | Ascending |
| Replaces previous ordering | Yes | No |
| Return type | `IOrderedEnumerable<T>` | `IOrderedEnumerable<T>` |

### Example 1: Two OrderBy Calls

```csharp
var result = students
    .OrderBy(s => s.Age)
    .OrderBy(s => s.Name);

// Primary ordering: Name
```

### Example 2: OrderBy with ThenBy

```csharp
var result = students
    .OrderBy(s => s.Age)
    .ThenBy(s => s.Name);

// Primary ordering: Age
// Secondary ordering: Name
```

### Example 3: Descending Secondary Key

```csharp
var result = students
    .OrderBy(s => s.Age)
    .ThenByDescending(s => s.Name);
```

## 22. Reverse vs Descending Sort

`Reverse()` reverses the current element order, while `OrderByDescending()` sorts values using a key.

| Feature | Reverse | OrderByDescending |
|---|---|---|
| Purpose | Reverses sequence order | Sorts by descending key |
| Uses key selector | No | Yes |
| Performs key-based sorting | No | Yes |
| Depends on current order | Yes | No |
| Example | `Reverse()` | `OrderByDescending(n => n)` |

### Example 1: Reverse

```csharp
int[] numbers = { 3, 1, 5, 2, 4 };

var result = numbers.Reverse();

// Output: 4, 2, 5, 1, 3
```

### Example 2: OrderByDescending

```csharp
var result = numbers.OrderByDescending(n => n);

// Output: 5, 4, 3, 2, 1
```

### Example 3: Sort Then Reverse

```csharp
var result = numbers
    .OrderBy(n => n)
    .Reverse();

// Output: 5, 4, 3, 2, 1
```

**Important:** Reversing an ascending sort also reverses the relative order of equal-key elements, whereas stable descending sorting preserves their original relative order.
