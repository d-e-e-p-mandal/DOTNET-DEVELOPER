# 08.02 — INNER JOINS

**Chapter:** 08 — LINQ Joins & Set Operations  
**Namespace:** `System.Linq`  
**Total Syllabus Topics:** 15

An **inner join** combines elements from two sequences when their join keys match.

Only matching records appear in the result. Unmatched records are excluded.

This section covers all **15 syllabus points in their original order**, with C# examples and outputs.

---

## 1. Join

`Join()` performs an inner join between two sequences.

### Syntax

```csharp
outer.Join(
    inner,
    outerKeySelector,
    innerKeySelector,
    resultSelector
);
```

### Example 1: Join employees with departments

```csharp
record Employee(int Id, string Name, int DepartmentId);
record Department(int Id, string Name);

Employee[] employees =
{
    new(1, "Amit", 10),
    new(2, "Rahul", 20),
    new(3, "Priya", 10),
    new(4, "Sneha", 30)
};

Department[] departments =
{
    new(10, "IT"),
    new(20, "HR")
};

var result = employees.Join(
    departments,
    e => e.DepartmentId,
    d => d.Id,
    (e, d) => new
    {
        Employee = e.Name,
        Department = d.Name
    }
);

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Employee}: {item.Department}"
    );
}
```

**Output:**

```text
Amit: IT
Rahul: HR
Priya: IT
```

Sneha is excluded because department `30` does not exist in the department sequence.

### Example 2: Join integer sequences

```csharp
int[] first = { 1, 2, 3, 4 };
int[] second = { 2, 3, 5 };

var result = first.Join(
    second,
    x => x,
    y => y,
    (x, y) => x
);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
2, 3
```

**Key point:** `Join()` returns matching pairs from two sequences.

## 2. Join Method Syntax

Method syntax expresses an inner join using the `Join()` extension method.

### Syntax

```csharp
var result = outer.Join(
    inner,
    outer => outer.Key,
    inner => inner.Key,
    (outer, inner) => new
    {
        Outer = outer,
        Inner = inner
    }
);
```

### Example 1: Students and courses

```csharp
record Student(int Id, string Name, int CourseId);
record Course(int Id, string Name);

Student[] students =
{
    new(1, "Amit", 101),
    new(2, "Rahul", 102),
    new(3, "Priya", 101)
};

Course[] courses =
{
    new(101, "C#"),
    new(102, "Java")
};

var result = students.Join(
    courses,
    s => s.CourseId,
    c => c.Id,
    (s, c) => new
    {
        Student = s.Name,
        Course = c.Name
    }
);

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Student}: {item.Course}"
    );
}
```

**Output:**

```text
Amit: C#
Rahul: Java
Priya: C#
```

### Example 2: Join using calculated keys

```csharp
int[] first = { 11, 22, 33 };
int[] second = { 1, 2, 3 };

var result = first.Join(
    second,
    x => x % 10,
    y => y,
    (x, y) => $"{x}-{y}"
);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
11-1, 22-2, 33-3
```

**Key point:** Method syntax uses lambda expressions to specify the join keys and output.

## 3. join...on...equals Query Syntax

LINQ query syntax supports inner joins using:

```csharp
join ... on ... equals ...
```

### Syntax

```csharp
var result =
    from outer in outerSource
    join inner in innerSource
        on outer.Key equals inner.Key
    select new
    {
        Outer = outer,
        Inner = inner
    };
```

### Example 1: Employees and departments

```csharp
record Employee(string Name, int DepartmentId);
record Department(int Id, string Name);

Employee[] employees =
{
    new("Amit", 10),
    new("Rahul", 20),
    new("Priya", 10)
};

Department[] departments =
{
    new(10, "IT"),
    new(20, "HR")
};

var result =
    from e in employees
    join d in departments
        on e.DepartmentId equals d.Id
    select new
    {
        Employee = e.Name,
        Department = d.Name
    };

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Employee}: {item.Department}"
    );
}
```

**Output:**

```text
Amit: IT
Rahul: HR
Priya: IT
```

### Example 2: Numeric join

```csharp
int[] first = { 1, 2, 3 };
int[] second = { 2, 3, 4 };

var result =
    from x in first
    join y in second
        on x equals y
    select x;

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
2, 3
```

### Important syntax rule

Use `equals`, not `==`, in a query-syntax join condition.

**Correct:**

```csharp
join d in departments
    on e.DepartmentId equals d.Id
```

**Incorrect:**

```csharp
join d in departments
    on e.DepartmentId == d.Id
```

**Key point:** `join...on...equals` is the query-syntax equivalent of an inner join.

## 4. Outer Key Selector

The outer key selector extracts the matching key from each element of the outer sequence.

### Syntax

```csharp
outer.Join(
    inner,
    outerItem => outerItem.Key,
    innerItem => innerItem.Key,
    (outerItem, innerItem) => result
);
```

### Example 1: Employee department ID

```csharp
record Employee(string Name, int DepartmentId);
record Department(int Id, string Name);

Employee[] employees =
{
    new("Amit", 10),
    new("Rahul", 20)
};

Department[] departments =
{
    new(10, "IT"),
    new(20, "HR")
};

var result = employees.Join(
    departments,
    e => e.DepartmentId,
    d => d.Id,
    (e, d) => $"{e.Name}: {d.Name}"
);

foreach (string item in result)
{
    Console.WriteLine(item);
}
```

**Output:**

```text
Amit: IT
Rahul: HR
```

The outer key selector is:

```csharp
e => e.DepartmentId
```

### Example 2: Calculated outer key

```csharp
int[] outer = { 10, 20, 30 };
int[] inner = { 1, 2, 3 };

var result = outer.Join(
    inner,
    x => x / 10,
    y => y,
    (x, y) => $"{x}: {y}"
);

foreach (string item in result)
{
    Console.WriteLine(item);
}
```

**Output:**

```text
10: 1
20: 2
30: 3
```

**Key point:** The outer key selector determines the key extracted from each outer element.

## 5. Inner Key Selector

The inner key selector extracts the matching key from each element of the inner sequence.

### Syntax

```csharp
outer.Join(
    inner,
    x => x.Key,
    y => y.Key,
    (x, y) => result
);
```

### Example 1: Department ID

```csharp
record Employee(string Name, int DepartmentId);
record Department(int Id, string Name);

Employee[] employees =
{
    new("Amit", 10),
    new("Rahul", 20)
};

Department[] departments =
{
    new(10, "IT"),
    new(20, "HR")
};

var result = employees.Join(
    departments,
    e => e.DepartmentId,
    d => d.Id,
    (e, d) => d.Name
);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
IT, HR
```

The inner key selector is:

```csharp
d => d.Id
```

### Example 2: Calculated inner key

```csharp
int[] outer = { 1, 2, 3 };
int[] inner = { 10, 20, 30 };

var result = outer.Join(
    inner,
    x => x,
    y => y / 10,
    (x, y) => $"{x}-{y}"
);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
1-10, 2-20, 3-30
```

**Key point:** Both key selectors must produce matching, compatible key types.

## 6. Result Selector

The result selector constructs the output for each matching pair.

### Syntax

```csharp
(outerItem, innerItem) => result
```

### Example 1: String projection

```csharp
int[] outer = { 1, 2, 3 };
int[] inner = { 2, 3 };

var result = outer.Join(
    inner,
    x => x,
    y => y,
    (x, y) => $"Match: {x}"
);

foreach (string item in result)
{
    Console.WriteLine(item);
}
```

**Output:**

```text
Match: 2
Match: 3
```

### Example 2: Numeric projection

```csharp
int[] outer = { 1, 2, 3 };
int[] inner = { 2, 3 };

var result = outer.Join(
    inner,
    x => x,
    y => y,
    (x, y) => x * y
);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
4, 9
```

### Example 3: Object projection

```csharp
var result = outer.Join(
    inner,
    x => x,
    y => y,
    (x, y) => new
    {
        OuterValue = x,
        InnerValue = y,
        Product = x * y
    }
);

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.OuterValue}, {item.InnerValue}, {item.Product}"
    );
}
```

**Output:**

```text
2, 2, 4
3, 3, 9
```

**Key point:** A result selector can produce strings, numbers, anonymous objects, or custom objects.

## 7. Anonymous Result Projection

Anonymous types allow joined results to be projected without defining a separate class.

### Syntax

```csharp
(outer, inner) => new
{
    Property1 = outer.Value,
    Property2 = inner.Value
}
```

### Example 1: Employee report

```csharp
record Employee(string Name, int DepartmentId);
record Department(int Id, string Name);

Employee[] employees =
{
    new("Amit", 1),
    new("Rahul", 2)
};

Department[] departments =
{
    new(1, "IT"),
    new(2, "HR")
};

var result = employees.Join(
    departments,
    e => e.DepartmentId,
    d => d.Id,
    (e, d) => new
    {
        EmployeeName = e.Name,
        DepartmentName = d.Name
    }
);

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.EmployeeName}: {item.DepartmentName}"
    );
}
```

**Output:**

```text
Amit: IT
Rahul: HR
```

### Example 2: Calculated anonymous result

```csharp
record Product(int Id, string Name);
record Price(int ProductId, decimal Amount);

Product[] products =
{
    new(1, "Mouse"),
    new(2, "Keyboard")
};

Price[] prices =
{
    new(1, 500m),
    new(2, 1200m)
};

var result = products.Join(
    prices,
    p => p.Id,
    price => price.ProductId,
    (p, price) => new
    {
        p.Name,
        Price = price.Amount,
        DiscountedPrice = price.Amount * 0.9m
    }
);

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Name}: {item.Price}, {item.DiscountedPrice}"
    );
}
```

**Output:**

```text
Mouse: 500, 450.0
Keyboard: 1200, 1080.0
```

**Key point:** Anonymous projection is useful when a joined result is needed only within a limited scope.

## 8. DTO Result Projection

A DTO (Data Transfer Object) is a named type used to represent the result of a query.

### Example 1: DTO class

```csharp
class EmployeeDto
{
    public string EmployeeName { get; set; } = "";
    public string DepartmentName { get; set; } = "";
}
```

```csharp
record Employee(string Name, int DepartmentId);
record Department(int Id, string Name);

{
    new("Amit", 10),
    new("Rahul", 20)

        DepartmentName = d.Name
    }
);

foreach (EmployeeDto item in result)
{
    Console.WriteLine(
        $"{item.EmployeeName}: {item.DepartmentName}"
    );
```

**Output:**

```text
Amit: IT
Rahul: HR
```

### Example 2: Record DTO

```csharp
record EmployeeDto(
    string EmployeeName,
    string DepartmentName
);
```

```csharp
var result = employees.Join(
    departments,
    e => e.DepartmentId,
    d => d.Id,
```

### Comparison

| Anonymous Projection | DTO Projection |
|---|---|
| Compiler-generated type | Explicit named type |
| No class declaration required | Class or record declaration required |
| Convenient for local queries | Convenient for reusable results |
| Type generally remains local to its scope | Can be used in method signatures |

**Key point:** DTO projection provides a reusable, strongly typed structure for joined results.

## 9. Composite-Key Join

A composite-key join matches records using multiple key values.

All key components must match.

### Example 1: Employee ID and year

```csharp
record Employee(int Id, string Name, int Year);
record Salary(int EmployeeId, int Year, int Amount);

Employee[] employees =
{
    new(1, "Amit", 2025),
    new(1, "Amit", 2026),
    new(2, "Rahul", 2026)
};

Salary[] salaries =
{
    new(1, 2025, 50000),
    new(1, 2026, 60000),
    new(2, 2026, 45000)
};

var result = employees.Join(
    salaries,
    e => (e.Id, e.Year),
    s => (s.EmployeeId, s.Year),
    (e, s) => new
    {
        e.Name,
        e.Year,
        s.Amount
    }
);

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Name}, {item.Year}: {item.Amount}"
    );
}
```

**Output:**

```text
Amit, 2025: 50000
Amit, 2026: 60000
Rahul, 2026: 45000
```

### Example 2: Product and location

```csharp
record Stock(int ProductId, int LocationId, int Quantity);
record Order(int ProductId, int LocationId, int Required);

Stock[] stocks =
{
    new(1, 10, 100),
    new(1, 20, 50),
    new(2, 10, 75)
};

Order[] orders =
{
    new(1, 10, 5),
    new(2, 10, 10)
};

var result = stocks.Join(
    orders,
    s => (s.ProductId, s.LocationId),
    o => (o.ProductId, o.LocationId),
    (s, o) => new
    {
        s.ProductId,
        s.LocationId,
        s.Quantity,
        o.Required
    }
);

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.ProductId}, {item.LocationId}: " +
        $"{item.Quantity}, {item.Required}"
    );
}
```

**Output:**

```text
1, 10: 100, 5
2, 10: 75, 10
```

**Key point:** Composite-key joins require equality across every component of the key.

## 11. Custom Equality Comparer

A custom equality comparer changes how join keys are matched.

### Syntax

```csharp
outer.Join(
    inner,
    outerKeySelector,
    innerKeySelector,
    resultSelector,
    comparer
);
```

### Example 1: Case-insensitive join

```csharp
string[] employees = { "IT", "HR" };
string[] departments = { "it", "hr" };

var result = employees.Join(
    departments,
    e => e,
    d => d,
    (e, d) => $"{e}: {d}",
    StringComparer.OrdinalIgnoreCase
);

foreach (var item in result)
{
    Console.WriteLine(item);
}
```

**Output:**

```text
IT: it
HR: hr
```

### Example 2: Custom comparer class

```csharp
class FirstLetterComparer : IEqualityComparer<string>
{
    public bool Equals(string? x, string? y)
    {
        if (ReferenceEquals(x, y))
            return true;

        if (string.IsNullOrEmpty(x) ||
            string.IsNullOrEmpty(y))
            return false;

        return char.ToUpperInvariant(x[0]) ==
               char.ToUpperInvariant(y[0]);
    }

    public int GetHashCode(string value)
    {
        return string.IsNullOrEmpty(value)
            ? 0
            : char.ToUpperInvariant(value[0]).GetHashCode();
    }
}
```

```csharp
string[] first = { "Apple", "Banana" };
string[] second = { "Ant", "Berry" };

var result = first.Join(
    second,
    x => x,
    y => y,
    (x, y) => $"{x}: {y}",
    new FirstLetterComparer()
);

foreach (var item in result)
{
    Console.WriteLine(item);
}
```

**Output:**

```text
Apple: Ant
Banana: Berry
```

**Key point:** Custom comparers implement `IEqualityComparer<TKey>` and must provide consistent equality and hash-code behavior.

## 12. Duplicate-Key Multiplication

When both sequences contain duplicate matching keys, the join produces every matching combination.

### Formula

For a particular key:

\[
\text{Matching Pairs}
=
\text{Outer Occurrences}
\times
\text{Inner Occurrences}
\]

### Example 1: Two matches on each side

```csharp
int[] outer = { 1, 1 };
int[] inner = { 1, 1 };

var result = outer.Join(
    inner,
    x => x,
    y => y,
    (x, y) => $"{x}-{y}"
);

foreach (var item in result)
{
    Console.WriteLine(item);
}
```

**Output:**

```text
1-1
1-1
1-1
1-1
```

Total:

\[
2 \times 2 = 4
\]

### Example 2: Three matches and two matches

```csharp
int[] outer = { 5, 5, 5 };
int[] inner = { 5, 5 };

var result = outer.Join(
    inner,
    x => x,
    y => y,
    (x, y) => x
);

Console.WriteLine(result.Count());
```

**Output:**

```text
6
```

Total:

\[
3 \times 2 = 6
\]

### Example 3: Multiple keys

```csharp
int[] outer = { 1, 1, 2 };
int[] inner = { 1, 1, 2, 2, 2 };

var result = outer.Join(
    inner,
    x => x,
    y => y,
    (x, y) => x
);

Console.WriteLine(result.Count());
```

**Output:**

```text
7
```

Calculation:

\[
(2 \times 2) + (1 \times 3) = 7
\]

**Key point:** Duplicate matching keys increase the number of joined results.

## 13. Multiple Joins

Multiple joins combine data from three or more sequences.

### Example 1: Employees, departments, and locations

```csharp
record Employee(string Name, int DepartmentId);
record Department(int Id, string Name, int LocationId);
record Location(int Id, string City);

Employee[] employees =
{
    new("Amit", 10),
    new("Rahul", 20)
};

Department[] departments =
{
    new(10, "IT", 100),
    new(20, "HR", 200)
};

Location[] locations =
{
    new(100, "Kolkata"),
    new(200, "Delhi")
};

var result = employees
    .Join(
        departments,
        e => e.DepartmentId,
        d => d.Id,
        (e, d) => new
        {
            Employee = e.Name,
            Department = d.Name,
            d.LocationId
        }
    )
    .Join(
        locations,
        x => x.LocationId,
        l => l.Id,
        (x, l) => new
        {
            x.Employee,
            x.Department,
            l.City
        }
    );

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Employee}: {item.Department}, {item.City}"
    );
}
```

**Output:**

```text
Amit: IT, Kolkata
Rahul: HR, Delhi
```

### Example 2: Multiple joins using query syntax

```csharp
var result =
    from e in employees
    join d in departments
        on e.DepartmentId equals d.Id
    join l in locations
        on d.LocationId equals l.Id
    select new
    {
        Employee = e.Name,
        Department = d.Name,
        l.City
    };

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Employee}: {item.Department}, {item.City}"
    );
}
```

**Output:**

```text
Amit: IT, Kolkata
Rahul: HR, Delhi
```

**Key point:** Multiple joins connect records across several related sequences.

## 14. Nested Joins

Nested joins use one join query as the source for another join.

### Example 1: Nested method syntax

```csharp
record Student(int Id, string Name, int CourseId);
record Course(int Id, string Name, int TeacherId);
record Teacher(int Id, string Name);

Student[] students =
{
    new(1, "Amit", 101),
    new(2, "Rahul", 102)
};

Course[] courses =
{
    new(101, "C#", 1),
    new(102, "Java", 2)
};

Teacher[] teachers =
{
    new(1, "Mr. Sen"),
    new(2, "Ms. Roy")
};

var courseTeachers = courses.Join(
    teachers,
    c => c.TeacherId,
    t => t.Id,
    (c, t) => new
    {
        CourseId = c.Id,
        CourseName = c.Name,
        TeacherName = t.Name
    }
);

var result = students.Join(
    courseTeachers,
    s => s.CourseId,
    ct => ct.CourseId,
    (s, ct) => new
    {
        Student = s.Name,
        Course = ct.CourseName,
        Teacher = ct.TeacherName
    }
);

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Student}: {item.Course}, {item.Teacher}"
    );
}
```

**Output:**

```text
Amit: C#, Mr. Sen
Rahul: Java, Ms. Roy
```

### Example 2: Nested Join expression

```csharp
int[] first = { 1, 2, 3 };
int[] second = { 2, 3 };
int[] third = { 3 };

var result = first.Join(
    second.Join(
        third,
        y => y,
        z => z,
        (y, z) => y
    ),
    x => x,
    y => y,
    (x, y) => x
);

Console.WriteLine(string.Join(", ", result));
```

**Output:**

```text
3
```

**Key point:** Nested joins allow the result of one join to participate in another join.

## 15. Join Performance

Join performance depends on source sizes, key equality, duplicate matches, and execution environment.

### 15.1 In-memory Join Performance

LINQ to Objects typically builds a hash-based lookup for the inner sequence.

```csharp
int[] outer = Enumerable.Range(1, 1000).ToArray();
int[] inner = Enumerable.Range(500, 1000).ToArray();

var result = outer.Join(
    inner,
    x => x,
    y => y,
    (x, y) => x
);

Console.WriteLine(result.Count());
```

**Output:**

```text
501
```

### 15.2 Time Complexity

Let:

- \(n\) = number of outer elements
- \(m\) = number of inner elements
- \(r\) = number of matching result pairs

Typical average-case time complexity:

\[
O(n+m+r)
\]

This assumes efficient hashing and equality comparisons.

### 15.3 Memory Complexity

The inner-source lookup requires additional memory.

Typical auxiliary memory complexity:

\[
O(m)
\]

This excludes memory used to materialize the output.

### 15.4 Duplicate-Key Performance

```csharp
int[] outer = Enumerable.Repeat(1, 100);
int[] inner = Enumerable.Repeat(1, 100);

var result = outer.Join(
    inner,
    x => x,
    y => y,
    (x, y) => x
);

Console.WriteLine(result.Count());
```

**Output:**

```text
10000
```

Because:

\[
100 \times 100 = 10000
\]

Even with efficient key lookup, duplicate keys can produce large results.

### 15.5 Deferred Execution

`Join()` uses deferred execution in LINQ to Objects.

```csharp
List<int> outer = new() { 1, 2 };
List<int> inner = new() { 2, 3 };

var query = outer.Join(
    inner,
    x => x,
    y => y,
    (x, y) => x
);

outer.Add(3);

Console.WriteLine(string.Join(", ", query));
```

**Output:**

```text
2, 3
```

The join executes when the query is enumerated.

### 15.6 Materialization

```csharp
int[] outer = { 1, 2, 3 };
int[] inner = { 2, 3, 4 };

var result = outer.Join(
    inner,
    x => x,
    y => y,
    (x, y) => x
).ToList();

Console.WriteLine(result.Count);
```

**Output:**

```text
2
```

`ToList()` executes the join and stores the resulting elements.

### 15.7 Performance Comparison

| Operation | Typical Complexity |
|---|---|
| Build inner lookup | \(O(m)\) average |
| Process outer sequence | \(O(n)\) average, excluding result emission |
| Produce matching pairs | \(O(r)\) |
| Complete inner join | \(O(n+m+r)\) average |
| Auxiliary lookup memory | \(O(m)\) |
| Materialize results | Additional \(O(r)\) memory |

**Key point:** Hash-based joins are generally efficient, but duplicate-key multiplication and materialized output size can significantly affect performance.
