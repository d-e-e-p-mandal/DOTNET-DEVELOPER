# 07.07 — GROUPING WITH GroupBy

**Chapter:** 07 — LINQ Aggregation & Grouping  
**Namespace:** `System.Linq`  
**Total Syllabus Topics:** 22

`GroupBy()` organizes elements into groups based on a common key.

Each group contains a key and the elements associated with that key.

This section follows all **22 syllabus points in their original order**.

---

## 1. GroupBy

`GroupBy()` divides a sequence into groups based on a key selector.

### Syntax

```csharp
source.GroupBy(x => x.Property);
```

### Example 1: Group numbers by even and odd

```csharp
int[] numbers = { 1, 2, 3, 4, 5, 6 };

var groups = numbers.GroupBy(
    n => n % 2 == 0 ? "Even" : "Odd"
);

foreach (var group in groups)
{
    Console.WriteLine(group.Key);

    foreach (int number in group)
    {
        Console.WriteLine(number);
    }
}
```

**Output:**

```text
Odd
1
3
5
Even
2
4
6
```

### Example 2: Group students by department

```csharp
record Student(string Name, string Department);

Student[] students =
{
    new("Amit", "IT"),
    new("Rahul", "HR"),
    new("Priya", "IT"),
    new("Sneha", "HR")
};

var groups = students.GroupBy(s => s.Department);

foreach (var group in groups)
{
    Console.WriteLine($"Department: {group.Key}");

    foreach (var student in group)
    {
        Console.WriteLine(student.Name);
    }
}
```

**Output:**

```text
Department: IT
Amit
Priya
Department: HR
Rahul
Sneha
```

### Structure

```text
Source Sequence
      │
      ▼
   GroupBy
      │
      ├── Key: IT
      │     ├── Amit
      │     └── Priya
      │
      └── Key: HR
            ├── Rahul
            └── Sneha
```

**Key point:** Elements with equal keys are placed in the same group.

## 2. IGrouping<TKey, TElement>

Each group returned by `GroupBy()` implements:

```csharp
IGrouping<TKey, TElement>
```

Where:

- `TKey` is the type of the grouping key.
- `TElement` is the type of the elements inside the group.

`IGrouping<TKey, TElement>` implements `IEnumerable<TElement>`.

### Syntax

```csharp
IEnumerable<IGrouping<TKey, TElement>>
```

### Example 1: Explicit grouping type

```csharp
int[] numbers = { 1, 2, 3, 4 };

IEnumerable<IGrouping<string, int>> groups =
    numbers.GroupBy(
        n => n % 2 == 0 ? "Even" : "Odd"
    );

foreach (IGrouping<string, int> group in groups)
{
    Console.WriteLine(group.Key);
}
```

**Output:**

```text
Odd
Even
```

### Example 2: Group element type

```csharp
string[] names =
{
    "Amit",
    "Ankit",
    "Rahul"
};

IEnumerable<IGrouping<char, string>> groups =
    names.GroupBy(name => name[0]);

foreach (var group in groups)
{
    Console.WriteLine(
        $"{group.Key}: {string.Join(", ", group)}"
    );
}
```

**Output:**

```text
A: Amit, Ankit
R: Rahul
```

### Structure

```text
IGrouping<TKey, TElement>
        │
        ├── Key
        │
        └── IEnumerable<TElement>
```

**Key point:** Each `IGrouping<TKey, TElement>` contains one key and the elements associated with it.

### Syntax


### Example 1: Integer key

**Output:**

```text

```

### Example 2: String key

```csharp
string[] words =
{
    "Apple",

var groups = words.GroupBy(w => w[0]);

foreach (var group in groups)
```

```text
A
```

### Example 3: Access key and elements

```csharp
int[] numbers = { 1, 2, 3, 4, 5 };

var groups = numbers.GroupBy(
```

**Key point:** `Key` identifies a group; enumerating the group retrieves its elements.

## 4. Key Selector

A key selector determines the value used to group each element.

### Syntax

```csharp
source.GroupBy(x => x.Property);
```

Its general delegate type is:

```csharp
Func<TSource, TKey>
```

### Example 1: Group by numeric property

```csharp
record Student(string Name, int Age);

Student[] students =
{
    new("Amit", 20),
    new("Rahul", 21),
    new("Priya", 20)
};

var groups = students.GroupBy(s => s.Age);

foreach (var group in groups)
{
    Console.WriteLine(
        $"{group.Key}: {string.Join(", ", group.Select(s => s.Name))}"
    );
}
```

**Output:**

```text
20: Amit, Priya
21: Rahul
```

### Example 2: Group by calculated key

```csharp
int[] numbers = { 5, 12, 17, 24, 29 };

var groups = numbers.GroupBy(n => n / 10);

foreach (var group in groups)
{
    Console.WriteLine(
        $"{group.Key}: {string.Join(", ", group)}"
    );
}
```

**Output:**

```text
0: 5
1: 12, 17
2: 24, 29
```

### Example 3: Explicit key selector

```csharp
Func<int, string> selector =
    n => n % 2 == 0 ? "Even" : "Odd";

int[] numbers = { 1, 2, 3, 4 };

var groups = numbers.GroupBy(selector);
```

**Key point:** The key selector defines which elements belong together.

## 5. Element Selector

An element selector determines what value is stored inside each group.

### Syntax

```csharp
source.GroupBy(
    keySelector,
    elementSelector
);
```

### Example 1: Group students but select names

```csharp
record Student(string Name, string Department);

Student[] students =
{
    new("Amit", "IT"),
    new("Rahul", "HR"),
    new("Priya", "IT")
};

var groups = students.GroupBy(
    s => s.Department,
    s => s.Name
);

foreach (var group in groups)
{
    Console.WriteLine(
        $"{group.Key}: {string.Join(", ", group)}"
    );
}
```

**Output:**

```text
IT: Amit, Priya
HR: Rahul
```

### Example 2: Select calculated values

```csharp
int[] numbers = { 1, 2, 3, 4 };

var groups = numbers.GroupBy(
    n => n % 2 == 0 ? "Even" : "Odd",
    n => n * 10
);

foreach (var group in groups)
{
    Console.WriteLine(
        $"{group.Key}: {string.Join(", ", group)}"
    );
}
```

**Output:**

```text
Odd: 10, 30
Even: 20, 40
```

### Example 3: Select anonymous objects

```csharp
record Product(string Name, string Category, decimal Price);

Product[] products =
{
    new("Mouse", "Electronics", 500m),
    new("Keyboard", "Electronics", 1200m),
    new("Chair", "Furniture", 3000m)
};

var groups = products.GroupBy(
    p => p.Category,
    p => new
    {
        p.Name,
        p.Price
    }
);

foreach (var group in groups)
{
    Console.WriteLine(group.Key);

    foreach (var product in group)
    {
        Console.WriteLine(
            $"{product.Name}: {product.Price}"
        );
    }
}
```

**Output:**

```text
Electronics
Mouse: 500
Keyboard: 1200
Furniture
Chair: 3000
```

**Key point:** The key selector determines the group; the element selector determines the contents of that group.

## 6. Result Selector

A result selector transforms each completed group into a custom result.

### Syntax

```csharp
source.GroupBy(
    keySelector,
    resultSelector
);
```

The result selector receives the key and the elements associated with that key.

### Example 1: Group count

```csharp
string[] names =
{
    "Amit",
    "Ankit",
    "Rahul",
    "Rohan"
};

var result = names.GroupBy(
    name => name[0],
    (key, elements) => new
    {
        Letter = key,
        Count = elements.Count()
    }
);

foreach (var item in result)
{
    Console.WriteLine($"{item.Letter}: {item.Count}");
}
```

**Output:**

```text
A: 2
R: 2
```

### Example 2: Group sum

```csharp
record Sale(string Category, int Amount);

Sale[] sales =
{
    new("A", 100),
    new("B", 200),
    new("A", 300)
};

var result = sales.GroupBy(
    s => s.Category,
    (key, elements) => new
    {
        Category = key,
        Total = elements.Sum(s => s.Amount)
    }
);

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Category}: {item.Total}"
    );
}
```

**Output:**

```text
A: 400
B: 200
```

### Example 3: Element selector and result selector

```csharp
int[] numbers = { 1, 2, 3, 4 };

var result = numbers.GroupBy(
    n => n % 2 == 0 ? "Even" : "Odd",
    n => n * 10,
    (key, elements) => new
    {
        Key = key,
        Total = elements.Sum()
    }
);

foreach (var item in result)
{
    Console.WriteLine($"{item.Key}: {item.Total}");
}
```

**Output:**

```text
Odd: 40
Even: 60
```

**Key point:** A result selector produces one custom result per group.

## 7. Equality Comparer

`GroupBy()` uses equality to determine whether two keys belong to the same group.

By default, it uses:

```csharp
EqualityComparer<TKey>.Default
```

A custom `IEqualityComparer<TKey>` can change the grouping behavior.

### Syntax

```csharp
source.GroupBy(
    keySelector,
    comparer
);
```

### Example 1: Default string equality

```csharp
string[] words =
{
    "Apple",
    "apple",
    "Banana"
};

var groups = words.GroupBy(w => w);

foreach (var group in groups)
{
    Console.WriteLine(
        $"{group.Key}: {group.Count()}"
    );
}
```

**Output:**

```text
Apple: 1
apple: 1
Banana: 1
```

### Example 2: Case-insensitive equality

```csharp
string[] words =
{
    "Apple",
    "apple",
    "Banana"
};

var groups = words.GroupBy(
    w => w,
    StringComparer.OrdinalIgnoreCase
);

foreach (var group in groups)
{
    Console.WriteLine(
        $"{group.Key}: {group.Count()}"
    );
}
```

**Output:**

```text
Apple: 2
Banana: 1
```

### Example 3: Case-insensitive department grouping

```csharp
record Employee(string Name, string Department);

Employee[] employees =
{
    new("Amit", "IT"),
    new("Rahul", "it"),
    new("Priya", "HR")
};

var groups = employees.GroupBy(
    e => e.Department,
    StringComparer.OrdinalIgnoreCase
);

foreach (var group in groups)
{
    Console.WriteLine(
        $"{group.Key}: {group.Count()}"
    );
}
```

**Output:**

```text
IT: 2
HR: 1
```

**Key point:** The equality comparer determines which keys are considered equivalent.

## 9. Grouping by Multiple Properties

Grouping by multiple properties uses a composite key.

A composite key contains two or more values.

### Example 1: Department and city

```csharp
record Employee(
    string Name,
    string Department,
    string City
);

Employee[] employees =
{
    new("Amit", "IT", "Kolkata"),
    new("Rahul", "IT", "Delhi"),
    new("Priya", "IT", "Kolkata"),
    new("Sneha", "HR", "Delhi")
};

var groups = employees.GroupBy(
    e => new { e.Department, e.City }
);

foreach (var group in groups)
{
    Console.WriteLine(
        $"{group.Key.Department}, {group.Key.City}: {group.Count()}"
    );
}
```

**Output:**

```text
IT, Kolkata: 2
IT, Delhi: 1
HR, Delhi: 1
```

### Example 2: Category and year

```csharp
record Sale(string Category, int Year, int Amount);

Sale[] sales =
{
    new("A", 2025, 100),
    new("A", 2026, 200),
    new("A", 2025, 300),
    new("B", 2026, 400)
};

var groups = sales.GroupBy(
    s => new { s.Category, s.Year }
);

foreach (var group in groups)
{
    Console.WriteLine(
        $"{group.Key.Category}, {group.Key.Year}: {group.Sum(s => s.Amount)}"
    );
}
```

**Output:**

```text
A, 2025: 400
A, 2026: 200
B, 2026: 400
```

**Key point:** Elements belong to the same composite-key group when all key components compare equal.

## 13. Custom Key Equality

Custom key equality allows grouping according to application-specific equality rules.

### Example 1: Case-insensitive grouping

```csharp
string[] departments =
{
    "IT",
    "it",
    "HR",
    "hr"
};

var groups = departments.GroupBy(
    d => d,
    StringComparer.OrdinalIgnoreCase
);

foreach (var group in groups)
{
    Console.WriteLine(
        $"{group.Key}: {group.Count()}"
    );
}
```

**Output:**

```text
IT: 2
HR: 2
```

### Example 2: Custom comparer class

```csharp
class FirstLetterComparer : IEqualityComparer<string>
{
    public bool Equals(string? x, string? y)
    {
        if (ReferenceEquals(x, y))
            return true;

        if (string.IsNullOrEmpty(x) ||
            string.IsNullOrEmpty(y))
            return false;

        return char.ToUpperInvariant(x[0]) ==
               char.ToUpperInvariant(y[0]);
    }

    public int GetHashCode(string value)
    {
        return string.IsNullOrEmpty(value)
            ? 0
            : char.ToUpperInvariant(value[0]).GetHashCode();
    }
}
```

```csharp
string[] names =
{
    "Amit",
    "Ankit",
    "Rahul",
    "Rohan"
};

var groups = names.GroupBy(
    name => name,
    new FirstLetterComparer()
);

foreach (var group in groups)
{
    Console.WriteLine(
        $"{group.Key}: {group.Count()}"
    );
}
```

**Output:**

```text
Amit: 2
Rahul: 2
```

### Important equality requirement

If two keys are considered equal:

```csharp
comparer.Equals(x, y) == true
```

Their hash codes must also be equal:

```csharp
comparer.GetHashCode(x) ==
comparer.GetHashCode(y)
```

**Key point:** Custom grouping equality is defined through `IEqualityComparer<TKey>`.

## 14. Nested Grouping

Nested grouping creates groups inside other groups.

### Example 1: Department, then city

```csharp
record Employee(
    string Name,
    string Department,
    string City
);

Employee[] employees =
{
    new("Amit", "IT", "Kolkata"),
    new("Rahul", "IT", "Delhi"),
    new("Priya", "IT", "Kolkata"),
    new("Sneha", "HR", "Delhi")
};

var groups = employees
    .GroupBy(e => e.Department)
    .Select(department => new
    {
        Department = department.Key,
        Cities = department.GroupBy(e => e.City)
    });

foreach (var department in groups)
{
    Console.WriteLine(department.Department);

    foreach (var city in department.Cities)
    {
        Console.WriteLine($"  {city.Key}");

        foreach (var employee in city)
        {
            Console.WriteLine($"    {employee.Name}");
        }
    }
}
```

**Output:**

```text
IT
  Kolkata
    Amit
    Priya
  Delhi
    Rahul
HR
  Delhi
    Sneha
```

### Example 2: Year, then month

```csharp
record Sale(int Year, int Month, int Amount);

Sale[] sales =
{
    new(2025, 1, 100),
    new(2025, 2, 200),
    new(2025, 1, 300),
    new(2026, 1, 400)
};

var groups = sales
    .GroupBy(s => s.Year)
    .Select(year => new
    {
        Year = year.Key,
        Months = year.GroupBy(s => s.Month)
    });

foreach (var year in groups)
{
    Console.WriteLine(year.Year);

    foreach (var month in year.Months)
    {
        Console.WriteLine(
            $"  Month {month.Key}: {month.Sum(s => s.Amount)}"
        );
    }
}
```

**Output:**

```text
2025
  Month 1: 400
  Month 2: 200
2026
  Month 1: 400
```

**Key point:** Nested grouping organizes data into multiple hierarchical levels.

## 15. Group Ordering

`GroupBy()` does not automatically sort groups by their keys.

Use `OrderBy()` or `OrderByDescending()` to order groups.

### Example 1: Ascending group keys

```csharp
int[] numbers = { 31, 11, 21, 12, 22 };

var groups = numbers
    .GroupBy(n => n / 10)
    .OrderBy(g => g.Key);

foreach (var group in groups)
{
    Console.WriteLine(group.Key);
}
```

**Output:**

```text
1
2
3
```

### Example 2: Descending group keys

```csharp
var groups = numbers
    .GroupBy(n => n / 10)
    .OrderByDescending(g => g.Key);

foreach (var group in groups)
{
    Console.WriteLine(group.Key);
}
```

**Output:**

```text
3
2
1
```

### Example 3: Order groups by element count

```csharp
string[] words =
{
    "Apple",
    "Ant",
    "Banana",
    "Avocado",
    "Berry"
};

var groups = words
    .GroupBy(w => w[0])
    .OrderByDescending(g => g.Count());

foreach (var group in groups)
{
    Console.WriteLine(
        $"{group.Key}: {group.Count()}"
    );
}
```

**Output:**

```text
A: 3
B: 2
```

**Key point:** Ordering groups is a separate operation from grouping.

## 16. Element Ordering within Groups

Elements inside groups can be ordered independently of the groups themselves.

### Example 1: Ascending elements


## 22. Deferred Execution

`GroupBy()` uses deferred execution.

Creating the query does not immediately enumerate the source.

### Example 1: Query creation

```csharp
List<int> numbers = new()
{
    1, 2, 3
};

var groups = numbers.GroupBy(
    n => n % 2 == 0 ? "Even" : "Odd"
);

numbers.Add(4);

foreach (var group in groups)
{
    Console.WriteLine(
        $"{group.Key}: {string.Join(", ", group)}"
    );
}
```

**Output:**

```text
Odd: 1, 3
Even: 2, 4
```

The element `4` is included because the source is enumerated after it is added.

### Example 2: Observe execution

```csharp
IEnumerable<int> Generate()
{
    Console.WriteLine("Enumeration started");

    yield return 1;
    yield return 2;
    yield return 3;
}

var groups = Generate().GroupBy(n => n % 2);

Console.WriteLine("Query created");

foreach (var group in groups)
{
    Console.WriteLine(group.Key);
}
```

**Output:**

```text
Query created
Enumeration started
1
0
```

### Example 3: Repeated enumeration

```csharp
int[] numbers = { 1, 2, 3, 4 };

var groups = numbers.GroupBy(n => n % 2);

foreach (var group in groups)
{
    Console.WriteLine(group.Key);
}

foreach (var group in groups)
{
    Console.WriteLine(group.Key);
}
```

**Output:**

```text
1
0
1
0
```

The grouping query is executed again for the second enumeration.

**Key point:** `GroupBy()` defers processing until its result is enumerated.

## 23. Buffering Behavior

`GroupBy()` buffers source elements when producing groups in LINQ to Objects.

When enumeration begins, it consumes the source and builds an internal grouping structure before yielding the first group.

### Example 1: Observe source enumeration

```csharp
IEnumerable<int> Generate()
{
    for (int i = 1; i <= 4; i++)
    {
        Console.WriteLine($"Generating {i}");
        yield return i;
    }
}

var groups = Generate().GroupBy(n => n % 2);

foreach (var group in groups)
{
    Console.WriteLine($"Group: {group.Key}");
}
```

**Output:**

```text
Generating 1
Generating 2
Generating 3
Generating 4
Group: 1
Group: 0
```

All source elements are generated before the first group is displayed.

### Example 2: Buffering with an element selector

```csharp
int[] numbers = { 1, 2, 3, 4 };

var groups = numbers.GroupBy(
    n => n % 2,
    n =>
    {
        Console.WriteLine($"Processing {n}");
        return n * 10;
    }
);

foreach (var group in groups)
{
    Console.WriteLine($"Group {group.Key}");

    foreach (var value in group)
    {
        Console.WriteLine(value);
    }
}
```

**Output:**

```text
Processing 1
Processing 2
Processing 3
Processing 4
Group 1
10
30
Group 0
20
40
```

### Example 3: Materialize grouped results

```csharp
int[] numbers = { 1, 2, 3, 4 };

var groups = numbers
    .GroupBy(n => n % 2)
    .ToList();

Console.WriteLine(groups.Count);
```

**Output:**

```text
2
```

### Buffering characteristics

| Feature | GroupBy |
|---|---|
| Deferred execution | Yes |
| Source enumeration starts | When result is enumerated |
| Source consumed before first group | Yes, in LINQ to Objects |
| Stores grouped elements | Yes |
| Additional memory required | Generally \(O(n)\) |
| Repeated query enumeration | Rebuilds grouping |

**Key point:** `GroupBy()` is deferred but uses buffering when the grouping query executes.
