## 1. Count per Group

Counting per group determines how many elements belong to each group.

### Syntax

```csharp
source
    .GroupBy(x => x.Key)
    .Select(g => new
    {
        Key = g.Key,
        Count = g.Count()
    });
```

### Example 1: Count students by department

```csharp
record Student(string Name, string Department);

Student[] students =
{
    new("Amit", "IT"),
    new("Rahul", "HR"),
    new("Priya", "IT"),
    new("Sneha", "HR"),
    new("Rohan", "IT")
};

var result = students
    .GroupBy(s => s.Department)
    .Select(g => new
    {
        Department = g.Key,
        Count = g.Count()
    });

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Department}: {item.Count}"
    );
}
```

**Output:**

```text
IT: 3
HR: 2
```

### Example 2: Count even and odd numbers

```csharp
int[] numbers = { 1, 2, 3, 4, 5, 6, 7 };

var result = numbers
    .GroupBy(n => n % 2 == 0 ? "Even" : "Odd")
    .Select(g => new
    {
        Type = g.Key,
        Count = g.Count()
    });

foreach (var item in result)
{
    Console.WriteLine($"{item.Type}: {item.Count}");
}
```

**Output:**

```text
Odd: 4
Even: 3
```

**Key point:** `Count()` calculates the number of elements within each group.

## 6. Multiple Aggregates per Group

Multiple aggregation operators can be combined to produce a detailed summary of each group.

### Syntax

```csharp
source
    .GroupBy(x => x.Key)
    .Select(g => new
    {
        Key = g.Key,
        Count = g.Count(),
        Sum = g.Sum(x => x.Value),
        Average = g.Average(x => x.Value),
        Minimum = g.Min(x => x.Value),
        Maximum = g.Max(x => x.Value)
    });
```

### Example 1: Department salary report

```csharp
record Employee(string Department, int Salary);

Employee[] employees =
{
    new("IT", 50000),
    new("IT", 70000),
    new("HR", 40000),
    new("HR", 60000)
};

var report = employees
    .GroupBy(e => e.Department)
    .Select(g => new
    {
        Department = g.Key,
        Count = g.Count(),
        Total = g.Sum(e => e.Salary),
        Average = g.Average(e => e.Salary),
        Minimum = g.Min(e => e.Salary),
        Maximum = g.Max(e => e.Salary)
    });

foreach (var item in report)
{
    Console.WriteLine(
        $"{item.Department}: Count={item.Count}, " +
        $"Total={item.Total}, Average={item.Average}, " +
        $"Min={item.Minimum}, Max={item.Maximum}"
    );
}
```

**Output:**

```text
IT: Count=2, Total=120000, Average=60000, Min=50000, Max=70000
HR: Count=2, Total=100000, Average=50000, Min=40000, Max=60000
```

### Example 2: Sales summary

```csharp
record Sale(string Category, int Amount);

Sale[] sales =
{
    new("A", 100),
    new("A", 300),
    new("B", 200),
    new("B", 400)
};

    .GroupBy(s => s.Category)
    .Select(g => new
    {
        Category = g.Key,
        Count = g.Count(),
        Total = g.Sum(s => s.Amount),
        Average = g.Average(s => s.Amount)
    });

foreach (var item in report)
{
    Console.WriteLine(
        $"{item.Category}: {item.Count}, {item.Total}, {item.Average}"
    );
}
```

**Output:**

```text
A: 2, 400, 200
B: 2, 600, 300
```

**Key point:** Multiple aggregates allow a single grouped report to contain several statistics.

## 7. Filtering Groups

Filtering groups selects only groups that satisfy a condition.

### Syntax

```csharp
source
    .GroupBy(x => x.Key)
    .Where(g => condition);
```

### Example 1: Groups with at least two elements

```csharp
string[] words =
{
    "Apple",
    "Ant",
    "Avocado",
    "Banana",
    "Cherry"
};

var groups = words
    .GroupBy(w => w[0])
    .Where(g => g.Count() >= 2);

foreach (var group in groups)
{
    Console.WriteLine(
        $"{group.Key}: {group.Count()}"
    );
}
```

**Output:**

```text
A: 3
```

### Example 2: Filter by total sales

```csharp
record Sale(string Category, int Amount);

Sale[] sales =
{
    new("A", 100),
    new("A", 300),
    new("B", 100),
    new("B", 150)

    .GroupBy(s => s.Category)
    .Select(g => new
    {
        Category = g.Key,

    Console.WriteLine(
```

**Output:**


## 8. Duplicate Detection

Duplicate detection identifies values that occur more than once in a sequence.

### Syntax

```csharp
source
    .GroupBy(x => x)
    .Where(g => g.Count() > 1);
```

### Example 1: Duplicate integers

```csharp
int[] numbers = { 1, 2, 2, 3, 3, 3, 4 };

var duplicates = numbers
    .GroupBy(n => n)
    .Where(g => g.Count() > 1)
    .Select(g => new
    {
        Value = g.Key,
        Count = g.Count()
    });

foreach (var item in duplicates)
{
    Console.WriteLine(
        $"{item.Value}: {item.Count}"
    );
}
```

**Output:**

```text
2: 2
3: 3
```

### Example 2: Duplicate strings

```csharp
string[] names =
{
    "Amit",
    "Rahul",
    "Amit",
    "Priya",
    "Rahul"
};

var duplicates = names
    .GroupBy(n => n)
    .Where(g => g.Count() > 1);

foreach (var group in duplicates)
{
    Console.WriteLine(
        $"{group.Key}: {group.Count()}"
    );
}
```

**Output:**

```text
Amit: 2
Rahul: 2
```

### Example 3: Case-insensitive duplicates

```csharp
string[] names =
{
    "Amit",
    "amit",
    "Rahul",
    "RAHUL"
};

var duplicates = names
    .GroupBy(n => n, StringComparer.OrdinalIgnoreCase)
    .Where(g => g.Count() > 1);

{
    Console.WriteLine(
        $"{group.Key}: {group.Count()}"
    );
}
```

**Output:**

```text
Amit: 2
Rahul: 2
```

**Key point:** Grouping equal values and checking `Count() > 1` identifies duplicates.

## 10. Top Element per Group

Top-element retrieval selects the highest-ranked element from each group.

### Syntax

```csharp
source

    .Select(g => g.OrderByDescending(x => x.Value).First());
```

### Example 1: Highest marks per department

```csharp

    string Name,
    string Department,
    int Marks
);

    new("Rahul", "HR", 70),
    new("Sneha", "HR", 90)

var result = students
    .GroupBy(s => s.Department)
    .Select(g => g
        .OrderByDescending(s => s.Marks)
        .First());

foreach (var student in result)
{
    Console.WriteLine(
        $"{student.Department}: {student.Name} - {student.Marks}"
    );
}
```

**Output:**

```text

HR: Sneha - 90
```

### Example 2: Highest-priced product per category

## 11. Top N Elements per Group

Top-N retrieval selects a specified number of highest-ranked elements from each group.

### Syntax

```csharp
source
    .GroupBy(x => x.Key)
    .Select(g => new
    {
        Key = g.Key,
        TopItems = g
            .OrderByDescending(x => x.Value)
            .Take(n)
    });
```

### Example 1: Top two students per department

```csharp
record Student(
    string Name,
    string Department,
    int Marks
);

Student[] students =
{
    new("Amit", "IT", 80),
    new("Priya", "IT", 95),
    new("Rohan", "IT", 90),
    new("Rahul", "HR", 70),
    new("Sneha", "HR", 90),
    new("Ankit", "HR", 85)
};

var result = students
    .GroupBy(s => s.Department)
    .Select(g => new
    {
        Department = g.Key,
        TopStudents = g
            .OrderByDescending(s => s.Marks)
            .Take(2)
    });

foreach (var group in result)
{
    Console.WriteLine(group.Department);

    foreach (var student in group.TopStudents)
    {
        Console.WriteLine(
            $"{student.Name}: {student.Marks}"
        );
    }
}
```

**Output:**

```text
IT
Priya: 95
Rohan: 90
HR
Sneha: 90
Ankit: 85
```

### Example 2: Top two sales amounts

```csharp
record Sale(string Category, int Amount);

Sale[] sales =
{
    new("A", 100),
    new("A", 300),
    new("A", 200),
    new("B", 500),
    new("B", 400)
};

var result = sales
    .GroupBy(s => s.Category)
    .Select(g => new
    {
        Category = g.Key,
        TopSales = g
            .OrderByDescending(s => s.Amount)
            .Take(2)
    });

foreach (var group in result)
{
    Console.WriteLine(
        $"{group.Category}: " +
        string.Join(", ", group.TopSales.Select(s => s.Amount))
    );
}
```

**Output:**

```text
A: 300, 200
B: 500, 400
```

**Key point:** `OrderByDescending()` followed by `Take(n)` retrieves the top N elements within each group.

## 12. Nested Reports

Nested reports organize grouped information into multiple hierarchical levels.

### Example 1: Department and city report

```csharp
record Employee(
    string Name,
    string Department,
    string City
);

Employee[] employees =
{
    new("Amit", "IT", "Kolkata"),
    new("Priya", "IT", "Kolkata"),
    new("Rahul", "IT", "Delhi"),
    new("Sneha", "HR", "Delhi")
};

var report = employees
    .GroupBy(e => e.Department)
    .Select(department => new
    {
        Department = department.Key,
        Cities = department
            .GroupBy(e => e.City)
            .Select(city => new
            {
                City = city.Key,
                Count = city.Count()
            })
    });

foreach (var department in report)
{
    Console.WriteLine(department.Department);

    foreach (var city in department.Cities)
    {
        Console.WriteLine(
            $"  {city.City}: {city.Count}"
        );
    }
}
```

**Output:**

```text
IT
  Kolkata: 2
  Delhi: 1
HR
  Delhi: 1
```

### Example 2: Category and subcategory report

```csharp
record Product(
    string Category,
    string Subcategory,
    decimal Price
);

Product[] products =
{
    new("Electronics", "Computer", 5000m),
    new("Electronics", "Computer", 3000m),
    new("Electronics", "Mobile", 10000m),
    new("Furniture", "Chair", 2000m)
};

var report = products
    .GroupBy(p => p.Category)
    .Select(category => new
    {
        Category = category.Key,
        Subcategories = category
            .GroupBy(p => p.Subcategory)
            .Select(subcategory => new
            {
                Name = subcategory.Key,
                Total = subcategory.Sum(p => p.Price)
            })
    });

foreach (var category in report)
{
    Console.WriteLine(category.Category);

    foreach (var subcategory in category.Subcategories)
    {
        Console.WriteLine(
            $"  {subcategory.Name}: {subcategory.Total}"
        );
    }
}
```

**Output:**

```text
Electronics
  Computer: 8000
  Mobile: 10000
Furniture
  Chair: 2000
```

**Key point:** Nested grouping supports hierarchical reports containing multiple levels of summaries.

## 13. Date-Based Grouping

Date-based grouping organizes records using components of a date.

Common grouping keys include day, month, and year.

### Example 1: Group by full date

```csharp
record Sale(DateTime Date, int Amount);

Sale[] sales =
{
    new(new DateTime(2026, 1, 10), 100),
    new(new DateTime(2026, 1, 10), 200),
    new(new DateTime(2026, 1, 11), 300)
};

var result = sales
    .GroupBy(s => s.Date.Date)
    .Select(g => new
    {
        Date = g.Key,
        Total = g.Sum(s => s.Amount)
    });

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Date:yyyy-MM-dd}: {item.Total}"
    );
}
```

**Output:**

```text
2026-01-10: 300
2026-01-11: 300
```

### Example 2: Group by year and month

```csharp
var result = sales
    .GroupBy(s => new

        s.Date.Month
    })
    .Select(g => new
    {
        g.Key.Year,
        g.Key.Month,
        Total = g.Sum(s => s.Amount)
    });

foreach (var item in result)
{
    Console.WriteLine(
        $"{item.Year}-{item.Month:D2}: {item.Total}"
    );
}
```

**Output:**

```text
2026-01: 600
```

**Key point:** Date-based grouping uses date components as grouping keys.

## 20. Grouping Performance

Grouping performance depends on the number of elements, grouping keys, equality comparisons, and subsequent operations.

### 20.1 Basic GroupBy Performance

```csharp
int[] numbers = Enumerable.Range(1, 1000).ToArray();

var groups = numbers.GroupBy(n => n % 10);

Console.WriteLine(groups.Count());
```

**Output:**

```text
10
```

For LINQ to Objects, hash-based grouping typically requires:

- Average time complexity: \(O(n)\)
- Additional memory complexity: \(O(n)\)

These estimates assume efficient hashing and equality comparisons.

### 20.2 Grouping with Aggregation

```csharp
int[] numbers = Enumerable.Range(1, 100);

var report = numbers
    .GroupBy(n => n % 2 == 0 ? "Even" : "Odd")
    .Select(g => new
    {
        Key = g.Key,
        Count = g.Count(),
        Total = g.Sum()
    });

foreach (var item in report)
{
    Console.WriteLine(
        $"{item.Key}: Count={item.Count}, Total={item.Total}"
    );
}
```

**Output:**

```text
Odd: Count=50, Total=2500
Even: Count=50, Total=2550
```

### 20.3 Materializing Grouped Reports

```csharp
int[] numbers = { 1, 2, 3, 4, 5, 6 };

var report = numbers
    .GroupBy(n => n % 2)
    .Select(g => new
    {
        Key = g.Key,
        Count = g.Count()
    })
    .ToList();

Console.WriteLine(report.Count);
```

**Output:**

```text
2
```

`ToList()` executes the query and stores the resulting report.

### 20.4 Avoiding Repeated Grouping

```csharp
int[] numbers = Enumerable.Range(1, 100);

var report = numbers
    .GroupBy(n => n % 10)
    .Select(g => new
    {
        Key = g.Key,
        Count = g.Count(),
        Total = g.Sum()
    })
    .ToList();

foreach (var item in report)
{
    Console.WriteLine(
        $"{item.Key}: {item.Count}"
    );
}
```

**Output:**

```text
1: 10
2: 10
3: 10
4: 10
5: 10
6: 10
7: 10
8: 10
9: 10
0: 10
```

Materializing a report avoids rebuilding the grouping query during later enumerations.

### 20.5 Grouping Performance Comparison

| Operation | Typical Complexity |
|---|---|
| `GroupBy()` | \(O(n)\) average |
| `Count()` per group | \(O(m)\) |
| `Sum()` per group | \(O(m)\) |
| `Average()` per group | \(O(m)\) |
| `Min()` per group | \(O(m)\) |
| `Max()` per group | \(O(m)\) |
| Sorting a group | \(O(m \log m)\) |
| `ToList()` materialization | \(O(n)\) over the produced results |

Here, \(n\) is the number of source elements and \(m\) is the number of elements in an individual group.

**Key point:** Grouping is generally efficient for reporting, but repeated enumeration, sorting, and materialization can affect execution time and memory usage.
