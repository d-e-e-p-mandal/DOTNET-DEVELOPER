# 1. Introduction to XML

## What is XML?
- **XML (eXtensible Markup Language)** is a markup language used to **store**, **transport**, and **exchange** structured data.
- Unlike HTML, XML does **not** define how data should be displayed.
- Instead, XML focuses on storing data in a structured format.

**XML is:**
- Human-readable
- Machine-readable
- Platform-independent
- Language-independent
- Self-descriptive

---

## Why XML?
- Suppose we have employee information.

**Without XML:**
```
Employee 101
Deep
IT
50000
```
- We don't know which value represents what.

**Using XML:**
```xml
<Employee>
    <Id>101</Id>
    <Name>Deep</Name>
    <Department>IT</Department>
    <Salary>50000</Salary>
</Employee>
```
- Now every value has a meaningful tag.

# XML Syntax Rules
- Every XML document must follow these rules.

---

## Rule 1
- Only one root element.

**Correct:**
```xml
<Employees>
......
</Employees>
```

**Wrong**
```xml
<Employee>

</Employee>

<Customer>

</Customer>
```

---

## Rule 2
- Tags are case-sensitive.

**Correct:**
```xml
<Name>

</Name>
```

**Wrong:**
```xml
<name>

</Name>
```

---

## Rule 3
- Closing tag is mandatory.

**Correct:**
```xml
<Name>Deep</Name>
```

**Wrong:**
```xml
<Name>Deep
```

---

## Rule 4
- Attribute values must be inside quotes.

**Correct:**
```xml
<Employee Id="101">
```

**Wrong:**
```xml
<Employee Id=101>
```

---

## Rule 5
- Tags must be properly nested.

**Correct:**
```xml
<Employee>

    <Name>

    </Name>

</Employee>
```

**Wrong:**
```xml
<Employee>

<Name>

</Employee>

</Name>
```

# XML Components

**An XML document consists of:**
- Declaration
- Root Element
- Child Element
- Attribute
- Text
- Comment
- CDATA

---

## XML Declaration
- Usually appears at the beginning.

```xml
<?xml version="1.0" encoding="UTF-8"?>
```

### Meaning

| Part | Meaning |
|------|----------|
| version | XML Version |
| encoding | Character Encoding |

---

## Root Element
- Every XML document has exactly one root element.

**Example:**
```xml
<Employees>

</Employees>
```

---

## Child Element
- Elements inside another element.

```xml
<Employee>

    <Name>Deep</Name>

</Employee>
```

- Here, Employee is parent. Name is child.

---

## Attributes
- Attributes provide additional information.

```xml
<Employee Id="101">
```

- Id is an attribute. 101 is its value.

---

## Text Value
```xml
<Name>Deep Mandal</Name>
```

- Deep Mandal is text content.

---

## XML Comment
```xml
<!-- Employee Details -->
```

- Ignored by XML parser.

---

## CDATA Section

Used when data contains reserved characters.

```xml
<![CDATA[
if(a < b)
{
}
]]>
```

# Complete XML Example

```xml
<?xml version="1.0" encoding="UTF-8"?>

<Employees>

    <Employee Id="101">

        <Name>Deep Mandal</Name>

        <Department>IT</Department>

    </Employee>

    <Employee Id="102">

        <Name>Rahul</Name>

        <Department>HR</Department>

        <Salary>45000</Salary>

    </Employee>

</Employees>
```
