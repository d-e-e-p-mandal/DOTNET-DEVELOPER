## 2. System.IO Namespace

### System.IO

`System.IO` is the main namespace in .NET used for file and directory operations.

**Namespace:**

```cs
using System.IO;
```

**Purpose:**
- Create files
- Read files
- Write files
- Delete files
- Create directories
- Manage paths
- Access drive information

Common Classes:

```text
File
FileInfo
Directory
DirectoryInfo
Path
DriveInfo
StreamReader
StreamWriter
FileStream
```

### File vs FileInfo

| File | FileInfo |
|--------|--------|
| Static Class | Object Class |
| Simple Operations | Detailed Operations |
| No Object Required | Object Required |
| Faster For Small Tasks | Better For Repeated Tasks |

---

### Directory vs DirectoryInfo

| Directory | DirectoryInfo |
|------------|------------|
| Static Class | Object Class |
| Simple Folder Operations | Detailed Folder Information |
| No Object Required | Object Required |
| Quick Operations | Advanced Operations |
