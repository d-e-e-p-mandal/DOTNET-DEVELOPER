### Namespace :
- It is logical container (repository/folder)
- It does not take physical space.
- using System means that we can use classes from the System namespace.

Example-1: 
folderName :
```cs
using System;

namespace FolderName{
    class Program {
        public static void Main(string[] args) {

        }
    }
}
```
Example-2 : Nested Folder :
```cs
namespace FolderName.NestedFolderName {
    
}
```
