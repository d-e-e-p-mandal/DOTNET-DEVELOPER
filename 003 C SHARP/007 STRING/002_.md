# Text Handling Classes in C#

## 1. String (System.String)

- Immutable (cannot be modified)
- Most commonly used
- Best for normal text

```csharp
string name = "Hello";
```

---

## 2. StringBuilder (System.Text.StringBuilder)

- Mutable (can be modified)
- Fast for repeated string operations
- Best for loops and large text

```csharp
StringBuilder sb = new StringBuilder();

sb.Append("Hello");
sb.Append(" World");
```

---

## 3. ReadOnlySpan<char>

- High-performance read-only view of characters
- Does not allocate new memory
- Mainly used in performance-critical applications

```csharp
ReadOnlySpan<char> span = "Hello";
```

---

## 4. Span<char>

- Mutable view of character data
- Very fast
- Cannot be stored on the heap

```csharp
Span<char> chars = stackalloc char[5];
```

---

## 5. Memory<char>

- Heap version of Span
- Can be stored and passed around

```csharp
Memory<char> memory = new char[10];
```

---

## 6. ReadOnlyMemory<char>

- Read-only version of Memory

```csharp
ReadOnlyMemory<char> memory = "Hello".AsMemory();
```

---

## 7. Regex (System.Text.RegularExpressions.Regex)

Used for pattern matching and validation.

```csharp
Regex.IsMatch("abc123", @"\d+");
```

---

## 8. StringReader

Reads a string like a text file.

```csharp
StringReader reader = new StringReader("Hello");
```

---

## 9. StringWriter

Writes text into a string.

```csharp
StringWriter writer = new StringWriter();
writer.Write("Hello");
```

---

## 10. TextReader

Base class for reading text.

```csharp
TextReader reader = Console.In;
```

---

## 11. TextWriter

Base class for writing text.

```csharp
TextWriter writer = Console.Out;
```

---
